# M16 《墨子·小取》“七事”解释竞争与术语映射防固化 v0.1

## 1. 研究目标

M15 解决一段文本支持某项主张的范围问题。M16 进一步处理“同一古典术语为什么会被不同研究者解释为不同推理操作”的问题。研究对象先限定为《墨子·小取》的“或、假、效、辟、侔、援、推”。

核心原则：原典文本、传统校注、近现代解释、当代研究必须分层；解释框架是竞争假设，不是古籍原文；不把任何一套现代逻辑标签固化成先秦作者的自觉分类。

## 2. 原典层：先记录文本，不先决定现代类别

《小取》自述辩论目标包括明是非、明同异、察名实、处利害、决嫌疑，并提出“以名举实，以辞抒意，以说出故，以类取，以类予”。随后分别界定“效、辟、侔、援、推”，又以“其然也同，其所以然不必同”“其取之也同，其所以取之不必同”限制从相似处直接推广的做法，最后警告相关论辩形式可能转而危险、远离根据，必须审慎且不可常用。

《小取》传本和校注存在字形、断句、脱文补校等差异。例如“辟/譬”“举也物/举他物”、“其然也同”是否为旧本脱文，以及“危/诡”等，必须把数字录文、具体版本与校勘者补字分开记录。中国哲学书电子化计划页面列有《正统道藏》《墨子闲诂》《四部丛刊初编》等版本入口，但“页面列有版本”不等于项目已完成逐字影印互校。

## 3. 解释史中的竞争框架

### H1：逻辑方法分类（胡适，民国时期）

胡适《墨辩新诂·小取篇》将“效”解释为演绎论证，将“辟”解释为以他物说明此物，将“侔”解释为比辞，将“援”解释为援例/个体到个体，将“推”解释为归纳/由已取个体推至未取同类。该解释便于与现代逻辑学对照，但其分类本身属于近现代解释史，不是原典术语的唯一固有含义。

### H2：辩论过程中的“七事”（唐君毅）

唐君毅反对简单把七事理解为七种并列逻辑规则，提出它们可放在人际论辩和行动过程内理解，可能共同组成一个整体辩论历程。该解释改变了分析单位：从孤立推理形式转向论辩实践及其阶段关系。

### H3：统一类比论证理论的组成部分（周博群，2024）

周博群《再论〈墨子·小取〉篇的“辩学七事”》提出不同于通行观点的新解，借助马伯乐与唐君毅的研究，把七事理解为统一类比论证理论的组成部分，而非七种相互独立的推理类型。这是当代学术解释，需与原典、胡适和唐君毅观点分别登记。

### H4：语言形式、修辞与论辩实践取向

部分研究者对把七事全部逻辑化提出质疑，强调《小取》中的语言形式、修辞功能和辩论实践。该方向不应被简单归入“非逻辑”，而应继续区分说明、举例、平行表达、援引对方承诺、类推扩展等具体语用功能。

## 4. 关键发现：同一个“推”不能被提前锁定

“推”在原文中有自己的定义，但胡适把它解释为归纳；其他现代研究则可能把“推类”放入类比推理理论；更广的研究还讨论古代推类实践可能包含不同逻辑性质。由此，工程系统必须同时保存：

- 原典术语与原文定义；
- 解释者、著作、年代和学术背景；
- 解释者所采用的分析单位（单个推理式、论辩动作、完整过程或类比理论组成部分）；
- 现代映射标签及其适用范围；
- 支持证据、反例、异文、校注依赖和不确定性。

不能因为一篇研究把“推”映射为 induction，就在所有案例中自动把“推”编码为归纳；也不能因另一篇研究把七事视为统一类比理论，就抹去“效”在文本中的标准/法式功能。

## 5. M16 原型契约

原型文件：prototype/yixiang_interpretation_competition.py

- 每个解释位置必须包含解释者、著作、年代、解释层、分析框架、目标术语、解释陈述、适用范围、原典依据、研究文献依据和保留意见。
- 每项解释必须链接到声明的原典文本引用，避免二手研究脱离原典自我循环。
- 汇总只报告“无已登记解释 / 单一解释 / 同一框架下多个解释 / 多框架竞争”。
- 共享文本依据只报告引用重叠，不推断解释者独立性。
- 不计算哪一解释“胜出”，不自动判断训诂正误，不建立古典术语与现代逻辑类别的一对一映射。
- winner_position_id 固定为 null，interpretive_truth_established 与 independence_established 固定为 false。

## 6. 对项目架构的影响

1. M14 负责文本见证的来源依赖；M15 负责片段与原子主张的覆盖范围；M16 负责解释史中的竞争解释及其框架差异。
2. 未来类象系统输出“推类”结论时，必须声明采用哪一种解释框架，不得隐藏框架选择。
3. 评估集应按解释框架分层，避免训练标签把某一现代解释当作唯一古典真值。
4. 如果不同框架对同一段原文给出不同结构，系统应保留多种解释，并把分歧转成待核验问题，而不是投票生成伪共识。

## 7. 测试

11 项测试覆盖胡适/唐君毅框架竞争、2024 年统一类比框架、同框架多解释、无登记解释、原典锚点门禁、重复 ID、保留意见、共享文本依据不等于独立、不同见证引用、年代类型校验和不自动选胜者。
