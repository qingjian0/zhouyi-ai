# M42：类象因果机制的模型失配与潜在混杂稳健性审计 v0.1

## 目标

M40/M41 的决策依赖先验、似然、测量和因果结构假设。M42 不把这些假设视为天然正确，而是要求在登记的压力情景中检查策略价值是否崩溃。

## 压力维度

- 先验偏移；
- 结果似然偏移；
- 测量协议/测量误差偏移；
- 潜在混杂处理状态：已处理、敏感性有界、未建模、未知；
- 情景校准声明与来源证据。

以名义策略价值和所有压力情景价值的最小值作为 worst-case proxy。超出预设偏移界限或混杂未解决时，结果降为 REVIEW_REQUIRED；最差值低于任务阈值时标记 FRAGILE。

## 古典约束

《墨子·小取》“其然也同，其所以然不必同”提醒：一个机制模型下成立的解释不能自动推广到竞争机制或改变后的条件。M42 将其落实为模型竞争和反事实压力情景审计；这不是古代已有现代敏感性分析。

## 现代依据

Pearl/Bareinboim 的 transportability 与 selection diagrams 强调不同环境中哪些机制发生变化；现代分布偏移研究区分协变量偏移、标签偏移与条件机制变化。自适应实验推断研究（Cook et al., 2024）进一步说明分配策略与停止机制会影响有效推断。

## 限制

本模块不发现潜在混杂、不估计敏感性参数、不验证压力情景是否覆盖真实世界，也不校准概率。ROBUST_WITHIN_DECLARED_SET 只表示在登记情景集合内未跌破阈值，不代表普遍稳健或因果识别成功。
