# E12-A18：分叉、汇合与状态转移结构发现

日期：2026-11-11  
状态：研究原型，等待完整 CI 与后续配对基准

## 研究问题

A17 能发现线性有向路径，但许多系统关系并非单链：一个条件可能同时激活多个过程（分叉），多个证据可能汇入一个决策（汇合），边还可能携带状态转移标签。

## 本阶段实现

- FORK：同一中心节点向两个不同类型/关系目标发出边。
- JOIN：两个不同类型/关系来源汇入同一中心节点。
- 边签名包含关系名、相邻节点类型、可选 transition 标签。
- 由观测图自动枚举二臂结构，不预设固定 ontology。
- 通过训练集条件 outcome 分布计算 log-likelihood gain，扣除近似结构复杂度。
- validation 独立检查泛化收益。
- 候选预算、最小支持度、复杂度预算限制搜索。
- motif ID 使用 canonical JSON 与 SHA-256；结果保存数据集摘要、split IDs、grammar version。

## 易学结构如何进入实验

阴阳二态、四象四态、八卦状态、六十四卦变化、太玄三分可以被编译为不同的候选状态空间或转移模板。例如，二态语法限制状态数为 2，四象语法允许 4 个离散状态，太玄三分允许 3 值状态编码。

但这只是候选语法，不是对世界的先验真理。必须和无语义通用语法、随机语法、打乱标签语法进行同预算比较；并做语法消融、标签置换、节点重命名、关系反转和 OOD 组合测试。任何传统语法只有在锁定测试上稳定提高指标才算有用。

## 重要限制

- FORK/JOIN 目前仅支持两个臂，不支持任意 DAG、多层汇合、超图或递归结构。
- transition 是观测标签，不代表真实状态变化的因果机制。
- 只做预测性关联发现，不识别因果效应。
- split 按 observation ID 排序，正式评估需预注册 split manifest。
- 复杂度码长为近似值；多候选比较尚未校正多重检验。
- 反复调参可能污染 validation；正式结论必须使用 locked test。
- 本阶段不触碰 A7 epistemic status，也不产生 evaluator receipts。

## 验收

专项测试覆盖 fork、join、方向保持、状态转移标签、无信息结构拒绝、候选预算确定性、非法端点、重复 ID 和复杂度预算。

CI 成功只代表软件契约与合成测试通过，不代表在真实任务中优于 Transformer、A16 或 A17。
