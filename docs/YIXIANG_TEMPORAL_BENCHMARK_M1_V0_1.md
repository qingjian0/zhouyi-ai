# M1 合成时间基准 v0.1

## 目的

为多尺度时间表示建立可复现的最小实验输入。生成器把潜在过程真值与采样观测分离，避免把采样稀疏误认为过程阶段变化。

实现：`prototype/yixiang_temporal_benchmark.py`。

## 生成机制

- 潜在过程由有序阶段组成，默认三个阶段：emergence、transition、stabilization。
- 阶段边界由 phase_lengths 决定；阶段长度可以不相等。
- 同一潜在过程可用不同 sample_interval 采样。
- 每条观测包含快变量、慢变量和延迟响应变量。
- missing_indices 只删除观测，不修改潜在阶段和真值。
- 事件顺序指标使用共享事件 ID 的成对顺序准确率。

## 测试

新增 `tests/test_yixiang_temporal_benchmark.py`，覆盖：
1. 不同采样率保留相同潜在阶段；
2. 缺失观测不改变潜在真值；
3. 不等长阶段；
4. 非法阶段长度拒绝；
5. 缺失索引校验；
6. 成对事件顺序准确率；
7. 重复事件 ID 拒绝；\n8. 非有限时间参数与越界缺失索引拒绝；\n9. 延迟响应按配置滞后触发。

## 当前边界与下一步

这是确定性合成数据生成器和指标基线，不包含阶段检测器、学习算法、跨域泛化结论或真实世界有效性证明。当前 phase_label 是生成器提供的真值，只能用于评估，不可作为模型输入后再宣称识别成功。

下一步应实现至少三类阶段边界预测基线（固定窗口、基于信号变化的简单检测、层级/多尺度候选），在相同数据切分、参数预算和观测输入下比较边界 F1、事件顺序、缺失鲁棒性、跨采样率迁移及计算成本。应另设隐藏真值的评测接口，防止标签泄漏。
