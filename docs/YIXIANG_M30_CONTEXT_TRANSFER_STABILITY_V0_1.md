# M30：跨情境迁移与类象认知稳定性 v0.1

## 1. 研究问题
类象在情境变化后，哪些性质保持、弱化、反转或失效？外观相似、属性相似、结构同构、功能等价、形成机制相同和系统行为相似必须分别提出主张、分别取证。M30 不把稳定性压缩成单一相似度分数，也不把局部维度的保持外推到更高层级。

## 2. 古典材料：先秦两汉为主
### 《淮南子·说林训》
本篇以“类不可必推”限制推类。相邻论例包括蚕、蝉、蜉蝣对食物的不同反应；“人食礜石而死，蚕食之而不饥”；“鱼食巴菽而死，鼠食之而肥”；“瓦以火成，不可以得火；竹以水生，不可以得水”；六尺之席横卧可越、竖植则难越，所谓“势施异也”；以及钓、罧、罩、罣等不同操作而同得鱼的例子。
这些材料提示：主体/生理条件不同可改变作用结果；产物来源不代表生成条件可逆继承；姿态/施势与形态交互改变任务难度；手段不同可以同果，但同果不代表同机制。迁移必须记录主体、任务、环境、姿态/施势和目标。数字见证：https://zh.wikisource.org/zh-hans/淮南子/说林训；另参识典古籍《说林训》转录。数字转录不等同校勘定本。

### 《荀子·正名》
“物有同状而异所者，有异状而同所者”；“状变而实无别而为异者，谓之化”。应区分可观察形状、对象所处/所属与对象连续性。不能仅凭形状一致断定对象/类别相同，也不能因形态变化就断定实体连续性中断。原文：https://zh.wikisource.org/zh-hans/荀子/正名篇。

### 《墨子·小取》
“其然也同，其所以然不必同”以及“远而失，流而离本”，限制由结果相似向原因/机制迁移。辟、侔、援、推的推论需要审查同异点与适用范围。胡适《小取》篇新诂属于现代解释史材料，“果同因异”等说法可作现代分析线索，不应反向当作先秦原文术语。原文：https://zh.wikisource.org/zh-hans/墨子/小取；校释：https://zh.wikisource.org/wiki/《墨子·小取》篇新诂。

### 《周易·系辞下》
“刚柔相推，变在其中”；“变通者，趣时者也”；“近取诸身，远取诸物，以类万物之情”。可用于研究取象、变与时，但不能直接证明现代机器学习中的不变性、域泛化或因果机制迁移。孔颖达《周易正义》属于后世疏解，应与传文分层。传文：https://zh.wikisource.org/zh-hans/易传/系辞下；正义：https://zh.wikisource.org/zh-hans/周易正义/08.2。

## 3. 六类稳定性
- morphology：外形/表面形态保持；
- attribute：明确测量的属性保持；
- structural_relation：部件、角色与关系保持；
- function：在明确任务和评价标准下功能保持；
- mechanism：产生结果的机制保持；
- system_behavior：系统级输入—状态—输出规律保持。
六类稳定性不构成自动蕴含链：形态稳定不推出属性稳定；结构关系稳定不推出功能稳定；功能相同不推出机制相同；局部机制相同也不必推出整体行为相同。

## 4. 迁移权限与门禁
TransferKind 分为 feature、relation、function、mechanism、system。每条权限绑定源/目标情境、迁移类型、证据基础、限制条件、反例和人工审定理由。feature 需要形态或属性证据；relation 需要结构关系证据；function 需要任务相关功能证据；mechanism 必须有机制层证据；system 必须有系统行为层证据。有反例的迁移不能无条件 ALLOW；应进入 CONDITIONAL、REVIEW 或 BLOCK。同一情境不是跨情境迁移。门槛是保守的声明审计，不代表证据字段存在就证明迁移成立。

## 5. 实验设计
比较 feature similarity、pure classification、structural-relation baseline 与待测类象迁移方法。记录算法/模型版本、训练数据、参数与计算预算、任务、迁移维度、源/目标情境、指标、结果和局限。训练/测试按对象、来源家族或情境家族分组；同一对象近重复样本及同一情境家族不得跨 split。
对抗样例包括：表面相似而机制不同；表面不同而机制相似；功能相同而实现不同；局部关系相同而整体行为不同；同一对象在环境/主体/任务改变后出现保持、弱化、反转、失效。指标按维度报告，不用综合相似度掩盖失败。统计结果应说明样本规模、分组、置信区间与重复实验。没有结果记录不得声称实证稳定。

## 6. 原型边界
prototype/yixiang_context_transfer_m30.py 提供情境、情境对、证据基础、稳定性评估、迁移权限、变化剖面与实验评估契约。审计器检查端点、证据上下文、证据基础、人工审定、反例、分组泄漏、基线与结果引用。原型不自动理解自然语言情境、不发现不变量、不估计语义相似度、不证明因果/机制同一，也不自动判定迁移真值。M29 不确定性状态与 M27 统一图目前没有端到端自动适配；本模块不宣称全链路集成。
