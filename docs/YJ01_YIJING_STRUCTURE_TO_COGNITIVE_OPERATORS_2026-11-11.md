# YJ-01：易学结构到可学习认知算子的形式化规范

日期：2026-11-11  
状态：研究规格；不是传统理论的科学验证，也不是已训练模型或性能结论。  
上游：N0.7 PR #178（认知算子代数与 SROK）  
目标：为 ZNCA / TRLW / SROK 提供可审计的易学结构算子契约，避免把术语标签直接当作计算机制。

## 0. 核心结论

易学理论不能被压成一个统一的「五行 embedding」或「六十四卦分类器」。不同理论单元表达的是不同种类的结构约束：

- 阴阳：互补、对待、消长及条件性转化；
- 五行：多关系、有方向、受条件调制的作用网络；
- 卦、爻与爻位：有序位置、角色、层级和组合状态；
- 卦变：在特定规则和条件下发生的局部/整体状态转换；
- 时位：状态解释依赖阶段、位置、环境与观察时点；
- 象数理：表征、结构量化、关系解释之间的相互约束；
- 取象比类：跨域结构映射，同时保留差异和适用边界。

这些内容不能共享一个无差别的「关系边」实现。统一的是算子接口、证据契约、组合规则和验证协议；不统一的是每个理论家族的语义和变换机制。

**工程原则：统一接口，不抹平语义；把传统解释转成候选结构先验，不把它们写成不可质疑的世界定律。**

## 1. 理论来源与证据分层

实现前必须为每个候选机制标注其知识状态：

| 层级 | 含义 | 系统处理 |
|---|---|---|
| T0 文本/传统陈述 | 可定位到典籍、注疏或明确流派 | 记录出处、版本、解释者，不自动视为事实 |
| T1 形式结构 | 可被形式化的对待、位置、组合、变化关系 | 可作为结构假设进入原型 |
| T2 经验假设 | 声称该结构有助于某类现实任务 | 必须预注册任务、指标和对照 |
| T3 实证支持 | 在独立数据和重复实验中通过检验 | 仅在验证范围内提升权重 |
| TX 未验证/不可操作断言 | 无可观测变量、无可证伪预测或超自然断言 | 不进入预测内核；可作为文化文本研究对象 |

不同易学流派对卦象、爻变、五行配属、时位和象数关系存在差异。系统必须保存来源和解释谱系，不允许把某一解释伪装成唯一传统定义。

## 2. 统一工作状态与算子契约

在 N0.7 的 TRLW 工作空间上增加显式上下文与结构约束视图：

`W=(V,H,R,X,Z,Ctx,Tm,Evd,U,B,Σ,ν)`

- `V`：类型化对象；
- `H`：关系超边；
- `R`：角色与位置绑定；
- `X`：离散结构状态；
- `Z`：连续表示；
- `Ctx`：领域、环境、条件与任务上下文；
- `Tm`：事件时间、有效时间、阶段/周期；
- `Evd`：证据、出处、解释谱系；
- `U`：不确定性、冲突与未知；
- `B`：并行候选分支；
- `Σ`：类型与算子 schema；
- `ν`：版本。

每个易学结构算子都必须实现统一契约：

`O=(family, signature, parameters, pre, transform, post, invariants, evidence_policy, context_scope, cost, failure_modes, version)`

执行结果不是一个裸分数，而是：

`Result = (candidate_deltas, applicability, constraint_report, evidence_trace, uncertainty, cost, status)`

允许状态至少包括 `APPLIED`、`NOT_APPLICABLE`、`NEED_CONTEXT`、`NEED_EVIDENCE`、`CONFLICT`、`BUDGET_EXHAUSTED`。算子不适用时必须显式拒绝，不能靠相似度强行执行。

算子组合 `O₂ ∘ O₁` 仅当 O₁ 的输出类型、后置条件、时间/作用域和证据要求满足 O₂ 的前置条件时成立。组合必须保留原始证据链与每一步 delta。

## 3. 阴阳：互补状态与条件性转化算子（YY）

### 3.1 不采用的简化

不把阴阳等同于善恶、男女、正负电荷，也不把所有对象硬分为两个互斥类别。二元标签本身不能表达互根、消长、相待和转化。

### 3.2 可计算候选

定义带语义轴的双端关系：

`DualAxis(a, b | domain, context, time, evidence)`

一个对象在某个明确维度上可有状态 `s∈[0,1]`，但这个数值只表示该任务定义的轴向程度，不表示宇宙普遍阴阳比例。双端关系允许：
- 对待：同一语义轴上两个端点的差异；
- 互补：两个状态共同满足一个功能/约束；
- 消长：状态随时间的相对变化；
- 转化：在显式阈值、事件或上下文条件下改变主导端。

建议原子算子：
- `YY_AXIS_BIND`：将对象映射到指定领域轴，必须给出轴定义；
- `YY_COMPLEMENT`：检测两个状态是否构成互补，而非简单相反；
- `YY_BALANCE_UPDATE`：在给定目标/约束下更新相对状态；
- `YY_POLARITY_TRANSITION`：在触发条件和证据存在时生成状态转换候选。

不变量：轴定义在一次比较内固定；不同领域的轴不能未经映射直接比较；互补不等于相等；相反不自动意味着互补。

### 3.3 可证伪任务

构造含有互补、竞争、独立和伪二分的合成机制。比较：
1. 无双端结构；
2. 普通二分类；
3. 通用互补关系；
4. 易学启发的双端候选先验；
5. 随机/反向双端先验。

主要指标：样本效率、OOD 条件变化准确率、伪二分误判率、状态转移校准和拒答质量。

## 4. 五行：条件化有向作用网络（WX）

### 4.1 不采用的简化

五行不是五个无语义 token，也不是五种已证实的自然基本力。相生、相克、乘、侮不可压缩成单一正负权重。

### 4.2 结构表示

定义五个相位/角色槽位 `P={p₁,…,p₅}`，以及条件化有向作用张量：

`A[i,j | c,t,d]`

其中 c 为条件，t 为时间/阶段，d 为任务领域。作用类型至少区分：
- `PROMOTE`：促进/资助/生成候选关系；
- `RESTRAIN`：制约/抑制候选关系；
- `OVER_RESTRAIN`：在指定失衡条件下的过度制约候选；
- `REVERSE_RESTRAINT`：在指定条件下的反向制约候选；
- `UNKNOWN`：资料不足或该映射不适用。

相生与相克应作为不同的关系子图或关系类型处理；乘侮是条件化失衡模式，不是普通边的强度调大/调小。具体方向与含义必须绑定所采用的经典文本/流派解释版本。

作用可写为：

`m[j] = Σᵢ g(typeᵢⱼ, c, t, zᵢ, zⱼ; θ) · zᵢ`

但 `g` 不能只返回一个固定正负值；它可以输出作用类型、幅度、适用区间及不确定性。学习得到的矩阵不自动获得「五行」语义，必须通过有来源的槽位映射和对照实验建立语义对应。

### 4.3 必需约束

- 保留有向性，不假定 `A[i,j]=A[j,i]`；
- 作用类型与强度分离；
- 条件、时位和领域是显式输入；
- 环路反馈不能自动解释为传统生克循环；
- 乘侮必须有独立触发条件和失衡证据；
- 缺失边是 UNKNOWN，不是零作用；
- 不同传统配属表必须版本化。

### 4.4 实验

比较通用有向网络、普通正负图、固定五行拓扑、可学习条件化五行候选拓扑、随机拓扑和拓扑扰乱。测试机制 OOD、条件反转、失衡识别、反事实干预和负迁移。

## 5. 卦与爻位：有序角色结构（YAO）

卦不能只作为类别 ID；爻位也不能作为普通位置 embedding。它们至少包含有序槽位、上下关系、角色约束和整体组合。

对于六爻结构，表示为有序槽位：
`H=(l₁,l₂,l₃,l₄,l₅,l₆)`
每个槽位记录：
`Line=(polarity, position, role, relation_context, source, interpretation_version)`

其中 polarity 仅表示所采用体系中的阴/阳爻形态；position 是结构位置；role 是解释上下文赋予的角色；relation_context 是与其他爻/卦体的关系。不得假定六个槽位的语义在所有卦、所有流派中恒定。

算子：
- `YAO_BIND_POSITION`：把爻绑定到有序位置；
- `YAO_ROLE_CHECK`：检查角色、位置与上下文的适配候选；
- `YAO_RELATION_QUERY`：查询相邻、对应、承乘比应等指定关系（每种关系须独立定义）；
- `YAO_REORDER_VIEW`：改变观察视角/序列视图，同时保留原始顺序和变换来源。

不变量：顺序不能在无显式变换时丢失；位置关系与实体属性分开；「得位/失位」是解释规则，不是直接的真值判定。

## 6. 卦变：受规则约束的离散状态转移（BIAN）

定义状态 `x_t`、变换规则 `r`、条件 `c_t` 和事件 `e_t`：

`x_{t+1}=T_r(x_t | c_t,e_t,interpretation_version)`

变换可涉及局部爻位变化、关系重组或整体视图改变。每次变换必须记录：
- 哪些槽位/关系发生变化；
- 哪些结构保持不变；
- 触发条件与时间；
- 使用的规则版本；
- 证据来源；
- 变换前后的可逆性/信息损失。

首个原型可实现受限的局部位翻转，但必须标为 `BIT_FLIP_BASELINE`，不能把它说成完整卦变理论。随后才研究多爻变化、互体/错综等视图算子，并分别定义语义。

停止条件：检测状态循环、规则冲突、无有效触发条件、预算耗尽。反事实推演必须复制分支 delta，不能覆盖真实观察状态。

## 7. 时位：时间与位置联合条件算子（SHIWEI）

同一关系在不同阶段、位置、环境和观察时间可能具有不同解释。定义：
`Context=(domain, phase, position, environment, valid_time, observed_time)`

算子 `SHIWEI_CONDITION` 将关系候选绑定到上下文，并输出适用范围。必须区分：
- 事件发生时间；
- 事实有效时间；
- 系统获知时间；
- 传统解释中的阶段/时令；
- 模型推断出的周期性。

周期不可由样本偶然相关直接推断为固定天时规律。时间窗、阶段边界、时区和历法换算必须显式指定。没有足够时间证据时输出 UNKNOWN。

## 8. 象数理：多视角互约束，而非三个流水线模块（XSL）

将象、数、理定义为三类相互校验的表征视图：
- 象：对象、属性、关系、形态与可观察结构；
- 数：数量、比例、序列、位置、组合和约束；
- 理：解释机制、关系规律、条件与适用边界。

三者不是固定的先后步骤。提出解释时，理必须能指出它依赖哪些象与数；新增观测可修正象；数量矛盾可否定某个理；一个理也可预测应进一步观察什么。

最小契约：
`XSL_CHECK(observation_view, quantitative_view, mechanism_hypothesis)`
返回互相支持项、冲突项、缺失项和可区分候选的下一项观测。

禁止把「理」当作不可检验的最终答案。多个解释并存时保留分支，不用单一综合分数抹去分歧。

## 9. 取象比类：部分结构映射（XIANG）

取象比类的计算核心不是表面相似，而是带约束的跨域结构映射。

给定源域关系结构 `G_s` 和目标域结构 `G_t`，学习部分映射：
`φ: V_s ⇀ V_t`

映射需分别检查：
- 类型兼容；
- 角色保持；
- 关键关系保持；
- 方向/极性保持；
- 条件和时间范围兼容；
- 结构差异与未映射节点；
- 反例和负迁移风险。

`XIANG_MAP` 输出必须包含映射覆盖率、结构保持率、冲突关系、未映射部分、目标域证据和适用边界。禁止仅凭词面/向量相似度判定类象成立。

类象是可撤回假设：目标域新证据可使映射降权、拆分或撤销。源域和目标域的实体身份、事实证据不能互相继承；只允许显式声明的结构假设迁移。

## 10. 统一算子注册表（第一版）

| Family | Operator | 输入重点 | 输出重点 | 关键失败 |
|---|---|---|---|---|
| YY | YY_AXIS_BIND | 对象、轴定义、领域 | 双端轴绑定 | 轴定义缺失 |
| YY | YY_COMPLEMENT | 双端状态、功能约束 | 互补候选 | 仅表面相反 |
| YY | YY_BALANCE_UPDATE | 当前状态、目标、反馈 | 状态 delta | 目标/反馈缺失 |
| WX | WX_INFLUENCE | 有向作用、条件、时位 | 作用候选与幅度 | 条件不兼容 |
| WX | WX_IMBALANCE | 作用网络、偏离、证据 | 失衡候选 | 把相关性当机制 |
| YAO | YAO_BIND_POSITION | 有序槽位、解释版本 | 角色位置绑定 | 顺序/版本缺失 |
| BIAN | BIAN_TRANSFORM | 当前结构、规则、触发条件 | 离散 delta | 无合法触发 |
| SHIWEI | SHIWEI_CONDITION | 关系、阶段、有效时间 | 条件化适用范围 | 时间语义不明 |
| XSL | XSL_CHECK | 象/数/理视图 | 支持/冲突/缺失 | 任一视图无来源 |
| XIANG | XIANG_MAP | 源/目标超图、映射约束 | 部分结构映射 | 结构保持失败 |

这只是第一版注册表。每个算子在进入训练前必须补齐机器可读 schema、单元测试、正例、反例、拒绝样例和版本化解释来源。

## 11. 组合机制：不能只按固定流水线运行

组合允许跳过中间元素，例如 A→C→E 的非相邻组合；但必须满足类型、角色、证据和上下文约束。

建议区分四种组合：
1. **串行组合**：前一算子输出满足后一算子输入；
2. **并行组合**：多个算子对同一状态提出独立候选；
3. **约束交汇**：象、数、理多个视图相互校验；
4. **分支对照**：保留互相竞争的解释并主动寻找区分性证据。

不允许无条件把 YY、WX、BIAN、XIANG 的输出相加。跨家族组合必须声明接口映射。例如五行关系候选经过类象映射到生物领域时，必须重新验证角色、作用方向和目标域证据。

## 12. 最小实验矩阵与消融

首批实验使用合成结构任务，避免直接用现实复杂数据把文化解释、标注偏差和算法收益混在一起。

| 条件 | 内容 | 要回答的问题 |
|---|---|---|
| A0 | 无结构先验 | 基线能做到什么 |
| A1 | 通用关系图/超图先验 | 显式关系本身的收益 |
| A2 | 通用双端/互补算子 | 阴阳结构是否有额外收益 |
| A3 | 通用有向条件网络 | 关系动力学本身的收益 |
| A4 | 五行候选拓扑与条件作用 | 五行结构是否有额外收益 |
| A5 | 位置/角色/时位先验 | 位置条件是否改善组合泛化 |
| A6 | 受限状态变化算子 | 卦变式结构是否改善动态推理 |
| A7 | 结构类比映射 | 类象是否改善跨域迁移 |
| A8 | 完整组合 | 家族交互是否有协同收益 |
| A9 | 随机/反向/错配先验 | 排除先验只是增加容量或正则化 |

必须同时报告参数量、训练 FLOPs、候选预算、检索预算和样本量。高阶算子实验必须保留严格 pairwise 对照；不能把高阶模型的收益归因于易学结构，除非在保留 pairwise 统计的扰动实验中仍然成立。

指标至少包括：
- 组合泛化与机制家族 OOD；
- 跨域结构保持率和负迁移率；
- 样本效率与计算成本；
- 条件变化/反事实准确率；
- 校准、拒答、UNKNOWN 识别；
- 证据覆盖和错误自信率；
- 多 seed 置信区间。

训练/评估必须遵守预序列协议：预测先封存，随后才揭示答案；训练器不能读取 evaluator 的隐藏标签或未来事件。

## 13. 实施顺序与合并门槛

阶段 J1：只完成算子 schema、解释来源登记、确定性参考实现和合成单元测试。  
阶段 J2：将 YY/WX/YAO/BIAN/SHIWEI/XSL/XIANG 分别接入 N0.7 operator registry，不改变现有 SROK 搜索内核。  
阶段 J3：接入 N0.10 可学习角色绑定/高阶评分，但先固定算子结构，只学习参数。  
阶段 J4：使用 E13 验证跨域映射和干预响应；使用 N2 归因协议验证高阶增益。  
阶段 J5：通过机制 OOD、反向先验、错误先验和独立 evaluator 后，才考虑进入稳定实现。

进入 main 的门槛：
- 每个算子有可执行实现和完整契约；
- 解释来源和版本可追溯；
- 正例、反例、缺证据和不适用测试齐全；
- 与通用关系基线和错误先验比较；
- 不存在未经授权的证据/状态覆盖；
- CI 通过且性能成本可复现；
- 不宣称未验证的传统/超自然断言为事实。

## 14. 当前明确不做的事

- 不建立一个以六十四卦 ID 为核心的分类模型；
- 不把五行简化成五个 token 或五维 one-hot 后宣称完成理论融合；
- 不把生克固定为普遍因果律；
- 不把所有卦变简化为任意 bit flip；
- 不用词面相似度替代类象结构映射；
- 不把传统解释直接注入系统提示词作为不可质疑规则；
- 不宣称这套结构已经优于 Transformer、GNN 或其他模型；
- 不在缺少实证时将文化解释、哲学命题和经验规律混为一谈。

## 15. 研究判断

最值得验证的不是「易学是否正确描述了所有自然现象」，而是：

**易学中关于互补关系、条件化作用、位置角色、状态转化、时位约束和取象比类的结构思想，能否被抽象为通用的、可学习的关系计算原语，并在严格对照下改善组合泛化、动态推理和跨领域迁移？**

如果实验显示某个算子家族没有稳定增益，就应缩小适用范围或删除；如果通用关系算子同样有效，就不能把收益归功于易学来源。理论融入必须接受这种结果。
