# M54：公平基线对照协议 v0.1

## 目标与边界

M54 将既有基线原语升级为可执行的统一比较入口。每个候选方法获得完全相同的训练观测、候选变量集合、目标变量、样本预算、干预预算与成本上限。验证集和测试集不会进入候选方法的输入；评估真值只在所有候选方法完成提案后用于评分。

当前交付是协议与适配器接口，不等于已经完成 PC/FCI、SCM、Transformer 或类象 Agent 的端到端实测，更不构成类象优越性证据。

## 已实现

- 随机基线：固定种子、候选变量均匀抽样。
- 相关筛选基线：只在训练观测上按绝对 Pearson 相关排序。
- 外部适配器接口：可接入 PC/FCI、SCM、Transformer、类象 Agent；适配器必须返回统一 BaselineProposal。
- 统一评分：Precision、Recall、F1、SHD、干预覆盖、预算利用率、预算违规、提案合法性、轨迹有效率与工具错误数。
- 数据隔离：候选方法只接收训练集；EvaluatorTruth 不在 AgentContext 内；验证/测试行不向候选方法暴露。
- 划分审计：训练、验证、测试 unit_id 必须互斥且完整覆盖数据集。
- 预算审计：超样本数、超干预数、超成本均被记录；禁止干预时提出干预会被标记为非法。

## 公平比较的操作定义

1. 固定数据生成机制、样本单位与随机种子。
2. 在运行任何方法前固定 train/validation/test unit_id。
3. 所有方法共享相同训练观测与候选变量全集。
4. 所有方法共享 max_samples、max_interventions、max_cost 与干预权限。
5. 测试集只供评估端使用；禁止基于测试结果调参。
6. Oracle 仅作为 evaluator-only 诊断上界，不计入参赛方法排名。
7. 外部模型必须登记模型/权重版本、提示词、解码参数、软件版本、硬件、运行成本和随机种子；无法做到等预算时，必须单列资源差异，不得声称严格公平。

## 当前不包含

- 不内置完整 PC/FCI、结构学习 SCM、Transformer 或 Zhouyi 类象 Agent 实现。
- 不自动估计统计显著性、置信区间或多重比较校正；这些属于 M55。
- 不将预测准确率等同于因果结构恢复能力。
- 不把合成 SCM 结果外推为真实世界普遍结论。

## 后续验收

M55 应基于该协议加入多种 SCM 家族、重复随机种子、配对效应量、置信区间、多重比较校正、校准与失败案例分析。M56 再接入古籍来源可追溯的类象知识，并设置知识增强/关闭的盲测消融。
