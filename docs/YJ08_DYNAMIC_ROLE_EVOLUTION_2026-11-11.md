# YJ-08：动态结构角色演化

日期：2026-11-11  
分支：`research/yj08-dynamic-role-evolution-2026-11-11`  
基础：YJ-07 PR #213 → YJ-06 PR #210

## 1. 研究问题

YJ-07 从单个关系状态中归纳结构角色。YJ-08 将问题扩展到有序 episode：结构角色在状态变化中保持、分裂、合并、转化、新生或消失。角色 ID 仍由 YJ-07 的结构指纹产生；跨时刻实体对应只用于建立 lineage，不参与角色指纹。

## 2. 事件语义

- `PERSIST`：旧、新角色结构指纹一致，且存在达到阈值的实体对应。
- `SPLIT`：一个旧角色通过可追踪实体对应到多个新角色。
- `MERGE`：多个旧角色通过可追踪实体对应到一个新角色。
- `TRANSFORM`：一对一对应存在，但结构角色指纹发生变化。
- `EMERGE`：新快照中的角色没有达到阈值的前驱对应。
- `DISSOLVE`：旧角色成员在下一快照全部缺席，且下一快照明确声明 closed-world/coverage_complete。

这些是结构事件候选，不是语义或因果结论。低于对应阈值的实体对应不强行分类。

## 3. 关键防误判机制

1. **身份与角色分离**：实体 ID 仅建立跨快照对应；YJ-07 WL 指纹不读取实体 ID 或人工 Node.role。
2. **缺失不等于消失**：非完整覆盖快照不能支持 DISSOLVE。
3. **环境变化不等于角色变化**：context_changed 独立记录，不自动触发 split/transform。
4. **阈值与预算**：min_shared_entities、min_confidence、max_events、max_rounds 限制推断。
5. **证据账本**：每个事件记录前后 evidence IDs、episode、step、domain、干预标签及支持实体。
6. **时间不污染身份**：step 不进入结构角色 hash；只用于事件顺序和 lineage。

## 4. v0.1 边界

- 依赖可追踪实体 ID；跨系统实体解析仍未解决。
- split/merge 是基于结构角色分组与实体重叠的有限启发式，不是完整的概率 lineage 模型。
- min_confidence 是透明阈值，不是校准概率。
- 干预标签被记录，但本原型不估计因果效应。
- 暂不学习角色 embedding、角色分布、动态超边或跨域角色迁移。
- 当前结构角色仍受 YJ-07 WL 表达能力限制。

## 5. 验证范围

测试覆盖稳定角色、拓扑变化候选、实体重命名不变性、不完整观测下禁止误报 dissolve、完整覆盖下 dissolve、context 独立标注、低重叠抑制、阈值、证据唯一性、时间顺序和事件预算。

通过单元测试只说明该确定性实现满足测试契约，不证明现实世界中的角色演化、语义理解或因果泛化。

## 6. YJ-08.1：滞回与持续性确认

在初版基础上增加事件状态：

- `CANDIDATE`：只在单个相邻状态转移中出现，暂不写入稳定角色谱系。
- `CONFIRMED`：同一 lineage 事件在连续转移中重复出现，达到 `min_consecutive_transitions`。
- `UNCERTAIN`：保留为扩展状态；当前版本不把不确定性伪装成概率。

`consecutive_support` 记录连续支持次数。它是证据计数，不是置信概率。短暂拓扑扰动因此保留为候选；稳定重复的角色变化才升级为确认事件。

`DISSOLVE` 单独处理：必须连续多个快照均声明完整覆盖，且旧角色支持实体持续缺席。仅有一个完整快照的缺席仍是候选，不能确认消亡。

## 7. 新增验证

新增测试覆盖：
- 单次 split 后立即恢复：split 仍为 candidate；
- 连续稳定角色：持续事件达到阈值后 confirmed；
- 连续完整覆盖的角色缺席：达到持续性阈值后 confirmed dissolve。

该机制仍是确定性滞回规则，不是统计校准的变化点检测器。后续需要用合成噪声轨迹、缺失机制与干预对照评估阈值敏感性。

## 8. 组合规划器集成修复

主干基础上的完整测试还暴露出一个既有组合规划器问题：深度优先搜索会把仍然可用但与目标无关的算子插入有效路径，导致本应返回 `A_TO_C → C_TO_E` 的用例得到包含 `B_UNUSED` 的非最短链。

已将规划策略改为有界广度优先搜索（BFS），使最先返回的可行路径具有最少算子数；算子仍按确定性名称顺序扩展，保留深度、状态和结果预算。该修复属于组合规划器集成质量修复，不代表算子语义执行或组合结果有效性已经得到证明。
