## 当前限制（重要）

1. 这只是数据生成基础设施，不是关系结构恢复算法。
2. 当前关系观测仍显式包含有序参与者列表，因此角色槽位可从观测直接读取；它不能用于证明系统自主发现角色语义。
3. 同一 episode 的关系符号在两个关系类型间复用，当前只是合成标识，不带语义。
4. 当前 split manifest 只校验对象 ID 和 episode ID，不检查属性组合、关系模板或组合结构 OOD。
5. 尚未执行 GitHub Actions；代码已从 GitHub 回读。开发环境中的等价逻辑测试通过 7 项，但这不是仓库 CI 结果，也不能替代对提交文件的正式测试。
6. 尚未实现基线、结构恢复指标、成本统计或 20/100 seed 确认实验。

## 必须先修正的设计缺口

在进入 E10-A 学习器前，下一版生成器必须引入“角色不可直接读取”的观测形式，并提供足够的结果/状态约束，让角色能从跨样本证据中被识别，而不是把有序参与者数组直接当作答案。建议新增：
- 无序 participant set 的表层观测；
- 独立于关系角色的结果变量；
- 可识别性检查：若多个潜在角色结构对全部观测等价，则标记该 episode 不可识别，不计入结构恢复成绩；
- 置换对象、属性和关系符号后的不变性测试。

## 下一步门槛

只有完成上述观测设计、可识别性测试和泄漏攻击，才开始实现关系骨架学习器。否则学习器只会读出生成器暴露的答案。
