# ZNCA N2：可学习关系动力学参考实验

日期：2026-11-11  
状态：可执行研究原型；不是通用模型，不是 Transformer 替代品的实证证明。

## 1. 研究问题

N1 已能保存关系和事件，但静态关系图本身不会推理。N2 检验：能否把有角色、有类型的关系项作为状态更新算子，并从状态转移样本中学习其影响强度？

本原型采用同步状态更新：
\[
z_j^{t+1}=\sigma\left(b_j+
\sum_{e\in E_j}s_e w_e\prod_{i\in S_e}z_i^t\right)
\]
其中：
- (z_i^t\in[0,1]) 是状态变量；
- (S_e\) 是一条关系项的来源槽位集合；
- (s_e\in\{-1,+1\}) 表示抑制/促进方向；
- (w_e\geq0\) 是可学习影响强度；
- (b_j\) 是目标状态偏置；
- (sigma\) 是 sigmoid。

这是一种稀疏、显式、关系条件化的动力学算子。它不依赖 Token 序列，也不使用 Q/K/V 或 KV Cache。

## 2. 当前实现

`prototype/znca_dynamics.py` 包含：
- `StateSnapshot`：有界状态快照；
- `SourceSlot`：带语义角色的输入状态槽；
- `InfluenceTerm`：二元或高阶联合关系项；
- `TransitionExample`：带证据引用的前态/后态样本；
- `RelationalDynamicsModel`：同步状态更新、迭代 rollout 和全批量 BCE 学习；
- `influence_term_from_relation`：将 N1 的带角色关系断言编译为 N2 动力学项，并保留来源证据引用；
- L1 正则入口，用于后续稀疏化实验。

`tests/test_znca_dynamics.py` 测试高阶 AND 联合激活、促进/抑制、并行影响、同步更新、输入校验和训练收敛。

## 3. N1 → N2 连接

N1 的 `Relation` 通过 `influence_term_from_relation` 编译为 N2 的 `InfluenceTerm`。调用方必须显式指定哪个关系角色是状态更新目标；其余角色成为输入槽位。关系方向、角色标签和 evidence_refs 会被保留。这个编译器不会自动推断促进/抑制极性，也不会把关系置信度直接当作校准概率；polarity 和初始 weight 仍由实验配置或学习过程决定。

## 4. 与现有 E02/E13 的边界

- E02 已研究超边候选、结构生命周期、候选预算与验证集门槛；N2 不重复实现 CREATE/MERGE/SPLIT/PRUNE。
- E13 已研究关系结构发现、类象迁移、主动验证闭环；N2 提供一个可执行的动力学算子，供 E13 将来验证迁移后的结构是否能预测状态变化。
- N2 当前假设候选关系项已给定；自动发现候选结构、选择关系项、证据门控与反事实结构修订仍未实现。

## 5. 重要限制

1. 这是低维连续状态上的参考学习器，不是自然语言模型。
2. 训练数据和候选关系项必须由外部提供；目前没有从原始文本/图像学习状态变量。
3. 全批量梯度下降只拟合训练样本；必须另设验证集和锁定测试集。
4. 来源槽位的角色标签提供了结构先验；不能把已知角色的合成任务表现当作自主关系发现。
5. 乘积交互对高阶联合条件敏感，但高阶项数量仍可能组合爆炸；必须做候选召回率、稀疏度、计算成本与负例审计。
6. sigmoid 状态是有界激活，不自动等于概率或经过校准的置信度。
7. 当前计算复杂度约为每次更新 (O(|E|\cdot r))，其中 (r) 是每个关系项的来源数；状态变量数大并不意味着查询/推理自动为常数时间。

## 6. 下一轮必须做的实验

- Pairwise-only vs Pairwise+Higher-order：参数量和训练预算匹配；
- 单一路径 vs 多路径证据汇聚；
- 有角色槽位 vs 角色打乱；
- 真实高阶项 vs 随机高阶项；
- L1 稀疏化前后性能/结构恢复；
- 训练分布内 vs 未见组合/更长 rollout；
- 动态规则切换后的适应速度与旧任务遗忘；
- 同等 CPU 时间、峰值内存下与 MLP、GNN/超图模型对照。

## 7. 证伪条件

若在锁定测试上，高阶项没有稳定超过参数量匹配的 pairwise 模型；角色标签打乱不影响结果；或者提升只来自更多参数/更多迭代，则不得宣称 N2 的关系动力学机制有效，应简化或放弃相应机制。

## 8. 研究背景

- EpiGNN：通过 epistemic inductive bias 改进系统性关系推理，并处理多路径证据聚合，ICLR 2025。
- NoRA：指出仅靠关系路径组合的基准与模型假设过窄，NeurIPS 2025 Datasets and Benchmarks。
- Hypergraph Dynamic System：将超图与可控连续动力学联系，ICLR 2024。
- IRED：通过能量扩散/迭代优化执行推理，ICML 2024。

本原型的价值是提供可复现实验起点，不是宣称超越这些研究。
