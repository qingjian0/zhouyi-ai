# XSL-4: 易象多视角假设与证据并存契约

日期：2026-11-11  
状态：研究原型 / Draft  
依赖：XSL-1 typed validator、XSL-2 candidate enumerator、XSL-3 explicit role transforms

## 1. 研究目标

XSL-4 不把一个卦象、爻象或类象概念压成唯一释义。它把不同解释视角建模为可并存、可追溯、可反驳的独立假设。

同一源概念到同一目标概念，可以同时存在：
- 自然形态 / 物象；
- 功能与作用；
- 性情 / 行为倾向；
- 角色与关系；
- 时空位置与过程阶段；
- 生态环境；
- 动物、器物、人体等具体象类；
- 由特定传统、注家或现代研究提出的其他视角。

这些视角是候选解释的组织维度，不是预先断言的本体分类，也不意味着所有流派必须共享同一分类。

## 2. 核心数据契约

每个 `AnalogyPerspective` 至少记录：
- `perspective_id`：稳定且唯一的候选标识；
- `source_concept` / `target_concept`：类比两端；
- `lens`：本次解释采用的视角；
- `tradition_or_source`：流派、文本、注家、研究或提出者；
- `applicability_conditions`：适用条件；
- `evidence`：带来源引用、范围说明、主张说明和极性的证据记录；
- `counterexample_notes`：已知或待检验反例；
- `limitations`：明确不能推出的结论；
- `provenance`：候选如何产生、由谁或何种流程提出。

视角标签必须可扩展。系统不得因一个视角未列入预设枚举而丢弃候选。

## 3. 证据极性与认知状态

证据极性：
- `SUPPORTS`：该证据在所声明范围内支持候选主张；
- `COUNTERS`：该证据在所声明范围内构成反证或冲突；
- `CONTEXT_ONLY`：提供来源、历史或语境信息，不直接支持主张；
- `UNKNOWN`：当前无法判断证据方向。

评估状态只描述证据记录的结构状态：
- `UNTESTED`：没有附加证据记录；
- `EVIDENCE_ATTACHED`：至少有证据记录，但未同时记录支持与反对；
- `CONTESTED`：同时存在支持与反对证据。

这些状态不是事实真值、概率或置信度。尤其 `EVIDENCE_ATTACHED` 不等于“已证实”；只包含 `CONTEXT_ONLY` 或 `UNKNOWN` 的候选也不能被提升为支持成立。

## 4. 多视角竞争规则

1. 同一概念对的不同视角必须并存，不得自动合并成一个“综合象”。
2. 不设置默认唯一赢家；本原型不做视角排序、加权平均或概率融合。
3. 视角冲突是需要保留的数据，不是需要清洗掉的噪声。
4. 适用条件不同的候选可以同时成立于不同范围；不能脱离范围做全局比较。
5. 反例必须可定位到候选与适用范围，不可只写“存在例外”。
6. XSL-3 的角色变换只能作为独立假设引用；不得将其变换结果覆盖源关系图。
7. XSL-1 的结构保持结果只能说明指定映射满足指定结构约束，不等于因果等价或经典解释正确。

## 5. 与 ZNCA 的职责边界

- 象：保留感知到的形态、功能、关系、时空和情境特征。
- 数：编码可计算的状态、位置、组合、变化和约束。
- 理：表达关系规则、因果候选与适用边界。
- 变：表达显式状态转换和角色变换候选。
- 类：产生并保存多视角类比假设（本 XSL-4 范围）。
- 择：在证据、任务目标、风险和成本约束下进行后续选择；不是本原型的职责。
- 言：将被选择的解释转为语言；不得反向改写证据状态。

XSL-4 不创建第二套记忆系统。候选与证据应通过既有事件溯源 / CSF 体系保存，并引用稳定来源标识。

## 6. 必须防止的错误

- 把象征相似当作实体相同；
- 把功能相似当作因果机制相同；
- 把同一视角下的结构映射扩张成跨视角普遍规律；
- 将未知证据当作支持；
- 因多数票或文本频率而删除少数反例；
- 把流派差异伪装成统一共识；
- 以单一分数掩盖证据冲突、适用范围和负迁移风险。

## 7. 验证与消融路线

原型测试覆盖：
- 同一概念对保留多个视角；
- 无证据候选保持 `UNTESTED`；
- 支持与反对证据并存时保持 `CONTESTED`；
- 语境证据不被计为支持；
- `UNKNOWN` 不升级为支持；
- 缺失适用条件或限制说明时拒绝记录；
- 重复候选 ID / 证据 ID 拒绝静默合并。

后续实验应比较：
1. 单一视角解释；
2. 多视角并存但不仲裁；
3. 多视角 + 明确适用条件；
4. 多视角 + 反例检索；
5. 多视角 + XSL-2/3 结构映射。

指标至少包含正迁移、负迁移、错误类比率、反例召回、范围违规、拒答校准、证据可追溯性与推理成本。不得仅用解释流畅度或类比匹配率评价。

## 8. 当前边界

这是一个可执行的数据契约原型，不是易学解释知识库，也不是自动读懂卦爻的模型。它没有证明某个视角优于其他视角，也没有训练出新的认知模型。它只先确保多种解释能被精确记录、比较、质疑和撤回。
