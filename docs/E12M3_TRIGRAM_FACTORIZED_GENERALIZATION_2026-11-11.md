# E12-M3 — Trigram-Factorized Relation Generalization

Date: 2026-11-11  
Status: finite symbolic benchmark prototype; CI validation pending.  
Research lineage: E12-M2 motif discovery and the repository's Yixiang encoding contract.

## 1. Research question

Does representing a six-line state as an ordered pair of three-bit trigram states provide a useful compositional inductive bias for discovering relations that generalize to unseen lower-trigram inputs?

This experiment isolates one narrow claim. It does **not** assume that traditional trigram names carry semantic labels, that every domain follows GF(2) algebra, or that the resulting rule is a universal Yijing law.

## 2. Representation

A trigram is represented as a three-bit vector:

- lower trigram: (x \in GF(2)^3);
- upper trigram: (y \in GF(2)^3);
- a six-line state is the ordered pair ((x,y)), equivalent to six bits.

The existing repository convention is阳爻 = 1, 阴爻 = 0, bottom-to-top bit order. This prototype uses integer state IDs 0–7 for each trigram and keeps semantic trigram names out of the learner.

The tested relation grammar is:

[
y = A x \oplus b
]

where (A) is an invertible 3×3 binary matrix and (b \in GF(2)^3). There are 168 invertible matrices and 8 offsets, giving 1,344 candidate rules. This is a generic finite algebraic grammar over three binary factors, not a claim that all transformations of hexagrams are affine.

## 3. Episode protocol and leakage boundary

Each episode contains eight possible lower-trigram states, partitioned into:

- Support: four affine-independent input states;
- Gate: two disjoint input states;
- Locked Test: the remaining two states.

Support and Gate are visible to the learner. Locked Test is not passed to the inference function and is used only by the evaluator after selection.

Candidate rules are enumerated from the fixed grammar, filtered by Support, and independently filtered by Gate. The learner must return:

- `IDENTIFIABLE_WITHIN_AFFINE_GF2` only for exactly one survivor;
- `AMBIGUOUS` for multiple survivors;
- `INCONSISTENT` for no survivors;
- `BUDGET_EXHAUSTED` if the declared candidate budget cannot cover the full 1,344-rule family.

A truncated prefix must never be used to claim uniqueness.

## 4. Controls

Three task families are paired by seed:

1. **Affine:** generated by a rule in the declared 1,344-rule grammar. This is the positive control.
2. **Nonlinear:** includes a bit interaction outside the affine grammar. This tests whether the learner abstains or makes unsupported extrapolations.
3. **Permuted code:** an affine latent rule is conjugated by a random permutation of the eight trigram IDs, with permutations that make the observed mapping non-affine. This is a structural-code negative control.

A capacity-heavier categorical lookup baseline memorizes visible lower→upper pairs and abstains on unseen lower states. It is not a matched neural baseline; it is a transparent no-generalization control.

## 5. Metrics

Report by task family:

- identification / ambiguity / inconsistency rates;
- mean surviving candidate count;
- factorized model coverage;
- selective accuracy on covered Test cases;
- strict accuracy, counting abstentions as incorrect;
- lookup coverage and strict accuracy;
- exact candidate evaluations (1,344 per complete search);
- pooled per-example coverage and accuracy, with 95% Wilson score intervals for coverage, selective accuracy, and strict accuracy.

Coverage and selective accuracy must be reported together. A model cannot appear accurate merely by abstaining on difficult cases.

## 6. Falsification and interpretation

The structural-bias hypothesis is weakened if the factorized grammar does not generalize on affine tasks, if the lookup baseline matches its strict performance, or if the learner confidently extrapolates on nonlinear/permuted controls. A useful result requires high affine Test accuracy **and** appropriately reduced coverage or confidence on out-of-grammar controls.

The positive control is intentionally generated from the tested grammar. Success establishes implementation correctness and a narrow inductive-bias capability, not superiority on natural data. The negative controls are finite synthetic families, not an exhaustive test of out-of-distribution robustness.

## 7. Run

The benchmark defaults to 100 paired seeds per task family (300 episodes, 600 locked-Test examples). Confidence intervals are Wilson score intervals over pooled Test examples; they are descriptive intervals for this finite synthetic generator, not evidence of external validity.

```bash
python -m unittest tests.test_e12m3_trigram_factorized_generalization -v
python -m prototype.e12m3_trigram_factorized_generalization --seeds 100 --json
```
