# M47：类象因果发现基准的对照方法与统一指标 v0.1

## 目标

在真实模型比较前，先固定可复现的评测接口、指标和低复杂度对照，避免只报告单一准确率或为自研系统挑选有利指标。

## 指标

- 直接父节点 Precision / Recall / F1。
- Structural Hamming Distance（本原型针对目标节点父集，按 FP+FN 计算）。
- 干预覆盖率：真实直接父节点中被实际干预的比例。
- 预算利用率、预算违规。
- 证据不足时提前提交结论的比例。
- 轨迹有效率与工具错误数。

## 对照方法

- seeded random intervention；
- observational correlation screening（明确标记为关联启发式，不是因果发现）；
- evaluator-only oracle upper bound（仅用于检查指标上限，绝不提供给被测 agent）。

## 古典约束

《墨子·小取》“其然也同，其所以然不必同”要求比较时不能把相关性表现当作机制发现；“殊类异故，则不可偏观也”提醒需要多类任务和多种评价维度，不能只挑有利案例。

## 现代依据

Causal-Discovery-Bench 以实验轨迹、资源预算和多族指标诊断实验设计失败；ACED-Bench 以证据账本分解证据获取与证据保留问题。M47 将这些评价思想转为本项目可执行的统一接口，不复刻论文指标全集。

## 限制

相关性基线不具因果识别能力；oracle 仅是评估器上界；当前只评价单目标直接父集，不评价完整 DAG、效应估计、校准、跨域泛化或语言解释质量。
