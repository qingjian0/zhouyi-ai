# 《墨子·小取》类象论辩操作矩阵 v0.2

## 研究问题

《小取》不是把一切“像”归为同一种推理。它至少要求区分：建立比较对象、检查范例标准、平行化表达、援引共同承诺、从已认可者扩展到未认可者，以及检验推类是否越界。本文件把这些层次拆开，供 Zhouyi-AI 的语料标注与推理审计使用。

本文件是工作性分析，不把现代逻辑术语冒充先秦原词的唯一含义。篇章层次、字词异文、句读和传本关系仍需底本校勘。

## 一、先把七个术语分层

《小取》常见文本列出“或、假、效、辟、侔、援、推”等术语。七者不是七种完全平行的“类比算法”；更适合先按论证功能分组：

| 术语 | 最小工作释义 | 在推理流程中的角色 | 关键审查 |
|---|---|---|---|
| 或 | 提出某种可能情形/存在项 | 设定候选与例外 | 是否把可能误作事实？ |
| 假 | 假设、设例或借设情境 | 构造待检验场景 | 假设前提是否明示？ |
| 效 | 取法、效验或以标准核验 | 范例/标准对照 | 标准本身是否可靠、适用？ |
| 辟（譬） | 举他物以明此物 | 说明、类比、示例 | 只借哪一方面？ |
| 侔 | 比辞而俱行 | 语言结构平行 | 语法平行是否保留语义条件？ |
| 援 | 援引对方已承认的命题 | 对话承诺一致性 | 对方是否真承诺，情形是否同条件？ |
| 推 | 由已取之同推及未取之同 | 扩展既有判断 | 相关之同是否足以支持新结论？ |

这里的“七术”是分类框架，不意味着文本中每个术语都在所有篇章语境下具有唯一稳定定义。现代研究对《小取》七术之间的关系仍有不同解释：有研究把它们看成统一类比论证理论的组成部分，也有研究强调它们在论辩实践中的不同功能。Zhouyi-AI 应保留多种解释，不以单一学说锁死标注。

## 二、四种常被混称为“类比”的推理，必须分开

### 1. 辟：说明性映照，不自动授权推论

原文工作定义：“辟也者，举他物而以明之也。”

- 输入：目标对象 T、说明对象 S、被选定的比较维度 d。
- 输出：帮助理解 T 的说明映照。
- 必须记录：比较维度、映照目的、源域/目标域差异。
- 禁止推断：S 与 T 的全部属性相同；S 的因果机制必然适用于 T。

辟可以只承担“让某个关系变得可理解”的修辞/解释作用。只有另有论证前提时，才可进一步成为事实推论。

### 2. 侔：语言形式平行，不等于事实关系平行

原文工作定义：“侔也者，比辞而俱行也。”

- 输入：表达式 A、表达式 B、平行结构映射。
- 检查：主谓角色、量词范围、否定范围、条件从句、时态/情态、语义角色是否一致。
- 失败模式：句式平行但谓词含义不同；省略条件不对称；量词/否定作用域不同；一边是规范命题另一边是事实命题。

侔的核心风险是“形式相似造成的假对称”。不能只比较字面模板，也不能仅凭两句长度、词序相近判定可推。

### 3. 援：对话承诺的对称适用

原文工作定义：“援也者，曰子然，我奚独不可以然也？”

- 输入：对方已接受的命题 P、当前争议命题 Q、两者适用条件。
- 检查：P 是否确由对方承认；P 与 Q 是否在相关方面同类；差异是否构成正当区分。
- 失败模式：误报对方承诺；把对方在特定条件下的让步扩大为普遍原则；忽略身份、权限、时位、因果条件差异。

援首先是一种论辩策略。其有效性既涉及逻辑，也涉及对话记录与承诺归属。系统应把“对方承诺证据”作为独立证据类型。

### 4. 推：从已取之同扩展到未取之同

原文工作定义：“推也者，以其所不取之同于其所取者，予之也。”

- 输入：已接受案例 A、待扩展案例 B、共同属性/关系 R、拟扩展结论 C。
- 检查：A 与 B 的“同”是否与 C 相关；反例是否显示共享属性并不稳定蕴含 C；适用范围是否相同。
- 失败模式：共享偶然属性；关键因果条件不同；把局部同类扩张为全域同类；由结果相同推机制相同。

推是四者中最直接承担结论扩展责任的操作，因此应要求最严格的证据门禁。

## 三、《小取》的反推类规则：四条不可省略

1. “物有以同而不率遂同”：局部相同不推出整体相同。每次迁移必须标注同在何维度。
2. “其然也同，其所以然不必同”：现象或结果相同不推出成因相同。因果边必须另有证据。
3. “言多方，殊类异故，则不可偏观也”：不同论证路径、类别和理由不能只取一面；应显式记录竞争解释。
4. “以类取，以类予”必须结合上下文的“故”“名”“实”“辞”“说”理解：类不是脱离论证目的的纯相似标签。

## 四、工程数据模型：将论辩操作从关系类型中拆出

每条推理记录新增/明确以下字段（本文件先定义标注协议，不声称现有数据已全部具备）：

| 字段 | 类型 | 含义 |
|---|---|---|
| operation_kind | enum | PI / MOU / YUAN / TUI / XIAO / JIA / HUO |
| source_claim_id | string | 源论证/已接受命题 |
| target_claim_id | string | 待说明或待扩展命题 |
| dialogue_commitment_ref | string[] | 援所依赖的对话承诺证据 |
| parallel_form_map | object | 侔的句法/语义角色映射 |
| comparison_dimension | string[] | 辟/推的明确比较维度 |
| transferred_predicate | string | 真正被迁移的谓词或关系 |
| excluded_features | string[] | 明确不迁移的属性 |
| scope_conditions | string[] | 适用范围 |
| counterexample_refs | string[] | 反例证据 |
| causal_claim | boolean | 是否主张因果 |
| causal_evidence_refs | string[] | 因果证据引用 |

核心设计：operation_kind 是论证操作，relation_family 是被讨论的关系类型，evidence_kind 是支持证据的种类。三者不得混成一个字段。

## 五、可执行裁决规则

- 辟：若无比较维度，允许作为待解释的修辞候选，不允许作为事实推论。
- 侔：若关键语义角色、量词、否定或条件不对称，拒绝由句式平行推出结论。
- 援：若缺少对方承诺的可追溯证据，暂缓；若原承诺带有限定条件而新命题删除限定，拒绝扩张。
- 推：若共同点与目标谓词无关，拒绝；若相关性、条件或反例未核查，暂缓；只有关系保持、证据独立且范围明确时，才可在范围内接受。
- 所有操作：若原典字句未校勘，保留“文本候选”状态；不能因论证形式分析通过而升级文献可信等级。

## 六、与 Zhouyi-AI 现有模块的接口

- M2/M2.1：把“角色/关系结构映射”作为约束，不将论辩术语直接编码成实体关系。
- M3：将辟、侔、援、推产生的不同候选论证作为竞争解释，逐条保留支持与反驳。
- M4：干预比较维度或范围条件，观察结论是否改变；不把模拟反事实当作真实观察。
- M5：优先选择能区分竞争推理路径的观测；援需要核对对话承诺，侔需要核对句法语义，推需要找关键反例。
- M6：重复出现的残差只能提出新类别候选，不能自动创造古典术语或自动接受新规律。
- M7：编排时保留 operation_kind、evidence lineage 和 abstention 原因。

## 七、原典与研究入口

- 《墨子·小取》原文检索入口：https://ctext.org/mozi/xiao-qu/zh
- 《墨子·经说上/下》与《经上/下》应并读，避免只用《小取》定义反推全部墨家术语。
- Zhou Boqun, “The ‘Seven Dialectical Terms’ in the ‘Minor Choice’ 小取 Chapter of the Mozi 墨子,” *Bulletin of the Jao Tsung-I Academy of Sinology*, issue 11. 该研究主张把七术理解为统一类比论证理论的组成部分；本项目把它登记为一种现代解释，而非定论。
- “Logic and Language in Early Chinese Philosophy,” Stanford Encyclopedia of Philosophy：https://plato.stanford.edu/entries/chinese-logic-language/。用于比较名实、推类、侔等研究解释；不替代原典。
- Zhang Jialong and Fenrong Liu, “Mohist Logic,” 2007：https://eprints.illc.uva.nl/id/eprint/259/1/PP-2007-25.text.pdf。用于检验侔等结构的形式分析可能性。

## 八、下一步校勘优先序

1. 逐条收集《小取》七术原文、上下文、历代注释及不同数字见证。
2. 与《经上》《经说上》《经下》《经说下》《大取》逐条对照，标记术语是否同义、异义或仅部分重叠。
3. 为辟、侔、援、推各建立正例、反例、边界例；不能只拿一个例子定义整个操作。
4. 对“其然也同，其所以然不必同”等关键句建立异文对照表，未决时允许多个文本分支。
5. 只有完成原典与底本校核后，才把案例从数字转录候选升级到已核文本层。
