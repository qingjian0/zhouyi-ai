# 传统类象古籍语料库 v0.1

## 目标

清代以前文献为主体；清代及以后只作为查缺、校勘、版本辨析和学术争议补充。不是“全部古籍全文库”，也不把数字文本自动视为可靠底本。

## 文献层级

### 先秦
《周易》经传、《尚书》《诗经》《左传》《国语》《礼记》《周礼》；《荀子》《老子》《庄子》《墨子》《孟子》《韩非子》《吕氏春秋》。研究观象、取象、比类、名实、譬喻、物类、礼制与自然/社会关系。

### 秦汉
《淮南子》《春秋繁露》《史记》《汉书》《说文解字》《白虎通义》《论衡》《新语》《潜夫论》。区分宇宙论类比、感应论、名物训诂、政治譬喻与经验观察，不将其统称为一种理论。

### 魏晋至隋唐
王弼、韩康伯、虞翻易学材料、陆德明《经典释文》、孔颖达《周易正义》、李鼎祚《周易集解》及类书。研究注释传统、象义、爻位、关系和变化。

### 宋元
程颐、朱熹、邵雍、张载、蔡元定、胡瑗、张栻、俞琰等。研究观物、象数、格物、卦变、图书之学及相互批评。

### 明代至清以前
来知德、黄宗羲、王夫之、方以智、胡渭等。研究互体、错综、卦变、象数辨伪、名物考证及对前代易说的批判。

清代材料单列为补充层，不能反向覆盖早期文本。

## 类象标签轴

多标签而非唯一分类：形态/结构、属性、功能、关系、过程、时空、势态、名物、语言推类、象数结构。它们是项目检索标签，不宣称古人使用同一分类体系。

## 数据门禁

1. 原文、注疏、目录著录、现代研究、观察、假设、合成样本和模型生成内容分型保存。
2. 每条记录必须提供作品、时代判断、数字见证、精确篇章定位、文本状态和主张级审核状态。
3. OCR 未校核不得标为 verified；数字平台转录不等于古籍底本。
4. 作者、年代、传承、异文有争议时并列记录。
5. 注家解释不能冒充原文；模型生成不能自证为已审核。
6. 按作品、版本、篇章和解释模板分组划分训练/验证/测试，防止同源泄漏。
7. 仅保留必要短引，现代整理本和数据库许可单独核验。

## 新增先秦核心样本与理论含义

本版语料已纳入墨家、荀子与《吕氏春秋》材料：

- 《墨子·小取》“以类取，以类予”：推类方法的文本证据。
- 《墨子·小取》“其然也同，其所以然不必同”：明确区分现象相同与所以然相同，是防止错误因果类推的关键约束。
- 《墨子·小取》“则不可不审也，不可常用也”：要求对类推的适用范围和失效边界进行审查。
- 《荀子·正名》“凡同类同情者，其天官之意物也同”：将同类判断联系到感官条件与对象辨识。
- 《荀子·正名》“辨异而不过，推类而不悖”：把辨异与推类并列为受约束的认知活动。
- 《吕氏春秋·应同》“类固相召，气同则合，声比则应”：作为战国末期类应/感应论述保存，不作为现代自然因果事实。
- 《庄子·齐物论》相关比喻与视角转换材料：用于研究类象视角依赖和类别边界，不直接转成事实分类规则。
- 《荀子·解蔽》相关材料：用于研究心知、蔽塞、辨异和多重认知条件。
- 《淮南子·天文训》以飞行/蛰伏为分类依据的毛羽、介鳞材料，以及“物类相动，本标相应”的类应命题：区分经验性分类与宇宙论对应。
- 《周易·说卦传》“雷以动之，风以散之，雨以润之，日以烜之”：补充象—功能/过程关系，不将卦象缩成名物词典。
- 《管子·版法解》“法天地之位，象四时之行”：补充自然秩序向政治制度的规范性类比，明确与经验因果分层。

截至本次增补，语料文件包含 36 条候选记录、38 条文本主张，其中 17 条记录至少一条主张标注 reasoning_operations（以 JSON 数据文件的实际统计为准）。新增记录仍是候选短引与文本观察，不表示已完成底本校勘或学术审核。

### 关键理论结论（项目研究假设）

传统类象至少包含两类知识：

1. **正向方法论**：如何从已知之物选择可比对象、形成推类、辨认关系。
2. **负向约束/反类推理论**：相似处不保证原因相同；类推可能转移失当、远而失、流而离本，必须审察其边界。

因此，类象计算引擎不能只最大化相似度或关系匹配率，还必须学习哪些相同特征足以支持类比、哪些差异会破坏类比、现象相同但机制不同的反例，以及何时应拒绝推论或降低适用范围。


## M4 语料字段增补

机器可读 Schema 已增加可选主张字段：`xiang_domain`、`relation_family`、`shared_basis`、`non_shared_basis`、`scope_conditions`、`causal_status`。其中 relation_family 用于区分生成、分类、功能、方向、时序、感应、符号、规范类比、因果主张、修辞类比和词汇关系；causal_status 明确区分文本声称与独立观察/实验支持。验证器同步校验这些字段，防止随意创建未定义类型。

已有字段继续承担来源层和反例追溯：顶层 `source_type`、主张级 `claim_kind`、`counterevidence` 与 `variant_notes`。上述标签均为项目检索和工程治理约定，不应误称为古人共同使用的统一分类体系。

## 墨家类推结构的进一步增补

当前结构化语料另增两条先秦候选记录：

- 《墨子·大取》列举“重同、具同、连同、同类之同、同名之同、丘同、附同、是之同、然之同、同根之同”，提示“同”存在多种根据；个别术语释义仍待校勘。
- 《墨经·经说上》“二必异”“不连属”“不同所”“不有同，不类”等条目，提示数目、连属、处所与类同需要分层辨析。

本轮语料现为 36 条候选记录、38 条文本主张。相关专题分析见 `docs/CLASSICAL_YIXIANG_MOZI_DAQU_MOJING_ANALYSIS_V0_1.md`；《小取》论辩操作与“其然/所以然”边界分析见 `docs/CLASSICAL_YIXIANG_MOZI_XIAOQU_ANALYSIS_V0_1.md`。清代校释仅作为校勘史证据，不替代先秦文本见证。

## M5 主动观测接入

M5 原型从竞争假设的先验与候选观察的预测似然计算期望信息增益，并独立记录成本、风险、可行性和选择偏差。它只对非干预性观察排序；预测似然不是观察证据。详见 `docs/YIXIANG_ACTIVE_OBSERVATION_M5_V0_1.md`。


## M6 与类象语料的接口边界

M6 不直接把古籍句子或关键词聚类为新象。古籍主张必须先完成来源、篇章定位、文本状态、关系类型和解释层标注；只有经审查的结构化观察/残差才能进入 M6。清代及以后材料可作为校勘与补漏证据，但不得仅凭后世注释生成先秦新象。M6 当前原型见 `docs/YIXIANG_NOVELTY_DISCOVERY_M6_V0_1.md`。
