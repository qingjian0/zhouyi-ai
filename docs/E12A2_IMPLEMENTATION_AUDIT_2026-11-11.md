# E12-A2 实现审查与下一轮验证计划

日期：2026-11-11  
状态：[审查/设计]；本文件不报告新的实验结果  
目标分支：research/e12a2-selector-prototype-2026-11-11

## 1. 审查对象

静态检查对象为 E12-A1/E12-A2 联合研究分支中的：

- prototype/e12a2_active_measurement.py
- docs/E12A2_ACTIVE_MEASUREMENT_SELECTION.md
- docs/E12A1_TYPED_PREDICATE_INDUCTION.md

该实现是有限假设集合上的主动测量选择器，不是完整自主实验系统，也不是因果发现系统。

## 2. 已实现的计算机制

- Shannon entropy，以 bit 为单位；
- 对每个候选假设提供测量结果似然；
- 计算期望后验熵与 expected information gain；
- 按 IG / (cost + epsilon) 选择动作；
- 预算不满足时返回 BUDGET_EXHAUSTED；
- 所有可选动作均无信息增益时返回 NO_DISCRIMINATING_ACTION；
- 确定性 tie-break：先成本、后规范 action ID；
- 观测揭示后执行 Bayes 更新；
- 所有候选均给观测零似然时返回 INCONSISTENT；
- 选择器接口不接收 evaluator truth。

## 3. 静态审查发现

### 正向发现

1. 信息增益计算使用候选先验与动作条件似然，数学定义与协议一致。
2. 预算筛选发生在动作评分之前。
3. 无信息动作不会被强制选出。
4. 不可能观测不会被静默解释为新候选。
5. 候选 ID、动作 ID、概率和成本具有基本校验。
6. 选择结果具有确定性排序规则。

### 尚未解决的问题

1. 缺少独立、完整的 E12-A2 单元测试文件与可复核 CI 结果。
2. 似然分布由调用方提供，当前没有检验其校准程度。
3. 先验概率可能错误，尚未完成误导性先验与过度自信实验。
4. epsilon 与 tie_tolerance 需要预注册并进行敏感性分析。
5. 当前动作是有限候选下的被动测量，不支持真正改变环境的干预。
6. 没有环境进程与学习器进程的强隔离实现。
7. 尚未与随机测量、固定顺序、最大分歧和精确最优策略完成同预算比较。
8. 尚未提供多世界、多种子、逐 episode 的完整结果记录。

## 4. E12-A2-M 最小验收实验

固定两种候选机制，并建立以下动作：

- 无区分动作：所有候选预测一致；
- 均分动作：候选预测被均匀分割；
- 不均分动作：候选预测产生不均衡分割；
- 高成本区分动作：信息增益较高但成本也较高；
- 低成本弱区分动作：信息增益较低但单位成本效用可能更高。

必须覆盖：

- 等概率先验下均分动作的信息增益；
- 零信息动作不被选择；
- 成本变化会改变最优动作；
- 相同效用按确定性规则打破平局；
- 预算耗尽；
- 非法概率分布；
- 观测结果的后验更新；
- 所有候选零似然时拒绝；
- oracle 真值变化而 learner 输入不变时，选择结果不变；
- 输入排列变化不改变结果。

## 5. 对照实验

在相同测量预算和计算预算下比较：

A. Random action  
B. Fixed action order  
C. Maximum raw disagreement  
D. Expected information gain  
E. Cost-normalized expected information gain  
F. Exact optimal action（仅作小规模上界）  
G. Oracle action（仅作诊断上界，不属于学习器）

主要指标：

- 每个 episode 的实际熵下降；
- 唯一识别所需测量次数；
- 总测量成本；
- 可辨识任务识别率；
- 不可辨识任务歧义保持率；
- 错误自信率；
- 对精确最优策略的 regret；
- 计算操作数与候选规模。

至少先运行 5 个独立世界种子验证协议，再扩展至 20 个以上种子。所有区间按独立 world/episode 聚类。

## 6. 易象先验接入门槛

A2-M 的通用信息增益控制器通过测试之前，不接入易象先验。

通过后再比较：

- 无先验；
- 通用二元互补先验；
- 四状态分区先验；
- 八卦式分层因子先验；
- 容量匹配的随机置换先验；
- 可学习结构先验。

每组保持候选容量、测量预算、计算预算和数据生成器一致。先验必须允许被拒绝。

## 7. 下一步顺序

1. 为 E12-A2-M 增加独立单元测试与边界测试。
2. 加入随机/固定/最大分歧基线。
3. 构造可辨识与不可辨识配对世界。
4. 加入多种子逐 episode JSONL 与汇总报告。
5. 建立 evaluator 与 learner 的进程隔离协议。
6. 验证通用测量策略后，再开展易象先验消融。
7. A2-M 通过后才进入 A2-I 因果干预实验。

## 8. 结论

E12-A2 的数学选择器已经具备可审计的最小计算核心，但“实现了信息增益函数”不等于“证明主动观测有效”。当前最重要的工作是补齐独立测试、对照实验、概率校准、过程隔离和多世界评估。

在这些门槛完成前，不宣称 E12 已具备自主实验发现、因果发现或通用原语归纳能力。
