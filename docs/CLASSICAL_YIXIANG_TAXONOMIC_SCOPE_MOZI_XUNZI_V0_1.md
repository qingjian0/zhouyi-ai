# 《墨经》名类层级与《荀子·正名》共名/别名：推类层级门禁 v0.1

## 研究问题

类象系统必须回答两个不同问题：

1. 对象属于什么类别？这是名类、分类层级与成员资格问题。
2. 某个属性或谓词能否从一个类别迁移到另一个类别？这是推类范围问题。

如果把这两者合成一个相似度分数，就容易出现“上位类的某个成员有此属性，因此整个上位类都有此属性”的错误。

## 原典依据

### 《墨经·经下》“推类之难”

《经下》以“推类之难”提示总名、散名与大小层级之间的推类限制。传世录文与《墨子闲诂》对此句存在异文、断句与解释分歧，尤其“四足兽”“牛马”“物尽异”等字句不可未经校勘拼成定本。孙诒让《墨子闲诂》相关解释将其理解为总名与种别名之间的大小关系；吴毓江校注本另有对“牛马异”等字句的校订讨论。项目应保留底本文字、校改、注家解释三个层次。

### 《墨子·经上》“达、类、私”

《经上》“名，达、类、私”及《经说上》相关释例，可作为广名、类名、私名的层级入口。它提醒系统区分：
- 广泛统摄多个类别的共名；
- 对一类对象适用的类名；
- 指向特定个体的私名。

这不是可直接照搬的现代本体论，但能提醒我们：谓词在不同名类层级上的适用范围不相同。

### 《荀子·正名》“大共名”与“大别名”

《正名》提出“物”为“大共名”，“鸟兽”为“大别名”，并讨论推而共之、推而别之。其重点不是无限增加标签，而是说明分类粒度随辨别目的改变；同时还要结合“同类同情”“天官征知”和对象连续性判断，不能只依赖词语层级。

## 工程化规则

新增 `prototype/yixiang_taxonomic_scope.py`：

- 先记录 source category、target category、二者层级关系和目标谓词。
- 谓词必须标记为 universal、class-specific、subclass-specific、individual-specific 或 contextual。
- 向上概括：子类属性不能自动提升为上位类属性；即使声称是普遍属性，也要求谓词普遍适用的独立证据、成员范围证据、适用条件和反例搜索。
- 向下应用：上位类普遍属性只有在目标对象成员资格明确、且谓词具有继承证据时才允许记录。
- 兄弟类别迁移：必须有共享规则证据，不能仅凭共同父类或表面相似迁移属性。
- 缺少共享根据直接 REJECT；缺少成员证据、适用条件、反例搜索或继承证据时 ABSTAIN。
- 即使 SCOPE_RECORDED，也只表示当前分类迁移范围有记录，不代表古典名类体系等同现代生物分类学。

## 与《小取》七事和《荀子》观察门禁的关系

- 《荀子·正名》观察门禁：对象与感知证据是否落地，外观变化是否仍是同一对象。
- 《墨经》名类层级门禁：对象处于广名、类名、私名的哪一层，谓词适用范围到哪里为止。
- 《墨子·小取》七事门禁：从已知对象向另一对象进行论辩迁移时，是否保留共享根据、差异和反例。

三层顺序是：**观察与对象身份 → 分类与谓词范围 → 论辩迁移与结论审查**。前一层未确定时，后一层不得补造证据。
