# M10 类象组合涌现实验审计 v0.1

## 1. 研究问题

M9 解决“如何把多个不同关系轴的类象候选显式组合”，M9.2 解决“组合后的新性质主张是否有可审查结构”。M10 进一步问：

**在预先规定的测量、条件和反事实对照下，组合整体是否表现出单个成员、去桥接组合及替代解释对照无法解释的差异？**

本模块是实验设计与结果结构审计器，不是因果发现器，也不是涌现证明器。

## 2. 实验必须预注册

实验协议至少固定：
- 唯一 experiment_id 与待审计 claim_id；
- 测量指标及其方向（higher / lower）；
- 最小有意义效应阈值；
- 每个实验臂的最少独立实验单位数（至少 2）；
- 组合的全部成员，以及哪些成员预先声明为必要成员；
- 替代解释及其控制臂；
- 适用情境签名；
- 数据产生前的预注册引用和时间顺序声明。

代码只能检查是否声明了“数据前预注册”及其引用 ID，不能独立证明时间戳真实或注册内容未被事后修改。应将协议文件、时间戳和原始数据存入不可变来源系统。

## 3. 必须设置的实验臂

| 实验臂 | 目的 |
|---|---|
| member_only:<id> | 每个成员单独存在时的基线，防止把单体已有性质说成涌现 |
| intact_composite | 完整组合整体 |
| bridge_removed | 去除桥接关系，检验桥接是否必要 |
| member_removed:<id> | 对预先声明的必要成员逐一消融 |
| control:<id> | 针对预先登记的替代解释设置控制 |
| context_shift | 改变情境签名，检查结论的适用范围 |

所有实验臂须使用同一预注册测量定义；情境内各臂使用协议指定的 scope signature。context_shift 必须有不同的情境签名，但其结果仅作范围诊断，不强制要求性质消失——有些性质可能跨情境保持。

## 4. 判定逻辑

设预注册指标为 y，方向为 higher 时，比较效应为：

`effect(A,B) = mean(A) - mean(B)`

方向为 lower 时反转符号。完整组合相对于以下对照均须达到预注册的 minimum_effect：
- 每一个 member_only；
- bridge_removed；
- 每一个必要成员的 member_removed；
- 每一个替代解释 control。

每个实验臂必须达到 minimum_independent_units，默认最低要求为 2。独立单位 ID 用于避免把同一实验单位的重复读数冒充独立重复；同一单位可以跨臂配对，但当前 v0.1 只报告各臂均值和差值，不计算配对统计量。

若缺少实验臂、样本单位不足、证据引用重复、范围签名不符、预注册不成立或任何预注册对照未达到阈值，结果为 BLOCKED。结构和预注册对照全部满足时，也只进入 HUMAN_REVIEW。

## 5. 结果边界

M10 v0.1 只计算描述性均值差与门槛，不计算 p 值、置信区间、效应量标准化或统计功效；也不处理随机化检验、混杂调整、测量误差、批次效应和多重比较。minimum_effect 必须由领域专家根据量纲、仪器误差和实际意义预先确定，不能由模型看完结果后调节。

证据引用 ID 不重复不等于来源独立；independent_unit_id 不重复不自动保证实验单位真正独立。需要来源谱系审计、实验设计审查和原始数据复核。

即使结果进入 HUMAN_REVIEW，也不证明：
- 因果关系已经识别；
- 该性质在本体论意义上涌现；
- 该性质普遍存在或可跨域迁移；
- 所有替代解释均已排除。

## 6. 古典思想参照与现代实验的边界

《墨子·小取》关于“其然也同，其所以然不必同”的警示，支持将相同结果与相同形成机制分开；《荀子·正名》对同状异所、异状同所的辨析，支持保留对象与情境条件；《周易·系辞传》“引而伸之，触类而长之”可启发从局部关系扩展到组合结构。

这些原典提供的是推类边界、辨异和扩展的思想资源，不等于古代文本已经提出现代实验消融或复杂系统涌现理论。M10 的实验臂、预注册与效应阈值是现代可检验化设计，必须与古籍原义分层。
