# 《荀子·正名》：感官根据、同异辨别与对象连续性门禁 v0.1

## 文本结构

《正名》先问“何缘而以同异”，答以“缘天官”，继而区分目、耳、口、鼻、形体与心各自所辨的性质，并强调“征知”仍须等待感官接触其类。随后提出“同则同之，异则异之”，讨论大共名、大别名和约定俗成。篇末又区分“同状而异所”的二实与“状变而实无别”的化、一实。

这不是一套可直接等同现代感知科学的理论，但它提供了一个重要的古典认识论约束：**判断同异必须说明观察根据；对象外观与对象身份不能混为一谈。**

## 两组不可混淆的判断

1. **同状异所**：两个对象可以具有相同可见特征，却仍是两个个体。共享颜色、形状或声音，不能单独证明对象同一。
2. **状变而实无别**：同一对象可以在时间中发生外观变化，而其连续性仍然成立。形态变化不能单独证明对象已经更换。

由此，类象系统至少应区分：
- observed features：某一时刻实际观察到的特征；
- perceptual modality：视觉、听觉、味觉、嗅觉、触觉或内省；
- observation source：直接感官、仪器、他人报告、文本记录、模型输出；
- spatial location：观察发生的空间位置；\n- referent anchor：用于追踪对象的独立标识，与空间位置分开；
- continuity evidence：支持对象跨时间连续的证据；
- separation evidence：支持两个对象彼此不同的证据。

## 工程门禁

新增 `prototype/yixiang_observation_grounding.py`：

- 仅凭相同外观，不合并两个对象。
- 仅凭外观变化，不拆分同一对象。
- 同一对象锚点还必须有连续性证据，才能记录 SAME_REFERENT；位置变化不自动切断对象连续性，同一位置也不自动合并对象。
- 不同对象锚点还必须有分离证据，才能记录 DISTINCT_REFERENTS。
- 只有模型输出、文本转述或未经核验的证词时，不将其当作直接感官识别。
- 连续性证据与分离证据冲突时 ABSTAIN。
- 模型输出不能认证模型自己的对象身份判断。

该门禁是保守的数据质量与证据治理原型，不是通用视觉追踪算法，也不把《荀子》解释成现代计算机视觉理论。

## 与《墨子·小取》的组合

《荀子·正名》约束“比较对象是什么、观察依据是什么”；《墨子·小取》约束“从一个对象向另一个对象推论时，凭什么可以迁移”。两者可形成前后衔接的审查链：

1. 感官/来源证据是否可追溯？
2. 两个 referent 是否真为同一对象？
3. 当前共享特征是否与目标谓词相关？
4. 对象之间是否存在关键差异？
5. 迁移结论是否跨越因果、规范或情境边界？
6. 反例是否改变结论范围？

因此先做对象与证据的落地，再做类推，不可反过来由类推结果补造观察证据。
