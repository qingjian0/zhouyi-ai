# E02-H：未知非仿射布尔规则发现

## 研究问题

E02-E/F/G 的候选语言是有限阶乘积交互。E02-H 检验能否放宽规则表示：不给学习器目标成员或真值表，能否从样本中同时恢复未知的三变量成员集合与任意非仿射布尔真值表？

## 生成器与候选语言

- 8 个二值特征，目标关系阶数为 3。
- 生成器从满足以下条件的 3 输入布尔函数中抽样：三个输入变量均 essential、函数非仿射、最佳任意二变量函数的 Bayes 准确率不超过 0.75。
- 目标函数只用于生成标签和最终审计；不会传入候选搜索器。
- 学习器枚举所有二变量与三变量子集，并对每个子集拟合完整真值表。
- 对每个子集，按训练数据的每个输入状态统计正负标签数量，选择训练正确数最多的真值表。
- 训练选出的全局候选由独立 gate 验证；只有 gate accuracy >= 0.75 且相对成对真值表基线增益 >= 0.05 才允许 CREATE。
- 锁定 test 仅在结构决策后评估。
- 默认 30 个随机种子，训练 1024、gate 512、test 512，标签噪声 2%。

## 必须报告

- 成员集合恢复率；
- 完整真值表精确恢复率；
- CREATE 率；
- gate/test accuracy 与 pairwise baseline；
- 逐 seed 结果、支持证据和反例数量。

## 证伪标准

- 只恢复成员但无法恢复真值表，说明结构发现与规则识别仍有差距。
- gate/test 不能稳定优于 pairwise baseline，说明更丰富的规则语言没有带来泛化收益。
- 频繁错误 CREATE，说明门控未能保护持久结构。

## 公平性与限制

此实验给学习器更大的规则假设空间（所有 2/3 输入真值表），所以必须同时报告候选数量与运行成本；不能只拿准确率比较。生成器刻意排除 pairwise-easy 目标，使高阶基线具有意义。该实验仍是有限、合成的 Boolean 规则发现，不代表开放域概念发现或因果推断。
