# E12-A20-0：有限域因子图参考推理器

状态：参考实现首版；用于验证语义与测试，不是可扩展并行推理运行时。

## 实现范围

- 离散变量与有限状态域；
- HARD / SOFT / EVIDENCE / PRIOR 四类因子；
- 显式 forbidden assignment 硬约束；
- 负对数代价形式的非负有限能量；
- 穷举有限状态空间，作为小规模精确参考解；
- 确定性排序、top-k 假设、证据引用和硬冲突计数；
- 超出最大 assignment 数时返回 BUDGET_EXHAUSTED，绝不将部分搜索误报为收敛。

## 为什么先做穷举参考解

A20 的目标是并行假设图推理，但第一步不能直接实现近似消息传递后就宣称有效。小规模精确 solver 可以作为 oracle/reference implementation，用来验证后续并行消息传递、beam search 或局部更新是否得到相同或可接受的近似结果。

## 当前限制

- 只支持离散有限域；连续变量未实现。
- 只评估完整赋值；partial assignment、变量边缘概率和不确定性传播未实现。
- 使用完整笛卡尔积枚举，复杂度随变量域乘积指数增长。
- 因子代价需由调用者提供；没有从原始数据学习因子的训练器。
- 当前是顺序穷举 reference solver，不是并行执行引擎。
- EVIDENCE factor 仅携带引用，不代表引用内容已验证或具有密码学真实性。
- 不输出概率，只输出未校准的能量排序。
- 因子独立性、重复来源证据和相关证据去重尚未建模。

## 验收测试

1. 精确找到最低能量赋值。
2. HARD 因子拒绝违反约束的赋值。
3. 无可行解明确返回 NO_FEASIBLE_ASSIGNMENT。
4. 搜索预算耗尽明确返回 BUDGET_EXHAUSTED。
5. 变量/因子输入顺序变化不改变结果。
6. 证据引用随假设保留。
7. 无效域、无效因子作用域和非法能量 fail closed。

## 下一步

A20-1 将以该实现作为 reference oracle，增加局部因子消息、同步并行更新和近似推理；通过小型随机问题与精确结果比较误差、收敛率和运行成本。之后再加入多假设关系图和易象/太玄候选因子模板。
