# M4 反事实与条件干预基线 v0.1

## 目标

M4 检验一条已明确声明的类象关系，在条件改变后是否仍成立；识别关系不变量、条件敏感性、状态反转与不可判定情况。它承接 M3 的竞争候选和证据分层，但不把假设推演冒充为原典证据或现实因果结论。

## 核心语义

- 条件取值严格区分 `TRUE`、`FALSE`、`UNKNOWN`；未知不是假。
- 条件来源区分观察、推断、假设和干预。观察条件必须携带来源引用。
- `ConditionIntervention` 表示假设性的 do 操作；它不覆盖原始观察记录，而是在反事实副本中建立干预值。
- 规则由明确的必要条件构成：`requires_true` 与 `requires_false`。条件缺失或未知时，关系状态为 UNKNOWN；必要条件被违反时为 INACTIVE；全部满足时为 ACTIVE。
- 比较结果区分 INVARIANT、REVERSED、CHANGED、UNDETERMINED。只要基线或反事实一侧未知，就不能宣称稳定或反转。

## 输出解释

`intervention_only` 表示本次结果含假设干预；`changed_conditions` 记录实际改变的变量；`unknown_conditions` 保留无法判定的条件。即使输出 REVERSED，也只说明“在当前显式规则和干预设定下发生逻辑状态反转”，不表示现实世界已证明因果效应。

## 古籍研究接入规范

1. 原典中明确的条件句、时位、物候、主客、内外、远近等条件，先按原文语境记录，不直接翻译成现代因果变量。
2. 注疏解释与现代研究作为不同来源层级；不得覆盖原典原句。
3. 对每条规则保存原文、篇章位置、版本、异文、训诂、解释者及反例。
4. 由研究者提出的干预变量必须标记为假设；模型自行补出的变量必须标记为推断。
5. 清以前文献为主体；清代及以后主要用于校勘、辑佚、补漏与学术审查。

## 当前边界

- 这是透明的规则执行器，不是因果发现算法、结构因果模型或统计识别方法。
- 未建模混杂、选择偏差、测量误差和干预可实现性均可能使反事实失真。
- 规则成立不等于其历史解释成立；必须由可追溯文本和独立案例验证。
- 当前只处理二值条件与显式必要条件；多值状态、连续变量、时间演化、条件依赖图和概率不确定性留待后续版本。
- 合成单元测试只能验证程序语义，不证明易学理论的经验有效性。

## 测试范围

覆盖：稳定不变量、必要条件反转、未知值保留、干预消解未知、无关条件变化、重复输入拒绝、规则冲突拒绝及观察来源校验。
