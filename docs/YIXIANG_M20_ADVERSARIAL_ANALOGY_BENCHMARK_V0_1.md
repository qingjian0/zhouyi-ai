# M20 类推迁移对抗式成对基准 v0.1

## 1. 目标

M17 提供类推迁移门禁，M18 把古典案例接入 M8，但古籍案例尚未完成人工校勘与裁决。M20 因此不伪造古籍 gold，而构造一组明确标记为 synthetic_fixture 的成对对抗样例，用于检验 M17 的错误拒推边界是否被正确编码，以及 M8 能否检测这些边界。

## 2. 数据设计

16 条合成案例，组成 8 个对照对。每一对只改变一个关键因素或推论门槛，并共享 independence_group，必须处于同一个 split：

1. 关系方向保持 / 关系方向反转；
2. 材料来源关系 / 未证实的属性桥接；
3. 结果相同但机制未知 / 机制与边界条件受限地成立；
4. 同一对象、主体目标相符 / 主体目标改变；
5. 任务姿态保持 / 姿态改变；
6. 物种条件保持 / 跨物种外推；
7. 外观代理缺少桥接证据 / 已知反例破坏代理；
8. 类属谓词保持 / 数量谓词语义类型改变。

## 3. 数据隔离

- 所有样本 source_status=synthetic_fixture、label_status=fixture_expected、reviewers=[]。
- gold_decision 只是合成任务预期行为，不是人工 gold，更不是古籍解释裁决。
- 每对共享独立性组，不能拆分到不同数据集。
- holdout 只表示本合成基准中的模板留出，不代表真实古籍或真实世界 OOD 泛化。
- M8 只有显式 allow_fixture_expected=True 才允许对这些样本进行接口评分；结果必须标注 evaluation_basis=fixture_expected。

## 4. 评估重点

除四态决策指标外，重点观察：
- 对关键关系方向变化的敏感性；
- 同结果异机制时是否 abstain；
- 主体目标、姿态、物种、尺度和谓词类型变化时是否拒绝无条件迁移；
- 在桥接证据缺失时是否避免将未知错误转成 accept 或 reject；
- 成对样本是否保持 split 隔离。

## 5. 局限

这些样本由规则化模板人工构造，存在模板偏差和标签设计者偏差；它们只能测试实现契约和已知对抗边界，不能证明模型具有一般类象能力，不能代替人工古籍 gold，也不能用于宣称类象理论优于 Transformer。下一步必须在 M19 审定流程下建立小规模、来源独立、人工校勘的真实样本集，并与通用语言模型/结构基线做预注册对照。
