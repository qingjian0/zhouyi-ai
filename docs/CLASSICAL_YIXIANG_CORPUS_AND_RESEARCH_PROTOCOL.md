# 传统古籍类象研究总纲与语料建设规范 v0.1

> 研究对象：传统中国文献中与取象、观象、比类、象数、名实、分类、关系、时位、变化及跨域推理有关的全部可核验材料。  
> 史料优先级：**清代以前为主体；清代及清以后只承担查缺补漏、校勘、辑佚、异说追踪与现代学术审查，不得反向覆盖早期材料。**  
> 本文是语料与研究规范，不表示下列每一部书均已完成版本校勘或逐条数字化。

## 1. 总原则：先古文、再解释；先证据、再抽象

Zhouyi-AI 的类象理论不能只从《周易》单书抽取，也不能把后世“象数”“五行”“取象比类”的成熟体系整体倒灌到先秦文本。研究必须覆盖经、史、子、集、历算、医药、农工、地理、名物训诂等传统文献中真实存在的分类与推理方法，同时严格区分时代、文体、作者、文本层次和解释传统。

每一项知识至少区分五层：

1. **原典陈述**：古籍实际写了什么，保留原文、篇章、版本和上下文。
2. **历史解释**：注家如何解释原文；一位注家不代表全部传统。
3. **跨文本互证**：不同典籍是否使用相近术语、结构或推理方式；相似不等于同源。
4. **现代学术判断**：版本、年代、作者、文本层次、思想史位置等研究结论。
5. **项目操作定义**：为了计算而制定的形式化规则；必须明确标记为现代工程定义，不冒充古义。

禁止事项：
- 不将“清以前”误解为所有早期文献都同时、同义、同体系。
- 不把后世成熟的八卦配属、五行配属、纳甲、卦气、象数规则直接写成《周易》经文原义。
- 不因某个解释后来流行，就把它回填成先秦共识。
- 不以模型生成、网络转述或无版本古文作为独立史料。
- 不把形似、词同、数值对应自动认定为类象或因果关系。

## 2. 史料时间层与使用权重

| 层级 | 时间范围 | 角色 | 使用规则 |
|---|---|---|---|
| A | 先秦及秦代 | 理论根层 | 优先研究概念初见、语义环境、早期分类与推理方式；注意传世文本层累及出土材料差异 |
| B | 两汉 | 体系形成层 | 研究象数、阴阳、五行、气化、灾异、历法、医理等体系化过程；不得反投为先秦原义 |
| C | 魏晋南北朝、隋唐 | 注释与综合层 | 研究经学注疏、玄学义理、汉易资料保存、训诂与制度化解释 |
| D | 宋、元、明 | 重构与分化层 | 研究图书、义理、象数、心学及诸家重释；与汉唐解释并列比较 |
| E | 清代 | 查缺补漏层 | 重点用于辑佚汉易、版本校勘、考据、汇编异说；其理论结论不得自动优先于早期原文 |
| F | 清以后至现代 | 查缺补漏与学术审查层 | 用于新出土文献、目录学、版本学、语言学、思想史、数字人文及现代批评；不能替代古籍证据 |

时间层是资料管理字段，不是价值等级。早期材料优先，不意味着早期材料必然正确或完整；晚出材料可能保存早佚资料，但必须标注其转引链和可信度。

## 3. 第一批核心古籍范围

### 3.1 易学本体：经、传与早期易学材料

**基础文本**
- 《周易》经文：卦画、卦名、卦辞、爻辞；分项记录，不预设所有部分同一时代形成。
- 《十翼》：彖传上下、象传上下、系辞传上下、文言、说卦、序卦、杂卦。传世篇章结构与文本形成史分开记录。
- 《周礼》春官太卜等相关材料：三易、卜筮职官与制度语境。
- 《左传》《国语》中的筮例：记录占筮叙事、引《易》、解释者和事件结果；不得把后世占例规则直接套入。

**关键研究句群（以可靠底本逐字校核后入库）**
- 《系辞上传》：“仰以观于天文，俯以察于地理……近取诸身，远取诸物。”
- 《系辞上传》：“方以类聚，物以群分，吉凶生矣。”
- 《系辞上传》：“引而伸之，触类而长之，天下之能事毕矣。”
- 《系辞下传》：“易者，象也；象也者，像也。”
- 《说卦传》关于八卦取象、天地定位、山泽通气、雷风相薄、水火不相射，以及乾、坤、震、巽、坎、离、艮、兑的条目。

这些句子是高优先级语料入口，不应只摘录名句；每条必须带前后文、篇章、版本、异文、训诂与语义范围。

### 3.2 先秦类比、名实与推理方法

| 典籍 | 优先篇章/主题 | 对类象研究的价值 |
|---|---|---|
| 《墨子》 | 《经上》《经下》《经说上》《经说下》《小取》 | 名、实、故、类、同异、譬、侔、援、推等论辩与推类方法；建立论证结构，不把术语现代化后冒充原义 |
| 《荀子》 | 《正名》《非相》《解蔽》《天论》《礼论》 | 名实、分类、辨异、征知、心知、类推及认识偏误 |
| 《吕氏春秋》 | 《有始》《应同》《十二纪》及相关篇 | 时令、方位、物类、感应、政治秩序等跨域配类；逐条标注编纂层次 |
| 《管子》 | 《四时》《五行》《幼官》《宙合》《心术》等 | 时令、气、五行、政令、身体与秩序的对应结构；注意篇章年代与学派层累 |
| 《庄子》 | 《齐物论》《寓言》《天下》等 | 类别边界、视角转换、譬喻与认识限度；作为反例与批判材料 |
| 《韩非子》 | 《解老》《喻老》《难势》等 | 取譬、因果判断、势与条件推理；区分寓言论证与经验事实 |
| 《公孙龙子》 | 《白马论》《坚白论》《指物论》 | 名、指、物、属性与分类边界，帮助建立类象误判测试 |
| 《礼记》 | 《月令》《礼运》《乐记》等 | 时序、方位、礼制、物类与社会秩序的对应；区分制度规范和自然描述 |
| 《诗经》《尚书》《春秋》及三传 | 相关物候、譬喻、名物、灾异、礼制记载 | 早期物象词汇、比兴材料、历史叙事与解释框架；不能把文学修辞直接当作分类规则 |

### 3.3 先秦至两汉的自然知识与名物分类

必须纳入与类象相关的非易学知识传统，避免把“类象”缩窄成卦象配属：

- 天文、历法、律吕、数术：《周髀算经》《九章算术》及相关历志、律历志材料。
- 地理、地形、方域：《山海经》《禹贡》及地理类文献。
- 名物、训诂、分类：《尔雅》《方言》《说文解字》；区分词义训释、物类归属与后世名物考证。
- 医学与身体：《黄帝内经》各篇、《难经》及早期本草材料；将身体类比、脏腑关系、气血运行与现代生理学结论严格分层。
- 农事、工艺、物产：《考工记》《齐民要术》（北魏，作为后续层）及相关农书、器物文献；抽取结构—功能—材料—工序关系。
- 天地、气化与物类：《淮南子》《春秋繁露》《白虎通》等；记录阴阳、五行、时令、方位、物类体系如何逐步整合。

### 3.4 两汉易学与象数体系

优先追踪孟喜、京房、郑玄、荀爽、虞翻等易学传统，但要注意部分著作散佚，许多内容通过后世引文保存。重点材料包括：

- 《易纬》诸篇（版本、篇名、真伪与成书年代须逐项审查）。
- 《焦氏易林》：卦变、象辞、类比语句与文本层次。
- 《京氏易传》及后世辑存的京房易学材料。
- 《周易集解》（唐李鼎祚汇集汉魏诸家注，是追踪早期异说的重要中介，不等于汉代原始文本）。
- 《太玄经》及相关注释：作为不同符号系统的比较对象，不混同于《周易》。
- 《黄帝内经》《淮南子》《春秋繁露》等中阴阳五行、时令、身体、方位、物类关系的不同语境。

重点问题：八卦取象如何扩展；逸象如何出现；卦气、爻辰、纳甲、世应、飞伏、升降等规则各自的历史来源、适用体系与相互关系；哪些是文本原有，哪些是注家重构。

### 3.5 魏晋隋唐：注疏、训诂与综合

- 王弼《周易注》、韩康伯《系辞注》及相关注本：研究义理解释与象数取舍。
- 陆德明《经典释文》：音义、异读与版本线索。
- 孔颖达等《周易正义》：官方经学注疏体系及其整合方式。
- 李鼎祚《周易集解》：保存汉魏易说，必须区分被引原注与李氏编纂层。
- 李善《文选注》等注释传统中的譬喻、名物与典故材料，可按需纳入类比语料。

### 3.6 宋元明：图书、义理与多传统重释

**宋代重点**
- 邵雍《皇极经世》及相关先天学材料。
- 周敦颐《太极图说》《通书》。
- 张载《正蒙》。
- 程颐《伊川易传》。
- 朱熹《周易本义》《易学启蒙》及《朱子语类》相关条目。
- 苏轼《东坡易传》、朱震《汉上易传》等不同路径。

**元明重点**
- 吴澄《易纂言》。
- 胡一桂《周易本义附录纂疏》《周易启蒙翼传》。
- 来知德《周易集注》。
- 蔡清《易经蒙引》。
- 罗钦顺、王守仁等涉及理气、心性与象理关系的论述，按研究问题选录。

宋元明材料不能合并成单一“宋易”标签；必须分别标识图书象数、义理、史事、占筮、心性等解释取向。

## 4. 清代及清以后：只作补遗、校勘与查缺

清代材料的价值很高，但在本项目中不作为早期理论的默认权威。重点用途：

1. **辑佚**：借助清人辑佚本追踪汉代孟喜、京房、郑玄、荀爽、虞翻等佚说；同时回查其引用来源。
2. **校勘**：比较刊本、抄本、四库本、丛书本及现代整理本，识别删节、讹字、改写与重排。
3. **目录学**：利用《经义考》《四库全书总目》易类等书目，发现被遗漏的传统著作。
4. **异说补漏**：检查宋元明不同派别及清代汉学、宋学材料是否遗漏。
5. **现代审查**：利用现代易学史、出土文献、古文字、训诂、思想史、科学史和数字人文成果修订年代与释义判断。

清代补遗重点书目：惠栋《易汉学》《周易述》、张惠言《周易虞氏义》等、焦循《雕菰楼易学》相关著作、李光地《周易折中》《周易通论》、阮元《周易注疏校勘记》、朱彝尊《经义考》、马国翰《玉函山房辑佚书》及《四库全书总目》易类。王夫之《周易内传》《周易外传》等应依具体成书时间与学术归属标注，不简单按作者生卒年粗略归类。

现代材料优先关注：出土帛书、简牍、古文字释读；《周易》经传分层与成书研究；汉易辑佚的来源链审查；类比推理、分类学、符号学、认知科学、知识表示和科学史研究。现代学者的观点只作为带作者、年份、论据和争议状态的二级/三级证据。

## 5. 古文语料的采集与校勘规程

每一条文本记录至少保存：

- `source_id`：稳定来源标识。
- `work_title`、`chapter_title`：书名、篇名。
- `text_layer`：经、传、注、疏、辑佚、序跋、现代研究等。
- `author_attribution`：传统题署与现代作者判断分开。
- `composition_period`：成书年代范围及其依据；未知可空，不猜测。
- `edition`：底本、刊刻/抄写信息、整理者、出版信息。
- `locator`：卷、篇、章、叶码/页码、段落或可复现数字定位。
- `original_text`：原文转录；保留异体字、通假字和缺损标记。
- `normalized_text`：规范化文本；不得覆盖原文。
- `variant_readings`：异文及版本来源。
- `context_before`、`context_after`：必要上下文。
- `source_type`、`period_tier`、`evidence_grade`、`license_status`。
- `transcription_status`：影印核对、可靠点校本转录、二手转引、未核验等。

数字文本只作为检索入口。涉及关键理论主张、异文争议、罕见字、断句与年代判断时，必须回看影印底本或权威整理本。不能将网页转录的无标点文本当作已校勘原文。

## 6. 从古文到类象知识：双层结构

### 6.1 文本证据层

原文只负责提供可核验的语言证据。每条证据可拆为多个主张，但每个主张必须保留精确定位。禁止一段原文被模型概括后生成十条没有独立出处的“古代定律”。

### 6.2 可计算理论层

在证据层之上建立候选知识对象：

- **象项**：对象、现象、结构、属性、功能、过程、时空条件。
- **类项**：共同维度、分类准则、必要/非必要特征、边界案例。
- **关系项**：方向、角色、强度、条件、时间有效区间、是否可逆/对称。
- **类象映射**：源域、目标域、实体映射、保持关系、变化关系、失效条件。
- **解释主张**：传统解释、注家解释、项目定义、研究假设分别存储。
- **证据与反例**：支持、反驳、未决、冲突来源均可追踪。

一个“乾为天”之类的文本主张，不自动推出“现实对象 X 属乾”；必须另外提出映射依据，并经关系保持、上下文和反例审查。

## 7. 类象理论的研究维度矩阵

每个传统例证尽可能标注以下维度，可多选，但必须说明为何选取：

1. 形态象：形状、构造、边界、拓扑、部分—整体。
2. 属性象：寒热、燥湿、刚柔、明暗、轻重、强弱、动静等；尊重原文语义，不强行统一。
3. 功能象：作用、用途、角色、输入输出、制度功能。
4. 关系象：比、应、承、乘、生、克、制、化、合、冲等；每个术语须先考证语义和适用体系。
5. 过程象：生长、收藏、升降、往来、始终、转化、循环。
6. 时序象：四时、月令、昼夜、节候、阶段、周期。
7. 空间象：上下、内外、远近、方位、中心边缘、地势。
8. 数量象：奇偶、多少、比例、次序、周期、分合；数制与象数解释分开。
9. 势象：趋势、动静、消长、临界、蓄势、失衡；须有上下文依据。
10. 语用/制度象：礼制、名分、政治角色、社会组织中的类比结构。
11. 感应象：文本所述对应、共振或感应关系；与现代因果机制严格区分。
12. 复合象：多个维度共同形成的结构，不可简化为单一标签。

## 8. 关系理论必须从原文逐条建立

不得预先认定传统关系天然对称、可逆或传递。对每个关系词建立“词义史—文本用例—注家分歧—操作定义—反例”链条。

重点词群：
- 易学结构关系：承、乘、比、应、当位/不当位、中正、得中、卦变。
- 阴阳关系：对待、互根、消长、交感、偏胜、转化。
- 五行关系：生、克、制、化、乘、侮；区分不同文献中的用法。
- 名辩关系：同、异、类、故、名、实、指、物、譬、侔、援、推。
- 时空关系：上下、内外、远近、先后、方位、时位、得时/失时。
- 体用关系：体、用、主、客、动、静；不得跨时代固定成单一二分。

关系记录至少包括 `relation_id`、原词、异名、时代/文本范围、主体/客体角色、方向性、条件、时间性、可逆性证据、反例、来源与操作定义版本。无证据时取“未知”，而不是默认对称或反向。

## 9. 理论验证路线

### 阶段 I：古文语料完整性
- 建立古籍目录、篇章目录、版本记录和来源等级。
- 对《周易》经传、墨家名辩、荀子正名、先秦两汉类象材料优先完成逐篇索引。
- 输出缺篇、缺版本、无定位、异文未决清单。

### 阶段 II：概念史与关系词典
- 为“象、类、比、取、观、应、感、变、时、位、势、数、理”等词建立分期词义档案。
- 每个关系词至少收集正例、反例、异义例和跨文本比较例。
- 禁止用现代单一释义覆盖古代多义。

### 阶段 III：类象案例集
- 先做古籍内部的类象案例，再做跨领域案例。
- 每个案例必须包含原文证据、语境、解释分歧、映射维度、保持/不保持关系、反例与适用范围。
- 采用按书、篇、作者/学派、时代分组的留出测试，防止模型记住同一注家话语。

### 阶段 IV：形式化与程序验证
- 将已审定的关系定义写入版本化关系本体。
- 用静态关系保持、动态转移保持、条件关系、部分映射和拒绝类比测试逐层验证。
- 古籍主张不直接作为监督真值；应保留“原文证据—解释标签—操作假设”三种标签。
- 与随机映射、词面相似度、普通知识图谱关系匹配等基线比较。

### 阶段 V：跨域迁移
- 从自然物、器物、身体、时令、社会制度、历史事件等不同域构造任务。
- 以整本书、整类文本、整时代或整传统留出，避免同源注释泄漏。
- 同时评估正确迁移、错误迁移拒绝、条件边界、反事实敏感性和解释可追溯性。

## 11. 与现有 Zhouyi-AI 研究模块的衔接

- `YIXIANG_ONTOLOGY_SPEC.md`：定义结构对象、象/类/类象和时位势变概念；本文件补充历史文献范围和史料治理。
- `prototype/yixiang_encoding.py`：仅负责卦爻结构编码，不承载历史语义。
- source-grounded trigram profiles：保存有出处的八卦语义主张；应扩展到六十四卦、爻位、卦变、五行与其他传统概念，且保留多传统冲突。
- analogy evaluator：只检查显式映射与关系保持，不负责从古文自动发现正确解释。
- relation algebra：关系对称、逆关系、传递性必须由具体来源和版本声明，不能按常识推断。
- dynamic transition evaluator：验证有证据的状态变化映射，不将卦变结构直接等同于现实因果过程。

## 古代文献中的不同“类象/类比”实践：不可混为一谈

本项目新增 `method_families`，将文本中的推理实践分开标注。它是现代语料管理分类，不宣称古人使用了同一套术语系统：

1. **分类/类聚（classification）**：把事物按某些共同点归类；归类本身不自动产生推论。
2. **推类/类比论证（analogical_argument）**：由已知对象或事例推及另一对象；必须检查“同处”与“所以然”是否一致。
3. **譬、侔、援等修辞论证（rhetorical_analogy）**：按《墨子·小取》的篇章结构记录其论辩操作，不简化为现代相似度。
4. **感应/应同（cosmological_correspondence）**：保存古代宇宙论中的同类相召、气类相合等命题；不直接当作现代经验因果。
5. **名物训诂/词汇分类（lexical_taxonomy）**：记录名称、对象、类别、异名与边界，不与跨域类比混同。
6. **象数/符号对应（symbolic_correspondence）**：记录卦爻、阴阳、方位、时令等特定传统符号体系内的对应规则，并要求来源版本。
7. **观测/现象描述（phenomenological_observation）**：记录文本观察到的形态、过程、时序和条件，不预先赋予理论解释。
8. **因果主张（causal_claim）**：单独标记其论证类型与证据，不由类比关系自动推出。
9. **注疏/比较解释（commentarial_exegesis / comparative_exegesis）**：明确这是后世解释层，而非原典陈述。

尤其要区分《墨子·小取》的论辩推类、《荀子·正名》的名实分类、《吕氏春秋·应同》的宇宙论感应，以及《周易》经传中的拟象与象数结构。它们可以互相比较，但不能在语料层预先合并为一种无差别的“古代类比算法”。
