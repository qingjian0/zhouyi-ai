# 类象记录与评估规范 v0.1

## 目标与边界

本规范把取象比类拆成可审查的数据记录与最小可证伪评估。它不声称覆盖传统易学全部象学理论，也不把结构相似自动解释为因果关系。当前 Python 基线只评估显式实体映射和有向关系保持；形态、属性、功能、过程、时空、势象等维度仍需独立标注器或学习模型提供。

## 八类类象维度

- morphology：形态、组成、拓扑、边界与层次。
- attribute：性质、数量、强弱、方向与状态。
- function：功能、角色、输入输出与作用。
- relation：对象之间的有向/无向关系；方向策略必须显式声明。
- process：发生、发展、转折、衰退与循环。
- spatiotemporal：位置、阶段、顺序、环境与尺度。
- potential：趋势、潜势、稳定性与临界变化。
- integrated：多维联合形成的整体模式。

维度是标注切面，不是互斥类别；同一候选可同时标注多个维度。不能因两个对象共享维度标签就判定类象成立。

## 必需字段

每条记录包含稳定 candidate_id、源域与目标域、源实体、目标实体及显式映射、一个或多个类象维度、源关系与目标关系、适用条件、有效范围、支持证据与反例、可追溯出处、记录版本及审核状态。置信度是声明值，不是正确率。

## 当前最小计算基线

prototype/analogy.py 采用显式一对一实体映射，将源关系映射到目标域，再计算关系 precision、recall、F1 和实体映射覆盖率。关系类型按有向、精确匹配处理；不自动把关系视为对称，也不推断因果。若未来要支持逆关系或对称关系，必须在关系本体中显式定义并单独测试。

默认通过门槛：关系 F1 达到配置阈值；实体映射覆盖率达标；存在支持证据；存在明确条件和有效范围。反例始终记录。默认允许带反例的候选进入进一步验证；严格评估时可将未解决反例作为拒绝门槛，实验报告必须披露该策略。

## 基准任务与拆分

评测 retrieval（检索）、discovery（发现）、explanation（解释）、verification（验证）、transfer（迁移）、composition（组合）和 rejection（拒绝）。数据拆分至少包含随机 IID、整域留出（domain OOD）、关系族留出和组合结构留出（compositional OOD），并加入反事实扰动。来自同一底层模板、同一案例改写或同一来源的近重复样本必须归入同一拆分，防止泄漏。

## 对照与报告

至少比较无类象机制、普通语义相似度、随机映射、只看实体特征、关系保持评估器和可学习类象模型。控制参数量、数据量和计算预算。报告 precision/recall/F1、映射覆盖率、错误类比拒绝率、OOD 迁移收益、校准、成本及置信区间。

当前实现是可解释的规则评估器，不是神经网络、训练模型或自主发现系统。只有后续模型在预注册 OOD 基准上优于匹配对照，才能声称类象机制具有独立学习收益。

## 有限图上的候选映射发现（原型）

`discover_analogy_mappings` 在小规模符号图上枚举源实体到目标实体的单射映射，并按关系 F1、precision、recall 排序。它不生成新实体、不学习关系语义，也不从文本中抽取象。默认最多评估 10,000 个映射，结果显式返回 `truncated`；只要被截断，就不能把当前排名解释为全局最优。

发现阶段与确认阶段分离：没有支持证据的候选不会通过证据门槛，即使结构分数很高，也只能作为待审查候选。实际使用时应记录图快照、搜索预算、维度、条件、证据出处和有效范围。该算法是有限规模基准与后续学习型发现器的可复现参照，不适合直接用于大规模实体图的穷举。
