# 古典类象案例集 v0.1：从原典句段到可审查推理

## 定位

本案例集将先秦两汉原典中的取象、名实、类推、适配、殊途同归与感应批判，转成可供 Zhouyi-AI 训练和评估的结构化案例。清代以前为主体。此版本包含 **24 条案例、15 个作品/篇章来源入口**。

**重要证据状态：** 所有摘录目前均标为 `digital_transcription_candidate`、`unreviewed`。数字平台列出多个版本入口，不等于这些摘录已完成影印逐字核验、校勘或独立版本互证。不得将本案例集描述为已完成古籍校勘的权威语料。

## 数据结构与判读约束

每条案例包含：
- 精确篇章定位与数字来源入口；
- 原文摘录；
- 研究问题与操作类型；
- 前提、结论范围；
- 反例/边界；
- 竞争解释；
- 证据状态和复核状态。

案例里的 `operation` 是现代工程标注，不是声称古人已经使用同一套形式逻辑分类。案例结论只针对所引段落，不代表整部作品的全部思想立场。

## 新增案例：从《非攻上》识别规范一致性推论

XY-011 将《非攻上》的两条论证链分开：一条比较不同侵害行为的损害递进，一条在杀害无辜者的框架内扩展受害数量。它们共享规范理由，但不能混成同一种规模推理。详细论证图、反例和 M2–M8 接口见 [专题分析](CLASSICAL_YIXIANG_MOZI_FEIGONG_ANALYSIS_V0_1.md)；双链的机器可读结构见 [结构化图谱](../data/mozi_feigong_argument_graph.v0.1.json)。

## 新增案例：闻、说、亲的知识来源\n\nXY-024 将《经上》“知，闻、说、亲”及《经说上》释义转成证据来源案例，区分传受、推论和亲身观察。该案例与《荀子·正名》的天官—征知链互补，但不把古典认识论术语机械等同现代证据等级。\n\n## 新增案例：达、类、私的名称层级\n\nXY-023 依据《经上》“名，达、类、私”及《经说上》“物、马、臧”释例，区分广名、类名与私名。原文“有实必待之名也”存在异文与校改，必须分层保存。\n\n## 新增案例：推类之难与名类层级\n\nXY-022 将《墨经·经下》“推类之难，说在之大小”作为名类层级门禁的原典入口。其经说与后世校注存在异文和解释差异，案例仅引用较稳定的经文句，不把校改拼接为正文。\n\n## 新增案例：同其然不必同所以然\n\nXY-021 将《小取》关于“其然”与“所以然”、取舍与取舍根据的区分转成可审查案例。辟、侔、援、推在系统中只标记论辩操作，不充当结论真值担保。具体门禁见 [辩学七事与推类边界专题](CLASSICAL_YIXIANG_MOZI_INFERENCE_MOVES_V0_1.md)。\n\nXY-009 与 XY-012 进一步支持将感官观察、对象身份和时间连续性分开；工程门禁见 [《荀子·正名》感官根据与对象连续性专题](CLASSICAL_YIXIANG_XUNZI_OBSERVATION_GROUNDING_V0_1.md)。\n\n## 研究发现：类象不是单一的“相似度计算”

首批案例已显示至少六种彼此不可互换的结构：

1. **取材与表征**：从身体和外物观察中选取可表征的特征。
2. **论辩操作**：譬、侔、援、推承担不同的论证工作。
3. **名实与指称**：词语约定、对象分类和指称范围必须分开。
4. **条件适配**：关系是否成立依赖尺度、任务和情境。
5. **多路径同结果**：功能等价不意味着过程或机制等价。
6. **相关/感应与因果**：文本中的对应主张必须接受因果证据审查。

因此，系统不能仅凭共享属性或词面相似就合并概念；至少还要保存比较维度、适用条件、非共享属性和反例。

## 下一步校勘与研发门槛

1. 对每条摘录绑定具体影印底本、版本、页/叶码或卷篇行号。
2. 对关键字词记录异文、异体、通假、断句和注家分歧。
3. 至少区分“数字检索见证”“点校本转录”“影印逐字核验”“独立版本互证”四种证据状态。
4. 由两名独立审阅者复核核心摘录与解释；意见不一致时保留竞争解释。
5. 扩展反例集：同词异义、同名异物、异名同物、属性相似但功能不同、功能相同但机制不同、类同而结论不随。
6. 把通过复核的案例接入 M3 竞争解释与 M8 迁移基准；未复核案例只能用于开发/检索，不进入高可信评测集。
