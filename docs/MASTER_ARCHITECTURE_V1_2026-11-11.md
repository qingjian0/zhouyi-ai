# Zhouyi-AI 统一认知架构 v1

日期：2026-11-11  
状态：架构基线 / 集成规范；不是已完成的统一运行模型，也不是性能结论。  
基线：`integration/e09-v03-evidence-binding-2026-11-11` @ `50104ed486db3d5b28527eb9785e1fe3a199990b`

## 0. 最终架构决策

Zhouyi-AI 采用**非 Transformer 原生认知计算为主、语言模型可插拔为辅**的路线。

主创新对象不是某一种 backbone，而是一个类型化、关系驱动、非自回归的认知计算系统：

**ZNCA（认知组织） + TRLW（类型化关系潜在工作空间） + SROK（稀疏关系算子内核） + CSG-GCR（候选生成与全局协调） + ZPCM（持久认知记忆） + E09（证据治理） + MCRL/Hyper-Speed（计算决策与执行）**。

CPG-EI 是整个研究计划和实验范式的总伞，不再与 ZNCA、TRLW、SROK 并列争夺“总架构”身份。易象/象数理/类象是可学习、可证伪的结构先验与算子族，不是固定真理表，也不是独立的另一套 AI。

当前应优先构建的是**可运行的结构认知闭环**，不是先训练一个大参数语言模型。

## 1. 设计目标与非目标

### 目标

1. 内部认知以对象、属性、事件、角色、关系、超边、约束、证据和状态转移为基本计算对象。
2. 允许非相邻元素组合，例如从 a,b,c,d,e 中形成 a,b,c,e，而不要求沿文本位置逐个传播。
3. 允许多个候选结构并行提出、共享计算、竞争和联合约束收敛。
4. 允许连续潜在状态与离散可验证结构共存，不能把所有认知压成单一向量或纯符号规则。
5. 记忆长期持久化、按需检索、局部更新；模型上下文只是临时工作视图。
6. 所有事实、假设、类象、推断和输出主张保留证据谱系、时间、版本和不确定性。
7. 语言模型可以作为输入/输出适配器、教师、对照基线或可选专家，但不能代替内部认知系统并冒领其能力。
8. 面向桌面与移动端，按 RAM、延迟、吞吐、能耗、存储 I/O 和计算预算优化。

### 非目标

- 不宣称当前已实现 Transformer 替代品或通用智能。
- 不把“并行生成”简化为一次预测多个 Token。
- 不预设 Mamba、SSM、液态网络、Hopfield、EBM 或任何单一算法就是最终 backbone。
- 不把传统卦象、五行或类象映射直接硬编码为现实世界的因果规律。
- 不把百万级可检索历史称为百万 Token 原生注意力上下文。
- 不因架构名称相似就重复实现第二套生命周期账本、证据账本、持久存储或调度器。

## 2. 统一分层架构

### L0 输入与观测

输入适配器接收文本、图像、音频、视频帧、表格、传感器、工具结果和外部 API。输出统一 Observation：原始载荷引用、来源、时间、模态、解析状态、权限范围和完整性信息。

输入解析器可以使用规则、小型神经模型或外部 LLM，但解析结果必须是带来源跨度的候选，不得直接写成已确认事实。

### L1 语义与多模态 grounding

将观测映射为类型化实体、概念、属性、事件、角色、时空信息和关系候选。连续 embedding 用于相似度和检索；离散类型与角色用于硬约束；原始来源用于审计。解析置信度与事实可信度分离。

### L2 认知状态与工作空间（ZNCA / TRLW）

统一工作状态：

`W=(V,H,X,Z,B,C,P,T,
u)`

- V：带类型实体/概念/事件槽位；
- H：关系超边及其角色绑定；
- X：离散状态、变量赋值和结构编辑；
- Z：连续潜在表示；
- B：候选假设分支及其增量差分；
- C：硬约束、软约束和任务目标；
- P：证据与来源引用；
- T：有效时间、记录时间和任务时间；
- ν：schema、算子、模型、索引和结构版本。

真值状态、证据强度、模型置信度、不确定性、来源可靠性和推导成本必须分别存储。不得把一个 score 同时解释成概率、真值和证据量。

### L3 结构生成与组合（SROK / CSG-GCR）

SROK 负责有界、稀疏、类型安全的关系组合：角色候选检索、非相邻组合、部分算子应用、约束过滤、联合评分、来源聚合和预算报告。

CSG-GCR 负责更高层候选结构生成与全局约束协调：候选去重、分支共享、冲突识别、联合一致性、资源分配和停止条件。

生成策略是 propose → validate → rank → coordinate，不是无界枚举。所有搜索必须报告候选数、剪枝数、预算耗尽和是否完整搜索。

### L4 动态推演与状态更新（RSDN + 可替换后端）

RSDN 负责关系状态随时间、事件和干预变化的学习与更新。连续状态更新、离散结构编辑和事件驱动局部传播分离。

计算后端可插拔：
- 稀疏超图/关系消息传递：显式高阶关系；
- 递归状态更新、SSM/Mamba 类：连续状态压缩与长程动态；
- EBM/因子图/有限域求解/BP：联合约束与多候选能量评估；
- Hopfield 类联想更新：模式检索与收敛研究；
- NCA/液态/事件驱动网络：局部更新与自适应动力学研究。

这些是候选算子/后端，不是默认全量堆叠。通过任务与资源匹配实验选择。Transformer 不作为内部认知核心的默认依赖，但保留作为语言接口和公平基线。

### L5 易象与类象算子（Yixiang / XSL）

易象算子分成可组合的类型化算子族：
- 象：观测投影、特征抽取、结构视角；
- 数：离散状态编码、组合空间、基数与层次；
- 理：关系约束、带符号影响、守恒/不变量候选；
- 变：状态差分、条件转移和干预候选；
- 类：关系保持的部分映射、跨域结构对齐；
- 择：时、位、应、条件、目标与资源约束下的路径选择；
- 综：互、错、综等多视角变换与反向检验。

每个算子必须具有输入/输出类型、前置条件、后置条件、保持的不变量、适用域、可学习参数、计算成本、证据、反例和版本。传统命名是候选先验，不构成有效性证明。允许系统提出传统分类之外的新算子。

XSL 负责跨域映射和类象证据审计；Yixiang 负责算子定义、编码与对照实验。不得将“相似”直接提升为“同一”或“因果”。

### L6 证据治理与生命周期（E09 / E12-A6）

E09 是预测提交、证据揭示、作用域/数据切分绑定、学习者可见性和评估隔离的权威协议。训练学习者只能收到授权 SUPPORT；开发门控与锁定测试标签不得进入学习更新。

E12-A6 是候选结构生命周期状态和转换的唯一权威。其他模块只能引用其版本或通过适配器投影，不能复制第二套状态机。

评估器、学习者、协调器应在部署时隔离。当前 same-process 元数据检查不是安全边界。正式执行必须使用进程/服务隔离、最小权限、不可伪造的提交/揭示绑定、幂等交付和可恢复检查点。

### L7 持久认知记忆（ZPCM / DCMF）

ZPCM 负责持久事件历史与可重建的认知投影；DCMF 是事件流上的类型化记忆视图，不是多个重复数据库。至少区分：
- 事件/情景记忆；
- 语义事实与关系；
- 程序/算子经验；
- 目标与计划；
- 类象映射及其证据；
- 冲突、未知、撤回和反例。

使用追加式事件、双时间语义、可撤回断言、确定性物化、索引版本和增量重建。摘要、缓存和索引是派生视图，不可静默覆盖原始证据。

### L8 依赖、元认知与执行（CSL / MCRL / Hyper-Speed）

CSL 唯一负责结构依赖、失效传播、选择性重验证和 dirty-set 队列；不得成为第二套生命周期账本。

MCRL 负责元认知策略：估计不确定性、剩余信息价值、额外计算的预期收益和停止/继续/提问/工具调用决策。

Hyper-Speed 负责把获准计划编排为 DAG，进行并行调度、资源配额、重试、checkpoint、隔离工作区和执行回执。策略决策与执行引擎分离；调度器不能隐式获得 shell、GitHub 或其他高权限。

### L9 语言与行动接口

输出前将已验证的认知结构编译成最小充分上下文或结构化动作。语言模型/解码器负责表达，不拥有事实账本、生命周期、证据揭示或结构提交权限。生成内容解析回主张后，必须经验证，再由权威模块提交事件。

## 3. 核心闭环

`Observe → Ground → Retrieve → Propose → Compose → Infer → Commit Prediction → Reveal Evidence → Revise → Validate → Persist → Express/Act`

任何一步都可以返回上游；预算耗尽、证据不足、冲突未解或搜索不完整必须作为显式状态返回，而不是伪装成确定答案。

## 4. 非 Transformer 主路线的精确定义

“非 Transformer 为主”指：
1. 内部状态与主要推理不以 token 序列作为唯一状态；
2. 结构组合、关系动力学、约束协调和持久记忆可独立运行；
3. 语言解码与认知状态分离；
4. 主要认知计算后端优先评估非 Transformer 候选。

它不意味着禁止 Transformer，也不意味着 SSM 一定优于 Transformer。必须分别评估结构认知内核、语言接口和端到端系统，避免把外部 LLM 的能力计入内部内核成绩。

## 5. 移动端与长记忆

严格区分：
- 持久历史容量：磁盘可保存的原始事件/载荷；
- 有效认知容量：可检索且证据有效的知识与关系；
- 活动工作集：当前任务激活的结构、候选和证据；
- 模型上下文：单次语言模型调用实际接收的 token；
- 运行时状态：连续状态缓存、索引缓存和临时分支。

目标是磁盘优先、RAM 有界、按需检索、增量物化和局部失效传播。每个设备实验必须报告峰值 RSS、持久存储、索引大小、活动工作集、上下文 token、延迟、吞吐、能耗和热降频。百万级有效记忆不等于百万 Token 原生注意力。

## 6. 模块成功与退出条件

每个模块必须有独立基线、匹配预算对照、消融、OOD 测试和资源成本。如果收益不能覆盖复杂度，降级、替换或移除模块。架构层不为某个传统理论或网络家族提供免检特权。
