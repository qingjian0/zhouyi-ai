# M9 多视角类象生成、竞争与组合 v0.1

## 1. 研究问题

M8/M3 已经能够评估候选迁移、保留竞争解释；M9 进一步处理一个更细的问题：同一对观察对象可以在不同关系轴上形成多个并列候选，而这些候选不能被压成一个总相似度。形态相似、结构相似、功能相似、过程机制相似、时间变化相似、情境位置相似、象征规范对应，回答的是不同问题。

本模块把“多视角生成”与“多视角组合”拆开：

1. 每个关系轴独立形成一个 ViewCandidate。
2. 同一观察对上的多个候选并列保留，不自动排序为唯一解释。
3. 只有调用方显式提供组合桥接关系、桥接范围和桥接证据，才产生 CompositeProposal。
4. 组合结果仍是 HUMAN_REVIEW，不升级为事实、因果或类属证明。

## 2. 关系轴不是同一尺度

| 关系轴 | 主要问题 | 不允许直接推出 |
|---|---|---|
| morphological | 外形、形态特征是否对应 | 结构/功能相同 |
| structural | 部件、角色、组织关系是否对应 | 机制相同 |
| functional | 在指定任务下是否产生相近作用 | 实现机制相同 |
| process_mechanism | 过程步骤、作用路径是否对应 | 因果已被验证 |
| temporal | 状态变化、先后与节律是否对应 | 跨尺度时间规律 |
| situated | 主体、位置、任务、环境条件是否对应 | 脱离情境的普遍规律 |
| symbolic_normative | 象征、制度或规范关系是否对应 | 经验因果关系 |

关系轴采用 M8 的关系族命名，目的是与既有基准对齐；不意味着这些轴在古籍中以现代分类方式存在。

## 3. 竞争：并列，而非强制选一

group_competing_views 仅按同一有序观察对分组，返回多个候选 ID。它不计算统一分数、不做赢家通吃，也不把不同轴的证据互相抵销。

例如，同一器物与生物结构可能：
- 形态上相似；
- 结构角色部分对应；
- 功能上在某一任务相近；
- 但过程机制完全不同。

正确输出应保留这些局部判断并列存在。功能证据不能替机制证据背书；形态反例也不必然否定功能对应。

## 4. 组合：必须有显式桥接

compose_views 不是简单把多个相似标签拼起来。它要求：

- 至少两个候选，且候选来自同一有序观察对；
- 每个候选的关系轴不同，重复轴必须先完成内部证据协调；
- 桥接声明准确列出全部且仅列出参与组合的候选 ID；
- 桥接有明确关系、适用范围、理由和证据引用；桥接证据必须去重，且不得复用成员视图本身的证据引用；
- 桥接范围必须与所有成员候选的共同适用范围相交；
- 组合结果只生成 CompositeProposal，状态固定为 HUMAN_REVIEW。

这套约束只保证组合提案可追溯、范围不明显冲突；它不证明桥接关系真实、证据独立或组合具有涌现性质。

## 5. 非单调性与动态情境

新增证据、反例或情境改变时，不应在旧组合上直接累加“支持分”。调用方应重新构建候选视图与桥接声明：
- 关键情境条件失效：撤销该情境下的候选适用性；
- 反例只击中某一关系轴：局部修订该轴，不自动连带否定其他轴；
- 桥接证据失效：撤销组合提案，但可保留成员视图；
- 新关系轴出现：新增并列视图，不覆盖既有记录。

当前 v0.1 不提供持久化版本账本，也不自动执行上述撤销；这些是后续版本治理接口要求。

## 6. 与现有模块的关系

观察与取征 → 候选生成 → M9 多视角拆分 → M3 竞争解释 → M4 条件干预 → M5 主动观测 → 推论操作审计 → M9 显式组合 → M8 留出评估。

这是可配置的研究流水线，不要求每个任务机械经过所有步骤。尤其是文本训诂、规范类比和经验因果任务，必须选择各自适当的证据层。

## 7. 原典研究启发与解释边界

- 《周易·系辞传》“引而伸之，触类而长之”：提示由局部取类向更大结构扩展，但不能直接等同于现代组合算法。
- 《周易》时、位、变：提示关系解释应附着于具体情境与状态，不应把一个对象永久绑定单一象类。
- 《墨子·小取》“其然也同，其所以然不必同”：要求将结果对应与生成机制分开。
- 《荀子·正名》关于“同状而异所”等辨析：要求把可见形态与对象身份/所在条件分开。
- 《淮南子·说林训》异类譬喻：允许借譬理解关系，但不把譬喻本身当作跨域机制证据。
- 《庄子·齐物论》视域转换：提醒描述与分类可能依赖观察立场；本项目把视域显式化为情境条件，而非预设单一绝对观察者。

以上是工程设计的古典思想参照，不是声称原典已经提出 M9 数据结构。

原典入口与文本层说明：
- 《周易·系辞上传》“引而伸之，触类而长之”见第九章传文；应与前文“分而为二”“四营而成易”“十有八变而成卦”连读，不宜截取成脱离筮法语境的泛化口号。参见 https://zh.wikisource.org/wiki/周易/系辞上传 及相关古籍影印、注疏入口。
- 《墨子·小取》传本文字存在校勘问题。王引之校补“其然也同”及“所以取之”等文字，孙诒让《墨子间诂》又保存异文与训释；工程上应保留版本见证，不把某一数字转录固定成唯一底本。参见 https://zh.wikisource.org/wiki/墨子/小取 、https://ctext.org/mozi-jiangu/xiao-qu/zh 及《小取》篇新诂 https://zh.wikisource.org/wiki/《墨子·小取》篇新诂 。
- 《荀子·正名》“物有同状而异所者，有异状而同所者”应连同“状同而为异所者……二实”“状变而实无别……谓之化”理解。它涉及名实辨别、个体所在与对象连续性，不应简化为现代视觉特征分类。参见 https://zh.wikisource.org/zh-hans/荀子/正名篇 。


## 8. 验证计划

新增测试覆盖：
- 多轴竞争保持并列；
- 显式桥接才可组合；
- 桥接成员缺失/多余；
- 观察对不一致；
- 重复关系轴；
- 适用范围不相交；
- 桥接证据缺失、重复或复用成员视图证据；
- 证据轴与候选轴错配。

测试通过只说明契约实现符合这些边界，不证明多视角类象在真实任务上提高准确率。下一步需将 M9 接入 M8 的分轴留出基准，按关系轴、来源谱系、跨域程度分别报告覆盖率、错误率和弃权率。
