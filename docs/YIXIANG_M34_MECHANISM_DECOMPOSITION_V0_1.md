# M34：类象组合的因果机制分解与跨情境效应异质性 v0.1

## 1. 目标与边界
M33 建立干预、研究单位、匹配比较和因果主张的审计契约。M34 推进到机制分解：整体效应、直接效应、中介效应、成员交互和条件效应必须对应不同 estimand 与识别假设。本原型只审计声明结构，不估计因果效应、不识别真实机制、不证明类象理论有效。SHAP、attention、特征重要性等预测性 attribution 不得直接解释为因果贡献。

## 2. 古典材料：思想入口而非现代因果理论
- 《墨子·小取》：“其然也同，其所以然不必同。”同果异因限制由结果相似直接迁移机制。
- 《墨子·经说上》以“小故”“大故”讨论条件关系；其文本语境与现代必要/充分因果条件并不完全等价。
- 《墨子·经下》区分“物之所以然”“所以知之”“所以使人知之”，可作为对象机制、认识证据和表达说明分层的研究入口。
- 《荀子·正名》关于同状异所、异状同所及征知的论述，提示对象、感官、分类和情境条件不可混同。
这些是原典语句的现代研究启发，不是古人已经提出 SCM、潜在结果或中介分析。

## 3. 估计对象
区分总效应（TE）、控制直接效应（CDE）、自然直接/间接效应（NDE/NIE）、干预式间接效应、析因交互对比和条件平均处理效应（CATE）。每个 estimand 记录目标总体、结果尺度、识别策略、假设和预注册引用。自然直接/间接效应必须单列中介规格，并显式记录处理后中介—结果混杂与 cross-world 假设；存在处理诱导混杂时，常规自然效应识别可能失效，应考虑干预式间接效应或明确降级。

## 4. 析因交互
二因子 A、B 的 2×2 设计，四个条件结果为 Y00、Y10、Y01、Y11。加性尺度交互对比为 Y11 - Y10 - Y01 + Y00。该对比依赖结果尺度、处理版本、分配设计和识别假设。零加性交互不等于没有非线性、机制或其他尺度上的交互；缺少四个条件单元时不得补造交互值。

## 5. 跨情境异质性
情境分层至少记录对象家族、情境家族、测量工具和目标总体。区分真实 effect modification、样本选择/失访造成的构成变化、测量不变性破坏、机制结构改变、估计不确定性与偶然异质性。CATE/子组发现、效应估计和最终验证必须使用隔离的数据划分；不得用同一发现集挑选子组并宣称独立验证。本版只检查数据分割声明，不执行统计估计。

## 6. 机制路径与证据
MechanismPath 只保存候选路径及边证据。路径完整不等于机制已识别。需对照竞争路径、反例、时间顺序、处理后混杂和跨情境复现。测量不变性审计必须比较至少两个情境层，并保留测量工具与审查证据。

## 7. 原型对象
prototype/yixiang_mechanism_decomposition_m34.py 提供 EffectEstimand、EffectEstimate、MechanismVariable、MediatorSpec、MechanismPath、FactorialCell、ContextStratum、MeasurementInvarianceAudit、AttributionRecord 和结构审计函数。

## 8. 测试与限制
专项测试覆盖中介假设缺失、处理后混杂审计、cross-world 假设、析因单元、重复因子、未知 estimand、发现集复用、测量不变性、机制路径和 attribution 越权。尚未实现真实数据估计器、标准误/置信区间计算、DAG 调整集求解、自然/干预式中介效应估计、HTE 学习器、敏感性分析、失访权重、跨情境 transportability 估计及 M31/M32/M33 自动端到端适配。所有有效审计结果仍为 review_required，causal_truth_established 恒为 false。
