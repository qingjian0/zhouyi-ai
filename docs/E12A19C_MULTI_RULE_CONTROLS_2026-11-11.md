# E12-A19-C：多规则联合推理与随机结构对照

日期：2026-11-11  
状态：研究原型与专项测试已提交；实验结论仍需多种子/OOD 基准，不代表架构优势。

## 目标

A19-B 比较每个结构家族的单个候选规则。A19-C 增加受预算约束的多规则联合模型，回答多个局部规则能否共同提供单规则无法提供的信息，并加入保留规则激活频率的随机化空模型。

## 算法

1. 复用 A19 的训练集候选提案和共享图特征缓存。
2. 以轮询方式合并稀疏合取、类型路径、分叉/汇合三类候选，避免候选预算被先枚举的单一家族占满；总候选数不超过 max_candidates。
3. 仅使用训练标签计算每条规则的经验互信息，按分数降序、候选 key 升序确定性选择至多 max_rules 条。
4. 用固定步数、L2 正则的多类别 softmax/logistic 模型联合拟合规则激活向量。
5. 另训练单规则模型、训练集类别先验基线。
6. 随机化对照对每个规则列分别在训练集和验证集内部置换，保留该规则在各 split 的激活数量，但破坏样本级规则组合关系；用相同优化器、步数、规则数和正则训练。

## 防泄漏约束

- 候选来自训练结构；规则排序和参数拟合只读取训练标签。
- validation 结构用于计算候选激活，validation 标签只传入最终评分函数。
- 专项测试将 validation 标签整体翻转，要求拟合权重与训练拟合摘要保持不变。
- locked-test 只保留 ID 元数据，不接受 locked-test examples 或 labels。
- 本原型不访问 E12-A8 evaluator 的隐藏标签，也不签发 E12-A10 receipt，不改变 E12-A7 认知状态。

## 解释边界

随机化对照是“边际激活率保留、样本级关联破坏”的 null control，不是随机语法的完整替代；它没有保持图拓扑、节点度数或关系语义。多规则模型是小型可解释判别器，不是新的生成式基础模型，也不构成对 Transformer 的比较。

候选提案仍可能有大量相关/重复规则；互信息排序存在有限样本偏差；固定优化步数可能欠拟合或过拟合；validation 指标仅用于报告。正式结论还需预注册多 seed、组合 OOD、关系 OOD、状态转移 OOD、置信区间和多重比较校正，并与同预算随机语法、置换语义标签、传统易象语法对照。

## 下一阶段验收

- XOR/高阶协同任务：单规则无法表达时，多规则模型须在预注册测试上稳定获益。
- 单规则任务：增加规则数不得系统性恶化校准与泛化。
- validation-label mutation 不影响训练参数。
- 行序、候选排序与相同 seed 下结果确定。
- 随机化对照保持每列激活频率，并可复现。
- 候选、规则数、优化步数均受硬预算约束。
