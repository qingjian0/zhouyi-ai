# M48：因果发现比较基线与消融评估 v0.1

M48 提供可审计的结构指标：TP/FP/FN、precision、recall、F1、SHD，并按方法和消融条件分组聚合。反向边按一次删除加一次新增计入 SHD；当前未实现 SID、CPDAG/等价类评分、因果效应误差或不确定性区间。

建议比较组：
- 随机图/随机策略基线；
- 相关性或简单回归基线；
- 经典约束/评分型因果发现方法；
- 主动干预设计基线；
- Zhouyi-AI 完整系统；
- 移除类象关系、证据来源、反例审计、跨情境约束、序贯规划的消融组。

依据：因果发现评估文献指出数据规模、线性性、噪声分布会改变算法表现；常见结构指标包括 TPR/FPR、SHD、SID。CausalTime（ICLR 2024）展示了将真实时间序列特征与可量化真值图结合的基准构造思路。

古典约束：《墨子·小取》要求“殊类异故，则不可偏观也”；因此不能挑选单一有利场景或只报告单一指标。

限制：当前仅有指标和聚合函数，没有实现任何比较算法；平均值不替代置信区间、配对检验、跨 seed 稳健性或多重比较校正。
