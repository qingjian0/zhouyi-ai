# E02-I：证据门控的关系结构演化

## 研究问题

关系被发现后，系统能否在后续数据窗口中识别成员增减、规则变化和关系消失，并在不被单次噪声诱导的前提下更新结构？

## 实验设计

- 每个时间窗口重新从训练数据发现候选，不把隐藏成员、规则或变化时刻传给发现器。
- 候选规则沿用 E02-H 的有限语言：8 个二值特征上的 2/3 元子集完整真值表。二元候选以 Gate 准确率门控；三元候选还必须超过最佳二元真值表基线至少 0.05。
- 每个窗口还在 Gate 集上单独评估当前持久关系；候选失败不能直接推导当前关系失效，当前关系退化/退役必须依据它自己的 Gate 表现。
- 每个窗口使用互不重叠的训练集、Gate 集和锁定测试集；训练集负责候选发现，Gate 负责结构决策，测试集只在决策后评估泛化表现，绝不反馈给状态机。
- 隐藏目标成员与真值表仅用于实验结束后的精确结构评分，不传入发现器或状态机。
- 每个实验 5 个窗口，20 个种子/场景，共 140 个实验；每个窗口训练 1024、Gate 512、测试 512 条样本。
- 关系变化必须连续两个窗口得到相同的新结构签名，才允许 RECONFIGURE。
- 单个 Gate 失败只触发 DEGRADE；连续两个失败才触发 RETIRE。
- 持久关系必须重新满足 Gate 门槛：二元关系要求准确率至少 0.75；三元关系还要求相对同窗口最佳二元基线至少提升 0.05。

## 七种预注册场景

1. stable：成员与规则不变。
2. member_add：关系从二元成员增加为三元成员。
3. member_remove：关系从三元成员减少为二元成员。
4. rule_change：成员不变，规则真值表取反。
5. transient_rule_change：规则仅在一个窗口反转，随后恢复原规则。
6. disappear：关系信号消失，标签成为独立随机变量。
7. never_present：从第一个窗口起就不存在关系，作为无关系负对照。

## 状态迁移

| 当前证据 | 结构动作 | 含义 |
|---|---|---|
| 首次有效候选 | CREATE | 建立关系 |
| 与当前签名相同 | KEEP | 保留当前结构 |
| 首次观察到新签名 | HOLD_PENDING | 暂存，不改变持久结构 |
| 连续确认相同新签名 | RECONFIGURE | 创建新版本并替换旧版本 |
| 首次 Gate 失败 | DEGRADE | 降低当前关系状态，不删除 |
| 连续 Gate 失败 | RETIRE | 退役关系 |

## 主要指标

- 稳定关系误重配置率；
- 单窗口瞬态变化误重配置率；
- 成员增加/减少的重配置召回率；
- 同成员规则变化的重配置召回率；
- 消失关系的退役召回率与延迟；
- 每次状态变化前所需确认窗口数；
- Candidate Gate：本窗口候选在 Gate 集上的准确率。
- Current Gate：当前持久关系在 Gate 集上的准确率，独立决定 ACTIVE / DEGRADED 状态与退役计数。
- Candidate Test：本窗口候选在锁定测试集上的准确率。
- Persistent Test：状态机完成本窗口动作后，当前持久关系在同一锁定测试集上的准确率；若已退役则记为无持久关系，不伪造准确率。
- Gate 准确率、独立测试集成对基线差值、退化窗口率、持久关系覆盖率、候选搜索成本。
- 训练/Gate/测试样本 ID 两两不相交。

## 证伪标准

- 稳定场景频繁重配置：状态机对噪声过敏。
- 变化场景长期不重配置：系统无法跟踪结构演化。
- 消失场景不退役：旧关系无法遗忘。
- never_present 场景出现 CREATE：系统会在纯噪声中制造持久关系。
- 变化只在单个窗口出现就触发重配置：重复确认机制失效。

## CI 结果

完整结果见 [E02-I CI 结果报告](E02I_CI_RESULTS_2026-11-10.md)。GitHub Actions run 42821097953 全部成功：7 场景 × 20 seeds × 5 windows；稳定保持、成员增减、规则变化、瞬时冲击、关系消失和 never-present 负对照均达到本协议预设的 20/20 验收结果。160 个无关系窗口的 false CREATE 为 0。该结果仅支持当前有限布尔合成协议。

## 限制

这是有限布尔规则空间上的合成实验；变化类型与两窗口确认策略均预先定义。它不是开放世界关系演化，也没有学习变化机制本身。候选生成仍是穷举子集与真值表搜索，不是开放式创造关系。独立测试集分别评估本窗口候选与状态机决策后的持久关系；测试数据不反馈给状态机。最终结构正确率仍依赖生成器隐藏目标的事后审计。20 个种子/场景属于初步验证规模，不能替代更大规模重复实验、置信区间和多重比较校正。
