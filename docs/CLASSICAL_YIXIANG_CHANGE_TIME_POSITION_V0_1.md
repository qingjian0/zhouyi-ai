# 《周易》“变—通—时—位”与动态类象研究札记 v0.1

## 1. 研究问题

类象不能只描述静态相似关系。先秦两汉易学文本及后世经学解释还涉及变化、时机、位置、阶段和功能转化。本札记尝试把这些概念拆开，避免将“变”简单等同随机变化、把“通”简单等同成功、把“时位”简化成时间戳。

研究遵循：经文、汉魏注、唐疏、宋明解释和现代工程抽象分别保存。当前数字文本和点校本可作为检索/校勘入口，不能代替对更早版本和出土材料的独立审查。

## 2. 经文结构：变不是单一事件

### 2.1 《系辞下》“穷则变，变则通，通则久”

经文将“穷—变—通—久”排列为一个有方向的过程结构。紧邻段落还说“通其变，使民不倦”“神而化之，使民宜之”。唐代《周易正义》解释其人事应用时，以器用随时调整为例，强调变化的目的在于使事物适宜，而不是为了变化本身。

**项目解释（非古义替代）**：
- 穷：既有结构在当前条件下受阻或达到边界；
- 变：结构、策略、关系或状态发生改变；
- 通：新的组织方式恢复可行的作用路径；
- 久：新结构在后续条件中维持一定稳定性。

四者必须作为不同状态/事件记录。不能把“发生了变化”直接判成“变通成功”，也不能把短时有效直接判成“可久”。

### 2.2 “变通者，趣时者也”

“时”不是单纯的日历时间。它可能涉及阶段、条件窗口、时机和行动适宜性。项目需要把：
- 绝对时间；
- 相对顺序；
- 阶段/周期；
- 条件窗口；
- 决策时机；
分开存储。

若一项类象只在特定阶段成立，系统应将阶段条件放进 scope，而不是将它误学成无条件规律。

### 2.3 《说卦》“观变于阴阳而立卦，发挥于刚柔而生爻”

这段话至少包含两个层次：先观察阴阳之变以立卦，再发挥刚柔以生爻。经文没有直接给出现代数据结构，但它提示“观察变化”“建立整体状态表示”“展开局部位置”并非同一个步骤。

《说卦》另以“分阴分阳，迭用柔刚”说明六位成章。项目应分别保存：
- 阴阳：状态/对待的编码维度；
- 刚柔：爻的性质维度；
- 位：结构中的位置；
- 时：该位置所处的阶段/时机；
- 变：状态或关系转移。

这些是现代工程拆分，不应反向宣称为古代术语的唯一释义。

## 3. 《说卦》八卦功能序列：不是名物词典

《说卦》有“雷以动之，风以散之，雨以润之，日以烜之，艮以止之，兑以说之，乾以君之，坤以藏之”，并进一步描述万物从震、巽、离、坤、兑、乾、坎、艮的时序性变化。

这组文本包含动、散、润、烜、止、说、君、藏等不同功能谓词。它们不能被压扁为“震=雷、巽=风”等静态实体词典。对类象计算更有价值的研究问题是：

1. 一个象如何同时关联形态、功能、时序和位置？
2. 同一功能是否可由不同结构实现？
3. 一个象的功能是否会随阶段改变？
4. 功能相同但机制不同的对象，何时可以类推，何时必须拒绝？
5. 八卦序列是否表达一种特定解释传统，还是可由不同传本/注家给出其他次序？

## 4. 版本与解释史中的重要分歧

### 4.1 “易穷则变，变则通，通则久”的异文

《周易正义》点校文本记录：石经、岳本、闽本、监本、毛本作“易穷则变，变则通，通则久”；《释文》另记一本作“易穷则变通则久”。这不是无关紧要的标点差异：后一读法可能改变“变—通”之间的句法切分。

当前处理：
- 主记录保留多见本的分句读法；
- variant_notes 记录《释文》所见异文；
- 不将异文自动改写成单一确定文本；
- 后续需核对《经典释文》具体版本、石经拓本和宋本系统。

### 4.2 “观变于阴阳”的解释分歧

明代熊过《周易象旨决录》汇录不同解释：有人将“观变”联系揲蓍十八变后阴六、八与阳七、九的变化；有人反对把蓍数解释强加于“观变”句。该材料明确显示，后世注家对于“观变”的操作对象和层次并不一致。

工程上不能把某一家注解固化成唯一算法。应保留“观变对象”候选：阴阳状态、卦画结构、蓍数过程、自然变化等，并让版本/注家证据决定各解释的适用范围。

### 4.3 《说卦》篇章次序与传本问题

明代《周易象旨决录》引《隋书·经籍志》相关说法，讨论秦后《说卦》篇章散佚及传本篇数问题，并记录韩康伯本、费直传本等相关争论。此处是明代作者转述的文献史线索，不可直接当作秦汉传本实物证据；仍需回查《隋书·经籍志》原文及早期目录。

## 5. 动态类象的数据结构建议

建议将静态类象节点和动态转移事件分离：

- `state_id`：一个时点/阶段的结构状态；
- `position`：卦位、层级位置或系统角色；
- `time_scope`：有效时间窗口；
- `phase`：阶段标签及其证据；
- `conditions`：触发/约束条件；
- `transition_type`：维持、渐变、反转、跃迁、阻塞、恢复等；
- `transition_evidence`：观测证据；
- `outcome_status`：是否恢复可行、是否持续、是否仅短期有效；
- `interpretation_layer`：经文、注、疏、现代研究或模型推论。

不应直接把卦变等同现实系统的因果转移。卦画转换是形式结构；现实因果需要独立数据和识别假设。

## 6. 对 M5/M6 的直接启发

- M5 的观测候选应能区分“结构已穷”“暂时受阻”“阶段尚未到来”和“观测尺度不匹配”。
- M5 应考虑观测时机：同一测量在不同阶段可能有不同区分力。
- M6 只有在控制阶段、位置和条件后，仍出现可复现残差，才应提出新象候选。
- 若残差仅由阶段错位或条件缺失解释，应修正 scope/conditions，不要创建新类别。
- “通”应有独立结果指标；不能用模型内部的高分自证已经变通。
- “久”需要时间跨度上的留出验证，不能以一次成功观察确认。

## 7. 现代架构映射与可证伪实验

提出以下实验，不预设易象理论必然优于一般动态系统模型：

1. **去时位消融**：去除 phase/position，仅保留静态特征，比较跨阶段泛化。
2. **时机消融**：M5 不考虑阶段信息 vs 纳入阶段条件，比较单位成本信息增益。
3. **错误变通测试**：制造短期改善但长期退化的样本，检验系统是否把“变”误判为“通/久”。
4. **阶段错位测试**：相同结构在不同阶段呈现不同表象，检验是否误报新象。
5. **注疏谱系隔离**：训练/验证/测试按作品和注疏谱系隔离，防止同一解释被不同转录重复泄漏。
6. **不确定性保留**：经文异文或解释冲突未决时，检验系统能否并列假设而非强制选定。

## 8. 当前结论

本轮最重要的理论结论是：**类象不是静态相似映射，而是受时、位、条件和变化路径约束的关系结构。**

“穷—变—通—久”可以成为动态过程研究的文本入口；“观变—立卦—发挥刚柔—生爻”可以启发从整体状态到局部位置的建模；但两者与现代算法之间只能建立可检验的工程映射，不能宣称古籍已经提出现代状态空间模型、主动学习或因果推断。
