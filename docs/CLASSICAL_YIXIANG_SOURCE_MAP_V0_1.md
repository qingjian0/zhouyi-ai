# 传统类象研究文献地图与校勘计划 v0.1

> 研究定位：以清以前文献为主体，清代及以后文献用于校勘、辑佚、目录补漏与学术史审查。本文是调查框架，不声称已完成所列全部典籍的逐字校勘。

## 一、研究原则：先分层，后归纳

传统类象不能缩减为《周易》八卦取象表。需要研究古人如何观察、命名、分类、比类、取譬、推类、辨异、察时、定位、推变，以及这些方法在不同知识领域中的具体运用。

每条研究记录必须分开保存五层：

1. 原典层：作者/时代（有争议则标注争议）、篇名、原文、上下文、文本版本。
2. 传本层：版本、篇章异同、脱讹衍倒、出土文献与传世本关系。
3. 注疏层：注家、时代、解释原文、与其他注家的异同。
4. 现代研究层：校勘、训诂、思想史、科学史研究；记录书目信息和论证。
5. 计算抽象层：从原文提出的结构假设、形式化表达、反例、可检验任务。

不得把现代模型术语反向当作古义。相似词不等于相同概念；后世体系不得无标记地倒灌到先秦文本。

## 二、文献分区与优先级

### A. 易学核心文献（最高优先级）

| 文献群 | 重点文本 | 类象研究问题 |
|---|---|---|
| 经文 | 《周易》卦爻辞 | 物象、事象、情境、行动、时机、判断如何关联 |
| 传文 | 《彖传》《象传》《文言传》 | 卦体、爻位、德性、时位与象义如何组织 |
| 易传 | 《系辞上》《系辞下》 | 观象、制器、变易、推移、刚柔、时位、象数关系 |
| 易传 | 《说卦传》 | 取象、分类、方位、身体、家族、动物、器物等多重映射 |
| 易传 | 《序卦传》《杂卦传》 | 卦序叙事、相反相杂、关系性分类 |
| 早期材料 | 马王堆帛书《周易》及相关易学材料、上博楚简等已公布出土材料 | 早期文本形态、异文、卦序和解释传统差异 |

重点避免：把《说卦》象例当成无条件、唯一、跨时代不变的映射；把后世象数体系直接认定为经文本义。

### B. 先秦名辩、逻辑与认识论（最高优先级）

- 《墨子·小取》《墨子·大取》：类、故、理、譬、侔、推类与类推边界；考察何时可推、何时不可推。
- 《墨子·经上》《经下》《经说上》《经说下》：名实、同异、故、法、类及论证结构；注意经说文本训读争议。
- 《荀子·正名》：名、实、约定、分类与正名。
- 《荀子·解蔽》：认知偏蔽、整体把握与局部视角。
- 《荀子·非相》：形貌、征验与判断边界，研究不可由外形轻率推出内在属性。
- 《公孙龙子》相关篇章：坚白、离坚白、指物等名辩问题；版本、真伪和篇章层累须单独标注。
- 《庄子·齐物论》《天下》：彼此、是非、分类边界和学派方法反思，不能直接等同现代相对主义。

研究重点：相似关系、同类关系、因果关系、定义关系、指称关系必须分开；类推的有效范围和失效条件必须进入模型。

### C. 先秦诸子与整体变化思想（高优先级）

- 《老子》：有无、反复、柔弱、对待、变化等论述；逐章按语境研究，不先验套用阴阳二分。
- 《庄子》内篇及外杂篇：物化、齐物、寓言、技艺经验、视角转换；篇章层次需注明。
- 《管子》相关篇章，如《内业》《心术》《白心》《四时》：气、心、时序、秩序与治理；《管子》为复合文献，不宜一概归于单一作者。
- 《吕氏春秋》：《有始》《应同》《十二纪》及相关篇章，研究时序、分类、感应和政治—自然秩序。
- 《淮南子》：天文、时则、地形、精神、原道等篇，研究宇宙秩序、时空分类、变化与类比。
- 《春秋繁露》：阴阳、五行、灾异、感应等思想史材料；审查篇章真伪、层累和作者归属问题。
- 《韩非子》：参验、形名、势、术、法及因情境施策；研究判断与反馈，不把政治术语泛化为自然规律。

### D. 天文、历法、数术与时空秩序（高优先级）

- 《周髀算经》：天文、几何、测量和数理模型。
- 《灵宪》（张衡）及相关天文文献：天体结构与观测解释。
- 《史记·天官书》《汉书·天文志》《后汉书·天文志》：天象记录、分类体系与历史解释；区分观测记录和占验解释。
- 《汉书·律历志》：律、历、数与制度化表达。
- 《九章算术》及刘徽注：算法、关系、变换、问题结构；不把数学比喻当作古代算法原义。
- 《太玄经》：符号结构、数序和宇宙论，作为与易学比较的独立系统。
- 《京房易传》及汉代易学材料：纳甲、卦气等后起系统须标明时代层次。
- 《焦氏易林》：卦变、占辞和象类材料；文本传统与编纂问题需校核。
- 《黄帝内经》运气七篇等：时序、气候、身体系统关联；严格区分古代理论体系与现代医学事实。

### E. 礼制、政制、社会分类与人事类象（高优先级）

- 《周礼》《仪礼》《礼记》：礼制分类、角色、空间、器物、时序与制度关系。
- 《左传》《国语》《战国策》：政治事件、人物判断、譬喻、征兆与历史叙事；区分叙事修辞和事实因果。
- 《史记》各世家、列传及《汉书》相关篇章：人物、制度、事件的分类和历史解释。
- 《白虎通义》：汉代名物制度、礼制与宇宙论分类。
- 《论衡》：王充对谶纬、灾异和感应说的批评，是检验传统类象推论边界的重要反方材料。

### F. 医药、养生与身体系统（高优先级，独立审查）

- 《黄帝内经·素问》《灵枢》：脏腑、经络、气血、四时、病机等理论结构。
- 《难经》：脉、经络、脏腑等问题的解释体系。
- 《神农本草经》及历代本草传统：药物分类、性味、功用与经验记录。
- 《伤寒论》《金匮要略》：证候组合、病程、方证关系与辨证过程。
- 《针灸甲乙经》《脉经》：身体结构、诊断分类与操作体系。

研究边界：研究历史文本的分类、推理结构和知识史，不把传统医疗类象直接宣称为现代医学验证结论；现实健康决策必须采用现代医学证据标准。

### G. 兵学、农学、地理、水利、工艺（高优先级）

- 兵学：《孙子兵法》《吴子》《司马法》《六韬》《三略》《孙膑兵法》：形势、虚实、奇正、势、因敌变化、地形与时机。
- 农学：《齐民要术》《农书》《王祯农书》《农政全书》：物候、土壤、作物、季节、技术流程与条件关系。
- 地理与水利：《山海经》（文本层累须审查）、《水经注》《禹贡》及历代地理总志：空间关系、地形、水系、区域分类。
- 工艺：《考工记》《天工开物》：材料、形制、工序、功能、约束与技术适配。
- 生态与物候：历代岁时记、农书、地方志、博物类著作；保留地域和年代，不将局部经验普遍化。

### H. 博物、名物、训诂与类书（高优先级辅助材料）

- 《尔雅》《方言》《释名》《说文解字》：名物、词义、分类和训诂。
- 《广雅》《玉篇》《经典释文》：词义、音义、文本解释。
- 《本草纲目》《太平御览》《艺文类聚》《初学记》《册府元龟》等：汇集材料的线索价值；必须回溯引用原始出处，不能把类书转引当作原典。
- 历代名物、器物、舆服、地志、岁时和博物著作：建立跨领域类象案例索引。

## 三、时代分层与清代以后补缺规则

### 先秦至两汉：核心概念形成层

重点：取象、比类、名实、推类、阴阳、五行、时序、天人关系、形名与制度分类。必须区分先秦文本、汉代解释和汉代新体系。

### 魏晋南北朝至隋唐：注释、玄学、佛道交流与知识重组层

重点关注王弼、韩康伯易注传统，孔颖达《周易正义》，陆德明《经典释文》，以及隋唐医药、天文、地理、类书、道教文献。研究概念如何被重新解释和系统化。

### 宋元：图书易学、理学与象数体系深化层

重点关注周敦颐《太极图说》、邵雍相关著作、程颐《伊川易传》、朱熹《周易本义》及宋元易学诸家。将象数、义理、图书之学分流记录，不合并成单一传统标准体系。

### 明代：汇通、注疏与应用体系层

重点关注来知德易学、明代医药与本草、农政、兵学、地理和博物著作。考察既有理论如何进入具体应用，同时识别后世附会。

### 清代及以后：查缺补漏与审查层

主要任务：
1. 校勘先秦两汉至明代文本，检查版本、异文、脱漏和误引；
2. 搜索辑佚、出土文献整理和古籍目录，补充失传材料线索；
3. 对注疏谱系和作者归属进行学术史审查；
4. 利用清代朴学成果核对训诂、音韵、名物和版本；
5. 利用现代研究补充考古、科技史、医学史、思想史和文献学成果；
6. 将现代研究意见标为二级/三级证据，不覆盖原典本身。

清以后文献不是被排除，而是不作为古义的默认起点。若清代校勘发现早期版本差异，必须回到原典传本链条核验。

## 四、跨文献类象分析框架

每个案例至少回答：

1. 所观何物：自然物、器物、身体、社会角色、事件或制度？
2. 取象维度：形态、属性、功能、关系、过程、时空、趋势中的哪些维度？
3. 比类依据：共同特征是什么？哪些差异被忽略？忽略是否合理？
4. 关系保持：源域关系在目标域是否仍成立？是否只保留表面相似？
5. 情境边界：何时、何地、何种位置、阶段和环境下有效？
6. 变化机制：条件改变时，象义如何变化？是否有反例和例外？
7. 论证类型：定义、类推、譬喻、因果、征兆、规范判断，还是修辞？
8. 证据等级：原典直证、注疏解释、现代考证、工程假设分别标注。
9. 竞争解释：是否存在其他合理读法？是否允许未决？
10. 可计算任务：能否转成结构识别、关系保持、条件迁移、反例拒绝或预测任务？

## 五、文献数据结构建议

每条来源至少有以下字段：

- source_id：稳定标识。
- work_title、chapter_title：书名与篇章。
- author_attribution：作者/归属及争议说明。
- period、date_range：时代与年代范围。
- text_layer：经、传、注、疏、辑佚、现代研究。
- edition_id：底本、版本、影印/整理本信息。
- passage_locator：卷、篇、章、页码或简帛编号。
- original_text：原文及必要异文。
- context_before、context_after：上下文。
- annotation：训诂与注释，注明注家。
- claim_type：类推、譬喻、分类、因果、征兆、规范等。
- image_dimensions：形态、属性、功能、关系、过程、时空、势等。
- mapping_claim：明确写出源域—目标域映射。
- conditions、counterexamples、alternatives：条件、反例、竞争解释。
- evidence_grade、review_status：证据等级与审查状态。
- bibliography、license_note：书目与使用许可。

原文、校勘意见、注家解释和模型生成摘要必须分字段保存，禁止覆盖原文。

## 六、证据等级与审查状态

建议证据等级：

- A：原典可核——有可靠版本、明确篇章和上下文。
- B：传本/注疏支持——有明确注家或版本依据，但解释存在分歧。
- C：现代考证支持——有可追溯学术研究，尚需回到原始材料。
- D：工程假设——为计算实验提出的结构化解释，尚未获得文献或经验验证。
- X：存疑/争议——作者、篇章、版本、训读或解释有实质争议。

审查状态：unreviewed、transcribed、edition_checked、context_checked、commentary_compared、expert_reviewed、disputed。不能因模型重复生成而提高证据等级。

## 七、首轮实际研究顺序

1. 先完成《周易》经、传分层和关键版本目录；对《系辞》《说卦》逐段建立原文—注疏—争议表。
2. 并行处理《墨子·小取》《荀子·正名》《荀子·解蔽》，提取类推、名实、分类和认知偏差的论证形式。
3. 加入《吕氏春秋》《淮南子》《论衡》，形成感应/类同主张与反对意见的对照。
4. 建立天文历法、医药、兵学、农学、地理和工艺的领域案例集，所有映射都记录地域、年代、情境。
5. 再汇入魏晋隋唐、宋元明注疏和应用体系；清代以后用于校勘、辑佚、补漏和审查。
6. 先以少量高质量可核条目建立标注规范，再扩充语料；不以书目数量或自动抽取条数作为研究成果。

## 八、禁止的研究捷径

- 不把八卦象例表直接当成完整类象本体。
- 不把同属一类直接推成具有相同因果机制。
- 不把阴阳、五行、气、象、数、理直接翻译成现代物理/数学实体。
- 不将不同朝代、不同学派、不同注本的说法混成单一结论。
- 不用现代百科或类书转引替代原典版本核验。
- 不把卦象、占辞或历史征兆作为现代自然科学/医学结论。
- 不用模型生成的伪引文、伪篇章、伪出处填充语料。
- 不以一个成功类比证明整个理论普遍有效；必须保留失败样本和拒绝条件。

## 九、与 Zhouyi-AI 计算研究的连接

本研究地图服务于以下可检验能力：

- 取象：从具体对象和事件中抽取多维结构，而非关键词匹配。
- 比类：在源域与目标域间保持关系，明确失配项。
- 辨异：识别表面相似但结构不同的对象，主动拒绝错误类比。
- 观变：跟踪阶段、时位、条件和趋势变化。
- 会通：跨领域组合多个局部类象，同时保留来源和边界。
- 参验：将古典论述转成可复现任务，允许负结果推翻工程假设。
- 新象：只把经独立证据复现的稳定结构升级为新类别。

本地图是研究目录与方法规范。逐条原文录入、版本校勘、注疏比较、语料标注和跨域实验仍需分别完成，不能将文献目录的建立等同于文献研究已经完成。
