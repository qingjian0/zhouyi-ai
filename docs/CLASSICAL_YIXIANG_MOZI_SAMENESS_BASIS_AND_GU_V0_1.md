# 《墨子·大取》《墨经》同异—类—故的多层判断结构 v0.1

## 研究定位

本专题把《大取》的多种“同”、多种“异”，与《经上》《经说上》的“类”“故”并读。目标不是把古代术语强行翻译成现代逻辑标签，而是为 Zhouyi-AI 建立一个保留原词、解释竞争、判断范围和证据层次的类象认知模型。

本文中的现代数据结构属于项目操作化，不代表先秦墨家已经提出相同的形式系统。

## 一、核心发现：同异判断必须带有根据与范围

《大取》列举重同、具同、连同、同类之同、同名之同、丘同、附同、是之同、然之同、同根之同；又讨论有非之异、有不然之异，以及同异相待的情况。

这些术语至少提示两个不可省略的问题：

1. **根据是什么？** 是对象、属性、部分—整体、名称、类别、判断真值、生成根源，还是其他关系？
2. **在哪个范围内同或异？** 是某个谓词、某种称谓、一个整体、一个时间点，还是一个具体论证目的？

因此，“A 与 B 相同”是不充分的记录。必须改写为：

A 与 B 在比较根据 R、谓词 P、范围 S 和条件 C 下相同；此判断不自动推出其他根据下也相同。

## 二、将同异判断拆成不同层次

以下是工程分析维度，不是对《大取》十种“同”的逐项定论。

| 判断维度 | 要回答的问题 | 典型错误 |
|---|---|---|
| 数量/重合 | 是一个还是多个？是否重复计数？ | 数量相同误作对象同一 |
| 属性 | 是否共享某个属性？ | 一项属性相同误作整体相同 |
| 类属 | 是否属于同一类别？ | 某一上位类相同误作所有下位性质相同 |
| 部分—整体 | 是整体、部分还是整体中的成员？ | 一指误作一人；局部误作全体 |
| 连属/结构 | 是否属于同一结构或关系网络？ | 相连误作同一实体 |
| 名称/指称 | 名称相同是否指同一对象？ | 同名误作同物 |
| 判断/真值 | 是、非、然、不然的判断是否相同？ | 同一对象误作同一判断 |
| 根源/生成 | 是否有共同根源或生成路径？ | 同源误作现状与性质完全相同 |
| 时位/情境 | 是否在相同时间、位置和条件下比较？ | 跨时跨境误判为矛盾或同类 |

系统应允许同一对象对在不同维度上同时“同”与“异”，而不把这种情况视为数据冲突。

## 三、《大取》例证的工程化解释

### 1. 长人、短人与貌

文本以长人、短人说明：在某个可见外貌方面可以相同，但在长短方面仍有差异。

工程要求：
- 属性判断必须绑定属性维度；
- 一个维度相同不能覆盖另一个维度的差异；
- 不允许把局部同一提升为实体同一。

### 2. 指与首、人之体

指与首都是人的身体组成部分，但指不是人，首也不是人。

工程要求：
- 显式区分 part_of、member_of、instance_of 与 identical_to；
- 部分属性不能自动继承为整体属性；
- 整体的名称不能无条件赋予其部分。

### 3. 杨木与桃木

文本可在“木”这一共同称谓或类别层面讨论其同，同时仍保留具体树种差别。

工程要求：
- 类属相同不意味着实例相同；
- 上位类别的共同性不能覆盖下位类别的差异；
- 分类必须允许多层级和多重继承，但继承规则必须明确。

### 4. 小圈与大圈

在圆这一性质上可以相同，在大小这一量值上不同。

工程要求：
- 属性等价必须带属性名；
- 连续量值差异不必导致类别差异；
- 类别相同不意味着数值相同。

### 5. 一尺与千里之不至

距离尺度不同，但在“未到达”这一谓词下可能有共同判断。

工程要求：
- 结果/谓词相同不代表机制相同；
- 同一否定结果不能抹去距离、过程和条件差异；
- 不能把同一谓词的适用结果误作同一因果解释。

以上例证见《墨子·大取》数字文本；具体字句、断句和术语训释仍须逐条对照影印本及校释。

## 四、“故”必须与“类”分开建模

《经上》有“故，所得而后成也”；《经说上》对小故、大故有进一步说明。现存数字文本、校释与现代研究对相关文字存在不同处理。

至少应区分：

- **类判断**：两个对象在哪个根据下可以归为一类？
- **条件判断**：某项条件是否为结果成立所必需？
- **充分根据判断**：哪些条件组合足以支持结果？
- **因果判断**：是否有证据说明某因素导致某结果？
- **论证根据**：某命题在当前论辩中凭什么成立？

不可把古文“故”无条件映射成现代逻辑的 premise、cause 或 sufficient condition。必须保留原文语境与解释者信息。

特别是“小故”相关文本，不能只把某一个数字转录读法硬编码为形式规则。应并列存储：
1. 原始数字见证的读法；
2. 校勘者的订补；
3. 注家的解释；
4. 现代学者的逻辑重构；
5. 项目自己的形式化假设。

例如《经说上》“大故”文字在《墨经校释》页面中可见孙诒让、梁启超等人的不同处理意见；不能将校改结果伪装成无争议原文。

## 五、对 Zhouyi-AI 的认知架构约束

### 5.1 不再使用无范围的 SAME 边

建议把同异判断保存为带范围的断言：

- subject_a
- subject_b
- sameness_basis
- predicate
- scope
- context
- time
- evidence_refs
- interpretation_refs
- confidence_status
- counterexample_refs

这里的字段是建议的数据契约，尚不代表当前仓库 Schema 已全部实现。

### 5.2 同异判断与类象迁移分离

同异判断只回答“在什么方面相同或不同”。

类象迁移还必须回答：
- 共同点与待迁移结论是否相关；
- 源域和目标域是否保留同一关系；
- 关键差异是否破坏迁移；
- 条件是否一致；
- 是否存在反例；
- 是否有独立证据。

因此，不能由“同类”直接推出“结论可迁移”。

### 5.3 将“故”接入 M4 和 M5

M4 条件干预：
- 移除一个必要条件；
- 改变一个条件的值；
- 比较单条件与条件组合；
- 区分必要条件、充分条件和相关条件。

M5 主动观测：
- 优先观测最能区分竞争解释的条件；
- 若争议是同名异实，优先核实指称；
- 若争议是结果同而机制异，优先观测过程；
- 若争议是小故/大故，优先测试条件组合，而非重复观察结果。

### 5.4 进入 M8 的对抗评估

至少增加以下负控：
1. 属性相同但实体不同；
2. 同名异物；
3. 同物异名；
4. 部分与整体混淆；
5. 上位类相同、下位类不同；
6. 结果相同、原因不同；
7. 尺度不同、谓词相同；
8. 时间条件不同导致表面矛盾；
9. 单一必要条件被误判为充分条件；
10. 多个条件组合才足以成立，却被系统忽略其中一项。

验收原则：系统必须保留比较维度和适用范围；不能因为相似度高而越过关系类型与条件门禁。

## 七、下一步校勘与研究任务

1. 对《大取》十种“同”逐条建立原文—版本—校释—现代解释四层对照。
2. 对《经上》《经说上》“故”“小故”“大故”逐条登记底本和校改差异。
3. 对读《经下》《经说下》关于同、异、类、名实的条目。
4. 对照《荀子·正名》形、实、名、所的关系，避免名同、实同和类同混淆。
5. 对照《庄子·齐物论》彼是转换，检验参照关系是否被误作对象固有属性。
6. 把本专题十类负控转化为 M8 benchmark fixtures，比较当前系统与消融基线。
7. 由人工校勘者审查术语解释，不以模型生成的训释充当证据。
