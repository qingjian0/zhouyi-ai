# E12-M2：无监督重复结构发现协议

状态：研究原型 / 待 CI 与独立基准验证

## 研究问题

在没有目标标签、预先定义语义类别或外部相关性分数的情况下，系统能否从离散观察中发现可重复的组合结构？

本阶段将“原语”严格降格为**候选统计结构（candidate motif）**。频繁共现不等于语义、因果或可迁移知识，不能直接称为已发现的认知原语。

## 当前最小算法

输入为观察事务集合，每个事务包含一组离散符号。枚举阶数不超过 K 的组合，计算：

- 支持度：support(S) = count(S) / N
- 独立性期望：expected(S) = product_i support(i)
- 提升度：lift(S) = support(S) / expected(S)
- 排序分数：score(S) = log(lift(S)) * sqrt(support(S))

仅保留达到最低支持度和提升度的候选。结果确定性排序并限制最大候选数。

该算法是透明的频繁项集/共现基线，不是神经网络，也没有学习连续语义表示。

## 必须完成的验证

1. 合成数据：注入已知高频组合，检验能否恢复。
2. 负对照：独立随机生成项目，检查假阳性率。
3. 置换检验：保持单项边际频率，打乱行内关联，检查 lift 是否消失。
4. 阶数扫描：K=2、3、4，记录候选数、运行时间和峰值内存。
5. 多随机种子：报告均值、标准差和置信区间。
6. OOD：训练阶段未出现的成员组合，在新数据中检验结构能否迁移。
7. 基线比较：Apriori/FP-Growth（如依赖允许）、随机组合、仅支持度排序。

## 预注册的失败条件

- 在保持边际频率的置换负对照上，发现结果与真实数据没有显著差异；
- 恢复已知注入 motif 的 precision 或 recall 未超过预设基线；
- 计算成本随项目数/阶数增长不可控；
- 结果对随机种子或轻微噪声极度敏感。

## 重要限制

- 共现不代表因果。
- 高 lift 可能由低频偶然事件产生，因此必须同时报告 count/support。
- 事务边界决定了什么被视为“共同出现”，需要在真实任务中明确定义。
- 当前算法只处理离散符号，不解决自然语言切分、视觉对象发现或语义 grounding。
- 不得把合成任务成功描述为通用智能能力。

## 下一步

E12-M2.1 增加边际保持置换检验与多种子合成基准；只有统计检验和 OOD 结果通过后，才把候选 motif 接入动态超图生长模块。
