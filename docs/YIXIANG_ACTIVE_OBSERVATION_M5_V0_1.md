# M5 主动观测与信息增益基线 v0.1

## 目标

M5 在 M3 的竞争假设与 M4 的条件边界之上，选择“下一步观察什么”以最大程度减少假设不确定性，同时考虑观测成本、可行性、风险和选择偏差。M5 只规划非干预性观察；假设性 do 操作继续由 M4 单独表达。

## 古典理论依据（工程转译，不声称古人提出信息论）

- 《墨子·小取》：“以类取，以类予”，同时指出有共同点不代表必然整体相同，并区分“其然”与“所以然”。转译为：观测应优先检查竞争假设的区分性预测，而不是重复收集共同特征。
- 《荀子·正名》：“辨异而不过，推类而不悖”。转译为：观测设计必须显式寻找差异与反例。
- 《周易·系辞下》“近取诸身，远取诸物”可作为多尺度观测来源的文本入口；近身与远物不是同一测量尺度，需保留尺度和位置元数据。
- 《庄子·齐物论》的视角转换提醒系统记录观察者、指称方式和观察位置；视角差异不能直接当成对象事实变化。

上述文本中的论辩、取象、视角等语义各自独立。信息增益、贝叶斯后验和效用函数是 Zhouyi-AI 的现代工程形式，不回填为古代原义。

## 算法

给定假设先验 P(H_i) 与候选观察 O 的条件似然 P(o|H_i)：

1. 计算预测结果分布 P(o)=sum_i P(H_i)P(o|H_i)。
2. 对每种可能结果计算后验 P(H_i|o)。
3. 计算期望后验熵，并得到信息增益 IG(O)=H(H)-E_o[H(H|o)]。
4. 以透明启发式效用排序：

   U(O)=IG(O) * feasibility * (1-risk) * (1-selection_bias) / (1+cost)。

成本单位由调用者定义，故不同任务之间不可直接比较；权重和惩罚项是初始基线，必须通过消融与真实任务校准。

## 数据与语义约束

- 假设先验必须归一化；每个假设对每个候选观察必须提供完整归一化结果分布。
- UNKNOWN 不能被默认为 FALSE；缺失的似然不是零概率，而是输入不完整并拒绝评分。
- 预测似然是模型/研究者给出的预测，不是观察证据。输出标记 prospective_only。
- 观察与干预分离：M5 不接受 do() 干预作为观察候选；干预由 M4 记录。
- 观测风险、可行性、成本、选择偏差分别记录，不合并成一个不可解释的分数。
- 同分按观测 ID 稳定排序；保留完整排名，不只输出第一名。
- 观测执行后必须新建带来源引用的观察记录，更新假设证据；不得直接覆盖先验或原始观测。

## 主要边界

- 似然模型若错误，信息增益也会误导；高信息增益不代表真实性或因果识别。
- 选择偏差惩罚目前是显式线性启发式，不是偏差校正估计量。
- 风险、成本和可行性评分依赖任务定义，需做敏感性分析。
- 当前实现针对离散假设与离散结果；连续观测、相关观测、序贯停止、主动干预和分布漂移留待后续。
- 不允许用古籍类象相似度直接生成概率似然；文本解释与现代测量模型必须分别校验。

## 测试

合成单元测试覆盖：完全区分假设、完全无区分力、成本/风险/选择偏差惩罚、空候选、稳定同分排序、缺失假设分布、似然归一化、非法概率和重复 ID。通过合成测试只证明实现符合定义，不证明古典类象理论有效。
