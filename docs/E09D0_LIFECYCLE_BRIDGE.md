# E09-D0：证据账本到超边生命周期的桥接

状态：桥接适配器与测试已提交；尚待运行。  
分支：`research/e09-nongradient-learning-2026-11-10`

## 目的

将 E09-B2 的证据账本输出接入 E02-C 的 `EdgeProposal`，形成可审计的结构候选提交流程。该桥接不负责发现节点、成员或角色，也不负责计算验证收益。

## 证据规则

- 由调用方明确指定正类标签、超边成员、角色、关系类型、验证集收益和成本。
- 账本中同一输入出现矛盾标签时，该输入的所有记录从支持证据和反例证据中排除。
- 正类支持记录必须具有非空 `source_id`，且至少达到配置的不同来源数。
- `support_ids` / `counterexample_ids` 保留原始 sample ID，便于追溯。
- 多个 source ID 仍不等于多个可信独立主体；来源身份未经认证，可能被同一主体伪造。
- E02-C 继续负责成员/角色合法性、最小支持样本数、验证收益门槛、边预算和生命周期状态操作。

## 不能据此宣称

桥接成功不代表系统自主发现了超边；成员映射与正类定义仍由调用方提供。验证收益也必须来自未参与结构选择的保留验证数据。当前桥接只打通“证据审计 → 候选提案 → 生命周期门控”的接口。
