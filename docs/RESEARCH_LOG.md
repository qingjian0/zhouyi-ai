## 2026-11-10：E01-B 五种子基线与易象编码原型

### E01-B 首轮结果
- 新增五种子运行器，固定 seeds 7–11，每种子训练 1,200、测试 400 个合成样本。
- GitHub Actions 五种子运行步骤通过。
- 结果报告记录：学习器 Exact Match 0.9170 ± 0.0160，Micro-F1 0.9723 ± 0.0053；固定前缀与随机基线明显较低。
- 结果仅适用于与隐藏线性规则匹配的合成 IID 任务；不代表严格组合 OOD，也不代表自然语言或完整 CPG-EI 能力。
- 已明确将 E01-C 作为严格组合 OOD 的下一实验。

### 易象编码原型
- 新增阴阳二元编码、八卦三位编码、六爻二进制 ID、上下卦拆分和动爻翻转函数。
- 固定爻序为自下而上，初爻索引 0；明确二进制 ID 不等于文王卦序。
- 对 8 个三爻编码、64 个唯一六爻状态和动爻翻转建立单元测试。
- 易象编码 CI 通过；编码只保证程序约定，不赋予卦象未经验证的预测语义。

### 当前限制
- E01-C 严格 OOD、E01-D 神经网络对照、E02 动态超图均未开始。
- E01-B 的合成任务结构较简单，下一步必须提高任务难度。
