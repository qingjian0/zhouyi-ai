# E12-A1 候选基元提议器：首个纵向原型

日期：2026-11-11  
状态：[原型]；代码已提交，等待 CI 与复现实验  
分支：research/e12a1-candidate-induction-prototype-2026-11-11

## 1. 本原型验证什么

E12-A0 在已知的两个谓词中检查可辨识性。E12-A1 的第一条纵向切片进一步做到：从 Support 中观察到的取值自动提出候选谓词，并把候选组合成可执行表达式，再使用独立 Gate 选择候选。

当前 DSL 仅包含：
- 单变量阈值谓词：ge、eq；
- 奇偶谓词：even、odd；
- 双变量关系：gt、lt、eq_pair；
- 两个原子谓词的 AND 组合。

候选生成只读取 Support 的观测取值，不读取标签；候选评分读取 Support 标签和 Gate 标签。Locked Test 不进入 induce() 的参数，只在候选选择完成后由 run_demo() 评分。

## 2. 数据划分

合成任务使用两个整数通道，目标规则为：

    y = 1 iff x0 >= 2 AND x1 >= 2

该规则只存在于环境生成器中，不作为候选标签传入学习器。

- Support：9 个组合；
- Gate：4 个组合；
- Locked Test：3 个组合。

三个集合互不重叠。Locked Test 特意保留一个正例组合 (2, 2)，其余两个为负例，用于检查已选结构在未参与提议与选择的组合上的表现。

注意：本任务是小型、可解释的合成 smoke test。由于 DSL 包含正确表达式，成功只说明候选生成、组合、筛选和测试隔离这条软件路径可以工作；不能证明系统发现了开放世界语义，也不能证明跨规则族迁移。

## 3. 关键实现约束

1. **提议与评分分离**：proposal 函数只使用观测值；标签只参与后续评分。
2. **预算可控**：候选数量受 candidate_budget 限制；原子候选优先保留，避免预算截断时 AND 的索引错位。
3. **行为等价去重**：在 Support + Gate 上预测完全相同的候选归为一个行为等价类，避免把语法不同、观测行为相同的表达式误判为不同解释。
4. **Gate 参与选择**：候选先在 Support 拟合，再按 Gate 表现排序；Gate 不是 Locked Test。
5. **谨慎命名状态**：返回 CANDIDATE_SELECTED，而不是 IDENTIFIABLE。候选选择成功不等于潜在真实机制已被唯一识别。
6. **测试集隔离**：学习器函数 induce() 不接收 Locked Test；仅在选择冻结后由 demo 评估。

## 4. 本阶段未解决的问题

- DSL 仍由研究者预先定义，尚未学习新的算子语法。
- 只有二元 AND，没有 OR、NOT、变量绑定、时序关系和高阶关系的系统比较。
- 没有概率校准；Gate accuracy 不是置信度。
- 没有独立环境进程；Python 模块边界不是安全隔离。
- 没有真正的主动测量、反例驱动结构修订或多世界 OOD 评估。
- 尚未运行 CI，不能报告测试通过或实验结果。
