# 类象迁移有效性：关系保持、条件约束与拒绝推演 v0.1

## 研究命题

类象推理的核心不是源对象与目标对象“有多像”，而是：**在明确的比较维度与条件下，源域中被支持的关系，是否能以同一关系结构迁移到目标域？**

相似性只能提出候选，不能独自授权推论。一个可审查的迁移至少要说明：
1. 源域与目标域分别是什么；
2. 被比较的关系是什么，而非只列共同属性；
3. 共同依据为何与当前目标问题相关；
4. 关键差异是什么，差异是否会破坏关系；
5. 迁移适用于哪些条件；
6. 哪些反例已测试，哪些反驳仍未解决；
7. 证据分别来自何处，因果迁移是否另有因果证据。

## 原典材料中的不同机制

### 1. 《墨子·小取》：辟、侔、援、推不能合并成“相似”

《小取》把辟、侔、援、推分别说明。研究标注应分别记录其论辩角色：
- 辟：举他物以明此物，可能只是说明或譬喻；
- 侔：比辞而俱行，需检查平行句式中的隐含前提；
- 援：援引对方已承认的判断，核心在承诺一致性；
- 推：由已取之同推向未取之同，需检查相关条件是否真的保持。

这些是工作性释义，不能取代版本校勘、经说互证和历代训释。尤其不能仅凭句式平行就断定存在有效推论。

### 2. 《荀子·正名》：形、实、所与名的多层区分

《正名》讨论“物有同状而异所者，有异状而同所者”，并讨论形变而实未必分离的情形。它提醒系统至少要拆开：
- 可观察形态（appearance/form）；
- 所在或个体化条件（location/individuation）；
- 实体或对象连续性（referent/identity）；
- 名称与约定（name/convention）。

因此，“看起来一样”不能直接合并为同一对象；“外形变了”也不能直接判成新对象。名称约定与对象识别还需要分开评价。

### 3. 《淮南子·说林训》：同一目的不意味着同一机制

“钓者静之……为之异，得鱼一也”显示不同手段可通向共同目标。应建立两个层次：
- 结果/功能等价：在特定目标下都能“得鱼”；
- 机制/过程等价：工具、操作、成本、风险、适用条件是否相同。

前者成立不推出后者成立。目标一旦改成效率、成本、鱼种或生态影响，原来的功能等价可能立即失效。

《淮南子·要略》又将《说山》《说林》描述为“假譬取象，异类殊形”，说明异类之间可以借譬喻和取象沟通事理。但“可以跨类”不等于“跨类后所有性质都可迁移”。

### 4. 《论衡·感类篇》：对应关系不自动构成因果

灾异、政治行为与天人感应的文本论辩，必须拆分：
- 象征/政治解释；
- 时间共现；
- 经验关联；
- 因果主张；
- 干预或独立证据。

由时间先后、叙事对应或同类联想，不得直接升级为因果结论。王充具体论点须放回全篇与论敌语境，不能以一段话代表其全部立场。

## 迁移裁决的六道门

| 门 | 必须回答的问题 | 不满足时 |
|---|---|---|
| 关系一致 | 源域和目标域迁移的是同一种关系结构吗？ | 拒绝迁移 |
| 共同依据 | 是否有明确共同关系，而非泛泛相似？ | 拒绝迁移 |
| 相关性 | 共同依据与当前待推结论相关吗？ | 暂缓 |
| 条件范围 | 在什么背景、尺度、时间、角色下成立？ | 暂缓 |
| 差异与反例 | 哪些差异可能破坏迁移？反例测试过吗？ | 暂缓 |
| 证据独立 | 两侧证据是否可追溯？因果主张是否有因果证据？ | 暂缓 |

这里采用门控而非加权平均。高相似度不能抵消关系结构不一致、关键条件缺失或反例未处理。

## 裁决状态

- `ACCEPT_SCOPED`：只在明确证据与条件范围内接受迁移，不意味着普遍真理。
- `CANDIDATE_ONLY`：研究者可登记为候选；当前原型暂不自动授予此状态。
- `ABSTAIN`：信息不足、差异未解释、反例未处理或证据链缺失。
- `REJECT`：关系结构不一致或没有共同关系依据。

## 工程实现

`prototype/yixiang_analogy_validity.py` 实现上述保守门控；不进行自动古文理解、不认证文献、不计算“相似度分数”，也不把文本中的因果说法当作事实。

测试覆盖关系错配、共同依据缺失、相关性论证缺失、条件缺失、关键差异缺失、单侧证据、反例、未解决反驳及因果证据缺失。

## 研究边界与后续任务

1. 将《小取》每一种操作逐例标注，并与《大取》《经说》互校。
2. 将《荀子·正名》的“状—所—实—名”拆成可连接但不可混同的节点。
3. 为《淮南子·说林训》增加功能等价/机制等价/条件等价的对照案例。
4. 对《论衡·感类篇》建立“对应—相关—因果—反证”论证图。
5. 从《孟子》《庄子》《韩非子》《吕氏春秋》增加跨域类推的强弱例。
6. 所有数字摘录继续标记待核；逐条补齐影印底本、卷篇、页叶、异文与注疏层后才可升级证据等级。
