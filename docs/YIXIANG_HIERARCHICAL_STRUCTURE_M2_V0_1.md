# M2 整体—局部关系结构原型 v0.1

## 目标

将“整体由部分构成”“局部参与整体功能”“局部对整体产生影响”“空间相邻”“分类隶属”区分为不同关系类型，避免把所有关系统一编码为 contains 或 parent-child。

实现：prototype/yixiang_hierarchical_structure.py。

## 关系类型

| 类型 | 方向语义 | 是否强制无环 | 说明 |
|---|---|---:|---|
| PART_OF | source 是 target 的组成部分 | 是 | 严格部分—整体层级 |
| FUNCTIONAL_PARTICIPATION | source 参与 target 的功能/过程 | 否 | 允许反馈，不代表组成关系 |
| CAUSAL_INFLUENCE | source 对 target 有影响 | 否 | 仅表示待验证的因果主张，不自动证明因果 |
| SPATIAL_ADJACENCY | source 与 target 空间相邻 | 否 | 相邻不等于组成或因果 |
| TAXONOMIC_MEMBER | source 属于 target 分类项 | 是 | 分类隶属层级 |

## 数据与约束

- 节点有稳定 ID、层级标签和描述标签。
- 关系有稳定 ID、源节点、目标节点、关系类型和证据引用。
- 节点/边 ID 必须唯一；关系端点必须存在；禁止自环；每条关系必须有证据引用。
- 组成关系和分类隶属关系分别检查有向环。
- 因果影响和功能参与允许循环，因为反馈系统中可能存在合法回路；是否真为因果仍需独立识别与实验。
- 当前不自动抽取节点、不推断关系、不计算整体涌现属性，也不裁决历史类象是否成立。

## 测试覆盖

8 项测试覆盖关系类型分离、组成环拒绝、分类环拒绝、因果反馈环保留、功能反馈环保留、未知端点拒绝、证据缺失拒绝和重复节点 ID 拒绝。

## 下一步实验

1. 建立有真值的层级合成任务：多层部件、功能角色、反馈关系、空间邻接和分类树。
2. 加入局部扰动：替换部件、删除部件、改变功能角色、改变邻接关系。
3. 比较平面图、仅 PART_OF 层级图、完整 typed-relation 图。
4. 测量层级恢复、关系分类、局部扰动定位、整体任务性能、错误传播率和结构编辑成本。
5. 用跨层组合留出集测试泛化；按源结构分组切分，避免同一模板泄漏到训练和测试。
6. 在数据和实验协议完成前，不声称整体—局部递归学习能力已经实现。

## 理论连接

该原型只提供关系类型和结构约束，尚未实现真正的双向递归：局部结构生成整体候选、整体约束反向影响局部解释、局部反例触发整体重构。该能力应在后续独立模块中实现并评估。
