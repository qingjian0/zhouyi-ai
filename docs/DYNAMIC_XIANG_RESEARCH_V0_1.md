# 动态类象与变化路径保持研究 v0.1

## 1. 研究问题

静态关系对应不足以支持过程类象。两个系统在某一时刻具有相似结构，不代表其后续变化也相似。本研究增加一个可证伪要求：源域中的状态变化经类象映射后，应能在目标域找到保持顺序、事件类型与相关状态关系的对应变化。

该要求是动态结构对应，不等于因果等价、预测能力或传统易学解释已经成立。

## 2. 易象研究中的层次区分

工程上必须区分：

1. 卦体结构：阴阳爻、爻序、上下卦和六爻位置。
2. 卦德/功能解释：如健、顺、动、入等，必须标记文本来源与解释传统。
3. 物象与身象：具体物类、人体部位及其语境。
4. 关系与爻位：承、乘、比、应等，需明确传统定义或项目操作定义。
5. 时空与变化：方向、时节、阶段、动爻、卦变及变化路径。
6. 综合象：在特定问题与观察条件下，由多个结构维度共同构成的模式。

以上是研究建模层，不是宣称历代易学只有这六类，也不能将它们预先压成单一向量。

## 3. 动态类象的形式化

令源域状态系统为：

S = (X_s, E_s, R_s, T_s)

目标域状态系统为：

T = (X_t, E_t, R_t, T_t)

其中 X 是实体集合，E 是离散状态快照，R 是状态内的有类型关系，T 是有向状态转移。

类象候选包含：
- 实体映射 phi_x
- 状态对齐 phi_e
- 适用范围与观察窗口

静态关系保持要求：

phi_x(R_s(e)) 与 R_t(phi_e(e)) 在声明的关系类型和实体范围内一致。

动态关系保持要求：

若源域存在 e_i -> e_j，则目标域应存在对应的 phi_e(e_i) -> phi_e(e_j)，并保持事件类型。状态对齐还必须保持时间顺序。

可将其理解为一个近似交换图：

phi_e(T_s(e)) ~= T_t(phi_e(e))

这里的近似由状态事实 F1 和转移 F1 明确量化，而不是凭文字解释判断。

## 4. 当前实现

prototype/dynamic_analogy.py 实现有限离散状态轨迹评估：
- 有类型关系事实；
- 有向、严格向前的状态转移；
- 显式实体映射；
- 显式且保序的状态对齐；
- 状态事实 precision/recall/F1；
- 转移 precision/recall/F1；
- 额外目标转移降低 precision；
- 缺失或错误转移降低 recall；
- 输入校验阻止重复状态、重复关系、非单射映射和逆时间边。

关系谓词与事件类型当前采用精确匹配。这是保守基线，不表示自然语言同义、反向关系、尺度变换和多对多映射不可能成立；这些扩展必须通过显式关系本体和独立实验引入。

## 5. 易学映射的研究门禁

- 阴阳、四象、八卦、六十四卦的结构字段与解释字段分离。
- 卦序和方位必须使用独立版本/命名空间；不能从二进制索引推导历史顺序。
- 传统类象主张必须关联具体篇章、版本、定位和解释传统。
- 先秦出土文献、传世《说卦传》、汉唐注疏、宋代图学和现代研究不可混成一个无时间差别的标签表。
- “时位势变”进入程序时，先声明可观测变量与操作定义，再做预测或解释。
- 结构映射不构成因果证明；因果迁移需要干预或机制证据。

## 6. 实验计划

第一轮：完全匹配的三状态轨迹；静态相同但事件标签被篡改；转移缺失；目标额外转移；时间反序；部分实体映射。

第二轮：允许跳步的状态对齐、非等长轨迹和多路径演化；需要单独报告搜索预算与对齐不确定性。

第三轮：在相同底层案例上比较静态图匹配、动态转移匹配、普通语义相似度和可学习时序模型。按来源/案例族/领域划分，禁止近重复泄漏。

第四轮：把阴阳消长、爻位、卦变、五行条件关系作为带来源的候选状态变量接入；先做消融，再评估是否改善真实领域迁移。

## 7. 失败条件

若动态模块不能显著优于静态结构基线识别被篡改的变化路径，或其收益完全来自事件标签泄漏，则不能宣称动态类象提供了独立能力。若跨领域结果只在合成模板上成立，应限定为符号系统内的结构泛化。

## 路线图定位

本研究对应 P0-D（类象计算引擎）及 P0-E（易象状态演化）的交界验证。它不取代静态类象，也不把时位势变压缩成单一标签；后续应将带来源的阴阳消长、爻位、卦变和条件关系作为状态变量，在独立消融实验中逐步接入。

## 9. “象—类—比—验”的项目操作定义（研究假设）

为了避免把“象”误写成实体标签，本项目提出一个待检验的操作化框架：

- 观测 O：对象、事件、测量、文本片段或结构化记录，以及其证据定位。
- 问题 Q：当前观察/推理要解决的任务；决定哪些信息相关。
- 情境 C：时间、位置、尺度、环境、角色与边界条件。
- 取象选择 S：从 O 中选择与 Q、C 相关的特征、关系和过程，同时记录被排除信息与选择理由。
- 象表示 X：所选要素构成的带类型结构，不等于对象本身，也不等于最终解释。
- 类不变量 I：在声明的一组允许变换下仍保持的结构/关系特征。
- 证据 E：支持、反例、来源版本、观察方法和审核状态。

可写成项目定义：

X = Select(O | Q, C, S)

两个对象“同类”不要求所有属性相同，而要求在指定范围内具有一组可说明的不变量 I。类象映射 phi 只有在关系、过程、条件及证据检查后才可升级为可迁移映射。

这是一种工程化研究假设，不是对“象”字古义或全部易学传统的唯一解释。

## 10. 四级对应与证据门槛

1. 特征相似：共享若干可观测属性；只能提出候选。
2. 关系同构/同态：关键角色与关系在映射下保持；可支持结构类比。
3. 动态模拟：状态转移在映射下保持顺序和过程；可支持有限过程迁移。
4. 因果机制对应：还需因果结构、干预或机制证据；前三层均不能自动推出第四层。

此分级防止把表面相似、结构相似、动态相似和因果相似混为一谈。


## 11. 时—位—势上下文保持（增量）

状态快照可选附带五类上下文事实：

- `time`：时段、节候或阶段标签；
- `position`：结构位置、空间位置或角色位置；
- `potential`：趋势、消长、稳定/临界等带来源的势态标签；
- `environment`：外部环境与约束；
- `phase`：过程阶段。

上下文值默认精确匹配。跨域时若源值与目标值名称不同，必须通过 `context_value_mapping` 显式声明维度内的一对一对应；不做模糊匹配，也不从卦象自动推出现实含义。实体级上下文随实体映射迁移；空 subject 表示系统级上下文。

上下文在源域或目标域任一侧出现时，就纳入独立的 context F1 门槛；两侧均未提供时标记为未评估，而不是记作满分。当前上下文评价仍是符号标签保持，不等于真实时间连续性、趋势预测或因果机制验证。
