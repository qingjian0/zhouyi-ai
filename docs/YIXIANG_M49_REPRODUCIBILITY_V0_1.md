# M49：基准复现清单与统一报告 v0.1

M49 定义 BenchmarkManifest，要求记录代码 commit、数据与生成器版本、随机种子、训练/验证/测试情境划分、指标、方法、配置和环境引用。验证情境与测试情境必须与训练情境互斥；报告只接受通过清单审计的输入。

古典约束：《墨子·小取》要求察名实、明同异、审推类是否“远而失、流而离本”。M49 将其转化为来源、情境和评估边界必须可追踪的工程约束，不把古代论辩篇章等同现代可复现研究规范。

限制：清单只记录环境声明，不验证容器镜像、依赖锁文件或硬件；报告只输出调用方已计算的汇总结果，不执行实验、不生成置信区间、不证明可复现。完整复现还需 CI、依赖锁定、原始数据校验和独立复跑。
