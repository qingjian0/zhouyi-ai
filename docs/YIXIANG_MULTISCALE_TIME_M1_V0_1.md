# 多尺度时间模型 M1：数据结构与验收 v0.1

## 目标

建立能显式表示多时间尺度和层级事件的最小数据模型，避免把不同时间单位直接比较，也避免将采样频率误认为过程本身的时间尺度。

## 数据结构

实现于 `prototype/yixiang_multiscale_time.py`：

- `TimeScale`：时间尺度及其父尺度关系。
- `TemporalEvent`：事件所属尺度、时钟、区间、观测时刻、证据和可选父事件。
- `MultiScaleTimeline`：尺度层级与事件集合。
- `TemporalRelation`：区间关系及可比较性说明。

## 约束

1. 时间尺度层级必须无环。
2. 事件 ID 唯一，事件必须引用已声明尺度并附带证据。
3. 子事件必须位于父事件的祖先尺度下，且父区间包含子区间。
4. 父子事件只有在共享同一已校准时钟时才能进行包含校验；不同 clock 不可直接比较。
5. 同时提供 Allen 风格区间关系：BEFORE、MEETS、OVERLAPS、CONTAINS、DURING、STARTS、FINISHES 等。
6. 当前模型不自动推断时间尺度、不做重采样、不识别阶段边界、不推断因果。

## 测试覆盖

- 正确的宏观—中观—微观嵌套；
- 父子区间不包含时拒绝；
- 未校准时钟的父子事件拒绝；
- 时间尺度环路拒绝；
- 区间关系判定；
- 不同时钟不可比较。

## 后续实验

合成同一潜在过程的不同采样率版本，分别加入缺失观测、延迟响应、快慢变量和阶段长度扰动。比较单尺度序列基线、固定窗口、变化点检测及层级状态模型。报告阶段边界 F1、事件顺序准确率、缺失鲁棒性、跨采样率迁移和计算成本。

## 边界

该原型是可审计的数据结构和约束检查器，不是多尺度学习算法，也不证明易学时位理论与任何特定时间模型等价。
