# 类象关系类型学与迁移门禁 v0.1

## 1. 本轮要解决的问题

现有语料与原型已经能记录类象、竞争解释、条件干预、主动观测和新象候选，但“关系”仍容易被压缩成一个宽泛标签。古籍中的“类”“象”“应”“感”“比”“兴”“推”“法”“象”等词并非同义词；同一个词在不同篇章也可能承担不同论证功能。

本文件提出一套**项目级关系类型学**，用于标注和评估，不声称这是古人共同使用的统一理论。原典术语必须保留原样，工程类型只作为可比较的第二层标签。

## 2. 关系类型必须分开

| 工程关系族 | 核心问题 | 古典研究入口 | 禁止的偷换 |
|---|---|---|---|
| 分类 classification | 哪些对象归为一类？依据何在？ | 《周易·系辞》“方以类聚”；《荀子·正名》 | 分类相同不等于功能相同 |
| 属性 attribute | 双方共享何种性质？ | 《说卦》卦象属性及名物解释 | 属性相似不等于结构相同 |
| 功能 function | 对象对谁、为谁、在何任务下起何作用？ | 《说卦》“雷以动之”等；《淮南子·说林训》 | 同物不等于同用、同效 |
| 结构 structural | 部分、位置、角色及关系如何组织？ | 卦爻位次；《墨经》名实、同异 | 节点集合相同不等于关系保持 |
| 空间 spatial | 方位、内外、远近、上下如何约束？ | 《说卦》《淮南子·地形训》 | 方位对应不等于物理因果 |
| 时间 temporal | 同时、先后、周期、阶段、时机如何关联？ | 《管子·四时》《淮南子·天文训》 | 先后不等于因果 |
| 生成 generative | 某物如何由条件、材料或阶段形成？ | 《系辞》生生、刚柔相推；《考工记》 | 生成叙述不自动成为现代机制 |
| 因果 causal | 是否存在可识别的作用机制？ | 《论衡·感类》对感应因果的质疑 | 共现、感应、象征不等于因果 |
| 类应 correspondence | 两类事物是否被文本主张为相应？ | 《吕氏春秋·应同》《春秋繁露》 | 文本主张不等于经验验证 |
| 象征 symbolic | 某象在特定文化系统中指代什么？ | 卦象、礼制、政治象征 | 象征意义不等于对象属性 |
| 规范 normative | 自然秩序如何被转用于应然制度？ | 《管子·版法解》《礼记》 | 应然规范不等于自然定律 |
| 修辞 rhetorical | 比、兴、譬喻如何组织表达？ | 《诗经》《文心雕龙·比兴》 | 修辞有效不等于论证成立 |
| 词汇 lexical | 名称、训诂、音义之间是什么关系？ | 《尔雅》《说文》《方言》 | 同名、同音不等于同物同类 |

这些关系族可共存于一个复杂解释中，但不能因为同处一段文字就合并。例如《淮南子》一段可能同时包含分类、时序、类应与宇宙论因果主张，必须拆成多个 claim。

## 3. 类象映射的最小表达

每条映射至少要回答：

- **源项与目标项**：比较的对象、主体、事件或系统分别是什么？
- **映射维度**：属性、功能、结构、过程、时位、符号还是规范？
- **共享依据**：哪些属性/关系对目标命题确实相关？
- **关键差异**：主体能力、目的、机制、尺度、环境、历史阶段有哪些不相同？
- **作用条件**：映射在哪些条件内成立，哪些条件未知？
- **来源证据**：源侧和目标侧分别有哪些可追溯见证？
- **证据层级**：原典、古注、现代研究、观察、实验、项目假设或模型生成？
- **因果状态**：未声称、文本声称、观察关联、干预支持、受挑战或未知？
- **反例**：哪些材料会推翻、缩窄或改变这条映射？

形式上可表达为：

`M=(S,T,F,B^+,B^-,C,E_s,E_t,L_s,L_t,K)`

其中 `F` 为关系族，`B^+`/`B^-` 为共享依据/关键差异，`C` 为适用条件，`E_s`/`E_t` 为源侧/目标侧证据，`L` 为证据层，`K` 为反例集合。该形式是项目数据契约，不是古籍原有符号系统。

## 4. 迁移裁决：支持、未决、拒绝

- **拒绝 REFUSE**：关系族不匹配，或没有声明任何与目标命题相关的共享依据。
- **未决 ABSTAIN**：缺少条件、任一侧证据、反例审查未完成、因果状态未知/受挑战，或模型生成材料被用来认证映射。
- **范围内支持 SCOPE_SUPPORTED**：关系族一致，存在共享依据、适用条件、源/目标两侧证据，且没有已知未处理反例，因果状态也不再未决。

`SCOPE_SUPPORTED` 只表示当前声明的映射结构和证据卫生达到门槛，不表示映射为真，不代表因果成立，也不代表可推广到条件范围之外。任何外推都必须重新评估。

## 5. 与既有模块的边界

- M2/M2.1：负责整体—局部结构约束；本类型学为关系增加语义类型。
- M3：比较竞争映射，保存支持、反例和未决状态。
- M4：只能对显式条件做假设干预；不能把反事实输出升格为观察证据。
- M5：选择能区分关系族或适用条件的观察；信息增益仍是预测值。
- M6：只有排除旧类别范围错误、主体错配和条件遗漏后，才可提出新象。
- M7：编排上述流程，不得让同一证据在多个阶段循环自证。
- M8：可将关系族错配、条件缺失、来源缺失、反例未处理作为独立错误类型，报告拒绝/未决表现。

## 6. 本轮新增的反例优先实验矩阵

1. **同属性异功能**：对象共享颜色/形状，却因主体或任务不同而功能不同。
2. **同结果异机制**：结果相同但生成机制不同，检验系统是否错误升级为因果等价。
3. **同名异物/异名同物**：引入训诂与名物考证，检验词汇关系是否污染对象分类。
4. **同象异解**：同一经文在不同时代、不同注家中出现竞争解释，检验系统是否错误合并。
5. **同位异时/同时异位**：控制时位，测试静态映射的外推错误。
6. **自然描述—政治规范跨域**：检验系统是否把规范类比误判为经验因果。
7. **同源多网址**：多个数字平台转录同一底本，只能计为一个来源谱系。
8. **模型自证**：模型生成的解释不得作为独立来源或审定标签。

## 7. 古籍扩充顺序与覆盖缺口

先秦两汉继续优先，但不把研究局限于易学：
- 经：经传、三礼、春秋三传、尔雅、诗书；
- 史：史例、制度、地理、天文记录、灾异叙事；
- 子：儒道墨名法兵农医、杂家、天文历算、术数；
- 集：诗赋、楚辞、总集、文论、比兴与譬喻；
- 出土文献：甲骨、金文、简帛、敦煌写本、碑刻；
- 类书与目录：追踪佚文、异文和引文谱系，不把转引当原典。

特别补足当前薄弱的训诂、名物、音义、出土材料和史例反证。清代及以后材料只用于版本、辑佚、校勘、术语史和现代学术审查。

## 8. 质量门禁

- 原文/注疏/现代研究/项目解释/模型生成层级混淆：零容忍。
- 关系族不明或混合：不得进入自动迁移。
- 只有源侧证据、没有目标侧证据：ABSTAIN。
- 未声明共享依据：REFUSE。
- 关键条件未知：ABSTAIN，不把 UNKNOWN 当作 False。
- 已知反例未处理：ABSTAIN。
- 因果状态未知或仅文本声称：不得输出“因果已证实”。
- 数字转录未经底本核对：保持 candidate/unreviewed。

## 9. 本文状态

v0.1 是项目级操作化规范。它需要在真实古籍语料、独立评审样本和反例优先基准上验证；不构成对传统类象理论的最终解释，也不宣称该类型学覆盖所有古代思想流派。
