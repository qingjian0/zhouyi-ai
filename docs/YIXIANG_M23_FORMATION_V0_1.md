# M23：观象—取象—立类的形成机制 v0.1

## 1. 研究问题

M23 将类象认知拆为可区分、可追溯的阶段：观象、取象、立类、比类、推类。当前工程只实现前三阶段的来源链审计，不把后两阶段的关系比较与推论迁移重复实现；它们分别由既有 M17 等模块处理。

核心问题不是“如何给对象算一个相似度”，而是：
1. 哪些内容属于原始观察记录？
2. 哪些内容是观察者选出的特征？
3. 选择特征的任务目的、尺度与排除项是什么？
4. 类别的判准是什么，成员资格由哪些证据支持？
5. 反例是否保留，是否有可审查的处理记录？

## 2. 原典研究：先秦材料的不同侧面

### 2.1 《周易·系辞上》：观物取象与制器尚象

“古者包牺氏之王天下也……仰则观象于天，俯则观法于地，观鸟兽之文与地之宜……近取诸身，远取诸物，于是始作八卦。”以及“见乃谓之象，形乃谓之器，制而用之谓之法，利用出入，民咸用之谓之神。”

M23 从中提取研究问题：观察对象/现象、选取表征、形成符号结构、落实到用途，彼此不是同一操作。这里的“观”“取”“象”“器”“法”必须保留原典语境，不把它们直接等同现代计算机视觉、特征工程或符号 grounding。

版本边界：上述文字以传世《周易正义》系统通行文本为工作底本；正式语料应补入《经典释文》、帛书《系辞》及出土材料对校。不得把传世本句序或后世解释伪装成唯一先秦原貌。

### 2.2 《说卦传》：象类、方位、物类与解释层次

《说卦》以乾坤震巽坎离艮兑配天、地、雷、风、水、火、山、泽，并进一步列举马、牛、龙、鸡、雉、犬、羊等象。该文本提示象的组织可能包含自然现象、动物、身体、方位、家族、属性等多条轴线；这些列表不是一个无条件、无歧义的现代分类树。

研究要求：
- 分清经传文本层、注疏层与现代整理层；
- 每个象例保留原句、章节、版本和注释来源；
- 同一卦象的不同取象不得预先合并；
- 不把“乾为马”等条目当成跨情境恒真属性，须记录解释传统、适用语境和竞争说法。

### 2.3 《荀子·正名》：名、实、类与约定

“名无固宜，约之以命；约定俗成谓之宜，异于约则谓之不宜。”以及“同则同之，异则异之”相关论述，要求区分对象、称名、分类约定和推论规则。一个名称被共同采用，不等于该分类天然唯一；分类规则也不能由名称本身循环证明。

### 2.4 《墨子·小取》：类同与所以然

“其然也同，其所以然不必同”直接限制从表面共同点跳到机制相同。M23 因此要求每项特征带有观察证据和选择理由，每项类别归属带有独立判准与成员证据；仅仅共享标签或外观不能自动形成类属结论。

### 2.5 《庄子·齐物论》：视角与区分

彼/是、物/我、成心与言辩的讨论提醒研究者：观察和分类活动可能受立场、任务与语言框架影响。它不意味着观察事实任意，也不意味着所有分类同样有效。M23 把“观察者、情境、任务目的”作为记录字段，而非把视角差异当成事实等价。

### 2.6 《淮南子·说林训》：同物异用、异势异效

同一对象因主体、用途、姿态和环境不同而表现出不同作用；因此，取象必须声明用途和条件，类别不能把所有关系差异压平。

## 3. 与现代研究的关系

M23 与现代概念形成、特征选择、分类学习、知觉心理学和符号 grounding 有交集，但不能将其当作古典术语的翻译。现代实验需分别比较：
- 仅凭名称/标签分类；
- 仅凭表面特征分类；
- 加入任务目的和情境条件；
- 加入独立成员证据与反例；
- 允许多类别归属与未决状态。

不能预设多维类象一定优于 Transformer；必须与同数据、同预算、同训练/测试划分的基线比较。

## 4. M23 数据模型

### Observation
记录对象、观察者、情境版本、观察描述、观察模态、记录方法、解释备注和原始证据引用。观察描述与观察者解释分开保存；它不自动断言观察描述完全客观，只保证来源可追溯。

### FeatureSelection
记录选出的特征、操作性描述、支持它的观察及证据、选择理由、任务目的、被排除的替代特征、审查状态。

### CategoryAssignment
记录对象归入的类别、类别判准、所依赖特征、成员证据、反例和反例处理状态。

### FormationTrace
把上述记录连成来源链。不存在从 Observation 到 Category 的自动语义推导；每一步必须有显式人工登记和证据引用。

## 5. 工程裁决规则

1. 原始观察、选中特征、类别归属分别存储，不允许相互覆盖。
2. 特征必须引用同一 subject 的已存在观察，且证据必须来自这些被引用观察；禁止跨对象借用证据。
3. 特征必须声明选择理由与用途；不声明理由时不得进入 provisional。
4. 类别必须声明判准、特征引用和成员证据。
5. 未解决反例阻止 provisional formation；已解决反例仍保留引用，不得删除。
6. 未知或缺失不能自动补成“相似”“同类”或“成立”。
7. 全部门禁通过只表示形成记录完整，不能证明特征选择正确或类别为真。
8. 一个对象可有多个类别归属；M23 不强迫互斥分类，也不建立单一分类本体。

## 6. 与 M1–M22 的接口

- M1/M2：观察和特征选择绑定时间区间、层级结构；M23 不替代时间/关系模型。
- M3/M4：竞争解释与条件干预可以对特征选择和类别判准提出反例。
- M5/M6：主动观测、新象发现可以提出候选，但不能绕过人工来源链自动确立新类。
- M7/M9/M10：组合候选需保留每个组成象的来源与任务目的；涌现主张不能替代成员证据。
- M11/M12/M13：动态路径、条件路径和角色迁移需引用产生时的特征/类别版本。
- M14/M15/M16：原文见证、片段范围和术语解释是证据上游；不得由工程类别反向改写原典。
- M17：比类/推类仍须通过关系、根据、范围、条件和反例门禁。
- M18/M19/M20/M21：案例 gold、人工审定和对抗样例应分别标注观察、特征、类别与推论层。
- M22：每条形成记录应绑定 context_id/version；情境变化后重审受影响的特征选择与类别归属。

## 7. 测试边界

原型：prototype/yixiang_formation.py
测试：tests/test_yixiang_formation.py

专项测试覆盖完整来源链、缺观察、特征证据不在观察中、无选择理由、无类别判准、无成员证据、反例未解决、反例保留、未知特征引用、未审状态、版本校验、重复 ID/证据及不强制每条记录必须建立类别。

这些是软件契约测试，不是古典理论正确性、认知心理学效度或模型能力的证据。

## 8. 预注册实验

主问题：显式记录“观察—特征选择—类别判准—成员证据—反例”是否减少过度泛化，并提升跨任务/跨情境稳定性？

对照：
A. 名称/标签基线；
B. 表面特征基线；
C. 特征 + 任务目的；
D. 特征 + 类别判准 + 成员证据；
E. 完整 M23 + 反例保留 + M17 推类门禁。

指标：
- feature provenance completeness；
- category assignment precision/recall；
- counterexample retention rate；
- overgeneralization rate；
- selective risk / abstention；
- cross-context stability；
- annotation agreement；
- inference and review cost。

数据切分必须按原典作品/版本/注疏谱系、对象族和任务族分组，防止同源文本或近重复案例泄漏。人工 gold 由独立标注者按观察、特征、判准、成员、反例五层分别标注；分歧保留，不用多数票掩盖解释争议。

## 9. 主要风险与停止条件

- “观象/取象”可能有多个历史语义层次，不能假定跨典籍同义。
- 现代特征选择框架可能把古典整体性压缩成属性列表。
- 观察描述本身也可能带有概念负载，不能把它当作绝对中性输入。
- 类别可能重叠、层级化或随任务改变，不能强制单标签分类。
- 若 M23 只增加标注负担而未降低过度泛化，或仅提高拒绝率而不提高正确分类，应暂停扩展并回到简单基线。

M23 是观测—取象—立类的可追溯数据契约原型。它不实现自动感知，不证明古典易象是一套现代机器学习算法，也不声称已经发现了人类认知的唯一机制。
