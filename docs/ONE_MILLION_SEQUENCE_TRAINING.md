# Zhouyi-AI 百万输入 / 百万连续输出架构与训练协议

状态：研究目标已确定；本文件定义工程实施协议，不代表模型能力已经实现。

## 1. 硬性目标

- 输入：单次任务最多处理 1,000,000 tokenizer tokens。
- 输出：单次连续生成最多 1,000,000 tokenizer tokens。
- 设备：普通消费级电脑与普通手机；必须分别报告设备、内存、峰值 RSS、峰值显存、功耗/耗时和吞吐。
- 架构：非 Transformer 序列核心优先；不以 Transformer 作为默认主干。允许 tokenizer、轻量语言接口或对照基线，但必须单独计量其贡献。
- 认知：类象、关系学习、CPG-EI 组合推理和证据记忆必须成为可训练、可测量的内部能力。
- 真实性：不允许用截断输入、摘要替代原文、外部模型代答、分段拼接输出或缓存答案冒充 1M 端到端能力。

“1M 输入”和“1M 输出”是两个独立验收项目，必须分别通过；两者都通过后才可宣称达到百万输入/输出目标。

## 2. 候选总体架构

采用可替换的混合循环认知架构，而不是押注单一网络：

1. **流式序列主干**：优先评估 selective SSM、门控循环网络、线性递归模型及多尺度状态空间模型。主干逐块更新状态，训练和推理均支持状态续接。
2. **稀疏情景记忆**：原始输入与输出按块持久化；模型选择性写入带来源、位置、时间和校验摘要的记忆条目。查询时检索证据并通过主干原生计算路径重放/融合，避免把全部历史压进固定向量。
3. **层级索引**：按文档、段落、事件、概念和关系建立可重建索引；索引是导航结构，不是原始证据替代品。
4. **CPG-EI 认知层**：将语义单元、类象、关系超边、候选推理和证据链纳入统一状态；支持 CREATE/MERGE/SPLIT/PRUNE/RETYPE 的受验证更新。
5. **持续生成控制器**：维护输出位置、目标约束、实体/术语一致性、未解决问题、已承诺事实和生成检查点；输出日志可恢复且可审计。
6. **解码接口**：优先验证循环/状态式解码；语言 tokenizer/decoder 作为可替换接口，不把 token 预测本身等同于认知。

稀疏记忆、循环状态和关系记忆必须可独立消融，避免把检索系统的收益误报为主干网络的长程记忆能力。

## 3. 训练任务与数据协议

训练集不能只由随机合成 token 或单一 passkey 任务构成。至少建立以下任务族：

- 长程精确回忆：跨距离检索原文中的实体、数字、定义、约束和引用位置。
- 多跳联合检索：答案依赖多个分散片段的组合，而非单个关键词命中。
- 关系保持：跨段落、跨文档保持角色、属性、时间和因果方向（因果标签必须有独立标注）。
- 矛盾识别：识别来源冲突、时间冲突和同名异义，不把冲突强行压成单一事实。
- 类象形成：从正例、负例和反例形成可修订类别，报告边界和弃权。
- 组合泛化：训练时未出现的关系组合、实体组合和结构组合。
- 连续生成：在长输出中维持全局约束、实体一致性、结构闭合、引用有效性和跨段落逻辑。
- 状态续接：在进程重启、checkpoint 恢复和设备内存压力下保持生成位置与状态一致。

每条样本保留来源、文档/世界/规则族 ID、tokenizer 版本、切块策略、split、标签版本和摘要。必须使用 group-disjoint train/dev/locked-test，防止同源文档、模板或规则泄漏。locked-test 标签不得进入训练进程。

## 4. 长度课程与最终验收

长度课程是训练调度，不是降低目标。最终必须在完整 1M 输入和完整 1M 连续输出上验收。

| 训练/验证阶段 | 输入长度 | 连续输出长度 | 目的 |
|---|---:|---:|---|
| A | 4K | 4K | 状态更新、损失和恢复正确性 |
| B | 16K | 16K | 初步长程依赖 |
| C | 64K | 64K | 跨块检索与关系保持 |
| D | 256K | 256K | 状态容量、漂移与资源曲线 |
| E | 1M | 1M | 最终端到端目标 |

每一阶段都要同时测训练稳定性和未见长度泛化；不得仅因短长度收敛就跳过更长长度验证。阶段 E 必须使用真实 tokenizer 计数，记录完整输入/输出 token 数、丢失/重复 token、状态重置次数和实际峰值资源。

## 5. 必须报告的指标

### 输入侧
- 1M token 完整摄取率、丢失/重复/错序 token 数。
- 远距离精确检索准确率，按距离分桶。
- 多跳联合检索、关系保持、矛盾识别和 abstention。
- 原始证据可追溯率；摘要/索引命中不得计作原文精确回忆。

### 输出侧
- 实际连续输出 token 数及中断/重启次数。
- 全局约束遵循率、实体/术语一致性、结构闭合率。
- 跨长距离矛盾率、重复率、事实漂移率和引用有效率。
- 生成吞吐、首 token 延迟、每 token 延迟、峰值内存和功耗。

### 认知侧
- 类象边界质量、反例修订质量、组合 OOD、跨领域迁移。
- 证据冲突处理、校准、弃权质量和持续学习遗忘率。
- 与参数量、训练数据量、训练 FLOPs 匹配的 Transformer、SSM/RNN、检索增强和符号基线对照。

## 6. 失败条件与科学边界

- SSM/RNN 的固定状态可能形成信息瓶颈；线性复杂度不等于长程保真。
- 外部记忆提高检索表现，不自动证明主干网络自身记住了全部历史。
- 单一 passkey 或 Needle 测试不足以证明长程理解；必须加入联合检索、真实文档和组合推理。
- 1M 输入可处理不代表 1M 输出稳定；输出必须独立做连续生成压力测试。
- 设备规格必须公开；不得将服务器结果表述为普通手机结果。
- 若某项未达到指标，报告失败与边界，不得通过摘要、滑窗丢弃、外部模型代答或隐藏资源转移规避验收。

## 7. 实施顺序

1. 在现有 N0.10 流式/out-of-core 管线之上增加 token 级而非仅行数级的长度计量和完整性校验。
2. 建立统一的 1M 输入/1M 输出评测驱动器、locked-test 隔离、checkpoint 和资源监控。
3. 以最小可训练循环主干建立基线，比较 SSM、门控 RNN/线性递归和多尺度状态更新；先固定 tokenizer 与数据协议。
4. 加入稀疏情景记忆和层级索引，做有/无记忆消融。
5. 接入 CPG-EI 类象/关系认知任务，独立评估语言建模与认知能力。
6. 完成长度课程并最终在普通电脑、普通手机设备分别做 1M/1M 验收。

首个可交付不是“模型已达到 1M”，而是可复现的训练与评测闭环、基线模型、资源报告和明确失败边界。随后每次模型更新都必须在同一协议下比较。

## 8. 研究依据与阅读入口

- Huang, 2025, *How Well Can a Long Sequence Model Model Long Sequences?*：指出 SSM/线性递归模型在实际长程任务上仍存在局限，不能从理论复杂度推断实际长程能力。
- Liu et al., ACL 2025, *Scaling up the State Size of RNN LLMs for Long-Context Scenarios*：研究状态规模与长上下文能力的关系。
- Zhan et al., NeurIPS 2025, *Overcoming Long-Context Limitations of State-Space Models via Context-Dependent Sparse Attention*：指出多查询联合检索暴露出纯 SSM 的表达限制。
- Li et al., 2026 preprint, *History Replays Itself: Unleashing Long-Context Capability in Linear Attention*：提出稀疏情景记忆与原生 replay 思路；作为待独立复现的候选，不视为已验证结论。

本协议以可复现结果为准，论文主张必须经过本项目设备、数据和任务验证。
