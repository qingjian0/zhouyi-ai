# N0.12 审查：主动实验选择与预测边界

日期：2026-11-11  
分支：research/n12-active-operator-identification-2026-11-11  
PR：#184（Draft）

## 1. 研究定位

N0.11 负责在有限 DSL 中提出能够解释训练转移的候选程序；N0.12 不再重复枚举程序，而是在候选版本空间中选择最能区分候选的输入实验，接收独立观测后淘汰不一致假设。

这使研究路线从“拟合一组样本”推进到“知道哪些样本还不够，并主动寻找区分证据”。

## 2. 本轮发现并修复的输入/输出契约问题

### 2.1 候选程序输出没有经过状态校验

原型只验证查询输入有限且非空，但没有验证各假设程序输出是否有限、非空、维度一致。NaN/Inf 或改变状态维度的程序可能被当成普通分区输出，导致熵与候选淘汰结果失真。

修复：
- 对每个 hypothesis prediction 使用统一 state validator；
- 非有限、空或非法输出 fail-closed；
- 要求预测输出维度与输入状态维度一致；
- 对观测输出执行相同维度约束。

新增测试覆盖 NaN、维度变化和错误观测维度，确保失败不会污染候选版本空间。

### 2.2 容差相等关系不具传递性，分区可能受假设 ID 顺序影响

原实现按 hypothesis_id 顺序逐个把预测归入第一个容差匹配组。但绝对误差容差不是数学等价关系：A 与 B 接近、B 与 C 接近，不代表 A 与 C 接近。于是只改变候选 ID 排序，就可能改变实验分区和熵值。

修复：
- 先计算并验证全部预测；
- 按预测输出和 ID 稳定排序；
- 使用 complete-link 聚类，要求新成员与组内每个已有预测都在容差内；
- 新增只改变假设 ID 对应关系、不改变预测值集合的回归测试。

这定义了一个明确、确定性的容差分区规则，避免把非传递的“近似相等”误当作等价关系。

### 2.3 实验预算和容差类型过宽

原实现只比较预算是否小于零，浮点预算可能被接受；NaN 容差也可能绕过负数检查。

修复：
- max_experiments 必须是非布尔整数且非负；
- tolerance 必须是非布尔数值、有限且非负。

新增非整数预算回归测试。

## 3. N0.12 算法含义与限制

查询排序采用候选预测分区熵，平局时比较期望剩余候选数、最坏分区大小和输入字典序。这是有限候选集、确定性 oracle 下的主动版本空间缩减策略。

它不是未知真实世界分布上的全局最优实验设计，也不是贝叶斯期望信息增益。当前没有建模观测噪声、实验风险、成本或执行延迟。

identified 只表示“当前声明候选集合只剩一个”，不证明候选语法之外不存在其他解释。unidentifiable 只表示“当前有限查询池无法区分剩余候选”，不代表现实世界永远不可辨识。

## 4. 仍需处理的研究问题

1. **观测噪声**：从 exact elimination 发展到带噪声似然更新，并与容差过滤比较。
2. **查询成本与风险**： acquisition 应同时考虑信息增益、执行成本、风险、时间和可逆性。
3. **候选语法修订**：若观测不被任何候选解释，必须保留反例并触发 N0.11 grammar revision，而不是只抛错后停止。
4. **连续查询域**：有限 query_pool 无法覆盖连续/高维状态，需要候选生成器、约束域和有界优化。
5. **候选程序等价**：ID 集摘要只标识候选 ID 集合，不是程序语义哈希；若程序对象可变，应增加不可变程序版本或 canonical program digest。
6. **证据真实性**：source_id 是来源标签，不是来源真实性证明；真实系统需要签名、来源权限与独立 evaluator。
7. **易象类象 grounding**：候选变换必须有可观察的状态差分、适用条件、反例与跨领域映射证据，不能只给算子命名。

## 5. N0.11—N0.12—MTS-0 训练闭环

建议整合为：

- N0.11：生成有限候选可执行程序；
- N0.12：识别候选间分歧，选择主动实验；
- 外部环境/工具：执行实验并返回观测；
- MTS-0：先提交预测，再揭示证据，保存可审计顺序；
- 独立 evaluator：验证候选泛化、拒答与校准；
- 反例回流：更新语法、候选和适用域版本。

当前 MTS-0 仍是同进程策略原型，不可视为安全隔离；N0.12 也尚未与 N0.11/MTS-0 集成为端到端闭环。

## 6. 验证状态

本轮对 N0.12 原型增加了输入输出契约、预算类型和容差分区修复，并补充回归测试。
