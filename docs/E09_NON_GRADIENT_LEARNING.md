# E09：非梯度式自主学习机制研究协议

状态：研究设计（未执行、无实验结果）
日期：2026-11-10
所属路线：CPG-EI / Zhouyi-AI

## 1. 研究问题

在不使用反向传播、梯度下降或其他基于梯度的参数优化器时，系统能否仅凭经验样本、预测反馈、反例和计算预算约束，逐步形成、修正并迁移可执行的知识结构？

本实验研究的是**学习机制**，不是仅把神经网络换成超图，也不是把训练循环改名为“自组织”。必须证明系统确实从数据中改变了内部假设、规则或结构，并在未见样本上获得可复现收益。

核心假设 H1：在预先限定的有限规则任务中，结构假设生成、证据筛选和反例驱动修订可以在无梯度条件下学到可迁移规则。

H2：加入结构生命周期控制（CREATE / MERGE / SPLIT / PRUNE）后，系统在分布变化下能比冻结结构更快适应，同时控制旧任务遗忘。

H3：易象编码是否有帮助是独立问题；不得把传统卦象映射写入目标答案或规则生成器，再以此证明易象有效。

## 2. 操作性定义与边界

### 2.1 “非梯度式”判定

E09 主实验中禁止：
- 反向传播及自动微分；
- 梯度下降、Adam、RMSProp 等梯度优化器；
- 先用梯度训练模型、再把输出包装成结构学习；
- 通过测试集反馈选择规则、阈值、超参数或候选结构。

允许：
- 离散假设枚举、版本空间缩减和约束求解；
- 由支持样本与反例驱动的规则增删改；
- 遗传/进化搜索，但必须计入全部候选评估成本；
- 贝叶斯/MDL 评分、显式计数和非梯度统计更新；
- 记忆检索、程序合成、结构重写和验证集门控；
- 随机探索，但必须固定并报告随机种子。

如果某个实现使用了可训练神经网络或梯度优化，只能列为混合方法对照，不得计入“纯非梯度”主结果。

### 2.2 学习的最低证据

仅在训练样本上记忆答案不算学会规则。最低证据包括：
1. 保存训练前后的内部规则/结构快照；
2. 在训练中未出现的输入组合或规则实例上评估；
3. 提供反例，检查系统是否修订错误规则；
4. 提供噪声或分布变化，检查系统是否能拒绝、降级或更新；
5. 与简单查表、随机、固定规则和传统梯度基线比较。

## 3. 研究对象与算法族

所有算法先在同一小型有限规则语言上实现，使用相同输入、反馈、候选预算和停止条件。

| 代号 | 学习机制 | 主要更新对象 | 关键风险 |
|---|---|---|---|
| NG-A | 版本空间/假设消除 | 保留的规则集合 | 假设类预先给定，可能把答案藏在语言中 |
| NG-B | 反例驱动结构修订 | 规则条件、角色、关系边 | 过拟合单个反例、反复震荡 |
| NG-C | MDL/贝叶斯式规则选择 | 规则及其复杂度/权重 | 先验偏置、评分定义影响结果 |
| NG-D | 进化式程序/结构搜索 | 候选规则程序 | 搜索成本高、随机性大 |
| NG-E | 证据门控的超边生命周期 | 超边与证据关联 | 把手工生命周期策略误称为自主发现 |
| HYB | 梯度参数学习 + 结构学习 | 参数与结构 | 仅作为混合基线，不算纯非梯度 |

NG-A 至 NG-E 不预设谁最好；允许组合，但组合必须作为单独实验臂报告，不能隐藏单一机制的失败。

## 4. 统一任务基准

### E09-A：有限规则可识别性复现

从 E02-D 的有限域仿射规则任务出发，先复现已有符号枚举器，确认数据生成、假设类、支持样本和拒答逻辑。该阶段只是管线校验，不作为新方法成果。

### E09-B：未知规则族发现

训练/测试按规则族拆分。训练阶段不向学习器提供目标规则的名称或系数；测试包含未见规则实例。至少包含：
- 可分解低阶规则（低阶方法应能胜出）；
- 真正需要三元/高阶交互的规则；
- 变量角色置换和未见符号映射；
- 规则类外样本（必须允许拒答）。

### E09-C：噪声与反例修订

逐步加入标签噪声、缺失证据、矛盾样本和误导性相关特征。测量系统能否定位冲突、撤销过度概括的规则，并保留仍受支持的部分。

### E09-D：分布变化与持续学习

任务分阶段改变规则或输入分布。比较冻结结构、无约束更新、证据门控更新和结构生命周期更新。测试旧任务回放、灾难性遗忘、更新延迟和错误结构累积。

### E09-E：易象先验独立消融

在 E09-B 至 E09-D 的相同任务上比较：
1. 无先验；
2. 随机结构先验；
3. 传统易象结构初始化；
4. 可学习/可拒绝的易象先验。

传统结构不得直接编码标签。必须报告先验失配任务；若易象先验只在与其构造方式一致的数据上获益，不能声称普遍有效。

## 5. 必须设置的基线

- B0：随机猜测；
- B1：精确查表/最近样本记忆；
- B2：固定邻接或固定组合规则；
- B3：预先给定假设类的精确枚举器；
- B4：参数量与计算预算受控的梯度学习器；
- B5：静态超图或静态规则库；
- B6：当前动态超边生命周期机制；
- B7：非梯度算法的简单组合版本。

特别注意：B3 可能在有限规则任务上很强，但它依赖预先给定的假设语言。必须明确区分“在给定规则类内识别”与“自主发明规则类”。

## 6. 公平性与实验纪律

每个实验记录：
- 实验 ID、Git commit、数据生成器版本；
- 随机种子、训练/验证/测试划分；
- 规则语言及其表达能力；
- 候选生成数、每轮评估数、总样本访问数；
- CPU/GPU 时间、峰值内存、总计算预算；
- 超参数选择方式、停止条件；
- 原始逐种子结果、失败案例和结构快照。

正式结果至少 5 个随机种子，报告均值、标准差及适当置信区间。规则族 OOD 必须按规则族隔离，不能仅随机打散样本。测试集不能参与规则选择或阈值调整。

不同方法应同时报告：
- 相同样本/反馈预算；
- 相同候选评估预算；
- 相同墙钟时间预算（作为补充，不代替前两项）。

不能只比较参数量：非梯度搜索可能没有传统意义上的参数量，必须报告假设数量、候选数量、规则描述长度及评估成本。

## 7. 指标与验收

主要指标：
- 未见规则族准确率、精确匹配率；
- 规则识别覆盖率与拒答质量；
- 反例修订成功率、错误规则残留率；
- 分布变化适应速度、旧任务遗忘；
- 结构复杂度、冗余边率、结构震荡次数；
- 每个正确泛化样本的计算成本；
- 置信度校准和错误类比接受率。

E09 阶段验收必须满足：
1. 纯非梯度臂从未使用梯度更新；
2. 超过查表与随机基线，并在未见规则族上报告结果；
3. 在可分解规则控制任务上，不得系统性劣于合理的低阶基线；
4. 反例和分布变化实验可复现，且报告失败；
5. 所有结论均限定在实际测试过的规则语言和任务范围内。

若非梯度方法只在已知有限假设类中有效，结论应写为“有限规则识别有效”，不得写成“实现通用自主学习”。

## 8. 实施顺序

1. 固定 E09 规则 DSL、数据生成器和评测协议；
2. 复现 E02-D 精确枚举器作为可识别性基线；
3. 实现 NG-B 反例驱动规则修订；
4. 实现 NG-C MDL 规则选择；
5. 实现 NG-D 进化式结构搜索；
6. 加入动态超边生命周期与持续学习任务；
7. 最后做易象先验消融和混合方法比较。

先完成协议和基线审计，再执行新算法。不得先看测试结果再修改规则语言。

## 9. 当前结论

- E09 尚未执行。
- 本文是预注册式研究设计，不包含实验结果。
- E02-D 的有限规则枚举结果只能作为 E09-A 的复现起点，不能算作 E09 的成果。
- E09 的成功标准不是证明“非梯度必然优于梯度”，而是找出哪些学习子问题适合结构/证据驱动机制，哪些仍需要参数优化，以及二者如何在可审计的系统中协作。
