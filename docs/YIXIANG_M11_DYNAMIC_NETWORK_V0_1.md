# M11 动态类象网络审计 v0.1

## 1. 研究问题

M1/M2 提供时间层级与结构关系，M7 组织认知闭环，M9/M10 审查组合关系及组合主张。M11 将研究对象从“某时刻有哪些类象关系”推进到“关系如何沿时间发生、失效、重组、形成新通路并保持”。

本模块把《周易·系辞传》“穷则变，变则通，通则久”作为研究问题的启发式框架，而不是预设所有系统必然经历四阶段的普遍定律。

## 2. 四个阶段的可审查操作化

| 阶段 | 研究含义 | 最低证据要求 |
|---|---|---|
| 穷（QIONG） | 某关系/路径在给定条件下受阻或失效 | 明确关系、情境、失败结果和证据 |
| 变（BIAN） | 关系结构发生了可追踪变化 | 有起止快照、变化类型、触发条件及变化证据 |
| 通（TONG） | 新关系或路径在具体情境下可行 | 新关系出现在快照中，并有可行结果证据 |
| 久（JIU） | 同一关系跨不同观测窗口保持 | 同一关系至少在两个不同窗口有维护证据 |

阶段不是固定的线性状态机。可以缺阶段、重复、回退、分叉或形成循环；状态签名可以在较晚时刻再次出现。循环本身不等于稳定，重复出现也不等于持续有效。

## 3. 数据模型

- DynamicSnapshot：主体、严格递增的观测步、状态签名、情境签名、当前关系签名、证据引用。
- RelationTransition：主体、起止快照、触发条件、变化类型、发生变化的关系签名、证据引用。
- PhaseEvidence：阶段、快照、关系签名、观测窗口、结果类型、证据引用。
- DynamicNetworkAudit：结构问题、阶段计数、跨窗口持续的关系，以及解释上限。

同一主体的快照按观测步严格递增。状态签名允许重复；事件可以跨越中间快照，不强制相邻。允许一个快照有多个后继事件，以保留分叉候选，而不强迫单一路径。

## 4. 审计规则

1. QIONG 必须有 failed 结果。
2. BIAN 必须有 changed 结果，且存在指向该快照的转移事件，事件明确包含该关系签名。
3. TONG 必须有 viable 结果，且该关系确实出现在对应快照。
4. JIU 必须有 maintained 结果，且关系实际出现在对应快照；只有通过该项校验的记录才计入持续窗口。同一关系必须跨至少两个不同观测窗口被观察到。
5. 转移必须从较早快照指向较晚快照；主体不得中途切换。
6. 快照、事件和阶段证据的引用 ID 不得重复，以避免同一证据被重复计数。
7. 结构和证据通过后只进入 HUMAN_REVIEW，不输出自动接受结论。

## 5. 与既有模块的关系

- M1：提供多尺度时间、区间和阶段概念；M11 使用离散观测窗口，不把步数差当作真实时长。
- M2/M2.1：提供层级关系和双向约束；M11 将关系签名作为可追踪对象。
- M4：提供条件干预与反事实边界；M11 不将时间先后自动解释为因果。
- M6：提供候选结构重组与回滚；M11 提供重组前后的事件证据审计，不替代生命周期执行器。
- M7：可在后续接入统一闭环；当前 M11 是独立审计器。
- M9/M10：分别处理多视角组合与组合实验；M11 追踪组合关系随时间的变化。

## 6. 古典文本研究边界

《周易·系辞下》“变动不居，周流六虚”“上下无常，刚柔相易”“唯变所适”可作为时位变化的文本入口；《系辞上》“刚柔相推而生变化”可作为关系相互作用的文本入口。“穷则变，变则通，通则久”提供阶段性问题结构。

经文语句、历代注疏和现代系统建模必须分别记录。上述语句并未直接定义本模块的快照、事件、窗口或审计规则；这些属于现代工程操作化。不同注本对“穷”“通”“久”的解释差异，需在后续版本中逐条校勘，不应以单一现代释义覆盖。

## 7. 当前边界

- 不做未来预测、因果识别、连续时间插值或自动关系发现。
- window_id 由数据提供者定义；不同 ID 不自动保证观测窗口在统计意义上独立。
- 证据引用唯一不等于来源独立或证据真实，仍需来源谱系和原始材料审查。
- 目前不估计持续时间、风险率、转移概率、稳定性指数或统计置信区间。
- 阶段标签是研究者提供的证据主张，不由模型从古籍文本中自动推断。

## 8. 验收

专项测试覆盖完整四阶段路径、循环状态、时间倒置、未知快照、主体连续性、阶段证据要求、跨窗口持续性、无效久证据不得计入持续性、证据重复和输入边界。通过仅表示审计结构满足约束，不代表理论得到实证证实。
