# M45：统一实验事件与证据追踪 v0.1

M45 为实验候选、审批、执行、观察、信念更新、停止和跨域审计提供 append-only 事件契约。每个事件绑定 run、context、stage、artifact、evidence、actor、timestamp 和 payload 引用；事件序号与前序事件 ID 形成可审计链。

古典参照：《墨子·小取》“以名举实”“以说出故”“察名实之理”，强调名称、对象与论证根据需要相互对应；M45 将其落实为事件声明必须带有对象和证据来源，不把古代名实论等同现代数据溯源系统。

限制：当前是内存级逻辑追加与链审计，不提供数据库事务、签名、不可篡改存储、时钟可信性或分布式一致性。事件链不是密码学证明。
