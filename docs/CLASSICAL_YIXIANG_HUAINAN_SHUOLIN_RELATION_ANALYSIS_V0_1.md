# 《淮南子·说林训》功能关系、维度譬喻与多路径结果研究 v0.1

## 研究定位

本专题不把《说林训》解释为一套单一的“类比规则”。篇中并列了不同类型的关系材料：对象适用、主体用途、形制譬喻、工具的必要作用、多路径达成同一结果，以及跨物种/对象的效应差异。它们在工程上应进入不同的关系类型，不能只用“相似”或“类应”统一表示。

## 六种不可混同的关系结构

### 1. 主体—工具—用途适配

“毋贻盲者镜，毋予躄者履，毋赏越人章甫，非其用也”把对象的效用放在使用者能力、需求和具体用途关系中判断。

工程含义：工具的功能不能只写成工具的固有属性；至少应记录使用主体、主体能力、任务目标、环境和约束。相同工具对不同主体可能有不同效用。这里是文本中的适用性论说，不直接作为现代无障碍设计或工具科学的实证结论。

### 2. 维度选择性譬喻

“环可以喻员，不必以轮；绦可以为繶，不必以紃”提示譬喻可能只取某个形制/关系维度。喻体与本体不因此成为同一对象，也不自动共享材料、用途、制造过程或因果机制。

工程含义：类比契约必须声明“保留哪个维度”与“哪些维度不迁移”。若源/目标在必要情境轴上不同，只有明确的映射规则、边界和两侧证据才能登记为受限变换；不允许模型自行补齐差异。

“员/圆”“繶/紃”涉及字形与名物训释，当前不锁定唯一解释。

### 3. 同物异用：用途依赖主体与目的

“柳下惠见饴……盗跖见饴……见物同，而用之异”明确把同一物与不同使用目的并置。

工程含义：功能不是脱离主体和目标的单元属性。比较时必须检查 agent、goal、capability、environment；只要关键任务目标不同，就不能把一个用途的结论无条件迁移到另一个用途。

### 4. 必要部件不等于完整原因

“引弓而射，非弦不能发矢，弦之为射，百分之一也”将弦作为不可缺少的条件，同时强调其不足以代表完整射箭活动。

工程含义：区分必要条件、充分条件、促成条件和系统整体机制。某个部件缺失会使结果无法发生，不代表它单独足以产生结果；也不能把文本中的“百分之一”当作可复现的定量因果比例。

### 5. 多路径同结果：殊途同归不等于机制同一

“钓者静之，罟者扣舟，罩者抑之，罝者举之，为之异，得鱼一也”列出不同方法而结果相同。

工程含义：结果等价（outcome equivalence）不等于过程等价（process equivalence），更不等于因果机制等价。系统应分别比较目标、路径、工具、约束和中间状态；相同结果只能支持目标层面的对应。

### 6. 类似对象的效应不能跨对象无条件迁移

篇末以蚕、蝉、蜉蝣及人、鱼、鼠对食物反应的不同作例，收束为“类不可必推”。

工程含义：即使对象在某个粗类别上相近，生理、材料、环境或机制差异也可能使效果不随。古代文本中的物性与疗效叙述必须保留为历史主张，不得转为现代医疗、生物学或毒理事实。

## 理论综合：类象迁移的五层关系

本篇材料支持把类象迁移拆成至少五种独立问题：
1. **表征对应**：源/目标是否只在指定形制或结构维度上相似？
2. **适用关系**：主体能力、目的和环境是否使工具/对象适用？
3. **组成作用**：某个组成部分是必要条件、充分条件还是仅为促成因素？
4. **路径—结果关系**：不同过程是否仅共享结果，还是也共享中间结构？
5. **对象效应**：某种作用能否跨对象、物种或材料迁移？

它们不可折叠成一个 embedding 相似度，也不能由同一关系名自动推出。

## 可证伪验收问题

1. 在只改变非关键情境轴时，门禁是否仍允许原范围内迁移？
2. 在改变主体能力或目标时，功能类迁移是否会暂缓？
3. 在相同结果但不同路径时，系统是否避免推断机制相同？
4. 在只记录必要部件时，系统是否拒绝把它提升为充分原因？
5. 在只保持形制维度时，系统是否避免迁移用途、材料和因果属性？
6. 变换轴值、证据引用或边界任一不匹配时，系统是否稳定 ABSTAIN？

本专题给出的是文本结构分析和工程验收问题，不代表上述古代物性例证已通过现代实验验证。
