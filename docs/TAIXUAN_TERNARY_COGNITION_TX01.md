# 《太玄经》三值结构：可检验化研究设计（TX-01）

状态：研究设计 / 尚未验证性能增益  
分支：research/taixuan-ternary-cognition-2026-11-11

## 1. 研究目的

将扬雄《太玄经》的三值符号与层级生成结构，作为 CPG-EI 的候选离散状态先验，检验它是否能帮助系统学习组合结构、跨层级泛化和动态关系。此模块不把古代宇宙论直接视为现代数学定理，也不预设三值表示优于二值表示。

## 2. 文献依据与谨慎解释

《太玄》以一、二、三为三种基本符号，采用方、州、部、家四重组织，并形成三方、九州、二十七部、八十一首；每首九赞，合计七百二十九赞。相关古籍文本记载“一生三、三生九、九生二十七、二十七生八十一”以及八十一首、七百二十九赞。

本研究将其抽象为三值符号和层级组合结构。现代程序中的 0/1/2 编码只是实现约定，不等于古籍原符号的数值含义。把三值映射为 -1/0/+1 的平衡三进制，是额外的实验编码，不应反向宣称为《太玄经》原义。

## 3. 形式化候选表示

定义三值字母表：\(\Sigma_3=\{0,1,2\}\)。其中 0、1、2 分别作为古籍一、二、三的程序索引，不赋予固定语义。

四位三值向量表示一个首的结构索引：\(h\in\Sigma_3^4\)，因此 \(|H|=3^4=81\)。

每首九赞可由两位三值索引表示：\(p\in\Sigma_3^2\)，因此 \(|P|=3^2=9\)。

组合索引为 \(z=(h,p)\in\Sigma_3^6\)，因此 \(|Z|=3^6=729\)。

这是一种面向计算实验的分解方案，用来复现 81×9 的容量结构；不主张它已经穷尽《太玄经》的历法、占筮或哲学含义。方、州、部、家与四位索引之间的具体次序，应在后续校勘后单独建立版本化映射，不能凭空固定。

## 4. 与周易模块的关系

保留并行的表示族，不做强制替换：

- YI-BINARY：阴阳二值编码。
- TX-TERNARY：太玄三值编码。
- HYBRID：二值与三值双通道。
- LEARNED：不带传统结构的可学习表示基线。
- PERMUTED：保持类别数量但随机置换结构的负对照。

不同任务可以选择不同表示；由验证集决定是否启用，测试集不得参与选择。

## 5. 核心研究假设

- TX-H1：三值状态可能比二值状态更自然地表达三类关系或中间状态。
- TX-H2：四层三分结构可能改善分层组合任务上的样本效率。
- TX-H3：二值与三值并行表示可能提升异质关系任务的覆盖率。
- TX-H4：若收益来自真实结构而非参数量或编码容量，结构化三值方案应优于随机置换负对照。
- TX-H5：在不需要第三状态的任务上，三值方案可能无收益甚至退化；系统必须允许拒绝该先验。

以上全部是待检验假设。

## 6. 实验矩阵

| 组别 | 表示 | 目的 |
|---|---|---|
| A | 普通 one-hot / learned embedding | 无传统结构基线 |
| B | 二值结构 | 周易式二值对照 |
| C | 三值结构 | 太玄式三值候选 |
| D | 二值 + 三值双通道 | 混合结构 |
| E | 三值随机置换 | 检验结构是否真正有贡献 |
| F | 平衡三进制数值映射 | 检验数值几何假设 |

任务至少包括：三类状态辨识、层级组合泛化、未见组合预测、跨层级关系迁移、噪声与缺失状态鲁棒性。每组匹配训练样本、参数量和计算预算，进行多随机种子评估。

## 7. 指标与证伪条件

报告准确率、宏平均 F1、未见组合准确率、校准误差、拒绝率、训练样本效率、推理成本和峰值内存。报告所有种子及置信区间。

出现以下任一情况，不得宣称太玄先验有效：
- 三值方案不优于容量匹配的 learned embedding；
- 三值方案与随机置换负对照无显著差异；
- 增益只来自参数量或额外计算预算；
- 仅在按该编码人工构造的玩具数据上有效，无法迁移到独立任务；
- 结果不能跨种子复现。

## 8. 与 E12 / 阴符经研究的接口

- E12：把三值符号、四层结构作为候选特征语法；由基元提议器提出规则，Gate 独立验证。
- YF：把三值表示作为主体—环境—时机等三元交互的候选编码之一，但不预设这些概念必须恰好三分。
- 共享证据协议：记录表示版本、映射版本、候选规则、支持证据、反例、预测提交和揭示事件。
- 全局协调器：允许二值、三值和无先验模型并行竞争；根据证据与成本选择，而不是固定信奉某一经典。

## 9. 下一步

1. 校勘《太玄经》版本和符号图式，确认一二三画法、排列顺序及方州部家映射。
2. 实现可逆的 81 首 / 9 赞 / 729 组合索引原型。
3. 建立二值、三值、混合、随机置换四组最小对照。
4. 在 E02 / E12 的未见组合任务上进行多种子实验。
5. 只有通过独立任务、消融和负对照，才考虑把 TX-TERNARY 纳入默认认知引擎。
