# 《墨子·大取》与《墨经》“同异—类—故”结构研究札记 v0.1

## 1. 研究问题

《小取》明确提出类推方式及其限度；《大取》《经上》《经说上》《经下》《经说下》则提供更细的“同/异”“类”“故”论述。若只把这些文本归纳为“相似性推理”，会抹去墨家对不同相同关系、论据和推论边界的区分。

本札记区分三种材料：
- **原文见证**：数字底本当前显示的经文；
- **校释与现代研究**：孙诒让、王念孙等校释及现代墨辩研究；
- **项目操作化**：为 Zhouyi-AI 设计的检索字段和推理约束，不等同古人原有算法。

## 2. 《大取》：同不是单一关系

《大取》列举“重同、具同、连同、同类之同、同名之同、丘同、附同、是之同、然之同、同根之同”等不同“同”。不同传本、校注和现代解释对个别术语的断句与含义仍需进一步核验。

重要结论不是现在就把十个术语全部翻译成现代关系，而是：**古代文本自身已经提示“同”存在多种根据，不能被单一相似度指标替代。**

工程处理建议：
1. 原文术语逐字保存，不先归并为一个“相似”标签。
2. 为每个术语保存原句上下文、版本见证、注家解释和解释置信状态。
3. 项目关系类型与古代术语建立多对多映射；一个古词不必只映射一个现代关系，一个现代关系也不应伪称古人已有同名概念。
4. 不清楚的术语标为 unresolved，不由模型补造词义。

## 3. “辞—故—理—类”的论证链候选

《大取》可见“夫辞以故生，以理长，以类行也”这一表述。可先提出一个待检验的项目解释：

- **辞**：待论证的命题或表达；
- **故**：命题所依赖的理由、根据或论据；
- **理**：论证展开时需要保持的条理/关系；
- **类**：命题从具体案例迁移或扩展的路径。

该解释只是操作化假设。尤其“故”“理”的具体语义须结合《经上》《经说上》、篇章上下文和历代校释研究，不能直接等同现代形式逻辑的“前提/充分必要条件”。

《经上》《经说上》对“故”有“小故”“大故”的区分。当前数字文本可见“小故，有之不必然，无之必不然”等表述，但“大故”段落存在校勘问题，孙诒让等校释者对文字有订正。项目必须并列保存底本读法与校改，不应把校改后的逻辑解释伪装成无争议原文。

## 4. 《经说》中的类与异：不类并非简单反义

《经说上》相关条目可见“二必异”“不连属，不体也”“不同所，不合也”“不有同，不类也”等文本。它提示“异”可从数目、连属、同处、同类等角度理解。应当避免把“异”处理成单一布尔反义词：

- 两个对象可以数目上为二，但具有某种共同属性；
- 两部分可以属于同一整体，但仍然是不同部分；
- 两物可以处在不同位置，却在某个属性上相同；
- 两个名称可能同指，也可能异指；
- 两个对象在某一方面同类，不代表它们在其他方面也同类。

这些区分适合支持 Zhouyi-AI 的 typed relation 和局部—整体关系模型，但映射必须由具体文本与例证支撑。

## 5. 与《小取》的互补关系

| 研究层 | 《大取》《墨经》提供 | 《小取》提供 | Zhouyi-AI 对应 |
|---|---|---|---|
| 同异基础 | 多种“同”及“异”的分类 | 明同异之处 | typed relation / sameness basis |
| 类的边界 | 类同与非类、名实相关 | 以类取、以类予 | 分类约束与候选生成 |
| 论据结构 | 故、理与辞的关系 | 以说出故 | evidence / warrant / claim 分层 |
| 推论迁移 | 辞以类行 | 辟、侔、援、推 | 多种类推操作 |
| 迁移限制 | 同异分类、条件限制 | 有同不必全同；然同不必所以然同 | 关键差异、反例、拒绝迁移 |

## 6. 对类象本体的新增约束

本项目不应将“同类”当作图节点间唯一的无类型边。至少要分别表达：

- 属性相同；
- 功能相同；
- 结构/部分关系相同；
- 空间位置或连属关系相同；
- 名称相同或共同指称；
- 结果/现象相同；
- 根据/成因相同；
- 根源或生成关系相同；
- 仅在某个谓词或条件下相同。

以上是现代工程分析维度，不是对《大取》术语逐项作出的定论。对“丘同、附同”等术语，先保留古文原词与待校释状态。

## 7. 对 M5 主动观测的启发

若两假设只在表面属性上相同，而对结构、功能或成因的预测不同，观测应针对这些差异设计。若候选观测在所有假设下给出同一预测，它的信息增益为零或接近零；若某观测能区分“结果相同但成因不同”，它可能具有更高信息价值。

观测设计还要防止把不同类型的“同”混为一谈。例如：
- 同名不等于同物；
- 同处不等于同类；
- 同类不等于同因；
- 同结果不等于同机制；
- 同一整体中的部分不等于整体本身。
