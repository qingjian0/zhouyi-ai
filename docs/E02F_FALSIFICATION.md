# E02-F：训练集伪相关压力测试

## 研究问题

当训练数据中存在一个高度预测标签、但在独立环境中失效的伪关系时，E02-E 式候选发现器是否会把它错误写入长期结构？

## 实验设计

- 隐藏真实规则：8 个二值变量中的未知三阶乘积交互。
- 候选空间：单变量至四阶乘积交互。加入单变量候选是为了让伪相关能够与真实高阶关系直接竞争。
- clean 条件：训练、门控、测试均只含真实规则及独立标签噪声。
- train_only 条件：训练集额外加入一个与标签完全相关的第 9 个变量；门控和测试中该变量独立随机。
- 分割：训练、门控、测试使用独立随机种子；测试集不得参与候选选择或结构创建。
- 门控：训练集选出第一名候选，独立 gate 与成对基线比较；门控准确率低于 0.75 或相对成对基线增益低于 0.05 时拒绝 CREATE。
- 随机种子：默认 100 个，每个条件分别报告。

## 必须报告

- clean 条件的目标成员恢复率、创建率和测试准确率；
- train_only 条件的伪关系选择率、错误创建率、拒绝率；
- 门控准确率与成对基线增益；
- 支持证据和反例数量；
- 两个条件的逐 seed 结果，不只报告均值。

## 证伪标准

- 如果 train_only 条件中伪关系被创建，说明独立门控未能阻止该类伪发现。即使增益偶然为正，门控绝对准确率也必须达到 0.75。
- 如果 clean 条件也普遍拒绝真实关系，说明门控过于保守，发现能力与鲁棒性之间尚未平衡。
- 若只在该生成器下通过，不得外推到非乘法关系、自然语言或因果发现。

## 边界

这是针对训练环境伪相关的合成证伪实验，不是开放域学习器。候选空间仍然具有明确的乘积交互归纳偏置。0.75 的绝对准确率门槛是本实验的预注册工程阈值，不是普适统计显著性检验。单一 gate 的阈值不是严格的多重比较校正；后续需要重复门控、置信区间及独立确认集。
