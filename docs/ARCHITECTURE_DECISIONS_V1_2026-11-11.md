# Zhouyi-AI 架构决策记录 v1

日期：2026-11-11  
状态：本轮收敛决策；后续变更需记录理由、影响和迁移计划。

## ADR-001：非 Transformer 原生认知，语言层可插拔
**决策：** 内部认知不以 Transformer 自回归 Token 预测为唯一或默认机制。结构组合、状态动力学、证据治理和记忆独立运行。  
**原因：** 项目目标是结构化、非自回归认知，而非单纯更换语言模型主干。  
**代价：** 语言 grounding、训练目标和端到端优化更复杂。  
**回滚条件：** 若结构内核在任务/预算对照下无独立收益，可缩小其范围，不必维护“非 Transformer”标签。

## ADR-002：CPG-EI 是研究总伞，ZNCA 是认知组织框架
**决策：** 不再把 CPG-EI、ZNCA、TRLW、SROK 作为竞争的总架构。  
**分工：** CPG-EI 管研究计划；ZNCA 管认知生命周期/模块组织；TRLW 管工作空间表示；SROK 管稀疏组合内核。

## ADR-003：连续与离散双态共存
**决策：** 连续潜在向量用于相似性、可学习参数和动态状态；离散结构用于角色、关系、约束、版本和证据审计。  
**禁止：** 将连续相似度直接等同事实关系，或将符号结构假设为无学习成本。

## ADR-004：全局协调与组合搜索分离
**决策：** SROK 负责有界组合；CSG-GCR 负责候选结构的全局约束协调。  
**理由：** 避免多个模块重复搜索、重复打分或重复维护候选状态。

## ADR-005：单一权威所有权
**决策：** E09、E12-A6、ZPCM、CSL、Hyper-Speed 各自拥有不同的唯一状态。  
**禁止：** 创建第二个证据账本、生命周期状态机、持久事件账本、依赖失效图或调度器。

## ADR-006：易象是可证伪算子族
**决策：** 象数理、类象、互错综、变、时位应等以类型化算子和结构先验接入。  
**要求：** 每个算子有定义、grounding、适用条件、反例、独立测试和消融。传统名称不等于语义已被证明。

## ADR-007：先闭环后扩模
**决策：** 优先完成 SROK + 角色绑定 + 候选协调 + E09/E12-A6 证据/生命周期闭环，再做联合训练和语言模型规模扩展。

## ADR-008：研究分支不批量合并
**决策：** 每个 PR 通过契约、CI、OOD、资源成本和归属审查后逐项集成。  
**理由：** 分支数量、代码量和文档完整度都不是成熟度指标。
