# M48：类象认知架构消融与配对评估 v0.1

## 目标

检验新增模块是否对任务表现产生可测贡献，而不是把整体系统分数归功于任一理论模块。使用相同 episode、相同任务种子和相同评测指标，对 full 与 ablation 变体做配对比较。

## 预设消融组

建议在完整系统可运行后依次评估：去除主动实验选择、去除序贯策略、去除结果条件分支、去除停止规则、去除稳健性门禁、去除跨情境迁移门禁。每个变体必须记录实际启用的组件清单，不能只改标签。

## 统计方法

按 episode 配对计算方向统一后的差值；用可复现 bootstrap 估计均值差区间。若不同变体使用不同 seed 或 episode 集合，当前严格接口拒绝直接比较或发出警告。多次检验、指标选择和探索性分析仍需另行登记。

## 古典约束

《墨子·小取》对“同异”与“所以然”的区分提醒：观察到整体表现变化，不应未经拆解便把变化归因于某个局部模块。M48 用模块消融和竞争解释控制落实这一审慎原则。

## 限制

配对消融效应仅适用于登记的 benchmark 与配置；不能自动证明某个古典理论机制在一般认知任务中成立，也不能消除实现细节、超参数和多重比较造成的偏差。
