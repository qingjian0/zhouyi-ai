# M15 文本片段—类象主张语义范围审计 v0.1

## 1. 研究问题

M14 已审计见证谱系与证据立场，但仍未回答“某段文字究竟支持主张的哪一部分”。M15 将主张拆成可单独审查的原子命题，并将每条证据链接到具体文本片段、文本层、解释情境、覆盖范围与人工审查记录。目标是阻止局部引文被扩张成整段理论、后世注释被误当作早期正文、异文被无声合并，以及脱离语境的类比被判为支持。

## 2. 理论与文本学依据

### 2.1 先秦论辩的内部约束

《墨子·小取》以“以名举实，以辞抒意，以说出故，以类取，以类予”概括名、辞、说、类的论辩活动。这里不能把“类”简单化为现代统计分类，也不能把所有援引都视为演绎证明。篇中辟、侔、援、推等操作的具体解释仍存在学术讨论；M15 因此不预先把一种解释写死，而是要求审查者明确文本支持的是哪一个命题、哪一种推论操作。

《荀子·正名》关于名实、同异与约定的讨论提醒我们：文本中词项的指称与分类边界必须放回其论辩和名制情境。《庄子·齐物论》所呈现的彼是视域转换，则提示同一语句可能随说话者、论辩位置和解释视域而改变功能。这些是研究问题来源，不意味着古籍已经给出现代语义标注 schema。

### 2.2 版本与解释层

传世正文、出土写本、类书引文、注疏、辑佚、校勘记和现代点校文本必须分层保存。异文不等于噪声；不同字词、语序、缺文和增文可能改变命题范围。注释可以作为“注释层证据”支持某种解释史主张，但不能自动升级为原典正文证据。

M15 与 M14 联用：M14 检查见证依赖关系；M15 检查片段与命题之间的审查关系。来源独立不代表语义充分，语义相似也不代表来源独立。

## 3. 数据模型

- ClaimAtom：一个可单独审查的最小主张单元；复杂主张必须拆分。
- InterpretationContext：时代/文本层、文体、说话者或叙述声音、论辩功能、条件。
- PassageSpan：具体见证中的片段、篇卷定位、正文/注释/引文/编辑/重构层、上下文前后文、异文组标识和可选字符偏移。
- EvidenceLink：片段对某一原子主张的支持、反驳、限定、无关或歧义关系；并记录覆盖范围、情境适配、审查状态、审查者和理由。
- AtomAssessment / ClaimAssessment：逐原子评估与整项覆盖汇总。

## 4. 关键门禁

1. WHOLE_ATOM 才能计入该原子命题的完整覆盖；PARTIAL_ATOM 只计局部覆盖，不得推升为完整支持。
2. 只有 ContextFit.COMPATIBLE 的审查链接可进入支持/反驳/限定汇总；不相容语境记为 mismatch，不确定语境保留 ambiguous。
3. 每个 claim atom 单独挂证据；整项主张只有每个原子均有完整支持且无反驳时，才标记 FULL_ATOM_COVERAGE。
4. QUALIFIES 只表示限定，不等于支持；若完整支持与限定证据并存，结果单列为 QUALIFIED_COVERAGE，不得标成无条件完整覆盖；覆盖范围不明的反驳/限定不进入有效计数；AMBIGUOUS 不得折算为支持；即使另有完整支持，存在同一原子主张的未解决歧义时，也不得标成 FULL_ATOM_COVERAGE。
5. COMMENTARY、QUOTATION、EDITORIAL、RECONSTRUCTION 与 BASE_TEXT 明确区分；ClaimAtom 默认只允许 BASE_TEXT 作为证据层，若主张本身讨论注释或引文，必须显式声明允许层；异文组标识保留，不自动择定“正确文本”。
6. 未审查/争议链接不得冒充完成审查；已审查链接要求审查者 ID 和实质理由。
7. 所有结论均是证据范围与审查状态，不是真理判定。semantic_truth_established 固定为 false。

## 5. 当前边界

- 原型不做古汉语自动断句、训诂、句法分析或语义蕴含识别。
- 不根据字符相似度、向量相似度或模型置信度自动判定 supports/contradicts。
- context_fit、relation、coverage 由人工或经过审查的上游流程提供；审查者 ID 不证明其身份或独立性。
- FULL_ATOM_COVERAGE 仅说明每个声明的原子主张均有完整覆盖记录，不代表主张为真，也不保证拆分穷尽、原子定义正确。
- 版本年代、正文/注释归属、引文来源和字符偏移必须由版本学证据核验；本原型只保存声明，不认证。
- 不把“更早见证”自动视为更优读法；也不把语义通顺自动视为原文。

## 6. 与先秦两汉类象研究的衔接

优先以《墨子·小取》《墨子·大取》《荀子·正名》《庄子·齐物论》《吕氏春秋·别类》《淮南子·说山训》《淮南子·说林训》为案例来源。先逐条建立原文见证、篇章位置、上下文、异文与解释层，再拆解主张；清代以前材料为主体，清代以后校勘、辑佚、注释和现代研究用于补漏。

不得把“以类取”“推类”等术语直接翻译成单一现代算法；先记录古典论辩语境中的操作，再提出可检验的计算假设。

## 7. 测试

22 项专项测试覆盖完整/部分覆盖、无覆盖、情境不合、情境不确定、反驳、限定、歧义、多原子主张、未审查证据、未知见证/情境、重复证据 ID、审查理由门槛、注释层区分、异文组保留、主张隔离和语义真实性边界。
