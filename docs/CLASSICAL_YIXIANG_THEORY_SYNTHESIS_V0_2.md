# 传统类象理论综合框架 v0.2：跨时代、跨学派、跨知识门类

## 0. 研究范围与纪律

本框架以清以前文献为主体，优先先秦两汉，再按魏晋南北朝、隋唐、宋元、明代推进；清代及以后材料主要承担异文校勘、辑佚、版本源流、注疏史和现代学术补漏。不得用清人解释覆盖先秦两汉原文，不得把数字转录当作底本，不得把传统宇宙论命题直接当作现代科学事实。

“类象”是本项目的研究总称，不意味着所有古代作者共享同一套理论术语。各书中的取象、比、兴、类、推、应、感、象数、名实、物化、时令、制器等必须先按原语境分别描述，再建立可比较的工程标签。

## 1. 跨典籍的十一类认知操作

| 操作 | 典籍入口 | 可提取机制 | 主要风险 |
|---|---|---|---|
| 观象/察物 | 《周易·系辞下》《说卦》 | 近取诸身、远取诸物；观天察地；取象制器 | 把观察材料与解释结果混为一谈 |
| 分类/群分 | 《系辞上传》《荀子·正名》《淮南子·地形训》 | 按属性、群类、方位、时序组织对象 | 类别边界随语境变化 |
| 比类/推类 | 《墨子·小取》《荀子·正名》 | 选择共享依据，比较后推论 | 相同现象不保证相同成因 |
| 辨异/拒推 | 《荀子·正名》《墨子·小取》 | 识别关键差异，判断是否可迁移 | 只看相似处导致过度类推 |
| 视角转换 | 《庄子·齐物论》 | 彼/是、此/彼依观察立场和指称关系变化 | 将视角依赖误读成事实任意相对 |
| 功能映射 | 《周易·说卦》 | 象与动、散、润、止、藏等作用联系 | 把功能象征误作物理机制 |
| 时位映射 | 《系辞》《说卦》《管子·四时》《淮南子·地形训》 | 时令、方位、阶段、状态联合定位 | 脱离具体时位而静态套象 |
| 类应/感应 | 《吕氏春秋·应同》《春秋繁露·同类相动》《淮南子·天文训》 | 同类相召、音律响应、阴阳感应 | 从局部可观察现象跳跃到宇宙论或灾异因果 |
| 规范转移 | 《管子·版法解》《管子·四时》《春秋繁露·四时之副》 | 自然周期映射到政令、礼制和治理 | 把价值规范冒充经验定律 |
| 比兴/修辞 | 《诗经》传统、《文心雕龙·比兴》 | 比以附理切类，兴以依微拟议 | 把审美唤起当成事实证据 |
| 注疏会通 | 《周易正义》《周易集解》《周易义海撮要》等 | 保存异说、概念转义和解释史 | 把后世注家观点回填为经文原义 |

以上操作标签是 Zhouyi-AI 的工程分类，不是声称古人已有同名统一算法。

## 2. 当前语料扩充批次

结构化语料由 18 条候选记录扩充至 33 条候选记录。本批新增或细化的典籍/解释层包括：

- 《周易·系辞下传》：近取诸身、远取诸物；刚柔相推、变通趣时。
- 《庄子·齐物论》：彼是互因、视角转换、命名与类别判断。
- 《荀子·正名》：辨异而不过、推类而不悖。
- 《吕氏春秋·应同》：类、气、声的类应主张及其异文。
- 《文心雕龙·比兴》：比与兴的不同修辞机制。
- 《周易正义》：孔颖达疏对近取/远取的唐代解释。
- 《春秋繁露·同类相动》：观察性现象、音律类比、宇宙论与政治征兆分层。
- 《管子·四时》：阴阳—四时—刑德的规范性时序结构。
- 《淮南子·地形训》：六合、四极、日月、星辰、四时、太岁共同组织空间—时间框架。
- 《周易义海撮要》：宋代汇解中不同注家对“方以类聚”的解释差异。
- 《孙子兵法·虚实篇》：水因地制流、兵因敌制胜，研究不变量与动态适应；须与银雀山汉简异文对勘。
- 《黄帝内经·素问·四气调神大论》：四时生长收藏与生命过程、养生原则的时序模型。
- 《周礼·考工记》：天时、地气、材美、工巧的多条件质量模型。

所有新增记录均为候选短引和文本观察，尚未完成逐条底本校勘和专家审核。特别是《春秋繁露》篇章真伪、董仲舒归属及后世传本层次，不得因传统题署而视为无争议。

## 3. 证据与来源层级

每一条“文本中出现的说法”与“我们认为它意味着什么”分开保存：

1. **原典文本见证**：具体版本、卷篇、章句、页码/叶码、影像和文本状态。
2. **古代注疏**：注家、时代、所释原句、注文和疏文分离。
3. **目录/版本记录**：书目、序跋、藏印、刊刻信息、辑佚来源。
4. **现代研究**：作者、论文/专著、论证与反对意见。
5. **项目解释**：字段定义、操作化、类象映射假设。
6. **模型推论**：生成候选，不可自我审核或自证为原典内容。
7. **观察/实验**：现代可复核的观察数据，与古代文本主张分离。

原文数字入口只证明“当前数字见证显示该文本”，不自动证明引文在最早传本中如此，也不自动解决作者、年代和篇章真伪。

## 4. 语料字段和计算操作

主张级字段目前包含：
- `xiang_domain`：知识领域。
- `relation_family`：生成、分类、功能、方向、时序、感应、符号、规范类比、因果主张、修辞类比、词汇关系。
- `shared_basis` / `non_shared_basis`：共享依据和关键差异。
- `scope_conditions`：适用范围和条件。
- `causal_status`：未声称、文本因果主张、观察支持、实验支持、受挑战、未评估。
- `reasoning_operations`：观测、选象、分类、比较、抽取共享依据、辨异、类推、视角转换、功能映射、时位映射、象征、修辞、规范迁移、反例测试、条件干预、拒绝迁移。

计算流程不应只做相似度排序，而应显式执行：
`observe → select → classify → compare → abstract_shared_basis → identify_difference → infer_by_analogy → test_counterexample → accept/underdetermine/refuse`。

每一步都需保存输入证据、来源层、条件、候选、反例和裁决理由。若关键条件未知，必须保留 UNKNOWN；若共享依据不足或关键差异破坏关系保持，则拒绝迁移。

## 5. 全传统古文献的覆盖地图

后续语料工作按经史子集扩展，不局限于易学专书：

- **经部**：群经、三礼、春秋三传、孝经、尔雅、纬书（须单独标识真伪和传本）。
- **史部**：正史、编年、纪事本末、政书、地理、职官、典章、金石、谱牒、方志；抽取制度类比、天象记录、地理时位和历史反例。
- **子部**：儒、道、墨、名、法、兵、农、医、天文历算、术数、杂家、小说家、释道典籍；保留各自术语和证据标准。
- **集部**：楚辞、别集、总集、诗文评、词曲、文论；区分比兴、象征、譬喻与事实推理。
- **出土文献**：甲骨、金文、简帛、敦煌文献、碑刻、写本；作为校正传世文献和时代断限的重要证据，不与后世传本混层。
- **类书与丛书**：用于追踪佚文、异文、引文源流；转引必须记录引书、被引文本和类书编纂年代。

优先补充的专门门类：
1. 易学经传、象数、义理、卦变与占筮文献；
2. 名辩、训诂、文字、音韵和目录学；
3. 天文、历法、五行、时令、地理和物候；
4. 医经、本草、脉学、针灸、养生；
5. 农书、农政、畜牧、物候；
6. 礼制、乐律、制度、兵法和治术；
7. 诗学、文论、譬喻、比兴和象征表达；
8. 佛道典籍中的譬喻、因缘、感应和修行阶段论。

## 6. 清代及以后材料的限定用途

清代及以后材料只进入校勘/补遗层：
- 查异文、辑佚、版本源流、目录著录；
- 对照清儒对早期经传的训诂与解释史；
- 检查近现代学术对作者、年代、文本层次的修正；
- 记录争议和反证，避免单一传统说法被固化。

除非研究对象本身就是清代思想史，否则清代注疏不得成为先秦两汉概念定义的默认来源。

## 7. 质量门禁与评估

- 引文准确率：逐字对照底本影像，不能只对网页转录。
- 版本可追溯率：作品、版本、卷篇、页/叶定位完整。
- 层级混淆率：原文/注疏/现代研究/模型生成混淆必须为零容忍错误。
- 类推精确率：错误迁移、跨域过度推论的比例。
- 反例召回率：系统是否能主动找出破坏类比的关键差异。
- 未知保留率：证据不足时是否正确输出未决。
- 跨时代泄漏：同一底本、注疏模板或同源文本不得泄漏到训练和测试两侧。
- 观点多样性：同一句经文的不同历史解释应并列保存，而非合并成单一“正确答案”。

## 8. 下一阶段研究问题

1. 如何区分“同类”“同象”“同功”“同气”“同声”“同位”“同时”？
2. 哪些共享属性足以支持推类，哪些差异是阻断性差异？
3. 取象是由观察者目标驱动，还是由对象结构约束，或二者交互？
4. 时、位、势变化后，类象关系何时保持、何时失效？
5. 感应文本中哪些是可观察相关，哪些是理论解释，哪些是政治修辞？
6. 如何把《墨子》《荀子》的反推类约束转化为可执行拒绝机制？
7. 如何从注疏异说中学习“同文异解”而不误把解释分歧当成文本异文？
