# E13-C.3：随机机制、观测噪声与风险敏感主动干预

日期：2026-11-11  
状态：研究设计与预注册协议；尚未实现为可运行原型

## 1. 研究问题

C.2 的有限状态转移系统是确定性的。真实系统通常存在两种不同不确定性：

- **机制随机性（aleatoric transition uncertainty）**：同一真实状态与动作可能产生多个后继状态。
- **观测不确定性（measurement uncertainty）**：真实状态确定，但传感器/观察者可能读到错误或不完整值。

二者必须分开建模。把观测噪声误认为机制随机性，会导致错误的机制类象；把机制随机性误认为测量噪声，则会过度平滑真实分叉。

第二个问题是：最能区分候选机制的干预，不一定值得执行。它可能昂贵、危险、不可逆或超出权限。因此查询选择需要同时考虑信息价值、成本和风险。

## 2. 分层概率模型

建议分离三个对象：

1. **TransitionKernel**：(P(s_{t+1}mid s_t,a_t,m,c))，表达机制本身的随机转移。
2. **ObservationKernel**：(P(o_tmid s_t,q))，表达真实状态到观测结果的测量过程。
3. **InterventionPolicy**：动作许可、成本、风险、可逆性和资源约束。

目标域预测必须先得到潜在真实状态分布，再经过目标观测通道得到可比较的观测分布。不得把源域传感器噪声直接复制到目标域；观测通道本身也需要显式映射或独立校准。

## 3. 轨迹概率

对动作序列 (a_{0:T-1})，候选机制 (M_i) 给出轨迹分布：

[
P_i(s_{1:T}mid s_0,a_{0:T-1})
=prod_{t=0}^{T-1}P_i(s_{t+1}mid s_t,a_t)
]

观测分布由 observation kernel 边缘化：

[
P_i(o_{1:T}mid a_{0:T-1})
=sum_{s_{1:T}}P(o_{1:T}mid s_{1:T})P_i(s_{1:T}mid s_0,a_{0:T-1})
]

有限小状态空间可精确枚举；较大空间再研究粒子近似或动态规划。近似算法必须报告采样预算、随机种子和误差区间。

## 4. 候选分歧与查询效用

不应继续用“预测字符串是否相同”的 0/1 分歧作为概率机制的唯一指标。

对于候选预测分布 (P_i)，可先用 Jensen–Shannon divergence 衡量候选间分歧：

[
JS(P_1,ldots,P_n)=Hleft(rac{1}{n}sum_iP_iight)-rac{1}{n}sum_iH(P_i)
]

这比直接比较分布的字符串更能表达概率差异，也避免 KL 在零概率事件上的无穷值问题。

但 JS 分歧只是候选预测差异，不自动等于真实 Bayesian Expected Information Gain。只有在候选先验、观测似然与概率校准均明确时，才能计算后验熵下降：

[
EIG(q)=H(Mmid D)-mathbb{E}_{osim P(omid q,D)}[H(Mmid D,o,q)]
]

如果没有可信候选先验，应报告等权假设下的 JS 分歧或区间，不得伪称贝叶斯信息增益。

## 5. 风险敏感查询选择

每个干预候选需记录：
- 直接成本 (C(q))：时间、金钱、能耗、设备损耗；
- 风险 (R(q))：伤害、不可逆性、隐私暴露、外部影响；
- 资源消耗 (B(q))；
- 授权状态与可执行边界。

一个可检验的基线效用是：

[
U(q)=EIG(q)-lambda_C C(q)-lambda_R R(q)-lambda_B B(q)
]

也应比较约束式选择：先过滤未授权或超过风险阈值的查询，再在可行集合中最大化信息价值。不能允许高信息增益抵消硬性安全/权限约束。

参数 (lambda) 必须在实验前固定或通过独立验证集确定，不得看完测试结果后调参。

## 6. 版本空间更新

观测结果 (o) 到来后：
- 若使用概率机制：更新候选后验 (P(M_imid D,o,q))；
- 若候选概率未校准：保留区间似然或仅做定性排序；
- 若观测通道未知：不得把观测值直接当作真实状态；
- 若所有候选似然为零：报告模型失配/CONTRADICTION，不能自动把似然地板抬高以隐藏失败；
- 若样本不足：报告 INSUFFICIENT_EVIDENCE，不强制选出单一机制。

保留机制不确定性与观测不确定性两条独立证据链。

## 7. 必须进行的消融与硬负例

| 对照 | 目的 |
|---|---|
| 确定性 FSTS | C.2 基线 |
| 随机机制、无观测噪声 | 单独测机制随机性 |
| 确定机制、有观测噪声 | 单独测测量误差 |
| 随机机制 + 观测噪声 | 测两种不确定性的可分离性 |
| 错误观测通道映射 | 验证是否错误归因 |
| 方向相反但边际分布相同 | 检验仅看终态分布的盲点 |
| 不同反馈结构但同一短轨迹分布 | 检验有限样本不可辨识性 |
| 高信息、高风险干预 | 检验硬风险约束 |
| 低成本低信息干预 | 检验成本权衡 |
| 未授权干预 | 必须拒绝执行 |

## 8. 指标

- 轨迹分布：log loss、Brier score、校准误差；
- 状态转移：转移矩阵恢复误差；
- 机制识别：候选后验/排序质量、错误接受率；
- 噪声分离：机制随机性与测量误差的归因准确率；
- 主动查询：EIG、累计成本、累计风险、识别所需查询数；
- 安全边界：未授权动作执行率必须为零；
- OOD：未见状态、动作组合、机制族和观测通道。

## 9. 易象先验的实验位置

阴阳、四象、八卦、变爻、互体、错综、五行只能生成候选结构偏置或动作序列假设。概率模型需要比较：
- 无先验；
- 随机置换先验；
- 通用结构先验；
- 单独易象先验；
- 易象组合先验。

必须报告先验是否改善样本效率、轨迹预测、机制识别和风险约束下的信息效率；若只提高训练集拟合或增加错误接受，应视为负结果。

## 10. 实施门槛

C.3 不应直接一次性实现所有概率推断。建议顺序：
1. 有限状态上的精确概率转移核；
2. 独立观测噪声通道；
3. 分布轨迹枚举和校准评估；
4. JS 分歧与真实 EIG 分开实现；
5. 成本/风险硬约束和效用排序；
6. 候选后验更新、零似然失配处理；
7. 多种子、OOD 和消融评估。

当前文件是预注册设计，不代表上述概率运行时已经存在。
