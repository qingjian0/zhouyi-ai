# M2.1 双向整体—局部约束评估原型 v0.1

## 目标与边界

在 M2 typed-relation graph 之上增加一个最小、可审计的整体—局部候选评估器。这里的“双向”指两个明确方向：

1. **局部 → 整体**：局部观察按证据可靠度对多个整体假设进行评分和排序。
2. **整体 → 局部**：整体假设显式给出局部特征预期；与观察不符时产生可追溯 residual，未观察到的特征保持 unknown。

它不是神经网络，不进行参数训练、自动特征抽取或循环式消息传递；不应描述为已实现递归学习或涌现认知。

## 评分规则

对假设 H 与已观察特征集合 O，使用透明的加权对数评分：

- 初始分数为 log(prior(H))。
- 匹配特征增加 log(reliability)。
- 冲突特征增加 log(1 - reliability)。
- 未观察特征不加分、不扣分，列入 unobserved_features。
- reliability=1 的冲突使用有限数值下限，确保竞争假设仍可见；该处理不代表硬证据被“解释掉”。

分数用于同一批候选中的相对排序，不是校准后的概率。不同任务、不同证据集之间不可直接比较。

## 反例与证据

每个冲突都保留 feature、expected、observed、reliability 和 evidence_ref。系统不自动修改假设，也不把反例覆盖为匹配。假设修订必须由上层流程显式提出新版本，并保留旧假设与修订理由。

## 下一步验证协议

构造可控的合成任务，至少比较：

1. 平面特征分类器；
2. 仅局部 → 整体的候选评分；
3. 双向预期检查与残差保留；
4. 完整 M2 typed-relation 图 + 双向候选评估。

指标：整体假设 top-1/top-k、局部关系分类、反例检出率、未知特征误判率、证据可靠度敏感性、候选排序稳定性、结构扰动后的恢复率。

必须按生成规则族分组切分训练/验证/测试（如后续引入学习器），留出未见组合；执行多随机种子、消融、负结果记录。不得让同一模板的近重复样本跨集合泄漏。

## 解释限制

类象匹配只是结构相似性证据，不等于因果关系、历史原义或现实规律。传统文本主张仍须记录具体版本、篇章定位、原文上下文、注疏层次和转引链。该模块不能替代文献校勘。
