# 显式关系代数与类象比较 v0.1

## 目的

现有类象基线把关系按“有向、类型精确匹配”处理。这是安全的默认值，但现实关系并不全都遵循同一种方向规则。比如“相邻”可以是对称关系；“包含/位于内部”可以是一对明确的逆关系。若把所有关系一律反转或对称化，会制造错误类比；若所有关系都只按字符串精确比较，又会漏掉有定义的等价表达。

本模块将关系语义从评估器中独立出来，以显式、可版本化的关系本体管理。每个本体具有 `ontology_id` 与 `version`；创建后关系类型映射不可变，避免同一评估过程中规则被静默修改。

## 操作规则

- **默认有向**：未声明性质的关系保持方向，不自动对称、不自动反转。
- **对称关系**：声明 `symmetric=true` 后，端点交换被视为同一关系。
- **逆关系**：通过互相指向的 `inverse_of` 声明一对逆关系。规范化时统一到字典序较小的关系名，并按需要交换端点。
- **不隐式传递**：本版不推导传递闭包，不把 A→B、B→C 自动推成 A→C。
- **不隐式因果**：关系类型名即使叫 causes，也不代表它已获得因果证据；本模块只比较标注语义。
- **重复语义边拒绝**：两条边经规范化后重合，输入被拒绝，避免重复计数掩盖数据问题。

## 评估输出

比较结果给出 precision、recall、F1，以及 matched、missing、unexpected 三组规范化边。缺失边表示源域关系映射后在目标域没有对应；意外边表示目标域出现了未被源域结构支持的关系。

## 与易学研究的连接

承、乘、比、应、体用、生克等术语不能直接硬编码成通用的对称或逆关系。必须先对具体文献、注本或研究定义进行版本化校勘，再决定其操作性质。某个关系在某一层次上可能有方向性，在另一层次上可能只是位置约束；关系属性必须绑定语境和定义版本。

本模块因此只提供最小关系代数接口，不预置任何易学术语的关系性质。后续可在来源档案基础上添加：
1. 术语的原文出处、版本、上下文和适用范围；
2. 关系角色、时间有效区间、条件约束；
3. 多元关系与高阶关系；
4. 关系变化与时位势变；
5. 反例、争议定义及跨版本比较。

## 边界

该实现是确定性结构比较基线，不是关系抽取模型，不理解自然语言，不判断经典训诂真伪，也不证明类象在现实世界成立。它只回答：在用户明确声明的关系语义规则下，映射后的关系集合是否一致。
