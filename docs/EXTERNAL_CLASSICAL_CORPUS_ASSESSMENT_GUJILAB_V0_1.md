# 外部古典文献语料评估：gujilab/chinese-classical-corpus v0.1

评估日期：2026-11-13  
用途：候选全文检索/批量摄入来源评估，不是类象理论证据或权威校本认定。

## 1. 资源概况

仓库：https://github.com/gujilab/chinese-classical-corpus  
数据说明：https://github.com/gujilab/chinese-classical-corpus/blob/main/README.md  
字段规范：https://github.com/gujilab/chinese-classical-corpus/blob/main/docs/schema.md  
许可证说明：https://github.com/gujilab/chinese-classical-corpus/blob/main/LICENSE

该仓库 README 声称其 v1.3 包含约 1,724 万字源语料，覆盖十三经、说文解字、资治通鉴和二十四史前 15 部，并附有约 197 万条古今文转换/断句指令数据。其来源清单包括殆知阁、chinese-poetry、CTP、维基文库、chtxt、NiuTrans 等。上述规模和覆盖范围是上游仓库的自述，摄入 Zhouyi-AI 前仍需对文件清单、卷数、篇章定位和抽样文本逐项复核。

## 2. 许可证与来源边界

上游 LICENSE 声明：
- `output/` 中结构化古典文本数据采用 CC0 1.0；
- `scripts/` 与 `docs/` 代码/文档采用 MIT；
- 同时列出殆知阁与 chinese-poetry 等上游来源。

这只是上游项目对其产物和来源的许可证声明，不自动替代对各上游数据库条款、数字转录权利、影印图像权利及具体文件来源的独立核验。Zhouyi-AI 应保留来源归属与权利审查字段，不因“CC0”标签跳过来源链审查。

## 3. 适用价值

适合作为：
1. 大规模古文全文检索入口和待摄入文本索引；
2. 篇章/卷次覆盖率盘点与缺文发现；
3. 对照 Zhouyi-AI 现有 111 项候选书目，发现缺失篇目和跨领域材料；
4. 为后续人工校勘建立检索候选、抽样框和异文比对任务。

不适合作为：
1. 未经核验的原典定本或唯一底本；
2. 直接标记为 `verified_primary` / `critical_edition` 的证据；
3. 仅凭不同 URL、数据集副本或不同数据提供方名称就认定为独立来源；
4. 把古今文指令对、现代释义、自动断句或模型生成文本混入原典层。

## 4. 已知质量风险

上游 README 自报的问题包括：
- 《说文解字》仍有 356 个字头显示为缺字占位符；
- 《资治通鉴》卷 258 存在已知字误；
- 部分史书文本由不同来源繁简转换、融合或补卷；
- 《南史》卷 2、7、68、74 使用维基文库补全；
- 不同作品采用不同数据源与处理流程。

这些问题意味着“数据集覆盖完整”不等于“每一条文本均经同一标准校勘”。特别是多源拼接可能使同一底本的镜像、转录和补全片段在表面上看似独立；必须保留逐卷、逐篇、逐片段来源谱系。

## 5. Zhouyi-AI 摄入规则

建议建立独立 adapter，不直接把上游 JSON 原样并入现有古籍语料：

| 上游字段 | Zhouyi-AI 处理 |
|---|---|
| `id` | 保存为外部稳定标识，另生成本项目 record_id |
| `source` | 映射到 work.title，需核验作品名与篇章 |
| `author` | 只保存为传统题署/上游元数据，不直接认定作者 |
| `era` | 映射为候选年代，不覆盖成书层累争议 |
| `category` | 映射为文类候选，不作为类象关系类型 |
| `content` | 保存为候选文本见证，不直接升级为校定原文 |
| `chapter` / `section` / `volume` | 转为 locator 候选，缺少精确章句/页叶时标记定位不完整 |

每个导入片段至少补充：
- 上游仓库、版本/tag/commit、文件路径、记录 ID；
- 原始上游来源及来源谱系组；
- 作品、卷、篇、章、段定位；
- 简繁转换、OCR、标点、清洗和缺文补全记录；
- 原始文本哈希与规范化文本哈希；
- 版权/许可审查状态；
- 独立校本或影像核对状态；
- 与本项目其他记录的重复/近重复关系。

原典文本、古注疏、现代译文、训练指令和模型生成内容必须分层保存。任何自动处理都不得把候选记录自动提升为 reviewed。

## 6. 首轮抽样核验建议

先做小批量，不一次性摄入全部 1,724 万字：
1. 《周易》经文与《系辞》《说卦》；
2. 《墨子》及《荀子》相关篇章；
3. 《庄子》《管子》《淮南子》；
4. 《吕氏春秋》《韩非子》《论衡》；
5. 选取一部史书和一部医书/农书，检验跨文类字段适配。

每部作品抽取若干段落，与至少一种可追溯的独立校本或影像对读；记录异文、漏字、错简、标点差异和定位误差。若上游来源与对照本同源，不得计为独立校验。

## 7. 结论

**建议纳入候选来源目录并开发只读摄入 adapter；暂不把其全文直接并入已校勘古籍语料。**

该资源的主要价值是扩大检索覆盖、发现缺文和降低人工搜集成本；Zhouyi-AI 的核心价值仍应建立在可追溯版本、逐条校勘、主张级证据、来源独立性和反例审查上。规模不能替代版本学质量，文本数量不能替代理论有效性。
