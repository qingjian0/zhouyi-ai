# 先秦至两汉类象的动态条件、视域与适用域研究 v0.2

## 研究目的

本专题把《周易·系辞》《庄子·齐物论》《淮南子·说林训》《管子·四时》与先秦推类研究并读，推进四个问题：

1. 象如何从观察中形成，又如何受整体关系和变化约束？
2. 同一对象为何会因主体、任务、时机、位置不同而呈现不同用途或结果？
3. 观察立场和参照对象改变时，哪些判断会改变，哪些关系可能保持？
4. 古代“推类”是否能被简单等同于现代类比推理？

本专题中的工程术语是 Zhouyi-AI 的现代操作化，不是古人已经提出的机器学习、状态空间或信息论模型。

## 一、关键文献观察

### 1. 《淮南子·说林训》：同物异用、同气异积、类不可必推

《说林训》保存了多组对类推边界极有价值的例子：

- “见物同，而用之异”：观察对象相同，不意味着不同主体的用途相同。
- “类不可必推”：不能把已知类别关系当成无条件推广许可证。
- “同气异积”：共同条件或共同材料，不意味着形成的聚集、配置和结果相同。
- “势施异也”：同一任务在不同姿态/情势下，难度和结果可能不同。
- “钓者静之，罧者扣舟，罩者抑之，罣者举之，为之异，得鱼一也”：操作路径不同可以达到相同目标，但结果相同不证明机制相同。
- “汤放其主……所为之则同，所以为之则异”：行为表面相似与行为缘由/根据不能混为一谈。

这些例子适合分别标注对象、主体、用途、任务、环境、动作、机制、结果和评价，而不是压缩为一个“相似度”。

数字文本入口：
- 《淮南子·说林训》：https://ctext.org/huainanzi/shuo-lin-xun/zhs
- 页面显示《四部丛刊初编》《摛藻堂四库全书荟要》《正统道藏》等版本入口，但当前项目尚未逐条回看影像并建立见证谱系。页面版本列表不能直接视为已完成互校。

### 2. 《庄子·齐物论》：彼是关系与视域索引

“彼出于是，是亦因彼”“彼亦一是非，此亦一是非”把判断放进参照关系中。其工程价值不是取消事实判断，而是要求系统记录：

- 观察者/判断者；
- 参照对象；
- 判断谓词；
- 评价标准；
- 时间与情境；
- 视域切换后发生变化的部分；
- 视域切换后仍保持的、且有独立证据的关系。

若两个命题在同一对象、同一时间、同一谓词、同一条件下冲突，不能仅用“视角不同”消解。视域多样性也不能替代事实证据。

数字文本入口：
- 《庄子·齐物论》平行段落检索：https://ctext.org/text.pl?if=en&node=41935&remap=gb&show=parallel
- 现有专题仍须继续核对郭象注、成玄英疏与传本差异；数字检索页面不是单一底本。

### 3. 《管子·四时》：时令是作用条件，不是装饰标签

《四时》以春夏秋冬、方位、气、政令和生长活动组织论述，并明确讨论“春行冬政”“春行秋政”等不合时的情形。它可作为“行动—时机—环境—结果”耦合的历史材料。

工程上必须区分：
- 文本内部的时令宇宙论/政治秩序主张；
- 可观察的季节环境变量；
- 具体制度行动；
- 结果与因果证据。

不能把古代时令配属直接当成现代气象、生态或医学事实。现代可检验变量需要独立定义和数据。

数字文本入口：
- 《管子·四时》：https://ctext.org/guanzi/si-shi

### 4. 《系辞》：观象与立象是研究入口，不是算法证明

“观象”“制器”“立象”等经传语句可用于研究观察、抽象、表达与行动之间的关系。必须先区分经文、传文、注疏及后世象数体系；不得把后世完整卦象配属表回填为先秦文本已经明确给出的规则。

## 二、推类概念的学术争议：不可把“推类”简单等于“类比推理”

晋荣东《推类等于类比推理吗？》（《逻辑学研究》2013年第4期）梳理了不同解释路径，并提出推类不宜简单等同于类比推理；其文讨论《墨辩》《荀子》《吕氏春秋》《淮南子》等材料，指出类同原则可能与演绎、归纳、类比等不同推论过程发生关系。

参考：
- 晋荣东，2013，《推类等于类比推理吗？》，《逻辑学研究》6(4):60–78。PDF：https://faculty.ecnu.edu.cn/picture/article/581/16/7f/23afa62d45eabbc4560e4003c0bf/d77124cc-b2fa-4bcc-88d9-2717a00e6232.pdf
- 李巍，2016，《逻辑方法还是伦理实践？——先秦儒墨“推类”思想辨析》，《文史哲》2016年第5期。PDF：https://www.lhp.sdu.edu.cn/__local/D/09/89/97CDB1BEE357C78543A0BF5065C_6C4E193B_4AA16D.pdf

两篇现代研究提供的是解释史中的不同论证，不是原典本身。李巍强调儒墨推类可能具有伦理实践与正当言行推广维度；晋荣东反对把推类一概收窄为类比推理。项目应把“推类”保留为历史语境中的上位研究术语，再对具体篇章的操作逐例标注，不预先规定唯一现代逻辑类型。

## 三、统一的动态类象记录模型

建议把类象事件表示为：

- entity_or_event：被观察的对象/事件；
- observer_standpoint：观察者或判断立场；
- reference_frame：参照对象、坐标或比较基准；
- observed_features：实际观察到的特征；
- relation_basis：共享关系或属性；
- non_shared_basis：关键差异；
- agent_capability：主体能力、资源和限制；
- task_or_goal：任务或目标；
- environment：外部环境；
- time_phase：时间、阶段或时令；
- process_path：过程与操作路径；
- outcome：结果；
- normative_evaluation：规范评价，若有；
- evidence_lineage：见证与来源谱系；
- counterexamples：已知反例；
- scope_conditions：结论成立范围。

这是一份研究建议，不意味着当前语料 Schema 已全部实现。

## 四、四个必须分离的层次

1. **对象/形态相似**：观察到哪些共同特征？
2. **功能/目标相同**：是否实现同一任务或结果？
3. **过程/机制相同**：是否通过相同因果路径实现？
4. **规范/评价相同**：是否在相同制度、角色和理由下获得相同评价？

其中任何一层都不能自动推出其他层。

例：
- 多种渔具都“得鱼”，只能先支持结果/目标层的相同。
- 不同主体对同一物有不同用途，说明功能依赖主体与任务。
- 同样的外在行为可能因动机、情境或规范角色不同而获得不同评价。
- 相同的观察形态可能因参照系不同而产生不同关系判断。

## 五、对 Zhouyi-AI 的工程约束

- M2：将对象、属性、关系、主体、任务、环境、时间和视域分开建模。
- M3：竞争解释至少区分“对象属性变化”“观察位置变化”“主体能力差异”“任务变化”“环境变化”“评价标准变化”。
- M4：支持单变量与多变量干预；移除主体能力、任务、时间或环境，检查结论是否仍成立。
- M5：优先选择能区分竞争解释的观测；不能把预测中的预期观测当成已执行证据。
- M6：新象候选携带主体/任务/时机适用域，跨域残差不能自动升格为普遍规则。
- M7：先做参照与条件对齐，再做迁移；结果相同不得直接升级为机制相同。
- M8：按作品、版本、注疏谱系隔离划分；增加主体—任务错配、同结果异机制、视域反转、时令错配等负控。

## 六、M8 新增对抗样例设计

建议加入：
1. 同一对象对不同主体用途不同；
2. 同一目标由不同过程路径实现；
3. 结果相同但机制未知；
4. 共享环境但主体能力不同；
5. 参照对象改变导致“彼/此”角色翻转；
6. 时间阶段变化导致谓词变化；
7. 评价相似但行动理由不同；
8. 时令标签相同但实际环境变量不同。

预期系统行为：范围内条件接受、证据不足暂缓、明确错配拒绝。所有新增合成样例只验证规则门禁，不代表已证明认知能力提升。

## 七、可证伪实验

- **主体消融**：隐藏主体能力/角色字段，测量错误迁移率变化。
- **任务消融**：隐藏任务目标，测量同物异用误判率。
- **过程消融**：隐藏过程路径，测量结果同一被误判为机制同一的比例。
- **时序消融**：隐藏时间/阶段，测量表面矛盾误报率。
- **视域消融**：固定单一参照系，比较参照转换任务表现。
- **来源隔离**：按底本/整理本谱系拆分训练与测试，测量同源泄漏对成绩的影响。

所有实验必须报告随机种子、数据划分、基线、参数/计算预算和失败样例；不能只报告有利结果。

## 八、待完成校勘

1. 《说林训》所引“见物同而用异”“类不可必推”“同气异积”“势施异也”等条目，逐条定位上下文、版本、卷页和高诱注。
2. 《齐物论》“彼出于是”“道枢”“两行”“朝三”相关段落，建立郭象注、成玄英疏和传本层次。
3. 《管子·四时》辨析篇章层累、四时政令语境及不同版本。
4. 《系辞》经传层次与后世象数注疏严格分离。
5. 现代研究对推类的不同解释纳入解释史，不覆盖原典证据。
6. 对 M8 所有新增 fixture 进行独立人工审查；审查前保持 fixture_expected。

## 结论

本轮研究将类象从“相似关系”推进到“条件化动态关系”：对象、观察立场、主体能力、任务、环境、时间、过程和评价都可能改变推类的适用性。真正可靠的类象认知引擎必须学会的不只是迁移，更是判断何时不能迁移、何时只能局部迁移，以及何时证据不足应当暂缓。
