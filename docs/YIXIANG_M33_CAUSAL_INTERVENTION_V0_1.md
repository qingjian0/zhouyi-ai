# M33：类象组合的因果干预与反事实分解 v0.1

## 1. 研究目标

M32 解决组合结构、成员/整体证据分层与整体反例登记；M33 进一步询问：对组合中的一个成员或关系实施明确干预后，整体结果如何变化？这种变化是否足以支持因果解释？

核心约束：
- 观察关联不等于干预因果。
- 对不同个体/组合实例的匹配比较，不等于同一个体同时观察到的两个潜在结果。
- 干预改变多个因素时，不能把结果差异归因于单一目标因素。
- 机制解释必须与替代解释竞争，并明确识别假设。
- 本原型只审计研究设计和证据契约，不自动识别因果、不证明反事实、不认证因果真值。

## 2. 与 M26/M31/M32 的差异

M26 声明符号组合结构；M31 研究跨情境不变量候选；M32 审计不变量组合与整体证据。M33 新增“干预对象—对照条件—处理条件—目标观测量—识别策略—反事实假设”链条。它不重写上述模块，也不宣称已将其数据结构自动接线。

## 3. 古典材料：可启发问题，不可替代因果识别

### 《墨子·经上》《经说上》与《经下》

《经上》讨论“故”，《经说上》区分“大故”“小故”等条件关系；《经下》有“物之所以然，与所以知之，与所以使人知之，不必同”，区分事物所以然、认识它的根据和使人知道它的方式。此处适合作为“对象机制、观察证据、传播/说明方式不能混同”的研究入口。

### 《墨子·小取》

“其然也同，其所以然不必同”提醒研究者：相同结果并不保证相同原因；“远而失，流而离本”警告推类跨越过远。M33 因此要求替代解释、干预目标与证据来源明确。四部丛刊本《墨子》卷十一可作版本见证；《墨子闲诂》可用于校补与解释史，不能把后世术语直接归为先秦原义。

### 《荀子·正名》

《正名》强调依据感官与“心有征知”辨同异，并区分“同状异所”“异状同所”。这可提醒实验设计控制对象、情境与测量差异；但它不是现代随机试验或潜在结果理论。

### 解释边界

古典“故”“所以然”“类”“征知”不与现代因果图、潜在结果、随机化干预一一对应。现代因果推断术语只作为工程分析工具，不倒灌为古文原义。

## 4. 干预类型

- REMOVE_MEMBER：移除一个组合成员。
- SUBSTITUTE_MEMBER：以预先定义的替代成员替换目标成员。
- REMOVE_EDGE：移除一条组合依赖/关系边。
- SWAP_ORDER：交换有序组合中的成员次序。
- CHANGE_CONTEXT：改变明确的情境条件。
- SET_MEMBER_VALUE：将一个成员属性设置为预先规定值。

每个干预必须声明唯一目标、对照条件、处理条件、改变因素、控制因素、预测方向与预注册引用。改变因素与控制因素不得重叠。

## 5. 反事实与研究单位

StudyUnit 记录组合实例、对象家族、情境家族、来源家族、处理条件、结果测量与证据。CounterfactualPair 记录匹配对照/处理单位，并要求：
- 同一目标总体或可辩护的匹配单位家族；
- 相同结果测量；
- 明确匹配依据；
- 可交换性、一致性、正值性与干扰假设；
- 处理分配和结果证据可追溯。

注意：两条不同单位的记录只是匹配比较，不是同一个体的真实反事实。个体层潜在结果不可同时观测；必须依靠研究设计与假设识别总体效应。

## 6. 因果主张审计

CausalClaim 要求：
- estimand（例如 ATE 或条件平均效应）；
- 目标总体；
- 识别策略；
- 一致性、可交换性、正值性、无干扰等适用假设；
- 替代解释；
- 效应估计与不确定性方法；
- 证据引用和审查者。

仅观察性回归或相关性分析只能标记为 ASSOCIATIONAL_ONLY。随机化或准实验声明也不会自动获得因果认证，仍需核验执行、依从性、失访、测量偏差、干扰与识别假设。

## 7. 关键反事实问题

1. 移除某成员后整体输出是否变化？
2. 替换为同类但不同来源成员，效果是否保持？
3. 移除一条关系边是否改变结果？
4. A→B 与 B→A 是否出现方向反转？
5. 固定成员而改变情境，整体规律是否失效？
6. 保持观测输出相似，内部机制是否不同？
7. 单因素干预与多因素同时改变能否区分？
8. 干预效果是否只在某些对象/情境家族成立？

## 8. 评估与报告

建议固定随机种子、数据划分、干预实现、样本量、测量定义、模型/估计器配置和置信区间方法。报告：
- 平均处理效应与异质性效应；
- 干预依从率与操纵检查；
- 失访/缺失与选择偏差；
- 混杂敏感性与负对照；
- 顺序交换效应、成员移除效应、边移除效应；
- 跨对象/情境家族复现；
- 负结果与未识别部分。

本 v0.1 还未实现估计器、随机化执行、DAG 调整集求解或敏感性分析；只审计输入设计是否完整。

## 9. 专项测试与边界
