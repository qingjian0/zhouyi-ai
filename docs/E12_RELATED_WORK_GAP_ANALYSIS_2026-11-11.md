# E12 相关研究差距分析：从组合泛化到原始基元归纳

日期：2026-11-11  
状态：[研究分析]；不是本仓库实验结果

## 1. 研究定位

E12 不应声称“第一个发现可复用基元的系统”。已有研究已经在视觉类别发现、组合表示、程序合成和概念学习中研究相关问题。E12 的研究价值应聚焦于以下组合：

1. 候选谓词由观测数据提出，而不是只在固定语义字典中选择；
2. 候选可以由任务证据、反例和主动测量持续修订；
3. 结构可以在关系/概念层级间复用，并记录来源与有效范围；
4. 易象先验作为可拒绝的 inductive bias，与容量匹配的通用先验对照；
5. 多条候选结构路径在固定预算下竞争，并保留不可辨识的解释。

这是一组需要逐项实验验证的研究目标，不是已确立的独特性或性能优势。

## 2. 相关方向及其对 E12 的启发

### 2.1 ExeDec：执行分解与程序组合

ExeDec 将复杂程序合成任务分解为执行子目标，并在每一步利用执行反馈。这说明“先形成子目标、执行、再用结果约束后续生成”是一条可比较的组合泛化路线。

E12 可借鉴：
- 把候选谓词作为可执行单元；
- 使用执行结果生成反例；
- 对候选结构进行逐步验证。

E12 不能简单复刻：
- 研究重点不只是把已知程序拆成子程序；
- 候选谓词本身也必须能够由观测提出；
- 需要单独评估候选生成质量与候选组合质量。

### 2.2 Swing-by Dynamics：概念学习的阶段性

该方向研究模型在组合数据中学习概念的动态过程。对 E12/E11 的启发是：不应只比较训练结束时的准确率，还要记录概念何时出现、何时稳定、何时能够被组合，以及错误概念是否会在后续阶段被修正。

建议加入：
- learning curves by primitive family；
- first reliable discovery step；
- concept reuse onset；
- false-discovery persistence；
- counterexample recovery trajectory。

### 2.3 CoGe-GCD：组合感知的类别发现

CoGe-GCD 将视觉 token 组织为可复用基元，再利用结构化空间关系提升未见组合上的类别发现。它与 E12 的“基元发现”和 E11 的“概念形成”直接相关。

E12 应借鉴：
- 区分感知/基元组织与后续组合归纳；
- 评估未见组合，而不只评估已知类别分类；
- 将结构化关系作为可测试的归纳偏置。

关键差异必须通过实验而非命名建立：E12 当前是一般可执行谓词与关系的有限 DSL 原型，不是视觉 patch primitive 模型。

### 2.4 CPF-GCD：潜在结构可辨识性

CPF-GCD 强调表示空间是否被组织成可分解的低秩组合结构，会影响新类别与潜在概念的发现。对 E12 的启发是：候选基元能否被识别，不只取决于搜索算法，也取决于观测通道、噪声、生成机制和表示结构是否提供了足够信息。

因此，E12-A1 必须先有可辨识性审计，再比较候选生成器。否则算法失败和问题本身不可辨识会被混为一谈。

### 2.5 组合结构不保证组合泛化

固定的组合表示并不自动带来任意任务上的组合泛化。训练分布偏差、shortcut 和缺失组合都可能让模型只记住训练组合。

E12 必须分别报告：
- 已见基元的新组合；
- 已见基元的新关系角色；
- 未见规则族；
- 新观测通道或新噪声环境；
- 新世界生成机制。

不能把这些统称为 OOD。

## 3. 对 E12 的架构修订建议

将 E12 的计算流程拆成六个可单独评估的模块：

1. Observation normalizer：保留来源、类型、时间、缺失值和测量条件。
2. Proposal generators：统计、时间、几何、关系、对比、预测残差等多家族并行提议。
3. Canonicalizer：类型检查、规范化、行为等价筛选。
4. Evidence evaluator：Support 拟合、Gate 选择、Locked Test 最终评分。
5. Active measurement planner：在预算内选择最能区分候选的测量。
6. Primitive lifecycle manager：PROPOSE、TEST、ACCEPT、REFINE、SPLIT、SUSPEND、RETIRE。

这六个模块不应一开始就用一个端到端神经网络替代。先做透明基线，才能判断每个机制是否真正带来增益。

## 4. 多路径并行与 E03 的接口

每个 proposal family 可以输出候选集合，但不应独立拥有无限预算。建议由 E03 统一分配预算：

- 每个提议器提交候选、来源、估计成本和不确定性；
- 去重器合并观测行为等价候选；
- 协调器在质量、复杂度、新颖性和成本之间保留 Pareto 集；
- Gate 结果更新各提议器的预算权重；
- 随机提议器持续保留少量探索预算，避免只强化当前成功家族；
- Locked Test 不得反馈给协调器。

需要与串行穷举、随机提议、单一最强提议器比较，且所有组使用相同总预算。

## 5. 易象先验的研究边界

易象先验应在基础候选生成器验证后单独接入。建议先比较：
- 无先验；
- 通用互补/层级/稀疏转移先验；
- 易象启发先验；
- 随机置换先验；
- 可学习先验。

每种先验均应记录其改变了什么：候选生成分布、搜索空间、正则项、状态编码，还是协调器偏好。否则即使结果变好，也无法知道增益来自哪一机制。

## 6. 当前最重要的研究缺口

E12-A1 原型只覆盖有限 DSL 的候选生成和 Gate 选择。下一阶段优先级应为：

1. 随机提议与固定特征对照；
2. 多潜在世界与规则族 OOD；
3. 独立 evaluator 进程；
4. 主动测量选择；
5. 反例驱动的谓词修订；
6. 多提议器预算协调；
7. 易象先验消融。

在这些测试完成之前，不应宣称 E12 已实现自主概念发现、因果发现或超越 Transformer 的能力。
