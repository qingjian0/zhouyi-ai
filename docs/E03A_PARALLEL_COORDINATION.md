# E03-A：并行多关系发现与全局协调

## 研究问题

当多个关系同时存在时，系统是否应并行生成候选，再由全局机制在共享资源约束下协调，而不是每次只寻找一个最优关系？

## 预注册任务

- 8 个二值特征，3 个独立输出通道。
- 三个隐藏三阶关系分别使用成员集合 (0,2,5)、(2,5,7)、(0,4,7)；均包含跳过中间元素的非连续组合。
- 每个输出通道有自己的未知非仿射三变量布尔真值表。
- 每个通道从 84 个二阶/三阶特征子集并行生成候选。
- 每个通道保留训练分数最高的 8 个候选。
- 全局协调器枚举最多 8^3 个候选组合，在共享特征预算 5 下最大化独立 gate accuracy 总和；禁止把完全相同的关系分配给多个输出通道。
- 对照一：每个通道独立使用 gate 选择最佳候选，不施加全局预算。
- 对照二：只允许连续特征子集的邻接组合。
- 所有结构选择完成后，才使用锁定 test 集审计。

## 关键指标

- 每个输出的成员恢复率和完整规则恢复率；
- 锁定 test accuracy；
- 独立选择是否违反共享特征预算；
- 全局协调选出的特征并集大小；
- 邻接组合消融的性能。

## 为什么这一步重要

E02 系列主要回答“一个关系能否被发现、验证和维护”。E03-A 开始检验多个关系能否同时提出候选，并在共享约束下协同存在。目标集合刻意采用非连续索引，防止算法退化为只组合相邻元素。

## 限制

这是有限候选空间中的多输出合成实验。目标三元组、输出通道数量、特征预算和协调目标均由研究者预先定义。全局协调器是显式枚举的手工优化器，不是自主学出的协调机制。通过只能证明该架构原型在此任务上的有效性，不能证明开放域组合智能。
