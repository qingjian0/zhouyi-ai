# M53：隐藏因果结构与观测偏差 v0.1

## 研究目标

M51 建立了二元 Logistic 与非线性交互 SCM 原型，M52 加入家族级拆分与泄漏审计。M53 扩展数据生成环境，显式覆盖观测数据中常见的识别障碍：

1. 隐藏混杂：U -> X、U -> Y，同时存在 X -> Y。
2. 碰撞点选择：X -> S <- Y；仅分析 S=1 会引入非因果关联。
3. 测量误差：观测到 X* = X + epsilon，而结构机制作用于 X。
4. 机制漂移：不同环境中的 X -> Y 系数发生变化。

## 数据隔离

Agent-facing 数据只提供 ObservedRow，不包含潜在混杂变量 U、真实未污染的 X 或结构因果效应。EvaluatorTruth 单独保存评估真值，不应传入候选选择器、提示词或训练输入。

audit_m53_dataset 检查记录类型、唯一 unit_id、有限观测值、选择标记和评估真值结构。它是数据完整性检查，不是因果识别证明。

## 实验原语

- hidden_confounding_dataset：生成 U 同时影响 X 与 Y 的观测总体。
- collider_selection_dataset：生成 X、Y 指向选择变量 S 的碰撞点结构；默认零处理效应，用于检验仅条件化于 S=1 是否产生虚假关联。
- measurement_error_dataset：加入经典加性 X 测量误差。
- mechanism_drift_dataset：为多个环境生成不同结构效应。
- paired_intervention_effect：使用相同单位外生噪声计算 do(X=1)-do(X=0)，作为已知机制下的干预估计校验。
- selected_correlation：仅返回被选择样本中的描述性相关，不得解释为因果效应。

## 必须遵守的解释边界

- 观测斜率偏离结构效应，说明该观测估计量在当前生成机制下有偏；不能单凭该结果断言某种算法普遍失败。
- 隐藏混杂通常不能仅凭观测分布非参数识别；需要额外假设、工具变量、代理变量、环境变化或干预。
- 对碰撞点进行条件化可能制造关联；是否发生及方向依赖具体分布和选择机制。
- 测量误差的偏差形式依赖误差模型；经典加性误差下的衰减现象不能推广到所有误差类型。
- 机制漂移要求报告环境条件和环境内效应，不得将跨环境平均值冒充稳定因果效应。
- 当前实现是合成数据协议与测试原语，不是完整因果发现 Agent，也没有真实数据或 Transformer 对照结果。
