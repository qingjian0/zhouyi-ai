# YJ-04：关系状态中的候选算子发现与主动辨识

日期：2026-11-11  
阶段：有界结构归纳参考原型  
分支：`research/yj04-relational-operator-discovery-2026-11-11`

## 1. 为什么需要 YJ-04

N0.11 从数值向量和人工限定的 DSL 中归纳短程序；N0.12 在有限候选程序之间选择区分性实验。YJ-01～03 将阴阳、五行、爻位、时位、卦变和类象表达为类型化算子，但其组合规划目前主要检查类型签名。

这留下一个断层：系统可以组合已经命名的算子，却不能从关系状态的变化提出一个此前未登记的候选机制。

YJ-04 将“发现”限定为一个可复现的结构任务：从前后状态和显式干预标签中抽取关系增删模式，以角色而非实体 ID 对齐样本，提出有证据来源的候选机制，再用留出轨迹和主动查询检验。

## 2. 机制假设的表示

候选机制由以下字段共同定义：

- 输入角色签名：角色 → 对象类型；
- 干预标签：观测记录中明确给出的动作/条件；
- 结构前置条件：多个支持样本中共有、且预测时必须存在的关系模式；
- 状态转移：按角色定义的关系删除与新增；
- 上下文约束：多个支持样本中稳定共有的上下文键值；
- 证据：样本 ID、观测/干预类型和领域；
- 版本：候选 ID 与版本号；
- 状态：提出、获得干预支持、或被反例否定。

候选不以实体名称或词面相似性为核心，而以类型化角色和关系方向为核心。不同实体 ID 可以通过角色绑定形成同构样本。

## 4. 原型行为

代码：`prototype/yijing_operator_induction.py`  
测试：`tests/test_yijing_operator_induction.py`

1. 将关系映射到角色对，消除具体实体 ID 的影响。
2. 计算 before/after 的关系增量和删量。
3. 按干预标签、角色类型签名和关系差分分组。
4. 从重复样本提取候选，并仅保留所有支持样本共有的结构前置关系与上下文条件。
5. 观测性样本只能提出候选；有显式干预样本才可进入 INTERVENTION_SUPPORTED，仍不等于已证明因果。
6. 留出验证只报告支持率和反例，不回流候选发现过程。
7. 对外部提供的有限实验池计算候选预测分歧，供主动实验选择。
8. 搜索预算、证据来源、候选版本和弃权均显式呈现。

## 5. 重要边界

- 干预标签是数据提供方显式给出的；代码不判断某条记录是否满足随机化、混杂控制或因果识别假设。
- INTERVENTION_SUPPORTED 不是“因果已证实”，更不是普遍规律。
- 当前候选只覆盖关系新增/删除，不学习连续强度、时间滞后、概率转移或隐藏状态。
- 当前角色在单个状态中必须唯一；多实例角色、集合角色和高阶超边需要后续扩展。
- 上下文共有键值是保守的精确交集，不等于自动发现了最小充分条件。
- 候选只允许在其训练证据覆盖的领域内预测；跨领域迁移必须先经过显式映射和独立验证。
- 主动查询只在外部给定的有限池内排序；分歧熵不是 Bayesian expected information gain。
- 当前没有连接 N0.10、N0.11、N0.12、E13 或 SROK runtime。
- 当前没有自然语言 grounding，也不把易学传统术语当作监督真值。

## 6. 易学结构如何参与，而不成为封闭标签集

阴阳、五行、爻位、时位、卦变、象数理和取象比类应作为可版本化的候选结构假设来源。例如：

- 阴阳：提出具有明确功能约束的互补关系假设；
- 五行：提出方向、关系类型、条件和作用强度分离的多关系影响假设；
- 爻位：提出角色与有序位置的绑定假设；
- 卦变：提出带触发条件的状态转移假设，而非任意 bit flip；
- 时位：提出阶段/环境条件对机制适用域的调制假设；
- 类象：提出跨域角色与关系保持映射，并要求负迁移反例；
- 象数理：作为结构、量化、机制解释之间的交叉校验，不是单向流水线。

系统也必须允许发现不属于这些传统命名体系的新候选；传统先验、通用关系先验、错误先验和无先验必须进入匹配消融。

## 7. 下一阶段验收

- 同一机制在实体重命名、节点排列下保持不变；
- 反向关系、角色交换和上下文变化能产生不同候选或明确弃权；
- 留出轨迹上的反例必须降低验证结果，不能被训练支持掩盖；
- 跨域映射必须单独报告映射误差，不允许只报汇总准确率；
- 与 N0.11 数值 DSL、N0.10 角色评分、N0.12 查询策略做预算匹配对照；
- 至少包含 no-prior、generic relational prior、Yijing-derived prior、wrong/reversed prior；
- 只有在干预识别假设、混杂控制和重复实验均有证据时，才讨论因果解释。
