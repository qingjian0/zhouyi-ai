# ZNCA：周易原生认知架构研究提案

日期：2026-11-11  
状态：原创架构研究提案；尚未证明优于 Transformer、SSM 或现有混合模型  
分支：`research/zhouyi-native-cognitive-architecture-2026-11-11`  
目标：从计算原语层重新设计模型，不把 Transformer、Q/K/V、KV Cache 或逐 Token 自回归设为不可替换前提。

## 0. 核心立场

本项目不再把“让 Transformer 更省内存”作为终点。研究目标升级为：设计一个以结构化状态、关系变换、类象迁移和多路径约束推演为核心的原生认知计算架构。

必须区分三件事：

1. **KV Cache 是 Transformer 解码时缓存历史 token 的 Key/Value 激活，不是智能或记忆的定义。**
2. **类象是跨域结构映射与关系迁移的认知操作，不是 KV Cache 的直接替代物。** 它可能参与检索、绑定、迁移和预测，但必须有明确数据结构与算子。
3. **替换 Transformer 不是删除神经网络。** 需要重新定义表示、状态、计算、学习和输出机制，并通过等资源实验验证。

本提案不宣称新架构已经实现或达到现有模型水平。它定义研究假设、可执行原型边界和证伪条件。

## 1. 要回答的根本问题

- 智能计算是否必须把输入压成单一 token 序列？
- 关系是否应该成为一等计算对象，而不是隐藏在 token embedding 与注意力权重中？
- 工作记忆是否必须保存每个历史 token 的 K/V？
- 推理是否必须逐 token 自回归，还是可以先形成结构化意图/候选，再进行并行或分块表达？
- 学习是否可以围绕对象、关系、状态转移和可验证预测进行，而不是只做下一个 token 预测？
- 易象、象数理、类象、时位、条件和变动，能否转化为可学习、可消融、可证伪的计算原语？

## 2. 研究假设

### H1：关系优先表示
把实体、属性、事件、关系、条件、时间和状态转移作为显式类型化对象，可能比纯序列隐藏表示更容易支持跨会话关系保持、多跳推理和局部更新。

### H2：结构状态记忆
将长期历史编译为可寻址、版本化、带证据来源的认知状态；将当前推理限制在稀疏活动子图和有界工作状态中，可避免内存随历史 token 总量线性增长。

### H3：类象迁移
在源域与目标域之间寻找部分关系保持的映射（允许缺失、冲突、角色置换和条件限制），可能提高未见领域的结构迁移能力。映射必须能被反例撤销，不允许把传统象义当作永真规则。

### H4：多路径推演
对多个候选结构并行提出、比较、约束传播和反事实检验，再由证据与预算进行裁决，可能减少单一路径过早坍缩。

### H5：分离认知与语言表达
先形成结构化的语义/行动计划，再由语言解码器表达，可让核心认知计算不依赖 Transformer 自回归主干。语言解码器可以是小型可替换组件，初期允许自回归，但不能承担唯一的记忆和推理职责。

### H6：移动端优先
若核心计算基于稀疏事件更新、局部关系传播、紧凑状态和分层持久化，可能在低 RAM 设备上实现更稳定的长程任务连续性。必须实测 CPU、内存、IO、功耗和延迟。

## 3. 总体架构：象—数—理—变—类—择—言

`象`、`数`、`理`、`变`、`类`不是装饰性标签，而是七类可独立测试的计算职责。

### 3.1 象：结构化观测层（Perception / Grounding）
把文本、图像、音频、工具结果和环境信号转换为带来源的 Observation：
- 对象与实体候选；
- 属性、状态、动作和事件；
- 空间/时间/因果/社会关系候选；
- 不确定性、缺失字段和观测条件；
- 原始片段与多模态数据的 source span。

象层不得直接把模型猜测写成事实。所有抽取项保留 observed / inferred / disputed 状态。

### 3.2 数：状态空间与组合层（State / Combinatorics）
定义对象状态、关系角色、离散与连续变量、组合空间和约束域：
- 二元、三值、多值与连续量表示分开；
- 编码 radix 与语义状态数分开；
- 支持非连续成员组合和高阶关系；
- 对象身份、角色身份和位置身份不可混淆；
- 状态空间可分解、合并、细化和版本化。

易经阴阳、卦爻等形式只作为候选编码/结构先验；必须与等容量随机编码、可学习编码和无先验对照。

### 3.3 理：不变量与约束层（Invariant / Constraint）
把可检验的关系规律表示为：
- 类型约束、关系约束；
- 条件规则与例外；
- 因果候选及其替代解释；
- 时间有效性与作用范围；
- 支持证据、反证和适用域。

规则必须有来源、置信状态、适用范围和失效条件。分数、能量、边际和概率不可混称。

### 3.4 变：状态转移层（Transition Dynamics）
核心计算不再定义为“对所有历史 token 做注意力”，而是对当前局部认知状态执行有条件的状态转移：
- 输入：当前状态、事件、目标、约束；
- 输出：候选新状态、变化理由、受影响对象；
- 支持局部更新、回滚、分支和合并；
- 通过依赖 DAG 只重算受影响部分；
- 支持时间尺度不同的慢变量与快变量。

可研究的底层算子包括稀疏超图消息传递、事件驱动更新、门控递归状态、约束传播、因子图/信念传播、局部能量下降和可微状态转移。它们是候选计算基元，不预设某一种必胜。

### 3.5 类：类象与结构迁移层（Analogy / Structural Transfer）
类象不是词语相似度，而是受类型和约束限制的关系映射：
- 在源结构与目标结构中寻找部分对应；
- 保留关系角色、方向、条件、时序和层级；
- 允许一对多、多对一、缺失和不可映射；
- 输出映射依据、未匹配部分、反例与适用范围；
- 通过对象不相交、领域不相交测试，防止记住具体对象。

类象映射必须与随机映射、反向映射、无先验、学习型映射和精确 oracle 对照。

### 3.6 择：多路径候选与证据裁决层（Hypothesis Arbitration）
不把第一次生成的答案当作唯一轨迹：
1. 提出有限数量候选结构/解释；
2. 依据约束快速淘汰矛盾候选；
3. 主动检索区分候选所需的证据；
4. 执行反事实、反例和边界测试；
5. 记录支持、反证、资源成本；
6. 输出最佳候选或明确 abstain / ambiguous / budget exhausted。

并行数量由设备预算决定。不能以候选越多越聪明为假设。

### 3.7 言：语言与行动表达层（Realization）
将已选择的结构化结果转换为自然语言、代码、工具调用或多模态输出：
- 语言生成器是可替换的表达模块；
- 核心状态与证据不依赖自然语言摘要保存；
- 工具调用从类型化 Action Plan 生成；
- 输出必须能追溯到支撑结构；
- 初期可用小型自回归解码器，但它不是整个认知系统。

## 4. 新的记忆机制：Cognitive State Fabric（CSF）

CSF 是持久认知状态织物，不是 KV Cache 的改名。

### 4.1 四种记忆对象
- **Event Ledger**：append-only 原始事件与观测；
- **Typed Relational State**：实体、属性、关系、超边、条件和时间版本；
- **Dynamic Working State**：当前任务的有限状态、目标、候选和局部活动子图；
- **Learned Memory Parameters**：可选神经记忆参数，用于模式压缩与快速召回，但不能替代证据账本。

### 4.2 工作记忆不是 token 历史缓存
每次输入只更新：
- 当前活动对象与关系；
- 当前目标和约束；
- 新增/变化事件；
- 被触发的依赖；
- 当前候选推演路径。

旧历史保留在事件账本和结构索引中。需要精确细节时按 source span 读取原始数据。

### 4.3 记忆读取算子
不采用单一 Q·K 相似度作为通用检索定义。比较：
- 类型化谓词查询；
- 实体/时间/关系索引；
- 有限深度结构匹配；
- 类象映射检索；
- 轻量向量召回；
- 神经记忆状态读出；
- 多路融合与证据覆盖优化。

向量检索仍可作为候选召回工具，但不是事实判定器。

### 4.4 记忆更新算子
事件到达时：
1. append 原始事件；
2. 生成结构变更提案；
3. 检查身份、时间、来源和冲突；
4. 计算受影响依赖；
5. 局部更新结构状态；
6. 保留父版本和变更记录；
7. 对高风险变化要求额外验证。

删除/纠错必须沿 provenance lineage 传播到派生索引、摘要、embedding 和缓存。

## 5. 不再把 Transformer 作为核心的模型候选

研究不押注单一现成架构。至少比较：

| 路线 | 可借鉴机制 | 不能直接照搬的限制 |
|---|---|---|
| RWKV-7 / 动态递归 | 有界状态、动态状态演化 | 仍以序列建模为中心，不等于关系认知 |
| Mamba-2 / SSM | 选择性状态更新、硬件友好扫描 | 压缩状态可能丢失精确可寻址事实 |
| xLSTM / mLSTM | 门控、矩阵记忆、递归更新 | 仍需验证长程精确绑定与结构迁移 |
| Titans / test-time memory | 惊讶驱动写入、神经长期记忆 | 神经记忆不是可追溯原文，可能发生干扰 |
| RetNet | 并行/递归/chunkwise 三种执行形式 | 仍是序列算子路线 |
| Hyena | 长卷积、门控、非注意力混合 | 长程精确关系和条件绑定需独立验证 |
| 图/超图与因子图 | 显式关系、高阶约束、局部传播 | 大图检索与动态更新成本必须控制 |

最终候选是**关系状态动力学网络（Relational State Dynamics Network, RSDN）**：以类型化对象/关系状态为计算单元，以事件驱动局部状态转移为主循环，以类象映射做跨域结构迁移，以多路径约束推演做候选选择，以可替换表达器生成语言。

RSDN 是本项目提出的研究对象，不是已有成熟模型，也不应宣称其理论优越性已成立。

## 6. RSDN 的最小数学草案

设当前认知状态为：

`S_t = (V_t, E_t, H_t, G_t, B_t, P_t)`

其中：
- (V_t)：实体/对象状态；
- (E_t)：二元关系；
- (H_t)：高阶关系/超边；
- (G_t)：目标与约束；
- (B_t)：信念及证据状态；
- (P_t)：过程/程序状态。

新观测事件为 (o_t)，系统产生候选转移：

`\hat S_{t+1}^{(i)} = F_{\theta}^{(i)}(S_t, o_t, G_t, C_t)`

候选集合经过约束与证据裁决：

`S_{t+1} = Select(\{\hat S_{t+1}^{(i)}\}, Evidence, Budget, Policy)`

类象映射定义为部分映射：

`M: (V_s, E_s, H_s) \rightharpoonup (V_d, E_d, H_d)`

其质量不只看节点相似度，而看关系保持、条件保持、反例率、未匹配率、跨域预测和复杂度成本。

这只是可执行研究的形式化起点。下一步要把每个对象和算子落成 schema、reference implementation 与测试，不可停留在符号表达。

## 7. 训练目标：从 next-token 单目标转向多目标认知学习

候选联合训练目标：

`L = \lambda_{obs}L_{obs} + \lambda_{state}L_{state} + \lambda_{rel}L_{rel} + \lambda_{trans}L_{trans} + \lambda_{analogy}L_{analogy} + \lambda_{plan}L_{plan} + \lambda_{lang}L_{lang} + \lambda_{cal}L_{cal}`

分别表示：
- 观测结构抽取；
- 状态跟踪；
- 关系与高阶关系预测；
- 状态转移预测；
- 类象映射与跨域迁移；
- 目标/行动计划；
- 语言表达；
- 置信校准与拒答。

不要求每个任务都由同一个损失端到端优化。先建立任务级监督和独立 evaluator，再研究联合训练与梯度冲突。语言建模可作为表达能力训练，不再是唯一学习目标。

## 8. 生成机制：先结构，后表达；候选并行，不强制单轨

研究流程：
1. 解析输入为 Observation；
2. 更新当前状态；
3. 生成多个有限候选解释/计划；
4. 通过约束、证据和反事实筛选；
5. 形成 Semantic Action Graph；
6. 并行生成可验证字段（实体、关系、步骤、代码结构）；
7. 由表达器线性化为语言或执行动作；
8. 对输出做一致性检查。

自然语言仍然有顺序，因此最后的表面实现可能使用自回归解码；但认知计划、关系结构和候选计算不必被限制为 token-by-token 生成。必须把“非自回归认知计算”和“非自回归自然语言解码”分开评测。

## 9. 移动端优先的资源模型

必须同时预算：
- 模型权重；
- 动态工作状态；
- 关系/超图索引；
- 临时传播消息；
- 语言表达器激活；
- 原始历史 IO 与解压；
- 多模态编码缓存；
- CPU/GPU/NPU、温度和电量。

目标是工作集受限，而非宣称所有计算都 O(1)。对任意全局查询、全库输出或全局结构重建，不承诺次线性。

首轮工程目标：
- 4GB RAM 设备可运行小规模 RSDN 原型；
- 原始历史 1M source tokens 存磁盘并可检索；
- 常驻工作状态有硬 byte/token budget；
- 新事件只触发局部依赖更新；
- 检索结果有 source span；
- 低内存时可降级、暂停后台任务和恢复；
- 不将 1M Effective Context 冒充 1M Native Attention。

## 10. 与现有 CPG-EI / PCS 的关系

不推翻已经形成的证据治理和生命周期成果。分工如下：
- **CPG-EI**：结构提议、组合、类象、关系推演与候选修订；
- **PCS/CSF**：持久认知状态、事件日志、版本和来源谱系；
- **RSDN**：新的核心神经/符号混合计算架构研究；
- **Zhouyi/Xiang-Shu-Li**：可消融的表征与结构先验，不拥有不可质疑的事实权威；
- **Hyper-Speed**：预算内的 DAG 调度，不拥有知识生命周期；
- **Language Realizer**：语言与行动表达，不拥有长期记忆。

现有六层记忆架构是存储组织方案，不是新模型的计算理论。可以保留为过渡期存储实现，但不应限制新架构。

## 11. 关键对照与证伪

至少比较：
A. 同参数量 Transformer；
B. RWKV-7 / Mamba-2 / xLSTM 等递归基线；
C. 纯 RAG + PCS；
D. 图/超图推理模型；
E. RSDN 无易象先验；
F. RSDN + 易象/类象先验；
G. RSDN + 神经记忆；
H. RSDN 双轨记忆。

控制参数量、训练 token、训练 FLOPs、设备、数据、查询预算和检索预算。测试：
- 长程精确回忆；
- 关系绑定和角色反转；
- 多跳与非连续组合；
- 事件时间更新；
- 冲突和否定；
- 对象不相交、领域不相交迁移；
- 类象反例与拒绝映射；
- 任务持续与中断恢复；
- 多模态对象关系；
- prompt injection 与记忆污染；
- 4GB/6GB/8GB 移动端 RSS/PSS、IO、能耗、温度和延迟。

**停止条件：**若 RSDN 在固定预算下未能稳定优于强基线，或只在合成任务上有效，则不宣称替代 Transformer；保留有用子模块，修订或放弃失败假设。

## 12. 研发阶段

### N0：理论与接口冻结
定义 Observation、Typed State、Relation、HyperRelation、Transition、AnalogyMap、Evidence、Candidate、ActionPlan 的 schema。

### N1：纯符号可执行原型
不训练大模型。实现事件账本、类型化关系结构、类象映射、约束传播、多路径候选、局部更新和 provenance。

### N2：可学习关系算子
引入小型神经关系编码器和状态转移器；与规则、图网络、Transformer encoder 对照。

### N3：语言接口解耦
将结构认知结果接入小型语言表达器；评估表达器替换是否改变核心推理结果。

### N4：移动端运行时
CPU 优先，内存映射/分页索引、稀疏活动子图、增量 checkpoint、内存压力降级。

### N5：联合训练与规模化
只有 N1-N4 的测量和基线完整后，才训练更大模型；研究多目标训练、蒸馏、量化和多模态扩展。

## 13. 本提案的结论

真正要替换的不是一个缓存，而是把“序列 token 的注意力流”作为唯一认知计算范式的假设。

本项目的研究方向是：

**以结构化对象和关系为基本表征，以事件驱动状态变化为基本计算，以类象为跨域映射算子，以多路径证据裁决为推理机制，以语言生成作为可替换表达层。**

这是一个需要从小规模可证伪原型逐步发展出来的新架构。当前只定义了研究路线，尚未证明它能够在通用语言能力、知识覆盖或训练效率上超过现有大模型。
