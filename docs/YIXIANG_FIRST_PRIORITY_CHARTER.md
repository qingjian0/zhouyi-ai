# Zhouyi-AI 易象理论优先研究纲领

> 本纲领确立项目研究优先级：易象、类象及周易理论是第一研究主线。数学、算法、数据、模型和工程优化均应服务于该主线。本文是研究治理与设计规范，不代表相关理论机制已实现或已被实验验证。

## 1. 项目定位与优先级

Zhouyi-AI 研究以易学思想为启发、以可计算认知机制为目标的智能架构。项目不得退化为“通用关系学习模型 + 周易知识库”，也不得仅以周易术语为既有神经网络重新命名。

最高优先级（P0）：
1. 取象、观象、类象、比类、象意抽象与跨域迁移；
2. 阴阳、四象、八卦、六十四卦的层次化状态表示；
3. 五行、生克、制化、乘侮及其动态关系；
4. 爻位、时位、应比、卦变、消长、变通与状态演化；
5. 象、数、理之间的联合表示和约束；
6. 上述机制进入真实模型计算、训练目标和推理闭环。

P1：动态超图、高阶组合、并行推演、自组织结构学习、记忆与证据协调。它们是实现易象认知的计算基础，不得反过来取代易象理论成为项目目标。

P2：通用语言建模、模型规模、优化器、推理加速、部署与产品化。只有在支持 P0/P1 验证或交付时才提升优先级。

## 2. 类象：核心认知机制

类象不是词向量相似度，也不是把两个事物贴上相同标签。模型应学习“从具体之象抽取结构，再在不同领域中寻找关系保持的对应”。

至少分解为：
- 形态/结构象：组成、拓扑、层次、边界、部分—整体；
- 属性象：性质、强弱、数量、方向、状态；
- 功能象：作用、用途、角色、输入输出；
- 关系象：相生相克、依赖、制约、互补、竞争、转化；
- 过程象：发生、发展、转折、衰退、循环；
- 时空象：位置、阶段、环境、顺序、远近；
- 势象：趋势、潜势、稳定性、临界变化；
- 综合象：多维特征及其关系共同形成的整体模式。

每个类象候选必须保存：源域与目标域、参与对象、映射维度、保持的关系、适用条件、证据来源、反例、置信度、有效范围和版本。支持关系保持的映射才可用于迁移；只在表面相似、关键关系不一致或证据不足时，模型必须允许拒绝类比。

类象学习任务：
1. 类象发现：从数据中提出候选对应；
2. 类象解释：说明哪些属性/关系构成对应；
3. 类象验证：检查关系保持、反例和边界条件；
4. 类象迁移：将源域已验证结构用于目标域；
5. 类象组合：组合多个局部类象形成高阶结构；
6. 类象修正：新证据出现时拆分、降权、撤销或重构映射；
7. 新象发现：发现现有分类体系未覆盖的稳定结构，并保留待验证状态。

## 3. 易学层次化表示

- 阴阳：互补、对待、消长及状态极性；不可简化为永恒的正负标签。
- 四象：阴阳两层状态的组合，以及状态之间的阶段性差异。
- 八卦：三爻结构、上下关系及卦象属性；编码约定必须固定并经过经典文献校核。
- 六十四卦：上下卦组合、六爻位置、整体卦体与关系结构。
- 爻位：初、二、三、四、五、上等位置语义；位置不能与爻值混淆。
- 卦变：动爻引起的局部变化及整体结构变化；同时记录变化前后状态和路径。
- 卦序：二进制索引、先天序、后天序、文王序等必须分别建模，严禁混为同一编码。
- 象数理：象的结构表示、数的形式约束、理的关系/规则解释应能相互校验。

## 4. 五行动态关系

五行不应只是一张静态 5×5 矩阵。研究表示应至少覆盖：
- 五类状态/过程的类型表示；
- 相生、相克及关系方向；
- 制化、乘侮等条件性关系；
- 强弱、阶段、环境和时位对关系作用的调节；
- 多环关系、反馈与整体平衡；
- 关系冲突、例外和适用条件。

传统关系可作为结构先验或初始化，但模型必须通过数据学习关系强度、条件和适用范围。不得把五行标签无依据地强加给现实对象，也不得把相关性直接宣称为因果规律。

## 5. 时、位、势、变

模型应联合建模对象状态、所在位置、所处阶段、外部条件和变化方向。重点研究：
- 同一对象在不同阶段的象意变化；
- 同一状态在不同位置/环境下的意义差异；
- 局部变化如何传导到整体；
- 消长、往来、循环、转折和临界点；
- 多条变化路径及其条件概率；
- 预测与实际反馈之间的持续校正。

## 6. 模型架构要求

易象机制必须进入可执行计算图，而不只是文档或提示词：
1. 多模态观测解析为对象、属性、事件、关系、时空和证据单元；
2. 类象引擎产生多维结构映射候选；
3. 易象状态引擎维护阴阳、四象、八卦、六十四卦、爻位与卦变表示；
4. 五行关系引擎处理有条件的促进、制约和转化；
5. 时位势变引擎维护动态状态及其演化；
6. 动态超图组合器构造跨层、跨域、高阶关系；
7. 推演器生成多个候选路径；
8. 证据协调器执行验证、冲突识别、校准和拒绝；
9. 自组织控制器在验证门控下创建、合并、拆分、修订或淘汰结构。

模块接口应允许端到端训练，也允许单模块独立验证。必须记录各理论模块对输出的实际贡献，不能把外部语言模型的能力归功于易象模块。

## 7. 数据集建设原则

数据集优先覆盖理论结构，而非只增加普通文本数量。建设以下分层语料与任务：
- 经典原文：易经经文、十翼及不同注本，版本、章节、训诂和出处可追溯；
- 概念本体：阴阳、四象、八卦、六十四卦、爻位、五行、时位等定义及异说；
- 结构数据：卦画、上下卦、爻位、卦变、卦序与关系图；
- 类象案例：跨领域对应、映射维度、关系保持说明、边界和反例；
- 动态案例：阶段变化、条件变化、局部—整体传导；
- 合成基准：可控生成类象、关系、卦变和反事实样本；
- 真实迁移集：检验跨领域结构迁移及错误类比拒绝。

每条样本必须有来源、版本、标注依据、许可/版权状态、质量等级和训练/验证/测试划分。传统文本解释存在流派差异时保留来源与分歧，不伪造唯一标准答案。禁止仅靠模型自生成数据形成自证循环。

## 8. 实验与成功标准

每个 P0 机制必须有独立基准、消融和失败分析。至少比较：
- 无易象模块；
- 普通语义相似度；
- 可学习随机编码；
- 仅传统固定先验；
- 仅可学习结构；
- 固定先验 + 可学习机制；
- 完整联合易象架构。

评估指标包括类象精确率/召回率、关系保持率、跨域迁移收益、错误类比拒绝率、反事实敏感性、状态转移预测、校准误差、分布外鲁棒性、计算成本和可复现性。

必须控制参数量、训练数据量和计算预算，避免把规模优势误认为理论贡献。实验未运行不得标记为完成；负结果必须保留。传统理论的哲学解释、计算假设和实证结论要分别标注。

## 9. 研究执行门禁

- 新研究提案首先说明它服务于哪一个 P0 理论问题。
- 通用优化工作若不能改善 P0/P1 的可验证能力，不得挤占核心研究资源。
- 新模块必须定义输入、输出、状态、损失、基准、消融和资源成本。
- 理论文档、代码实现、数据集和实验报告必须互相对应。
- 未经校验的经典映射只能标记为候选假设。
- 不以 PR 数量、代码行数或数据集规模代替研究进展。
- 主分支只接收通过测试、文档审查和实验门禁的成果。

## 10. 下一阶段顺序

A. 类象理论本体与多维关系定义；
B. 经典易学概念、卦爻结构和编码校勘；
C. 类象数据格式、数据集规范与基准任务；
D. 类象发现/验证/迁移的最小可执行模型；
E. 阴阳—四象—八卦—六十四卦及爻变状态引擎；
F. 五行条件关系与时位势变模型；
G. 将上述机制接入动态超图与并行推演；
H. 完整消融、跨域评估和可复现报告。

本纲领优先于旧路线图中“先做通用组合实验、最后再引入易象”的默认顺序。旧实验可保留，但必须重新评估其对易象主线的贡献。
