# E09-B2：追加式证据账本与冲突隔离

状态：实现已扩展；测试待运行。  
分支：`research/e09-nongradient-learning-2026-11-10`

## 规则

- 每条观察必须有稳定的 `sample_id`；同 ID、同内容重放幂等。
- 同 ID、不同内容属于完整性错误。
- 同一输入出现不同标签时全部隔离，不猜测哪条为真。
- 同标签重复输入在训练时去重，不能把重复采样伪装成独立支持。
- 新增可选 `source_id`，按输入和标签统计不同来源的数量，识别“同一来源重复提交”与“多个标记来源”。
- `source_id` 只是调用方提供的来源标记，不是身份认证、签名或可信度证明。不同 ID 也可能由同一主体控制。
- 未提供来源 ID 的记录单独统计，不默认当作独立来源。
- `extend` 现在先验证整批记录，再统一追加；遇到任何冲突整批拒绝，避免部分写入。

## 当前限制

账本仍是内存实现，无持久化、并发锁、签名验证、来源信誉模型或人工裁决接口。来源计数不是证据真实性评分。随机标签任务仍需概率/分布标签模型。
