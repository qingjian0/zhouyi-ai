# ZNCA N1：RSDN 符号参考核心

日期：2026-11-11  
状态：首个可执行参考实现；不是神经网络，也不是性能胜出结论。

## 目标

将 ZNCA 的关键接口从概念文档落实为不依赖第三方库的可执行核心，优先验证：
- 事件账本与当前认知状态分离；
- 对象、关系、角色与证据可显式寻址；
- 关系方向不被无意折叠；
- 事实撤回不删除原始历史；
- 类象映射是部分结构映射，必须检查关系与角色保持；
- 查询有显式扫描预算和结果上限。

## 当前实现

`prototype/znca_core.py` 提供：
- `Evidence`：证据 ID、来源引用、观测时间；
- `Entity`：类型化对象与属性；
- `RoleBinding`：关系中的显式角色；
- `Relation`：有来源、有效时间和置信度的关系断言；
- `ObservationEvent`：原子事件，包含新增观测或撤回；
- `CognitiveState`：事件账本、实体、证据、有效断言和撤回集合；
- `RelationQuery`：按关系类型、角色绑定和时间查询；
- `AnalogyMap`：受类型/角色约束的部分映射；
- `audit_analogy`：在目标域已观测结构上计算关系保持率并列出违反项。

## 关键语义约束

1. 撤回是追加式状态变化，不会物理删除原始断言或事件。
2. 关系必须引用已知实体和证据；事件应用失败时不得留下半更新状态。
3. 同一实体身份不能静默覆盖；后续实体变化应采用版本化 ID 或单独属性事件。
4. 类象映射只报告结构对应，不自动把源域事实投射为目标域事实。
5. 映射的未覆盖项、未保持项必须显式报告。
6. 查询扫描预算耗尽目前采用有界截断语义；调用方必须结合扫描数量/状态扩展接口，不能把截断结果解释为完整结果。N1.1 将把预算耗尽变成显式状态返回。

## 已知限制

- 当前是内存中的参考状态，不是百万级磁盘持久化引擎。
- 查询目前线性扫描断言；下一步实现按 relation_type、role/entity 和时间分段的倒排索引。
- 关系断言的置信度是输入字段，不是校准后的概率。
- 类象映射当前为显式映射，不会自主发现映射。
- 不包含神经编码器、梯度学习、自然语言感知或语言解码器。
- 不代表已经替换 Transformer，也不宣称优于现有模型。

## 下一阶段验收

- 显式 `BUDGET_EXHAUSTED` 查询状态，禁止静默截断；
- 事件日志持久化与恢复；
- 索引与扫描计数；
- 多跳关系路径查询及路径证据；
- 类象映射候选生成、负例和反例撤销；
- 与 E02/E13 现有结构提议/验证接口的适配器。
