# E01-CX 类象先验独立贡献预注册协议 v0.1

> 状态：协议草案；尚未执行正式实验。目标是在现有古籍语料、关系代数、迁移门控和 M8 合成基准之上，检验类象/易象先验是否提供独立增量。不预设先验有效，也不把传统命题当作现代经验事实。

## 0. 预注册承诺

1. 正式训练前执行形式化可学习性预检 Gate P；失败则不进入完整对照。
2. CX-3 同时比较传统类象方向关系与匹配的随机有向关系系统。
3. CX-4 同时报告错误类象接受率 FAR 与正确类象分布偏移保留率 CRR-OOD。
4. 先做 D vs C；只有达到主效应门槛才执行 D1–D6。
5. 失败必须区分形式化/数据生成错误与学习器/优化错误。
6. 测试集解锁前冻结来源、操作定义、生成器、split、种子、分析脚本和协议 SHA。

## 1. 研究问题

### RQ1：联合先验是否优于纯动态超图？

- C：纯动态超图，不注入传统类象/易象先验。
- D：同一骨干 + 联合类象/易象先验。
- 匹配参数预算、训练数据、优化预算、早停、调参次数和信息访问权限。

H1：组合 OOD Exact Match 上，D-C 至少 +3 个百分点，配对 95% CI 下界大于 0；同时错误迁移风险不越过门槛。未达到则不宣称独立增量。

### RQ2：方向结构是否超出一般有向关系？

- CX-3A：来源和操作定义明确的类象方向关系。
- CX-3B：随机有向关系系统（随机 DAG 或等价生成器）。

匹配节点数、边数、入/出度分布、关系频率、样本量和任务难度。只有 CX-3A 稳定优于 CX-3B，且排除拓扑、频率和词面提示差异，才支持“该类象方向结构提供额外归纳偏置”。否则只能说模型学会了一般有向关系。

### RQ3：先验是否压制反例？

CX-4 必须同时报告：
- FAR：关系不成立、关键结构被破坏或出现反例时，模型仍接受迁移的比例，越低越好。
- CRR-OOD：正确关系结构在预注册分布偏移后仍被正确保留/接受的比例，越高越好。

报告 FAR—CRR-OOD 联合结果、选择性风险/覆盖率和校准。不得只靠拒绝全部候选降低 FAR。

## 2. 古籍维度可形式化性筛查

分类：R=关系约束（角色、方向、结构不变量）；T=状态转移（状态、条件、路径、时间区间）；A=属性映射（可观察属性、尺度、映射）；X=暂不可形式化（训诂未决、价值判断、隐喻语境或不可观测构念）。R/T/A 可多选。X 不是否定其思想价值，而是不强行编码。

| 维度 | 候选形式 | 首轮处理与主要风险 |
|---|---|---|
| 形态、构造、边界、部分—整体 | A+R | 有可观察结构时纳入；外观相似不等于对象同一 |
| 属性、强弱、寒热、燥湿、明暗 | A | 只纳入语义有据且可操作测量者；防古今词义错置 |
| 功能、用途、角色、输入输出 | A+R | 明确任务/条件时纳入；同结果不等于同机制 |
| 对象关系、生克、制约、互补 | R | 方向、角色、条件明确才纳入；不默认对称/可逆/传递 |
| 过程、生成、发展、转折、循环 | T+R | 有阶段与转移证据时纳入；叙事顺序不等于因果 |
| 时间、时序、阶段、周期 | T+A | 单位/边界明确才纳入；象征时间不冒充客观时间 |
| 空间、上下、内外、远近、方位 | A+R | 坐标/相对位置明确才纳入；不强行统一不同传统 |
| 数量、奇偶、比例、次序 | A+R | 数制与运算可复现才纳入；防数值巧合和后设配数 |
| 势、趋势、消长、临界、稳定性 | T（有条件） | 需状态/时间证据；解释者判断不冒充观测事实 |
| 主体—客体、视角、远取近取 | R+T（部分） | 视角和信息可及性可操作才纳入 |
| 象变、多重取象、情境依赖 | T+R | 有条件切换记录才纳入；防事后任意解释 |
| 象征、感应、天人对应、规范类比 | X（默认） | 独立记录，不直接作为经验因果标签 |
| 吉凶、善恶、得失、政治正当性 | X（默认） | 保留原文与规范语境，不作无条件客观标签 |

该表是初始筛查，不代表已完成校勘。每个训练条目必须挂接古籍来源、篇章、主张、证据等级和审核状态；无定位条目不得进入训练。具体分类偏离本表，须在测试解锁前记录理由和版本。

## 3. 结构映射理论的边界

Gentner（1983）仅作为形式化设计参照，不是类象有效性的外部证明。首轮采用三个可检验约束：
1. 关系优先：不能只凭属性重合认定类比。
2. 系统性偏好：相互关联的关系系统优先于孤立匹配，但系统性不能替代反例检验。
3. 一对一映射：声明范围内源实体与目标实体一对一；多对一/一对多另立任务和对照。

类象不等同于结构映射理论；属性取象、感应、象征、时位、多重取象应独立处理或暂不形式化。

## 4. Gate P：形式化可学习性预检

目的：检查操作化约束能否被可复现学习器从合成样本中学到，并检查生成器、标签与 oracle 一致。通过只证明受控任务可学习，不证明古籍解释正确或现实规律成立。

步骤：
1. 从冻结约束生成合成教师任务；按教师规则族隔离 train/dev/test，不能只随机拆行。
2. 运行规范 oracle、固定预算简单探针、小型非线性表达能力对照探针。
3. 至少 5 个固定种子；报告教师族留出测试、混淆矩阵、FAR、CRR 和校准。
4. Gate P 通过：探针测试准确率至少 95%，FAR 不高于 5%，且每个预注册关系族均有有效样本。
5. oracle 与生成器不一致，或冻结规则产生矛盾 gold：形式化/数据生成失败，停止正式训练。
6. oracle 一致、非线性探针成功而简单探针失败：简单学习器表达能力不足，保留失败记录。
7. oracle 一致但所有探针失败：可学习性未建立；检查可观测性、样本覆盖、标签噪声和优化预算，不得直接判定理论错误。
8. 只有 Gate P 通过，才进入 D vs C。

| 结果 | 归因 | 决策 |
|---|---|---|
| oracle/标签冲突 | 形式化或生成器错误 | 回到来源、定义、标签、生成器 |
| oracle 一致；非线性成功、简单探针失败 | 简单学习器容量不足 | 保留结果，另立学习器版本 |
| oracle 一致；所有探针失败 | 可学习性未建立 | 检查可观测性、覆盖、噪声、优化 |
| C 成功而 D 退化 | 先验冲突/门控失败候选 | 检查权重、条件化、拒绝机制 |
| D 提升但 FAR 恶化 | 先验压制反例风险 | 不判总体成功，分析 FAR—CRR |

## 5. E01-CX 任务设计

- CX-1 表面名称替换：更换实体名称和非因果表面属性，保持潜在关系结构；按教师族隔离。
- CX-2 结构不变性：改变节点编号、输入顺序和表示排列，保持关系图同构；语义依赖顺序的样本单独标注。
- CX-3 方向双对照：类象方向关系 vs 匹配随机有向关系；测试方向反转、边替换、逆关系混淆和未知方向拒绝。
- CX-4 对抗双指标：错误相似、方向冲突、同结果异机制、条件破坏、反例注入，以及正确关系保持但表面变化的分布偏移样本。
- CX-5 组合规则变化：训练/测试使用不同组合规则和关系族组合，测试结构迁移而非仅标签替换。

五行生克只是一个有来源的传统关系族；另设随机有向关系和非五行关系族。禁止模型仅靠背诵固定五行口诀完成测试。

## 6. 分阶段预算与消融门槛

Stage 0：冻结来源、维度、定义、生成器、split 和分析脚本。  
Stage 1：Gate P，至少 5 个固定种子；失败即停止完整对照。  
Stage 2：D vs C，20 个预注册种子，种子内配对数据生成和划分。主指标固定为组合 OOD Exact Match；报告 D-C 配对差值和按教师族分层的 95% bootstrap CI（10,000 次重采样）。

只有同时满足以下条件才进入 Stage 3：
- D-C 至少 +3 个百分点，95% CI 下界大于 0；
- FAR 相对 C 恶化不超过 2 个百分点；
- CRR-OOD 不低于 C 超过 2 个百分点；
- 收益不由单一关系族或单一种子独占。

未达门槛，停止 D1–D6 完整消融，优先失败诊断；不得不断调参直至显著。

Stage 3（仅在主效应通过后）：
- D1 仅类象关系；
- D2 仅阴阳/四象/八卦状态；
- D3 仅五行关系；
- D4 类象与易象联合；
- D5 联合先验 + 可学习门控；
- D6 联合先验 + 门控 + 显式拒绝/修改/重构。

消融保持骨干、数据、预算、评估脚本一致；采用 Holm 多重比较校正，完整报告负结果。

## 7. 数据与证据治理

1. 按作品、篇章、版本/注疏谱系、案例模板和教师规则族隔离；同源改写不得跨 split。
2. fixture_expected 仅是合成程序合同标签，不是人工 gold。
3. 原文、注疏、现代研究、项目定义、模型推论分层保存。
4. 未经底本核验的古文保持 candidate/unreviewed，不作高置信监督标签。
5. 传统先验必须有无先验、随机关系和关系打乱对照。
6. 测试集锁定后不改阈值、样本和关系定义；修改产生新协议版本。
7. 报告失败、排除、缺失、资源预算及预注册偏离。

## 8. 统计报告与解释边界

报告配对 D-C 效应量、20 种子分布、按教师族聚类 bootstrap 95% CI；CX-3 方向组差值和反向误判率；CX-4 FAR、CRR-OOD、覆盖率、选择性风险和校准；消融效应量、CI、Holm 校正；参数量、样本量、步数、墙钟时间、峰值内存、调参次数和推理成本。

D 优于 C 仅支持该任务、形式化、预算和划分下的有限增量；D 不优于 C 不等于传统理论无价值；CX-3A 不优于 CX-3B 不得声称传统方向结构优于一般有向关系；FAR 高提示先验压制反例风险，CRR-OOD 低提示过度拒绝或先验刚性。Gate P 失败不得进入主实验。

参考：Gentner, D. (1983). “Structure-Mapping: A Theoretical Framework for Analogy.” Cognitive Science, 7(2), 155–170. DOI: 10.1207/s15516709cog0702_3. 此理论只提供关系优先、系统性、一对一映射的形式化参照。
