# E10-A 实现审查：协议与原型差距（2026-11-10）

状态：静态代码审查；未执行测试；未产生实验结果。
审查对象：
- `prototype/e10_structural_concepts.py`
- `tests/test_e10_structural_concepts.py`
- `docs/E10A_STRUCTURE_INDUCTION_PREREG_2026-11-10.md`

## 1. 结论

当前原型实现的是有限属性集合上的频繁项集/角色条件项集挖掘。它没有实现预注册协议所定义的潜在关系图恢复任务。协议方向值得保留，但不能把协议文本当成已经具备的系统能力。

## 2. 已确认的实现事实

- 输入是离散属性集合和可选角色槽位属性集合。
- 候选由单条观测中的属性子集枚举而来。
- 支持度按不同 object_id 计数；当前验证又要求每条观测的 object_id 唯一。
- 不接收显式目标概念标签；没有梯度更新。
- 候选枚举有硬预算，超过预算直接抛出异常，不返回部分结果。
- 输出是重复属性束，不是语义概念、因果关系或完整关系图。

## 3. 关键缺口与测试弱点

### 3.1 预注册协议与实现范围不一致

预注册协议定义了对象束、角色分配、关系骨架、条件关系、组合关系、未知关系拒答和结构恢复指标。当前代码没有关系实例或查询接口，也没有潜在图生成器、隔离 split、评测器或基线。因此目前只能作为 E10-A 的最小子实验，不能代表完整 E10-A。

### 3.2 表面符号重映射缺失

生成器固定使用 `amber`、`spiral`、`resonant`、`cobalt` 等属性符号。现有 `rename=True` 只改变对象 ID，没有置换属性词汇。测试也没有检查属性符号置换前后结构发现是否保持等价。

建议增加每 episode 独立的属性符号双射，并在评测端通过逆映射比较结构；学习器不得接触逆映射。

### 3.3 近似负例测试没有验证概念边界

近似负例共享 `amber` 与 `spiral`，只缺少第三个核心属性。但当前测试只断言某个包含唯一 decoy 的三元组不在候选中；由于其支持度天然低于阈值，这个断言几乎不检验误泛化。

更关键的是，`amber + spiral` 会被正例和近似负例共同支持。频繁项集算法会保留该高支持二元项，但当前测试没有要求系统区分“共同属性”与“可迁移概念”。下一版必须把概念边界与判别任务分开定义，不能仅凭支持度命名概念。

### 3.4 角色置换测试覆盖不足

现有测试只反转 role_attributes 的列表顺序，验证的是容器顺序不敏感。角色名仍作为候选特征的一部分。需要分别测试：
- 角色记录顺序置换；
- 角色名称的一致双射重命名；
- 角色槽位映射被破坏时，模型是否降低匹配置信度或拒答；
- 不同 episode 的角色符号是否独立重映射。

### 3.5 证据与数据模型边界不足

当前每个 object_id 只允许出现一次，无法表示同一对象的重复观测、时间变化、缺失属性、冲突证据或来源相关性。支持度按不同 ID 计数是合理的起点，但后续必须把实体身份、观测事件和证据来源拆开，避免重复观测被误当成独立对象，也避免不同来源的复制记录虚增支持。

### 3.6 报告字段不是防泄漏证明

`target_labels_received=False` 是程序写入的常量式报告字段，不是运行时信息流审计。应通过独立输入 schema、序列化边界、依赖检查和泄漏攻击来证明学习器无法访问潜在真值、生成器内部结构或评测标签。

## 4. 建议的修订顺序

1. **E10-A0：锁定当前原型边界**。将它命名为属性束挖掘子基线，不宣称关系结构发现。
2. **E10-A1：加入符号置换测试**。属性符号、对象 ID、记录顺序、角色符号分别独立置换；报告置换前后的结构等价度。
3. **E10-A2：加强 hard-negative 判别**。构造共享二元子结构、缺失关键角色、角色互换、关系方向反转等负例；检查系统是否能拒答或指出证据不足。
4. **E10-A3：建立实体—观测—证据三层 schema**。支持重复观测、缺失、来源相关性与时间戳。
5. **E10-A4：再实现关系骨架生成器和隔离 split**。学习器输入与潜在真值必须分离，测试集按对象身份、属性组合、关系模板和关系组合隔离。
6. **E10-A5：统一基线与成本评估**。先比较简单项集、近邻、固定模板、E09 learner、图/超图方法；随后再做参数量和计算预算匹配的梯度模型比较。

## 5. 当前可接受的结论

当前原型证明的是：在研究者构造的有限合成数据上，可以从离散属性观测中枚举重复属性束，并按对象 ID 统计支持度。

它没有证明：
- 系统能从原始感知中自主形成属性；
- 系统能恢复潜在关系骨架；
- 系统能发明训练 DSL 之外的新关系原语；
- 易象先验优于无先验或随机先验；
- 非梯度方法优于同预算梯度方法；
- 系统具备开放环境中的自主发现能力。

本审查未运行代码或测试。正式实验必须在实现、数据划分、基线和泄漏审计完成后执行，并报告完整 seeds 与失败案例。
