# M44：类象自适应实验统一决策引擎 v0.1

## 目标

M44 将 M37–M43 的实验候选、序贯规划、策略搜索、停止、稳健性和迁移审计组织为统一的门禁流水线。它解决的是模块间决策契约与审计状态统一，不声称已经完成所有底层估计器或端到端实验平台。

## 流水线

1. M37：主动实验候选与排序来源。
2. M38：序贯策略树/策略审计来源。
3. M39：open-loop 搜索来源。
4. M40：结果条件式策略候选。
5. M41：STOP / CONTINUE / REVIEW。
6. M42：模型失配与混杂压力情景审计。
7. M43：跨情境策略迁移审计。
8. M44：检查七阶段引用、证据来源和状态，输出 BLOCKED / REVIEW_REQUIRED / READY_FOR_HUMAN_REVIEW / STOPPED_FOR_HUMAN_REVIEW。

## 门禁原则

- 任一关键模块 BLOCKED，整体 BLOCKED。
- 缺失阶段证据、停止决策需复核、稳健性未通过或迁移未通过，整体 REVIEW_REQUIRED。
- 全部门禁通过后也只允许进入人工审查，不授权自动执行。
- STOP 只表示在声明效用下结束实验，不证明机制真值。
- 阶段引用是外部 artifact/evidence refs；M44 不伪造 M37–M39 与 M40–M43 的对象级自动适配。

## 古典方法论

《墨子·小取》“明是非之分，明同异之处，察名实之理，处利害，决嫌疑”可作为统一审计框架的文本参照：区分对象、辨析同异、核查证据、显式处理利害和疑难。《荀子·正名》关于名实与同异的辨析，进一步提醒统一接口不能抹平各情境差别。这里是现代工程结构，不是对古典概念的现代算法追认。

## 限制与下一步

M44 目前是门禁编排器，不是端到端运行时。缺少 M37–M39 到 M40–M43 的强类型适配器、统一事件日志、数据集版本追踪、真实 SCM benchmark、性能基线和独立复现。任何 READY 状态都必须经过人工审查，且不代表已执行实验或验证因果结论。
