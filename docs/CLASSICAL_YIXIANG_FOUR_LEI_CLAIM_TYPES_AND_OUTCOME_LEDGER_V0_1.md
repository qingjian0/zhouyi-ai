# 古典“类”六种论证用途与行动结果账本 v0.1

## 研究结论

古典文献中的“类”不能被统一压缩成相似度或单一类比算子。结合《墨子·小取》《荀子·正名》《淮南子·说林训》《吕氏春秋·别类》《吕氏春秋·安死》及《论衡·感类篇》，当前项目至少需要分开记录六种用途：

1. **类属/属性相似（taxonomic similarity）**：对象是否共享属性、名类或可辨识特征。
2. **论证性推类（argumentative analogy）**：一个案例是否为另一个命题提供理由；需明确共享根据、关键差异和推论范围。
3. **行动—结果关系（action-outcome relation）**：主体意图、行动方法、作用条件和实际结果之间如何关联。
4. **实践效用（practical utility）**：某种做法是否在明确目标、评价标准和时间跨度下真正有用。
5. **象征/分类对应（symbolic correspondence）**：文本如何将不同领域的对象、征兆、德运、颜色、声音或政事组织成对应关系；其象征结构可以被解释，但不能因此宣称现代经验因果。
6. **感应性因果主张（correlative causation）**：文本把同类相动、气类感召或天人应合提出为因果命题；必须保留其历史理论身份，同时将“文本确实提出该主张”与“该机制已被现代经验识别”分开。

五者可在同一段古文中同时出现，但不能互相替代。比如“得鱼一也”首先支持结果目标相同，不足以证明捕捞机制相同；高阳应造屋故事则提醒局部推理链成立并不保证长期整体结果良好；《安死》的“邻类”可引导研究行动方法与后果，但古代文本提出的因果主张仍需作为文本主张保存，不能自动升级为现代因果事实。

## 《墨经》“三物”解释分歧：不可过早固化为算法槽位

《墨子·大取》相关文字存在传本文字、篇章编次和校勘问题。数字文本与《墨子闲诂》页面可见孙诒让等校语，例如“夫辞”补字、“忘/妄”校改，以及“三物必具”句的移接意见；项目必须将底本文字、校勘者补字和现代解释分别存储，不得把校订文本伪装成无争议原文。

现代解释至少包括：
1. **三段论/论式解释**：把故、理、类分别映射到前提、规则/大前提和例证等论证位置。
2. **逻辑原则解释**：把“辞以故生，以理长，以类行”视为推论成立的基本约束。
3. **认识过程解释**：把三者理解为察类、循理、明故等认识环节。

晋荣东的研究对“推类就是类比推理”提出质疑，认为类同原则可以在演绎、归纳、类比等多种推理中发挥担保作用；他将“推类”理解为对推理本身的概称，并把“类”“理”放在从理由到结论的实质性担保结构中。李巍的研究则从伦理实践角度强调儒墨“推类”可涉及正当言行从典范场合向其他场合的推广。两种研究切入点不同，不应合并成唯一结论。

工程约束：
- 原典字句与校勘补字分字段存储。
- “故/理/类”先作为历史概念层记录，不直接映射为单一现代逻辑类型。
- 现代解释以 competing_interpretation 形式并列，附作者、年份、论证和适用材料。
- 对每一条具体推论分别识别其是规则适用、归纳概括、个案类比、规范推广还是修辞说明。

## 《吕氏春秋·应同》：感应、政治象征与因果不可混同

《应同》以黄帝、禹、汤、文王及五德/五行更替叙事，将天象征兆、德运解释、颜色和政事联系起来。现有数字文本检索入口标注《四部丛刊初编》本，但本项目尚未完成影印页逐字校核。其文字应先作为战国秦汉思想语境中的宇宙论—政治解释记录，而不是直接转换为现代自然因果模型。

必须区分：
- **文本内的对应主张**：祥瑞/征兆、五行之气、颜色与政事之间如何被文本联结；
- **政治合法性叙事**：王朝兴替如何借天象与德运获得解释；
- **象征/分类关系**：五行、颜色、方位等概念如何组织意义；
- **经验因果主张**：天象是否真实导致王朝兴替或政令效果。

《应同》的文本主张不能因被记录就升级为经验事实；《论衡·感类篇》的批判也不能反过来抹去《应同》作为历史思想材料的意义。项目应并列保存正面感应论、批判性论证和现代解释史。

熊凯 2006 年对《应同》提出一项值得保留的竞争解释：该篇并非仅为五德终始片段，还兼有“应”（感应/五德运转）与“同”（从同、帝王霸论）两面；文章进一步假设其五德终始论可能经过后期墨家改造以服务吕不韦的政治论述。此说是现代学术假说，不是定论；它提示 XY-019 不应只标注为五行象征映射，还应保存政治论辩与墨家思想关联的竞争解释。

余治平对《春秋繁露》感应体系的解释，则强调其理论构成包括一般感应原则、物物相感与天人应合，并把阴阳五行视为运行框架。这一解释应作为现代研究层，而非原典自证；尤其需要与《论衡·感类篇》的批判、传世文本版本层次并列比较。

《春秋繁露·同类相动》进一步把水趋湿、火趋燥、琴瑟同声相应等例证，与“美事召美类”“帝王将兴/亡”的祥瑞妖孽叙事相连。其论证结构值得研究，但必须设置跨领域迁移门禁：即使琴瑟共鸣可在声学条件下测量，也不能因此证明政治祥瑞与王朝兴亡具有相同机制。并且《春秋繁露》传世篇章的形成、归属与版本层次需要独立审查，不能未经论证将全部篇章直接视为董仲舒亲撰。四库全书本卷首提要明确记载：宋代已有多种卷帙不同的本子，楼钥校定本与明代重刻本存在缺篇、缺字和讹脱，四库馆臣又据《永乐大典》及楼钥本校补改定；提要同时指出今本“未必全出仲舒”。因此“卷十三·同类相动”必须附具体版本与文本层次，不得把四库本或数字转录当作无争议的汉代原貌。

## 证据层级

- 原典陈述：记录古人提出了什么主张。
- 注疏解释：记录后世如何解释原典。
- 现代研究：记录学术解释及其论证。
- 观察：记录可追溯的实际观测。
- 干预/识别证据：记录设计、比较组、假设和结果，仍须独立审查。
- 模型输出：只能作为待检验候选，不能为自身提供证据认证。

## 工程模型

新增 `prototype/yixiang_lei_claims.py` 与测试，提供六种 claim kind 和保守门禁：

- 缺少共享根据：拒绝（REFUSE）。
- 缺少适用条件或来源：暂缓（ABSTAIN）。
- 行动—结果记录必须分开填写意图、行动方法、作用条件和观测结果。
- 即使行动—结果字段齐全，也不能仅凭记录完整就宣布因果成立。
- 实践效用需要评价标准、即时结果和延迟结果；缺少延迟结果时不得判为效用已确认。
- 象征/分类对应与感应性因果主张分为两个 claim kind：前者只记录符号/分类结构；后者记录古人明确提出的感应因果命题，但文本主张本身不能当作现代因果识别证据。
- 模型生成证据不得认证模型自己的类象判断。

`SCOPE_RECORDED` 仅表示记录字段达到当前门槛，不代表结论为真，不代表因果关系成立。

## 尚未解决的问题

1. 逐条核对《安死》《别类》《说林训》各版本见证与异文，当前数字转录候选仍未完成影印校勘。
2. 为“实践效用”增加可比较的损失函数与多目标冲突记录，避免把效用简化为单一结果。
3. 增加跨时间阶段的结果轨迹，而非只存一个“即时/延迟”标签。
4. 在 M8 中增加六种 claim kind 的分层评估，报告各类错误率，不合并为一个总分。
5. 对干预证据引入预注册、混杂因素、选择偏差和反事实识别审查。

## 研究边界

这是现代工程操作化，不是对古代“类”概念的唯一训诂，也不是已验证的类象智能能力。古籍文本、注疏、现代研究与项目假设必须保持来源分层。
