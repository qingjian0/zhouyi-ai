# 类象组合涌现主张审计 v0.1

## 1. 为什么组合不等于涌现

多个视角组合后出现一个新的描述，不足以证明涌现。至少要区分：

- **组合**：多个候选视角由显式桥接关系连接；
- **复合性质**：对组合整体提出的性质主张；
- **涌现主张**：该性质不能由任何单个成员视角的既有预测直接给出，并且有组合层面的独立证据；
- **涌现成立**：需要进一步实验、反事实干预、重复验证和替代解释排除。

M9 组合原型只产生复合假设。新增审计器检查“涌现主张是否具备可审查结构”，不裁决涌现是否真实存在。

## 2. 最低审计契约

每条 EmergenceClaim 必须记录：

1. 对应的 composite proposal；
2. 明确的新性质描述；
3. 各单独成员视角的预测基线；
4. 成员基线证据；
5. 桥接关系证据；
6. 组合整体层面的证据；
7. 适用范围；
8. 替代解释；
9. 可证伪条件。

成员基线、桥接证据、组合层证据必须使用互不重叠的引用 ID，防止把局部证据重复包装成整体涌现证据。审计器只能检查引用 ID 不重复，不能证明来源真实独立；来源谱系去重仍须由上游证据系统完成。

如果所谓“新性质”已经出现在任一成员的基线预测中，则不能作为组合涌现主张，审计器将其阻断。若证据结构完整，只进入 HUMAN_REVIEW。当前原型只做字符串精确匹配，不能识别同义改写、隐含蕴含或语义等价；这些必须由人工审查或后续经过验证的语义层处理。

## 3. 与组合及因果验证的关系

推荐顺序：

多视角候选 → 竞争审查 → 显式组合桥接 → 组合性质主张 → 涌现结构审计 → 干预/反事实 → 独立重复验证。

不能把以下情况混为涌现：
- 组合后更容易命名或描述；
- 组合后出现统计相关；
- 组合后模型输出了训练数据中未见的词句；
- 多个局部性质简单相加；
- 只在单一情境中观察到一次的整体效果。

需要进一步检验：成员单独存在时是否没有该性质；桥接关系是否必要；移除某个成员或桥接后性质是否消失；改变情境后性质是否保持；是否存在共同原因或测量伪影。

## 4. 原典思想参照及边界

《周易·系辞传》“引而伸之，触类而长之”可作为由已知关系扩展到更高层结构的研究启发；《墨子·小取》警示相同结果不保证相同所以然；《荀子·正名》区分同状异所与状变而实无别。三者共同支持“扩展必须保留条件、差异和对象连续性”的工程约束，但不等于古人已经提出现代复杂系统的涌现理论。
