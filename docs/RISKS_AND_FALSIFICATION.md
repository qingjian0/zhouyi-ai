# 风险、失败模式与证伪条件

## 主要风险

1. **组合爆炸**：n 个节点的子集数量指数增长。缓解：限制阶数、top-k、预算约束、两阶段候选召回。
2. **语义单元抽取错误**：错误节点会污染所有后续推理。缓解：保留来源跨度、置信度和回看原文机制。
3. **超图过度复杂**：动态边可能比任务收益更昂贵。缓解：与普通图/静态超图进行预算匹配对照。
4. **易象先验伪增益**：人工数据可能暗中编码先验。缓解：随机编码、置换编码、hard negative 和外部数据验证。
5. **类比滥用**：相似性被误当成因果。缓解：显式关系对齐、反例搜索、拒绝机制。
6. **并行路径相关性**：多个路径可能共享同一错误来源。缓解：来源去重、依赖建模、独立性估计。
7. **自组织漂移**：错误反馈可能导致结构不断自我强化。缓解：离线验证、版本回滚、保留集门控。
8. **外部 LLM 污染评估**：外部模型可能完成任务，掩盖核心模块无效。缓解：分别报告纯结构模型和带 LLM 解析/表达的结果。

## 证伪条件

- E01 中跨距离组合没有优于简单基线，且在预算内无法改进。
- 超图在预算匹配后没有高阶关系收益，或收益小于额外成本。
- 易象模块与随机编码/可学习编码相比没有稳定增益。
- 并行推演仅靠增加计算量获得收益，固定预算后无优势。
- 自组织更新造成显著灾难性遗忘且无法通过门控控制。
- 完整架构的质量/成本 Pareto 前沿被简单基线全面支配。

出现以上情况时应缩小主张、调整设计或移除模块，而不是更改指标来制造成功。
