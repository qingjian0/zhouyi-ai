# 《墨子·非攻上》递进类推与规范一致性专题 v0.1

## 研究定位

本专题分析《墨子·非攻上》由窃桃李、攘犬豕鸡豚、取马牛、杀无辜者，递进至攻国的论辩，以及“杀一人—十人—百人”的数量扩展。核心不是把“小偷”和“战争”判为表面相似，而是识别论证依赖的共同规范理由、比较维度、尺度变化和可构成正当区分的情境差异。

原典入口：中国哲学书电子化计划《墨子·非攻上》：
https://ctext.org/mozi/condemnation-of-offensive-war-i/zh

页面列有《正统道藏》《墨子闲诂》《四部丛刊初编》等版本入口。当前项目仍将数字录文标为检索见证；“扡/拖”等字形、异文、句读与孙诒让校语须回看影印本核验。

## 一、必须拆成两条论证链

### A. 损害递进链：行为类型与损害程度

可抽象为：

1. 窃桃李：亏人而自利，通常被判为不义。
2. 攘犬豕鸡豚：侵害对象和损失扩大，文本称其不义更甚。
3. 取马牛：损害进一步扩大，罪责更厚。
4. 杀无辜者并取其财物：生命损害使不义更甚。
5. 攻国：若其造成更大规模的亏人，却被誉为义，则出现规范判断不一致。

这条链的核心共同依据是“亏人自利”，比较维度是侵害/损害的扩大。它不是说每一步的行为机制完全相同，而是主张在相关规范维度上存在可比较的连续性。

### B. 数量扩展链：同一行为类别的规模递增

第二段由杀一人推至杀十人、百人，再推到攻国。这里至少有两个层次：

- 数量扩展：在行为性质和责任条件相同的前提下，受害人数增加，不应使不义判断消失。
- 双重标准批判：论者否定小规模杀害，却称更大规模的攻伐为义，暴露其判断标准不一致。

A 链主要比较不同侵害行为的损害程度；B 链主要在同一“杀害无辜者”的规范框架内扩展数量。二者相关但不等同，不能被压缩成一个简单的“相似度递增”。

## 三、迁移成立的必要条件

1. **规范理由同一或相关**：必须说明不同案例为何都受“亏人自利”等同一规范理由约束。
2. **比较维度明确**：区分损害对象、受害人数、损害严重性、行为目的和责任归属。
3. **关键关系保持**：从个体行为到国家行为，需论证主体规模变化没有破坏所依赖的规范关系。
4. **尺度不偷换**：损害增加可以支持更重评价，但不自动推出所有道德维度按人数线性增长。
5. **排除正当差异**：防御、救援、制止侵害与主动攻伐不能只因均造成损害而被等同。
6. **规范结论与经验因果分离**：该段提出的是规范论辩，不是现代战争经验模型或因果定律。

## 四、潜在反例与对抗性测试

| 反例/差异 | 对迁移的影响 | 系统处理 |
|---|---|---|
| 防御行动与主动攻伐 | 目的和责任结构不同 | 暂缓或拒绝无条件类推 |
| 受害人数相同但责任条件不同 | 数量不再是唯一相关维度 | 要求补充责任证据 |
| 规模扩大但受害者/施害者关系改变 | 主体与因果链可能不对称 | 拆分角色映射 |
| 损害增加但存在救援/避免更大损害的情形 | 单一“亏人”维度不足 | 加入反事实与替代方案 |
| 仅因国家行为被称为“义” | 暴露规范双标，但仍需确认论敌原命题 | 追溯对话承诺/文本语境 |

## 五、接入 Zhouyi-AI

- **M2/M2.1**：表示两条链的不同结构：行为类型递进 vs 同类行为数量扩展；不把二者压成一个相似度向量。
- **M3**：并列竞争解释：损害程度递进、规范一致性反证、数量累积强化；允许一段文本有多个论证功能。
- **M4**：干预“主动/防御”“受害人数”“责任归属”“可避免损害”等条件，检查结论是否改变。模拟结果只能标为反事实分析。
- **M5**：优先寻找能区分竞争解释的证据，例如原文论敌、攻伐情境、受害者与行动者角色。
- **M6**：若多案例显示“尺度扩张时规范判断反转”，只能提出“双重标准检测”候选，不得自动宣布古代新范畴。
- **M8**：设置正例、边界例、反例，分别评估关系映射、范围条件、关键差异识别与正确弃权。

## 六、工程验收标准

一个合格系统应能：

- 识别 A、B 两条链并保持分离；
- 找出共同规范理由，而不误判所有属性都可迁移；
- 识别从个体到国家的尺度变化；
- 在防御与攻伐条件不同的案例上不做无条件迁移；
- 说明“规范一致性批判”与“经验因果证明”的区别；
- 当底本文字或情境证据不足时输出 ABSTAIN，而不是补造前提。
