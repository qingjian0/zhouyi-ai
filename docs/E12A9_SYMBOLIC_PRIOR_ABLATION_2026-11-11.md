# E12-A9 — 易象启发式先验消融实验

日期：2026-11-11  
状态：首个可执行原型；等待 CI 与独立审查  
依赖：E12-A2 主动测量选择器、E12-A8 prequential 主动实验循环

## 1. 问题与边界

研究问题：当候选假设、观测似然、动作集合、动作成本、测量噪声和预算相同，仅改变初始假设权重时，一个易象启发式结构先验是否能改善有限候选空间中的主动测量效率？

本实验把三位二值向量作为三个互补因素的操作化表示，并以固定因子概率构造先验。它只是可检验的现代实验编码，不宣称是《周易》原义、古代数值编码或唯一正确的阴阳映射。

## 2. 实验臂

- uniform：均匀先验。
- yijing_factorized：预先固定的三因素互补结构先验。
- shuffled_mapping：保持权重多重集不变，只改变符号与候选 ID 的对应。
- anti_aligned：将结构因素概率反向，作为误导先验压力测试。
- random：按 episode seed 生成可复现随机先验。

所有臂具有相同的八个候选 ID。似然、动作、成本、噪声和预算不因实验臂改变。

## 3. 世界族

- aligned：真实世界候选按结构先验分布抽样。
- uniform：真实世界候选均匀抽样。
- misaligned：真实世界按反向先验抽样。
- permuted：真实世界按置换后的结构分布抽样。

四组必须同时报告，不能只报告 aligned 条件下的优势。

## 4. 过程

每个 episode 从同一候选集合开始。选择器使用 E12-A2 select_measurement，揭示后使用 update_weights。动作提交记录先于测量结果写入；每个动作至多测量一次。不同策略在相同 episode seed 下共享每个动作的潜在噪声结果，降低策略间随机测量差异。

## 5. 指标

- 最终 MAP 候选正确率
- 实际后验熵下降（初始熵减最终熵）
- 平均测量成本与步数
- 高置信错误率（置信度至少 0.8 但 MAP 错误）
- 平均最终置信度

不能只看模型自己的期望信息增益；必须看对真实世界的实际熵下降、准确率和高置信错误。

## 6. 验证与限制

- 所有先验支持集一致且归一化。
- shuffled control 与结构臂的权重多重集一致。
- random arm 可复现。
- 所有策略预算一致，动作成本不能超支。
- seed 对齐的潜在观测噪声不依赖策略选择顺序。
- aligned、uniform、misaligned、permuted 四种世界族均报告。
- 若结构先验只在 aligned 获益，结论只能是任务分布匹配时的条件性归纳偏置。
- 若 shuffled mapping 同样获益，不能把收益归因于易象映射本身。
- 若 misaligned 条件产生更多高置信错误，必须如实报告。
- 仅有 8 个手工定义候选假设与 3 个二值因素；世界族分布由研究者显式设定。
- 先验映射不是从古籍训诂或历史数术考证自动导出。
- 这是有限假设贝叶斯选择，不是开放世界概念形成、关系发明或因果发现。

### 结果解释

1. 在 aligned 世界族中，结构先验准确率比 uniform 高 14 个百分点，但实际熵下降更低（0.788 vs 1.062 bits）。这是准确率与信息收敛指标不一致的信号，不能只挑准确率宣称全面改善。
2. 在 misaligned 与 permuted 世界族中，结构先验明显受损：准确率分别为 0.31、0.28，而 uniform 为 0.51、0.54。
3. shuffled mapping 在 aligned 条件下也达到 0.45，接近结构臂的 0.48；在 permuted 条件下反而达到 0.57。现有实验不能把收益归因于易象映射的特殊语义。
4. 初步结论是强烈的任务分布依赖性：预设结构与真实候选分布匹配时可能改善 MAP 判断，但错配时会伤害表现。当前没有证据支持普遍优势或传统映射的独特优势。
5. 该首轮试验未完整执行 E12-A3 预注册协议：缺少严格零信息 F5、held-out 机制族、Brier/log-loss 校准和世界块置信区间。因此它是探索性 E12-A9 smoke benchmark，不是 confirmatory result，也不能代替 PR #71 的 A3-P 审核。

## 9. 下一轮必须补齐

- 增加零信息候选组，验证所有先验都保持歧义，不得先验制造确定答案。
- 加入 Brier score、log loss、校准误差与后验 regret，避免 MAP accuracy 单指标误导。
- 采用真正 held-out 的因素组合/机制族，并执行 paired world-seed bootstrap 置信区间。
- 明确区分候选先验 P、似然/表示先验 L、动作/转移先验 T；本轮只改 P。
- 检验 prior tempering / rejection：当新证据与先验冲突时，系统是否能降低先验权重，而非锁定错误结构。
