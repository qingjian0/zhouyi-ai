# TX-02：多状态表示竞争与自主选择基准

状态：协议 + 数据生成器实现；学习器尚未实现，尚无性能结果。  
关联：TX-01、E02-B、E02-D、E12、YF-02/YF-03。

## 1. 研究问题

TX-01 只验证三值索引可逆性。TX-02 开始检验一个更强的主张：认知系统能否根据任务结构选择二值、三值、混合或自主学习的表示，而不是把某一种古典符号体系固定为普遍答案。

必须区分三件事：

1. **编码容量**：表示能否无损区分状态。
2. **关系学习**：能否从有限支持样本恢复隐藏关系。
3. **表示选择**：能否在任务未知时选择合适表示，并在分布变化后修正。

TX-02 的数据生成器只提供受控的关系归纳任务，不把数据生成器本身当作学习能力。

## 2. 任务族：有限环上的隐藏关系

对每个状态基数 K，取 K∈{2,3,4,5}，符号集合为 Z_K。每个 episode 隐藏一条规则：

\[
c=(\alpha a+\beta b+\delta)\bmod K
\]

其中 \(\alpha,\beta,\delta\in Z_K\)。支持集给出若干 (a,b,c) 实例；测试查询给出未见过的 (a,b)，要求从 K 个候选 c 中选出正确值。

为了避免模型只记住符号名称，每个 episode 对输入/输出符号应用一个独立随机双射。双射只改变可见标签，隐藏运算仍在潜在规范符号空间中定义。

该任务是有限代数关系归纳基准，不代表自然语言理解、真实因果发现或通用智能。

## 3. 表示条件

同一 episode、相同支持/查询数据、相同优化预算下比较：

- **BINARY**：二值位分解编码。
- **TERNARY**：三值位分解编码。
- **HYBRID**：二值与三值双通道。
- **LEARNED**：随机初始化、由训练目标学习的状态嵌入。
- **ONE_HOT**：不带数值几何假设的类别基线。
- **PERMUTED**：三值编码经随机置换的负对照。

注意：K=2/3 时某种编码与任务字母表天然匹配；K=4/5 时需处理补齐位、无效码和解码约束。所有表示必须提供相同的可见符号身份信息，且参数量、训练步数、总 FLOPs 尽量匹配。无法完全匹配时须报告差额，不能把计算量优势归因于理论先验。

## 4. 数据切分与防泄漏

- **Canonical track**：保留规范符号编号，测试编码结构本身是否提供归纳偏置；这是先验对齐条件，必须与随机置换对照一起解读。
- **Permuted track**：每个 episode 独立应用随机双射，测试系统是否能从支持样本适应符号重命名；此条件不应被误解为太玄三值天然有利。
- Episode 级拆分：训练、验证、测试不得共享隐藏规则实例。
- 规则系数拆分：测试集保留训练阶段未出现的系数组合。
- 符号重映射：每个 episode 独立采样双射；另设固定映射和跨映射迁移测试。
- 查询隔离：测试查询不得出现在支持集中。
- 候选顺序随机化：正确答案位置在各候选位置均衡。
- 测试集只在表示、超参数和选择策略锁定后评估。

数据生成器的种子只控制采样，不改变任务数学定义。

## 5. 自主表示选择器

建议的选择器输入是任务早期可见证据摘要，而不是隐藏任务标签：

- 支持样本的预测误差与校准；
- 候选规则数量及其不确定性；
- 验证任务的泛化误差；
- 表示成本（参数、FLOPs、延迟、内存）；
- 负迁移惩罚与历史任务表现。

候选动作：SELECT_BINARY、SELECT_TERNARY、SELECT_HYBRID、SELECT_LEARNED、DEFER_MORE_EVIDENCE。选择器只能使用训练/验证 episode 的反馈，不能读取测试规则参数或隐藏标签。

第一阶段先做静态验证集选择器；第二阶段再做预算受限的在线多臂/上下文 bandit；第三阶段才考虑让系统提出新基数 K 或非均匀状态划分。

## 6. 必须报告的指标

- episode accuracy、identified accuracy、coverage / abstention；
- 未见规则组合准确率；
- 跨符号置换迁移准确率；
- 不同 K 的分层结果；
- 校准误差、错误自信率；
- 样本效率（达到目标准确率所需支持样本数）；
- 表示选择 regret、选择稳定性；
- 参数量、FLOPs、延迟、峰值内存；
- 失败任务与表示切换记录。

不得只报告平均准确率；必须分别报告 K=2、3、4、5，防止某个状态数上的优势掩盖其他任务上的退化。

## 7. 消融与负对照

1. 去掉表示选择器，固定使用每种编码。
2. 把三值符号置换，检验收益是否来自结构而非任意标签。
3. 打乱支持样本标签，检查泄漏与偶然相关。
4. 只用 one-hot，建立无先验基线。
5. 只给状态频数，不给关系结构，检测边际统计捷径。
6. 匹配参数和计算预算；另报告未匹配的自然配置。
7. 在二值任务上检验三值过度参数化，在三值任务上检验二值表达代价。

## 8. 证伪条件

- 若结构化编码不优于容量匹配的 one-hot / learned embedding，不得宣称古典结构提供了学习优势。
- 若 PERMUTED 与 TERNARY 相当，不得把增益归因于太玄结构。
- 若选择器只在训练过的 K 或规则族上工作，不得宣称自主发现状态空间。
- 若选择器在分布变化后持续选择错误表示，须保留 DEFER / fallback，不得强制路由。
- 若优势来自额外参数或计算预算，结论必须限定为资源增加带来的收益。
- 只在合成数据有效时，结论只限于合成关系归纳。
