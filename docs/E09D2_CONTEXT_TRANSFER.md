# E09-D2：未知环境迁移与少样本适应

状态：基准首版已提交；测试待执行。  
分支：`research/e09-nongradient-learning-2026-11-10`

## 研究问题

当系统进入训练阶段从未出现过的新环境时，它会不会把旧环境规则错误迁移过去？获得少量新环境证据后，能否形成新条件关系，同时保留旧环境能力？

## 隐藏任务

- Context 0：`a == 1 AND c == 2`
- Context 1：`a == 2 AND b == 0`
- Context 2（初始训练完全隐藏）：`b == 2 AND c == 1`

学习器只接收四元组输入和标签，不接收目标表达式。Context 2 在初始阶段不出现；之后从训练基础组合中提供 6 个带标签支持样本。测试基础组合与训练/支持组合完全分离。

## 实验阶段

1. **Initial**：仅用 Context 0、1 训练。
2. **Zero-shot**：不提供 Context 2 样本，直接测量模型对 Context 2 的预测、覆盖率和错误率。不能预设模型会拒答。
3. **Few-shot adaptation**：加入 Context 2 的少量支持样本，重新拟合模型。
4. **Retention**：重新评估 Context 0、1，检查适应新环境是否损害旧环境能力。

## 主要指标

每个环境分别报告覆盖率、已作答准确率、总体正确率和拒答数。至少 5 个种子，并保留逐种子结果。不能只报告总体平均值。

## 可证伪假设

- H1：零样本迁移可能产生过度泛化；其正确率与覆盖率必须实测。
- H2：少样本证据能让模型建立 Context 2 的条件规则。
- H3：适应后旧环境性能不应无解释地大幅退化。
- H4：如果适应后不能稳定提升 Context 2 的正确率/覆盖率，或明显损害旧环境，则该适应策略不成立。

## 关键限制

- 上下文字段和有限类别 DSL 预先给定；不是自主发明环境概念。
- Context 2 的隐藏规则来自固定合成规则族，不代表开放世界泛化。
- few-shot 是有监督的重新拟合，不是无监督持续学习。
- 该原型不使用梯度更新，但仍依赖有限候选规则搜索。
- 需同时报告模型结构变化和所有环境的性能变化，防止只展示新环境收益而掩盖灾难性遗忘。
