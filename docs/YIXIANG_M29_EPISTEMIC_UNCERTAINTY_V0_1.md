# M29：类象认知不确定性与依赖传播 v0.1

## 1. 研究问题

M28 区分证据独立性，M29 进一步区分证据记录状态与类象主张的认知状态。主张不能仅由支持记录数量自动判定。一个来源可支持主张，但未必足够；多个来源可冲突；某项主张也可能只在明确条件下暂时成立。

## 2. 原典研究与工程边界

《墨子·小取》将辩论目的表述为“明是非之分”“明同异之处”“察名实之理”“决嫌疑”，并区分辟、侔、援、推，提醒推论“远而失，流而离本”。“其然也同，其所以然不必同”要求系统不能把结果相似直接升格为机制相同。M29 据此保留证据冲突、适用条件和推论状态，而不是简单累计支持票数。此为工程化启发，不是说《小取》已有现代概率或贝叶斯模型。参见《墨子·小取》数字见证：https://zh.wikisource.org/zh-hans/墨子/小取 与 https://ctext.org/mozi/minor-illustrations/zh 。

《荀子·正名》说“心有征知”，但又指出感官记录与心的征知有其条件；“五官簿之而不知，心征知而无说，则人莫不然谓之不知”。同时区分同状异所、异状同所、状变而实无别等情况。M29 的未知、证据不足和条件状态，借此避免把没有充分认识当成已知，也避免只凭外观相似作出确定判断。原文与四部丛刊本见证：https://zh.wikisource.org/zh-hans/荀子/正名篇 与 https://zh.wikisource.org/zh-hans/荀子_(四部丛刊本)/卷第十六 。

《庄子·齐物论》讨论彼是互因、视域变化及是非判断的相待关系。工程上应记录观察立场与适用范围，但不能据此推成“所有判断同样有效”或“无法裁决”。参见：https://zh.wikisource.org/zh-hans/庄子/齐物论 。

## 3. 状态体系

- UNKNOWN：尚无可用证据或未形成判断。
- INSUFFICIENT：有记录，但不足以支持当前判断。
- REVIEW_REQUIRED：有未审查或争议材料，或软依赖要求复核。
- PROVISIONAL：经人工审定的暂时成立，仍可被新证据修订。
- CONDITIONAL：仅在明确条件/范围下成立。
- WEAKENED：存在经审查的反面证据，主张被削弱。
- CONFLICTED：支持与反驳证据并存，尚未消解。
- STALE：依赖版本已变化，旧判断不再由当前依赖充分支持；不等于主张为假。
- REVALIDATED：人工针对新版本重新审查后的状态；作为传播屏障，但不等于永真。

状态不映射为单一概率分数。各状态不是简单线性概率刻度；CONFLICTED 与 INSUFFICIENT 尤其不能混为一类。

## 4. 传播规则

依赖方向为 prerequisite → dependent：

- HARD：上游 STALE、CONFLICTED、WEAKENED、CONDITIONAL、INSUFFICIENT 等不确定性向下游传播。
- SOFT：上游发生不确定变化时，下游进入 REVIEW_REQUIRED，不直接宣称失效。
- UNKNOWN 不自动污染下游：未知的可选关联不能等同于必要前提；若它是必要前提，应由调用者登记为 HARD 并提供 INSUFFICIENT 的审定状态。
- REVALIDATED 是人工复核屏障，阻止旧状态机械传播越过该节点。
- 多条依赖同时作用时，保留更严重的状态及来源轨迹，不覆盖其他来源的证据记录。

## 5. M27 显式适配

新增 adapt_m27_invalidation，要求调用者提供 M27 node_id 到 M29 claim_id 的映射。M27 stale 节点转为 M29 STALE，M27 review 节点转为 REVIEW_REQUIRED。未映射节点直接拒绝，不按字段名猜测映射。适配器仅把失效/复核状态接入认知状态图，不自动推断主张真假。

## 6. 测试范围

26 项测试覆盖未知、证据不足、未审查、暂时成立、条件成立、反面证据、支持/反驳冲突、HARD/SOFT 传播、M27 映射、重新验证屏障、循环与自依赖、悬空引用、分支隔离及语义真值边界。

## 7. 限制

- 不自动决定证据是否充分；PROVISIONAL/CONDITIONAL/WEAKENED/CONFLICTED/REVALIDATED 必须有人类审定记录。
- 不计算概率、不输出伪精确置信度。
- 不认证原典真伪、版本年代或语义蕴含。
- 不把古典文本解释成现代认知状态机。
- M27 的映射由调用方显式提供；未完成全仓库端到端接线与 CI 验证前，不声称已全链路集成。
