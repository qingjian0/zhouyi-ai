# 类象发生、抽象、迁移与修正机制 v0.1

## 1. 本轮研究结论

类象不应被实现为“看到两个对象相似就连一条边”。更可靠的计算描述是一个分层、可撤销的认知过程：

`观测 → 取象 → 抽象 → 定类 → 比类 → 关系检验 → 条件迁移 → 反例修正`

这是 Zhouyi-AI 的现代工程流程，不宣称它是古人明确提出的一套固定算法。传统材料提供问题意识、概念和历史案例；程序接口是现代操作定义，必须单独标记。

## 2. 先分清六种对象

1. **物/事（observed entity or event）**：实际被观察的对象、事件或过程。
2. **观象（observation）**：在特定观察位置、时间、尺度和任务下记录的可见信息。
3. **取象（selection）**：从观测中选择当前任务相关的属性、结构、功能、关系或过程；它必然有选择偏差，必须记录未选信息。
4. **象（pattern representation）**：经选择和组织后得到的模式表征，不等同于对象本身。
5. **类（category）**：由一组可说明的共同点、边界和用途形成的暂定集合；不是“相似”二字就能成立。
6. **类象（validated mapping）**：两个模式之间在指定维度、关系、条件和范围内的部分对应；允许失败、局部成立和撤销。

“象”至少有三个不可混同层次：
- 感知/记录层：观测到的形色、声音、运动、时序、位置等；
- 抽象/结构层：从多个观测中提取的稳定关系或功能组织；
- 解释/符号层：卦象、卦德、术数解释、注家义理等历史解释体系。

任何从第一层到第三层的映射都必须有来源和规则，不能把工程特征直接说成古义。

## 3. 传统文献对问题的不同贡献

### 3.1 《周易》经传：观、拟、立象、系辞、触类

《系辞》中的观象、拟形容、立象尽意、触类而长等材料，可用于研究“观察如何形成符号表征”与“已知模式如何扩展”。但《系辞》篇章层次与成篇年代仍有学术讨论，不能把所有命题一概归为某一先秦作者。

### 3.2 《墨子·小取》：推类必须辨论式与止境

《小取》不能被简化为一条无条件的“相似则推出”规则。推、止、类、故、譬、侔、援等论辩结构提醒我们：同一个论证形式在不同对象、行为、情态和目的下，可能允许推扩，也可能要求止推。计算系统必须表示“可迁移条件”与“禁止迁移边界”。

### 3.3 《荀子·正名》《非相》：分类依赖约定、辨异和适用目的

名称、类别与对象并非可以任意混用。类别是为辨同异、治理认知与实践而建立的秩序；“以类度类”不等于无边界外推。模型要同时评估成员证据与反例边界。

### 3.4 汉易：外部物象、卦爻内部结构与象数规则逐渐分化

现代易学史研究指出，汉代易学存在由外部物象比附到更多关注卦爻结构、卦变和象数体例的不同路径；不能把孟喜、京房、郑玄、虞翻等人的方法合并为一张静态配象表。具体历史断代与学派关系仍须按原典和研究逐项核对。

### 3.5 魏晋至宋明：象与意、象数与义理的解释张力

王弼“忘象”相关讨论、宋代图书之学、程朱义理、明代象数重构，提示“象”既可能是解释辞义的结构线索，也可能成为被批评的拘执对象。系统必须允许不同解释路径并存，不能假设象越多越好。

## 4. 类象的最小数学描述

令一个观测为：

`O=(E,F,R,C,T,S)`

- `E`：实体/事件标识；
- `F`：属性与结构特征；
- `R`：实体间关系图；
- `C`：环境、任务、边界等条件；
- `T`：时间与阶段；
- `S`：证据来源和观测状态。

取象不是简单复制全部 `F,R`，而是依任务选择一个投影：

`X = Select(O | task, scale, viewpoint, constraints)`

从多个观测中提出候选不变量：

`I = {f : support(f, D+) ≥ τ and conflict(f, D-) = 0}`

其中 `D+` 是支持样本，`D-` 是反例；`τ` 是明确配置的支持阈值。它只表示当前样本范围内的候选稳定特征，不是普遍本质。

比类映射 `M: X_s → X_t` 必须声明：
- 映射对象与角色；
- 保持的关系集合 `R_preserved`；
- 允许变化的关系集合 `R_changed`；
- 不可迁移的关系集合 `R_blocked`；
- 条件 `C`、有效时间与适用范围。

迁移结论只在已声明的子结构内成立：

`Valid(M) = Evidence ∧ Scope ∧ Conditions ∧ RelationFit ∧ CounterexamplePolicy`

关系保持不是因果保持；形态相似也不推出功能相同。若缺少目标域证据，输出只能是候选假设，不得判为已验证类象。

## 5. 七阶段计算闭环

| 阶段 | 输入 | 输出 | 主要失败方式 |
|---|---|---|---|
| 观测 | 原始资料/感知结果 | 带来源的观测 | OCR 错误、观察偏差 |
| 取象 | 观测、任务、尺度 | 被选特征与未选信息 | 选择偏差、遗漏 |
| 抽象 | 多个观测 | 候选不变量、变量特征 | 过拟合、伪共性 |
| 定类 | 候选不变量、反例 | 暂定类及边界 | 类别过宽/过窄 |
| 比类 | 源类、目标类 | 显式映射候选 | 表面相似、角色错配 |
| 检验 | 关系、条件、证据 | 通过/局部通过/拒绝 | 关系不保持、无证据 |
| 修正 | 新样本、反例、反馈 | 新版本类象与失效记录 | 过度修正、灾难性遗忘 |

这七阶段不是必须严格串行。多种取象视角可并行生成候选，之后统一执行证据、关系和边界审查；修正必须生成新版本，不能静默覆盖旧定义。

## 6. 关键区分：相似、同类、对应、推断、因果

- **相似（similarity）**：在某些选定维度上接近。
- **同类（category membership）**：满足一个类别在特定任务中的成员条件。
- **对应（correspondence）**：两个域中的结构角色形成可说明映射。
- **可推（transferable inference）**：源域的某项关系/规律在目标域条件下有证据支持。
- **因果（causality）**：需要独立的干预、机制或因果识别证据；不能由类象分数推出。

系统输出应分别给出状态，不得压缩为单一“相似度”。

## 7. 反例驱动的类别修正

反例不只是扣分。它可以揭示：
- 原类别把偶然特征误认为不变量；
- 类别缺少必要条件；
- 两种不同机制被表面相似掩盖；
- 关系方向、角色或尺度没有对齐；
- 该映射只在某一时段或环境成立。

修正策略应保留旧版本、支持证据和反例来源，并产生版本差异。若新反例推翻某条不变量，应将其降级为条件特征或删除，不得通过改写定义来隐藏失败。

## 8. 与现有代码的衔接

新增 `prototype/yixiang_process.py`：
- `Observation`：带证据的观察记录；每个特征必须声明 `morphology/attribute/function/process/spatiotemporal/potential/integrated` 等维度，抽象时只纳入本轮明确选择的维度，防止把季节、形态和功能等异质特征混为同一类；
- `derive_pattern`：从显式特征中抽取样本内共同项；仅对所选维度执行精确值比较，缺失值按未支持处理；
- `classify_observation`：按候选不变量和排除项评估成员资格；
- `revise_pattern`：利用正例和反例生成新版本。

它与 `prototype/analogy.py` 分工：
- 前者处理“如何从观测样本形成和修正候选象/类”；
- 后者处理“给定源/目标结构映射后，关系是否保持”。

当前实现不做 OCR、古文断句、自动语义抽取、神经表征学习或自主发现现实世界规律。输入特征仍由人工标注或上游抽取器提供。样本内共同项不等于哲学本质，更不等于自然定律。

## 9. 动态类象：从静态特征转向状态转移

静态类象回答“两个对象在什么维度上可比”；动态类象还要回答“对象从状态 A 到状态 B 的变化是否具有可比结构”。新增 `prototype/yixiang_dynamics.py`，将一条轨迹表示为按时间步严格排序的状态观测序列，并抽取有方向的特征转移 `(before, after)`。

设计约束：
- 转移有方向：`A→B` 不等于 `B→A`，不得默认可逆。
- 每条轨迹只对某一转移投一票，避免长轨迹因样本多而支配支持率。
- 时间步必须严格递增；轨迹内必须跟踪同一实体、同一领域。
- 缺失状态不视为“保持不变”；只有前后均可观测的特征才参与转移抽取。
- 多种转移并列时不强行选定；低支持率只保留为变量特征。
- 输出仍是样本范围内的候选变化模式，不等于机制或因果规律。

当前实现仅消费显式标注的状态和证据，不做原始感知、状态分段、趋势预测或因果发现。后续应进一步研究时、位、势、条件变化与状态转移的联合表达。

## 10. 时空情境联合类象

静态特征、动态转移与多元角色关系不能只靠串联三个独立模块来完成统一推断。新增 `prototype/yixiang_situated.py`，将一次情境表示为：状态特征、具名角色关系、时间步、位置、阶段、环境条件和证据来源。比较时分别报告状态保持率、关系保持率、条件匹配、位置匹配和阶段匹配，不将它们压缩为一个不可解释的总相似度。

该原型采用显式实体映射和显式必需条件键。关系类型与角色名精确匹配；条件只比较调用方声明的键；位置与阶段可独立设置为硬门槛。缺少证据、状态不一致、角色关系变化或条件冲突时拒绝接受。该机制仍是确定性符号比较，不会自动推断“时”“位”“势”的语义，也不声称得到因果规律。

《系辞下》“变动不居，周流六虚”“上下无常，刚柔相易”“唯变所适”可作为研究时位与变化不可脱离的文本入口。孔颖达《周易正义》将“六虚”解释为六位，并以爻位变动说明其迁移；这是唐代注疏的解释见证，应与经传原文分层保存。项目据此提出工程假设：同一状态/关系在不同位置、阶段和条件下，不能默认具有相同适用性。该假设仍须独立实验验证。

## 11. 实验计划

1. **不变量恢复**：合成数据中设置已知共同特征、噪声特征和偶然共现，检查是否恢复真实不变量。
2. **反例修正**：逐步加入反例，测量错误不变量删除率与有效不变量保留率。
3. **条件分布变化**：同一结构在不同时间/环境下改变，检查模型能否把规律降为条件性而非强行泛化。
4. **跨域关系迁移**：将候选类映射到独立目标域，使用已有有向关系评估器检验结构保持。
5. **拒绝能力**：构造表面特征相似但关系方向、功能或条件不同的负例，测量错误类象接受率。
6. **来源留出**：按古籍、篇章、注家和时代分组留出，防止同一解释传统在训练与测试中重复出现。

必须与简单特征交集、随机分类、最近邻、仅相似度和关系保持基线比较。没有实验数据前，不宣称本方法优于机器学习模型。

## 12. 史料与研究入口

- 《周易·系辞》：观象、拟象、立象、触类；需核验经传版本及篇章上下文。
- 《周易·说卦》：卦象结构和物类陈述；须区分传文陈述与后世配象扩展。
- 《墨子·小取》：类、故、譬、侔、援、推及论证止境。
- 《荀子·正名》《非相》《解蔽》：名实、同异、类推和认知偏误。
- 《吕氏春秋·应同》《淮南子》相关篇：同类、时令、感应和宇宙论的历史语境。
- 汉魏易学材料：外取象、内取象、卦爻结构和卦变规则的分期研究。
- 宋明易学：图书、义理与象数解释的分歧和重构。

## 13. 本版尚未解决的问题

- 如何从连续感知、图像、声音和自然语言中学习候选特征，而不把人工特征工程误当作类象智能？
- 如何表示多对多、层级、尺度变换和部分对应，而不局限于一对一映射？
- 如何联合处理互相冲突的传统解释？
- 如何区分“类的边界”与“类在新环境中的动态变化”？
- 如何让系统主动提出可检验的观察任务，以获取区分竞争类象所需的新证据？

以上均保留为后续研究问题。
