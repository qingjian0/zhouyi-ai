# M25：类间关系、跨轴映射与推论权限 v0.1

## 1. 研究问题

M24 建立类别节点、层级与多重归属。M25 研究类别之间的关系，以及关系能够授权何种推论。核心风险是把“某方面相似”扩张为“整体相同”，或把相关、功能对应误写成因果关系。

## 2. 原典证据与可支持的有限命题

### 2.1 《墨子·小取》：类推形式不同，适用范围不同

《小取》区分辟、侔、援、推等辩说形式，并指出这些形式在推行、转折、远引时可能危险、失当、离本；“其然也同，其所以然不必同”。篇末又说“殊类异故，则不可偏观也”，并通过白马/骊马、获/臧、车/船、盗人等例子展示谓词迁移的边界。

可支持的研究命题：类推不是单一算子；迁移必须检查类属、理由、范围和反例。不可把《小取》的辩说术直接等同现代形式逻辑中的某个单一推理规则。

### 2.2 《荀子·正名》：同异判断与名实核验

《正名》提出感官辨异、心的征知、同则同之异则异之，以及大共名/大别名。又区分同状异所、异状同所、状变而实无别等情况。

可支持的研究命题：外观相似、对象同一、名称相同是不同判断；类间关系应保留关系类型与对象身份，不以单一相似度替代。

### 2.3 《周易·系辞下》与《说卦传》

“近取诸身，远取诸物”及《说卦》多域取象，允许研究跨域对应如何建立，但不能仅凭对应条目推定存在物理因果或机制同一。象数对应、结构类比、功能类比、因果机制必须分开登记。

### 2.4 《淮南子·说林训》

其案例强调同一对象在势、位、用等条件变化时，结果可能不同。它支持情境限定的关系主张，不支持无条件迁移。

## 3. 关系类型

M25 将类间关系分为：
- similarity：相似，默认仅支持比较；
- structural：结构对应，可在明示结构不变量后提出关系迁移；
- functional：功能对应，必须绑定主体、任务和环境；
- causal：因果假设，必须有方向、机制证据和替代解释审查；
- temporal：时间先后或演变关系，不自动表示因果；
- contextual：情境依赖关系；
- symbolic：象征/约定关系，不等同物理机制；
- hierarchical：上下位类别关系；
- contrast：对照或差异关系。

## 4. 跨轴映射

跨轴映射不是关系标签的简单改名。每条映射必须声明源轴、目标轴、两端类别、映射规则、适用范围、情境版本、证据和理由。映射只在声明范围内有效，不自动继承源轴上的其他属性。

## 5. 推论权限

- compare_only：允许比较，不迁移属性；
- transfer_feature：仅迁移明确列出的特征，须说明适用域；
- transfer_relation：仅迁移结构/功能/因果关系，需关系不变量与独立桥接证据；
- causal_hypothesis：只登记待检验因果假设，不视为已证因果；
- blocked：保留被阻断的推论记录，不产生肯定结论。

M25 原型采用保守门禁：相似关系不能授权关系迁移；时间关系不能授权特征迁移；非因果关系不能授权因果假设。通过结构审计不代表语义推论正确。

## 6. 工程边界

`prototype/yixiang_intercategory.py` 只检查关系声明、端点、分类轴、范围、情境、证据和推论权限的结构一致性。它不自动识别相似关系、不自动生成跨轴映射、不证明因果、不判断古典文本解释真伪。

## 7. 可证伪实验

1. 构造表面相似但机制不同的成对案例，测量系统是否过度迁移。
2. 构造功能相同但结构不同、结构相似但功能不同的对照案例。
3. 构造时间相关但无因果关系的样例，测试因果升级错误率。
4. 跨轴映射加入适用范围外样例，测量范围外迁移率。
5. 对每类关系单独报告 precision、coverage、selective risk 和错误类型；不以总准确率掩盖某一关系族的失效。
6. 由独立标注者标记关系类型、允许迁移项、禁止迁移项和反例；合议前保留分歧。
