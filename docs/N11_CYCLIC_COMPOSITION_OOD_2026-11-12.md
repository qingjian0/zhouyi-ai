# N0.11：循环群相位组合的高阶结构 OOD

**状态：实验代码通过完整 CI；五种子正式结果已生成。**

## 研究问题

N0.10 的三元奇偶任务只证明显式三阶项可以拟合一个已知 IID 规则。N0.11 改为连续相位组合，并将一个角色的相位区域完整留作测试：

- 目标：`y = 1[cos(a + b + c) > 0]`
- 训练：角色 A 的相位仅来自 `[π/2, 2π)`
- 测试：角色 A 的相位仅来自 `[0, π/2)`
- 验证集：角色 A 仍来自训练区域 `[π/2, 2π)`，用于只在训练分布内校准 logit 方向。
- 角色 B、C 在训练、验证和测试中均覆盖 `[0, 2π)`
- 训练和测试相位区域严格不重叠。

这属于一个受控的组合分布偏移：模型必须把已学到的三元组合规律迁移到角色 A 未见过的相位区域。

## 结构表示

每个角色输入 5 维特征。前三类坐标构成一个显式 Fourier 张量分解：

`cos(a+b+c) = cos(a)cos(b)cos(c) - cos(a)sin(b)sin(c) - sin(a)cos(b)sin(c) - sin(a)sin(b)cos(c)`

三个角色的向量按不同坐标顺序排列，使 SROK 的逐维三阶乘积恰好提供上式的四个 rank-1 项；第五维常数项提供偏置。

这不是“模型自己发现了傅里叶表示”。我们显式提供了数学归纳偏置，实验检验的是：在该表示下，SROK 是否能学习并迁移三元组合项，以及屏蔽三阶项后能力是否消失。

## 对照设计

同一份训练数据、验证数据、测试数据和优化器，比较。验证集与训练集来自相同的 A 相位区域；测试集来自完全未见的 A 相位区域。每个模型的 logit 正负方向只能根据验证集准确率选择，测试标签不参与模型选择。

| 模型 | 活跃参数 | 作用 |
|---|---:|---|
| Unary | 15 | 仅一元特征 |
| Unary + Pairwise | 30 | 增加二元交互 |
| Unary + Pairwise + Triple | 35 | 增加三元交互 |
| Triple-trained / Triple-masked | 推理时仅用前 30 维 | 对已训练三阶模型做归因干预 |

这里是同一模型的嵌套特征消融，不是与 MLP、GNN 或 Transformer 的参数匹配比较。CI 还报告一个明确标注为 test-oracle 的诊断：把 pairwise 模型的 logit 方向反转后重新计算测试准确率。它只用于揭示方向反转，不用于模型选择、调参或主结果。若这个诊断显著高于按验证集确定方向的主结果，说明 pairwise 模型在 OOD 区域出现系统性方向反转，不能简单将其解释成“二阶特征没有信息”。

## 复现

```bash
python -m unittest tests.test_n11_cyclic_composition_ood -v
python -m prototype.n11_cyclic_composition_ood --seeds 5 --start-seed 7 --train-samples 3000 --test-samples 1500 --epochs 120 --json
```

CI 验收阈值针对这个已知解析目标：五种子平均三阶 OOD accuracy 和 balanced accuracy 均 ≥ 0.85；经验证集方向校准的 unary accuracy 处于 0.38–0.62；屏蔽三阶块后的准确率 ≤ 0.35；测试正类比例处于 0.45–0.55。阈值只验证实现是否按预期工作，不是现实任务能力标准。

## 五种子正式结果

CI 正式配置：5 个种子；每个种子 3,000 train / 750 validation / 1,500 held-out-region test；120 epochs。

| 模型 / 诊断 | 测试准确率（均值 ± 样本标准差） |
|---|---:|
| Unary（验证集校准方向） | 52.49% ± 4.36% |
| Unary + Pairwise（验证集校准方向） | 14.35% ± 1.78% |
| Unary + Pairwise + Triple | 92.41% ± 0.62% |
| Triple-trained / Triple-masked | 14.48% ± 1.83% |
| Pairwise 测试标签 oracle 反向诊断 | 85.65% ± 1.78% |

三阶模型的 balanced accuracy 为 92.43% ± 0.61%。Pairwise 在训练分布内的验证准确率平均为 62.45%，但在未见 A 相位区域的测试准确率降至 14.35%；如果事后用测试标签反转 logit 方向，准确率会变成 85.65%。这个 oracle 结果只用于暴露方向反转，不可部署，也没有参与选择。

**结论必须精确表述：**本实验显示显式三阶 Fourier/tensor-product 模型在该相位区域迁移任务上稳定泛化，而已训练的低阶模型发生严重方向反转；屏蔽三阶块后，三阶模型也失去该迁移能力。它不证明任意二阶模型都无法表达该目标，也不证明易象先验、自然语言推理或一般智能。

## 解释边界与下一步

- 任务是合成连续相位；目标规则已知。
- Fourier/tensor-product 特征是人为提供的先验，不是从原始语义中学习出来的。
- OOD 只涉及一个角色的相位区域，不等于未见语义规则族。
- 需要后续增加无 Fourier 先验的可学习编码器、容量/计算预算匹配的 MLP/GNN 基线，以及多个不同规则族。
- 只有当同一机制在多个任务族、多个随机划分和匹配预算下仍有优势，才值得把它作为 Zhouyi-AI 的核心归纳偏置。


## 验证校准与方向反转审计

模型方向只在训练分布内的 validation split 上选择；validation 的角色 A 相位仍然位于 [π/2, 2π)。测试集完全不参与选择。另行输出 pairwise 模型在测试集上反转 logit 符号后的结果，字段名明确包含 `test_oracle` 和 `diagnostic_only`，避免把它误读为可部署性能。若反向结果很高，表示该模型在未见相位区域发生了方向反转，提示低阶模型出现分布相关的负迁移；这不是证明所有二阶模型都无法表达该目标。
