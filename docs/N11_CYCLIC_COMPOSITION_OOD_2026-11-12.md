# N0.11：循环群相位组合的高阶结构 OOD

**状态：首个可执行实验已加入分支，等待 CI 实测。**

## 研究问题

N0.10 的三元奇偶任务只证明显式三阶项可以拟合一个已知 IID 规则。N0.11 改为连续相位组合，并将一个角色的相位区域完整留作测试：

- 目标：`y = 1[cos(a + b + c) > 0]`
- 训练：角色 A 的相位仅来自 `[π/2, 2π)`
- 测试：角色 A 的相位仅来自 `[0, π/2)`
- 角色 B、C 在训练和测试中均覆盖 `[0, 2π)`
- 训练和测试相位区域严格不重叠。

这属于一个受控的组合分布偏移：模型必须把已学到的三元组合规律迁移到角色 A 未见过的相位区域。

## 结构表示

每个角色输入 5 维特征。前三类坐标构成一个显式 Fourier 张量分解：

`cos(a+b+c) = cos(a)cos(b)cos(c) - cos(a)sin(b)sin(c) - sin(a)cos(b)sin(c) - sin(a)sin(b)cos(c)`

三个角色的向量按不同坐标顺序排列，使 SROK 的逐维三阶乘积恰好提供上式的四个 rank-1 项；第五维常数项提供偏置。

这不是“模型自己发现了傅里叶表示”。我们显式提供了数学归纳偏置，实验检验的是：在该表示下，SROK 是否能学习并迁移三元组合项，以及屏蔽三阶项后能力是否消失。

## 对照设计

同一份训练数据、测试数据和优化器，比较：

| 模型 | 活跃参数 | 作用 |
|---|---:|---|
| Unary | 15 | 仅一元特征 |
| Unary + Pairwise | 30 | 增加二元交互 |
| Unary + Pairwise + Triple | 35 | 增加三元交互 |
| Triple-trained / Triple-masked | 推理时仅用前 30 维 | 对已训练三阶模型做归因干预 |

这里是同一模型的嵌套特征消融，不是与 MLP、GNN 或 Transformer 的参数匹配比较。Pairwise 在训练相位区间内可能学习到错误的分布相关性，因此测试时出现低于随机的准确率也可能是负迁移；必须同时查看 balanced accuracy、正类比例和 BCE，不应只看单一准确率。

## 复现

```bash
python -m unittest tests.test_n11_cyclic_composition_ood -v
python -m prototype.n11_cyclic_composition_ood --seeds 5 --start-seed 7 --train-samples 3000 --test-samples 1500 --epochs 120 --json
```

CI 验收阈值针对这个已知解析目标：五种子平均三阶 OOD accuracy ≥ 0.85；unary accuracy 处于 0.40–0.60；屏蔽三阶块后的准确率 ≤ 0.35。阈值只验证实现是否按预期工作，不是现实任务能力标准。

## 解释边界与下一步

- 任务是合成连续相位；目标规则已知。
- Fourier/tensor-product 特征是人为提供的先验，不是从原始语义中学习出来的。
- OOD 只涉及一个角色的相位区域，不等于未见语义规则族。
- 需要后续增加无 Fourier 先验的可学习编码器、容量/计算预算匹配的 MLP/GNN 基线，以及多个不同规则族。
- 只有当同一机制在多个任务族、多个随机划分和匹配预算下仍有优势，才值得把它作为 Zhouyi-AI 的核心归纳偏置。
