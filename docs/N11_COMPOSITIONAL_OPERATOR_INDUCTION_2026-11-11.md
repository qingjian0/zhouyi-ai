# N0.11：从状态转移样本中发现可组合算子

日期：2026-11-11  
阶段：首个可执行算子归纳基线  
基于：main @ 69837916464d9be5fdf82e288eee836a2306a386

## 1. 研究问题

N0.10 学习完整角色绑定的结构分数，但仍假设候选关系和可用变换由外部给定。N0.11 把问题改成：只观察状态转移样本 (s, s')，能否从有限算子语法中发现一段短程序，并在未参与发现的输入上复现转移？

这比“在固定算子表中选一个标签”更接近算子发现，但仍是受控的程序归纳，不是从自然语言或现实世界中自动发明语义。

## 3. 原型内容

实现：prototype/operator_induction.py  
测试：tests/test_operator_induction.py

- 离散语法：neg、abs、swap、add、sub、max、min；
- 有序程序：允许两个及以上原语按顺序组合；
- 搜索：在最大深度和最大程序数预算内确定性枚举；
- 归纳：训练集必须由候选程序完整解释，避免把部分匹配误当成发现；
- 验证：独立验证集只用于测泛化，不参与候选生成；
- 复杂度：优先选择更短的程序；
- 预算：显式报告枚举数量和截断状态。

## 4. 关键防作弊设计

1. 训练输入与验证输入使用不同随机种子；
2. 验证集不参与训练支持度筛选；
3. 输出所有有限候选中的短程序，而非声称唯一发现；
4. 保留语法大小、深度和搜索截断元数据；
5. 通过改变训练样本、变量排列和目标程序顺序测试稳定性；
6. 对比无组合（depth=1）、二步组合和更深组合；
7. 通过错误映射与随机目标检查是否出现伪发现。

## 5. 关键限制

- 搜索空间有限且人工定义；语法外的真实算子永远不会被发现。
- 训练集上的精确拟合可能仍是过拟合；必须报告验证集表现。
- 等价程序可能很多；有限观测无法识别唯一真实因果机制。
- 当前状态是数值向量，尚无对象、关系、时位、证据来源或自然语言 grounding。
- 当前不是梯度学习模型，而是透明的有界枚举基线。
- 不应将数值向量变换直接等同于周易卦爻变换。

## 6. 与易象类象体系的连接路径

后续应把算子候选提升为有类型签名的结构程序：

- 输入：对象类型、角色、时位、关系状态及证据；
- 原语：取象、类象、互、错、综、应、变等候选变换；
- 前置条件：适用结构、关系约束、时间/位置条件；
- 输出：新关系、状态差分、候选解释；
- 证据：支持样本、反例、来源依赖和适用范围。

易象算子不应仅以名字作为监督标签。每个算子都要给出可执行语义和反例；系统也必须能提出传统命名体系之外的候选结构。需要专家/数据 grounding 来定义什么是观察到的对象和状态，不能让模型凭空给数值程序贴上易学含义。

## 7. 下一轮实验

- 深度 1/2/3 的程序发现率与计算成本；
- 训练样本数量变化下的识别稳定性；
- 等价程序类与可识别性分析；
- 变量重命名、输入排列和分布偏移；
- 从二元原语组合到三元/非相邻角色绑定；
- 与枚举 DSL、遗传程序合成、神经程序归纳进行匹配预算对照；
- 将离散程序结构与 N0.10 的连续结构评分器连接，测试提案—评分—验证闭环。

## 8. 交付边界

该代码是 CPU 友好的研究基线，不是端到端神经算子发现器，不具备自然语言语义 grounding，不证明周易理论正确性，也不构成通用智能或 Transformer 替代品。它的价值是把“算子发现”转化为可重复、可证伪的实验任务。
