# 先秦两汉类象理论校勘札记 v0.1

## 范围与方法

本札记以清以前文献为研究主体，先秦两汉材料优先。引用的是可追溯的数字文本入口，不把网页转录等同于出土写本或作者手稿。正式入库时仍须记录底本、版本、卷篇、异文、校勘记和注疏层；清代及以后材料只用于校勘、辑佚、补漏和学术史审查。

## 一、《周易·说卦》：象不只是名物对照

可核文本入口：[中国哲学书电子化计划《周易·说卦》](https://ctext.org/book-of-changes/shuo-gua/zh)。

本篇至少包含三种不同结构：

1. **卦象—自然物/方位**：乾、坤、震、巽、坎、离、艮、兑分别进入天地、雷风、水火、山泽等结构。
2. **卦象—功能作用**：“雷以动之，风以散之，雨以润之，日以烜之，艮以止之，兑以说之，乾以君之，坤以藏之。”这里不是简单名词替换，而是作用、过程和功能角色。
3. **卦象—时序/方位/万物过程**：“帝出乎震……成言乎艮”随后解释万物出、齐、相见、致养、悦、战、归、成终成始，体现循环阶段和空间方位的联合编码。

**对架构的约束**：一个象条目至少应区分象体、属性、功能、关系、方位、时位、过程阶段；不能把“震=雷=东方=春”压成无类型的同义词集合。不同段落的映射应分别保留原文语境和解释层级。

## 二、《墨子·小取》：类推必须带边界

可核文本入口：[中国哲学书电子化计划《墨子·小取》](https://ctext.org/mozi/minor-illustrations/zh)，并可对读《墨子闲诂·小取》数字文本。

篇中以“以类取，以类予”说明论辩中的类推，又区分辟、侔、援、推等方式。关键限制是：“其然也同，其所以然不必同”；并指出类推若“远而失，流而离本”，就必须审察，不可常用；“殊类异故，则不可偏观”。

**对架构的约束**：

- 表面结果相同，不足以推出内在机制相同。
- 类比必须声明共享属性/关系以及不共享的属性/关系。
- 推类应设置停止条件：类属不同、成因不同、关系链过长或关键条件缺失时，降低适用性或拒绝迁移。
- 记录反例不只是给候选减分；反例还应指出究竟是属性不相似、关系不保持、成因不同，还是适用条件越界。

这直接支持 M3 的竞争候选、反证保留和未决机制，也提示后续 M6 新象发现必须避免仅凭词面相似自动扩张类属。

## 三、《淮南子·天文训》：类应关系必须分层

可核文本入口：[《淮南子》四部丛刊本卷第三（维基文库）](https://zh.wikisource.org/zh-hans/淮南子_(四部丛刊本)/卷第三)。页面标注为“汉刘安撰、汉许慎注”，并说明所据为“景上海涵芬楼藏景钞北宋本”；这是一种后世传本数字转录，不能误称汉代原写本。

本篇从气化、阴阳、四时、万物分类，推进到物候、运动方向和“物类相动，本标相应”。许慎注文还对阳燧、方诸的操作方式以及虎啸、龙举等对应关系作解释。篇中同时包含：

- **气化/生成解释**：阴阳、四时与万物之间的生成次序。
- **分类归属**：飞行之类、蛰伏之类与阴阳归属。
- **方向/动力关系**：火上、水下、鸟高、鱼下。
- **物候与周期对应**：日月、节气与生物变化。
- **感应/征兆解释**：虎啸谷风、龙举景云，以及政治行为与风雨虫螟等灾异关联。

**对架构的约束**：不能把以上类型合并成单一“因果边”。至少应分成生成、分类、功能/运动、时序相关、感应对应、政治象征等关系族，并记录每条断言属于原文、注文还是后世解释。对灾异和感应断言，保留为历史思想材料，不直接提升为现代经验事实。

## 四、《管子·版法解》：象法天地的规范性用法

可核文本入口：[中国哲学书电子化计划《管子·版法解》](https://ctext.org/guanzi/ban-fa-jie/zhs)。

篇中以“法天地之位，象四时之行”引出左右、前后、春生秋杀、夏长冬藏与文武治理的对应。这是将自然秩序转用于制度与政治秩序的规范性类比。

**对架构的约束**：自然描述到政治规范之间存在跨域映射，不能因古籍提出对应就认定它是自然因果。必须记录映射方向、规范性目的、隐含价值前提和适用范围。

## 五、统一语料字段增补建议

在既有类象记录上增加或明确以下字段：

| 字段 | 含义 |
|---|---|
| `source_type` + `claim_kind` | 由既有顶层来源类型与主张类型共同区分原典、注疏、现代研究、项目定义和模型推论 |
| `xiang_domain` | 自然、物候、身体、社会、政治、制度等领域 |
| `relation_family` | 生成、分类、功能、方向、时序、感应、象征、规范类比 |
| `shared_basis` | 推类双方真正共享的属性或关系 |
| `non_shared_basis` | 已知不共享的属性、机制或条件 |
| `scope_conditions` | 适用时位、环境、主体、尺度及限制 |
| `causal_status` | 未声明、文本声称、观察支持、实验支持、被反例挑战 |
| `counterevidence` | 反例及其针对的映射层 |
| `variant_notes` | 异文、底本差异、校勘说明 |

## 六、当前结论

这四篇材料不构成一个无差别的“古人类象总理论”。它们分别展示了易象的结构化表征、墨家的类推逻辑与边界、汉代宇宙论中的多种类应关系，以及自然秩序向政治规范的跨域映射。Zhouyi-AI 应保留这种理论差异，而不是先用现代统一术语抹平差异，再将其作为模型规则。

下一步文献工作应逐篇扩展《周易》经传、《墨子》经说与小取、《荀子》正名/解蔽、《庄子》寓言与物化、《管子》四时/五行相关篇、《吕氏春秋》十二纪、《淮南子》天文训/地形训/时则训，并逐条建立底本和异文对照。
