# 类象认知下一阶段研究计划 v0.1

> 状态：研究议程与可证伪设计；不是已实现能力或实验结论。  
> 研究主线：多尺度时间 × 整体—局部递归 × 竞争类象 × 反事实 × 主动观测 × 新象发现。

## 1. 本轮目标与问题定义

现有原型已覆盖静态特征抽象、反例修正、多元角色关系、动态状态转移、时空情境比较和有序轨迹对齐。但这些模块仍主要处理显式标注的离散对象，尚未形成统一的层级认知过程。

下一阶段研究以下问题：

1. 同一过程在不同时间尺度上如何呈现不同状态，而不把快慢变化误判为不同机制？
2. 局部过程如何构成整体，整体约束又如何反馈局部解释？
3. 同一观测如何保留多个竞争类象，而不是过早压成单一分类？
4. 哪些条件变化会改变推演结果？能否区分相关、结构对应与因果效应？
5. 系统应选择什么新观测，才能最大程度区分当前竞争假设？
6. 当既有类别持续解释失败时，如何提出新象，同时防止把噪声包装成发现？

## 2. 统一研究对象：分层动态情境图

研究表示为分层动态情境图（Hierarchical Dynamic Situated Graph, HDSG）：

`H_t = (V_t, E_t, R_t, L_t, C_t, P_t, mathcal{E}_t)`

- `V_t`：对象、属性、事件与状态节点。
- `E_t`：二元关系边。
- `R_t`：有角色名称的多元关系/超边。
- `L_t`：层级归属与部分—整体关系。
- `C_t`：时间尺度、位置、阶段、环境和约束。
- `P_t`：候选类象及其适用范围。
- `E_t`：证据、来源、观察时间和审查状态。

每个候选类象不只是标签，而是带有：
- 结构签名与允许变化项；
- 适用范围和必要条件；
- 支持证据与反例；
- 竞争解释；
- 版本、来源和审查状态；
- 可区分它与竞争解释的预测/观察条件。

层级关系必须区分“部分属于整体”“参与整体过程”“整体对部分施加约束”，不可一律化约为包含边。

## 3. 六条研究主线

### R1 — 多尺度时间与阶段嵌套（P0）

**问题**：快变、慢变、周期、延迟、阶段跃迁如何共同表达？

候选机制：
- 多时间轴：事件时间、观测时间、持续时间、采样间隔分别存储。
- 尺度层级：微观状态转移聚合为中观过程，中观过程再组成宏观阶段。
- 时间关系：先于、重叠、包含、间隔、周期、延迟等关系独立表达。
- 阶段边界：由证据与变化点候选提出，不把固定时间长度直接当阶段定义。
- 跨尺度映射：明确聚合/细化规则，保留信息损失与不确定性。

**基准**：
- 同一生成机制、不同采样频率；
- 快慢变量混合；
- 阶段嵌套与阶段长度变化；
- 延迟响应、周期与非周期干扰；
- 缺失观测与时间戳噪声。

**基线**：单尺度序列对齐、固定窗口、变化点检测、层级 HMM/状态空间模型。

**指标**：阶段边界 F1、事件顺序准确率、跨采样率迁移、缺失鲁棒性、时间与内存成本。

**拒绝条件**：多尺度结构在控制参数量和计算预算后没有稳定增益，或只靠数据泄漏获益，则不保留为核心模块。

### R2 — 整体—局部递归生成（P0）

**问题**：整体如何由局部形成，整体又如何反向约束局部？

候选机制：
1. 局部候选生成：节点、属性、关系、事件。
2. 组合成中层子结构：过程、角色簇、功能单元。
3. 形成整体候选：系统状态、情境、过程模式。
4. 自上而下产生约束：角色期望、边界条件、整体一致性。
5. 自下而上更新：局部反例可拆解或重构整体。
6. 记录每次结构变更及其证据，不允许整体标签覆盖局部反证。

**关键约束**：
- 区分组成、因果、功能、空间邻接和分类隶属。
- 允许部分结构缺失；不能因一个局部不匹配就自动否定全部整体。
- 允许整体假设被局部反例推翻。
- 处理多种合法分解，避免唯一分组偏置。

**基准**：层级组合任务、部件替换、局部扰动、整体约束冲突、跨层级 OOD 组合。

**基线**：平面图网络、层级图网络、超图网络、仅自底向上聚合、仅自顶向下约束。

**指标**：层级结构恢复、局部扰动定位、整体任务准确率、错误传播率、结构编辑成本。

### R3 — 竞争类象与延迟裁决（P0）

**问题**：同一观测允许多个解释时，如何保留分歧并避免过早锁定？

每个候选假设维护：
- 结构兼容性；
- 证据覆盖与来源质量；
- 必要条件满足度；
- 反例和未解释现象；
- 适用范围；
- 与其他假设的差异；
- 下一步区分性观察。

候选集不应只按单一分数排序。建议先执行硬约束筛选，再展示多维证据剖面；若证据不足，输出“未决”而非强行选胜者。

**基准**：观测歧义、多假设同等拟合、证据逐步揭示、分布外样本、诱导性误导证据。

**基线**：单标签分类、Top-k 分类、贝叶斯模型比较、集合预测/选择性预测。

**指标**：校准误差、覆盖—风险曲线、错误过早裁决率、候选多样性、证据更新一致性。

### R4 — 反事实与干预边界（P1）

**问题**：改变一个条件后，哪些结果应当变化，哪些结构应保持？

严格区分：
- 观察性条件比较；
- 模型内部反事实模拟；
- 有识别假设的因果估计；
- 实际干预结果。

只在合成任务或具备明确识别假设的数据上评估干预效应。传统类象对应不能替代因果识别。

**实验**：受控变量翻转、混杂因素、不可观测混杂、结构变化、反事实一致性。

**指标**：干预效应误差、反事实一致性、混杂敏感性、识别假设违背时的拒绝能力。

### R5 — 主动观测与信息增益（P1）

**问题**：当多个类象仍然竞争时，下一步观察什么最有价值？

候选策略：
- 最大化候选解释间预测分歧；
- 最大化预期信息增益；
- 同时考虑观测成本、风险和可获得性；
- 先做模拟评估，再接入真实数据采集；
- 记录选择偏差，避免只采集支持当前模型的证据。

**基线**：随机观测、固定周期观测、最大不确定性采样、预期信息增益。

**指标**：单位成本假设区分率、样本效率、校准、选择偏差和失败安全性。

### R6 — 新象发现与结构重组（P1）

**问题**：旧类别解释持续失败时，如何提出可检验的新结构？

候选流程：
1. 收集未解释残差与反例簇；
2. 检查是否来自噪声、标注错误、缺失条件或数据分布变化；
3. 提出多个最小结构修改候选（拆分、合并、增加关系、增加条件或新类别）；
4. 用独立证据和留出数据比较；
5. 通过后创建新版本，保留旧版本及其适用范围；
6. 未通过则撤回，不将模型生成的解释自我认证为事实。

**指标**：新结构精确率、发现延迟、误创建率、版本回滚率、跨数据集复现率。

## 4. 统一推演闭环

`观测 → 多尺度分段 → 局部结构 → 整体候选 → 竞争类象
→ 预测差异 → 主动观测/反事实检验 → 证据更新
→ 保留/拆分/合并/新建 → 版本化`

任何一步都可返回未决；证据不足时不强行完成闭环。

## 5. 易学经典研究入口与边界

以下只作为研究问题入口，后续必须逐条核对版本、篇章、上下文和注疏，不把现代术语直接等同于古义：

- 《周易·系辞上》《系辞下》：变动、刚柔相推、时位、六虚。
- 《周易·说卦传》：取象、分类及多重象义。
- 《周易》卦爻辞与《彖》《象》：具体情境、位置、时机与行动判断。
- 《墨子·小取》：类推、譬、侔与推类边界。
- 《荀子·正名》《解蔽》：名实、分类、辨异与认知偏差。
- 《吕氏春秋·应同》《淮南子》相关篇章：同类、时序、变化与系统关联。

文献整理按“原典文本—版本/异文—历代注疏—现代研究—工程抽象”五层保存。清以前文献为主要研究对象；清及以后研究用于校勘、辑佚、目录补漏和学术审查。不得将后世成熟体系倒灌为先秦文本本义。

## 6. 实验治理与防止自证

- 先注册任务、数据生成规则、指标、基线和失败标准，再运行实验。
- 按源作品/领域/轨迹主体分组切分，避免相邻切片泄漏。
- 所有模型输出均标为候选，不得自动升级为已审定语料。
- 每条类象保留支持证据、反例、来源和适用边界。
- 进行消融：无易象先验、无层级、无多尺度、无竞争集、无主动观测。
- 匹配参数量、训练数据、搜索预算和计算成本。
- 同时报告正例、负例、拒绝案例和失败案例。
- 任何新增模块若无可重复增益，应允许移除。
