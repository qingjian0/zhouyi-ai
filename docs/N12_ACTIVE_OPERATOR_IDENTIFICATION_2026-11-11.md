# N0.12 — 主动算子辨识与可识别性

日期：2026-11-11  
状态：研究原型 / Draft PR  
接口兼容：可接收 N0.11 的程序对象，但本原型通过最小预测接口解耦，可独立在 main 上测试

## 1. 研究问题

N0.11 从有限 DSL 中提出能解释观测转移的程序，但训练拟合不等于真实机制。有限样本可能让不同程序产生相同输出，即观察等价（observational equivalence）。如果系统直接挑选一个候选，就会把数据不足伪装成确定性。

N0.12 不负责再造一个程序枚举器，而是在已有候选假设集合上执行主动辨识：

1. 计算候选对可选输入的预测；
2. 选择预测分歧最大、预期剩余版本空间较小的实验；
3. 获取环境/用户/工具返回的真实结果；
4. 淘汰与结果不一致的候选；
5. 在唯一候选、仍有歧义、预算耗尽、不可辨识之间明确区分。

## 2. 主动实验选择

对于查询 q，候选假设按预测输出分成若干分区，分区大小为 n_j，总候选数为 N：

H(q) = -Σ_j (n_j/N) log2(n_j/N)

优先选择熵最大的查询；平局时优先选择期望剩余候选数更小、最坏分区更小的查询，最后按输入字典序稳定决胜。此处是有限候选集合上的确定性版本空间缩减，不是对未知真实世界分布的无条件最优保证。

## 3. 可识别性与拒答

- identified：声明的候选集合只剩一个成员。它不证明候选语法之外不存在更好解释。
- ambiguous：多个候选仍存活，且查询池中还有可区分它们的输入。
- budget_exhausted：实验预算耗尽，多个候选仍存活。
- unidentifiable：所有剩余候选在当前有限查询池上预测一致；需要扩大输入域、增加观测类型或修改候选语法。
- 观测无法被任何候选解释时，不清空候选集合、不静默接受结果，而是抛出错误，要求保留反例并修订候选语法。

因此“唯一候选”必须表述为“在当前语法、数据、容差和实验域下唯一”，不可泛化成真实规律已被证明。

## 4. 可复现性与证据归属

每条实验记录保存输入、观测输出、来源标识、剩余候选 ID，以及候选版本空间 SHA-256 摘要。摘要只用于记录版本空间指纹，不用作用户身份或事件真实性证明。实验必须由环境、工具或明确标注的 oracle 提供结果；模型自己生成的预测不能冒充独立观测。

## 5. 原型边界

当前实现：
- 接收实现 apply(state) 的预测程序对象；可适配 N0.11 的 OperatorProgram，但不依赖尚未合并的 PR 分支；
- 使用显式有限查询池；
- 以精确候选预测分区计算信息增益；
- 用容差比较浮点输出；
- 对输入重复、冲突观测和无候选解释的观测 fail-closed；
- 实验预算和不可辨识状态显式报告。

当前未实现：
- 随机噪声/概率似然更新；
- 连续或无限输入空间的查询优化；
- 代价敏感实验（真实世界实验风险、时间、资源）；
- 候选程序语法扩展与反例驱动重合成；
- 真实语言/易象类象 grounding。

## 6. 必须进行的后续实验

1. 正数样本下 identity 与 abs 不可区分；负数查询应区分二者。
2. 对 4 个候选，平衡预测分区应优先于极不平衡分区。
3. 预算为 0 时不得执行实验，且明确报告预算耗尽。
4. 重复输入的冲突结果不得污染历史或候选集合。
5. 所有候选在当前查询池上输出一致时必须 abstain。
6. 将合成查询域换成留出域，测量选择策略是否过拟合候选语法。
7. 引入有噪声 oracle，比较 exact elimination、容差过滤与贝叶斯/似然版本。
8. 把实验成本、风险、延迟纳入 acquisition function，避免单纯追求信息熵。

## 7. 与易象类象架构的关系

N0.12 的价值不在于把“阴阳”硬编码成数值算子，而在于提供一个可证伪的学习协议。未来 YXO 候选必须携带类型签名、角色、时位条件、适用范围、证据来源与反例。主动实验需要询问能区分类象假设的具体情境，而不是只对向量做任意变换。

建议后续把链路收敛为：

结构候选生成 → 候选执行 → 主动实验选择 → 独立观测 → 反例淘汰/版本修订 → 证据与适用域维护

N0.12 只是这条闭环中的“主动辨识”模块，不是完整认知架构。
