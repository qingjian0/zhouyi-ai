# XSL-5 Cross-domain Transfer Benchmark — synthetic v0.1

Date: 2026-11-11  
Status: executable synthetic harness; not a real-world benchmark

## Goal

Test whether an analogy system transfers a candidate only when its relational structure, applicability conditions, and evidence scope permit it. The benchmark explicitly measures harmful transfer and correct abstention rather than rewarding a plausible-sounding analogy.

## Compared selectors

1. **Lexical baseline** — maximum Jaccard overlap of surface terms.
2. **Structure-only baseline** — maximum relation-signature overlap, ignoring context.
3. **Perspective-aware selector** — requires a SUPPORTS view, all required context, and no active counterexample context; otherwise abstains.

## Synthetic v0.1 construction

The default suite contains 48 deterministic cases:
- 24 positive transfer cases with active flow and bounded-channel context;
- 24 negative-transfer cases with stagnant-pool and blocked-channel context;
- a surface lexical distractor;
- an unknown-evidence candidate.

Labels are generated by construction. This suite is useful for testing whether the implementation obeys its declared rules. It is not evidence that the rules are semantically correct in natural domains or that Yi-Xiang improves intelligence.

## Metrics

- Coverage: selected cases / all cases.
- Precision: correct selected / selected.
- Recall: correct selected / positive transfer cases.
- False transfer: all incorrect selections, including wrong candidate choices in positive cases.
- Negative-transfer rate: selections made in no-transfer cases / all no-transfer cases.
- Abstention accuracy: correct abstentions / no-transfer cases.

These denominators are intentionally separate. A false-discovery fraction among selected answers must not be mislabeled as negative-transfer rate.

## Expected controlled behavior

| Selector | Correct selections | False selections | Negative-transfer rate | Coverage |
|---|---:|---:|---:|---:|
| Lexical | 0/24 | 48 | 100% | 100% |
| Structure-only | 24/24 | 24 | 100% | 100% |
| Perspective-aware | 24/24 | 0 | 0% | 50% |

These are expected results of the constructed toy suite, not empirical model results.

## Validation boundaries and next gate

Before calling this a useful scientific benchmark:
1. Replace synthetic cases with independently authored, domain-diverse examples.
2. Have multiple annotators label valid mappings, scope conditions, and counterexamples; report inter-annotator agreement.
3. Split by source domain and relation family to prevent template leakage.
4. Include near-miss and adversarial cases, including cases where surface and structural cues conflict.
5. Report per-domain metrics and confidence intervals, not only aggregate accuracy.
6. Compare all systems under matched retrieval access, context budget, and inference budget.
7. Keep a held-out test set inaccessible to prompt or rule tuning.

The next version should also score individual perspective/view selection, not only candidate-level selection, so a candidate with one valid and one invalid lens cannot hide view-level errors.

## Research references

- E-KAR evaluates analogy with rationales and annotated candidate explanations.
- AnaloBench evaluates abstract and long-context analogy retrieval/transfer.
- ANALOGICAL studies analogy across multiple linguistic and metaphorical complexity levels.
- Recent relational analogy work highlights multiple plausible relation structures rather than forcing one simplistic ground truth.

These works motivate benchmark dimensions; they do not validate this project's Yi-Xiang hypotheses.
