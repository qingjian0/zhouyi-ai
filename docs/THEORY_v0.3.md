# CPG-EI 数学理论 v0.3（研究草案）

> 本文给出可实现、可证伪的最小数学定义。它不是已证明收敛的理论，也不意味着该架构优于现有模型。

## 1. 输入与语义单元

输入序列或多模态观测记为 (X)。解析器产生语义单元集合：
[
V_t={v_i}_{i=1}^{n_t},qquad
v_i=(z_i,	au_i,a_i,p_i)
]
其中：
- (z_iinmathbb R^d)：连续语义表示；
- (	au_i)：类型标签，如概念、实体、属性、事件、时间、空间、证据；
- (a_i)：属性/槽位集合；
- (p_i)：来源、时间戳、置信度、证据指针及可追溯元数据。

语义单元不是 Token 的简单改名。它应有可判定的语义类型、可组合接口和证据来源。单元可由多个 Token、图像区域、音频片段或结构化字段共同构成。

## 2. 动态超图

定义时刻 (t) 的动态超图：
[
mathcal H_t=(V_t,E_t)
]
每条超边：
[
e=(S_e,ho_e,phi_e,w_e,q_e)
]
- (S_esubseteq V_t)：参与组合的节点集合，大小至少为 2；
- (ho_e)：关系类型，如因果候选、共指、约束、类比、时序、组成；
- (phi_e)：组合后的表示或消息；
- (w_e)：可学习的组合分数；
- (q_e)：证据支持度、来源和不确定性。

超边允许连接不相邻节点，因此可表达跨位置组合。超边不自动意味着节点间存在因果关系。

[

## 4. 稀疏组合与预算约束

对候选集合 (C_t)，选择子集 (E_tsubseteq C_t)。优化目标：
[
min_	heta mathcal L_{mathrm{task}}
+lambda_E|E_t|
+lambda_Csum_{ein E_t}mathrm{Cost}(e)
+lambda_Rmathcal L_{mathrm{redundancy}}
]
可使用 top-k、阈值门控、预算背包、稀疏正则或两阶段召回-重排。组合预算 (B) 约束：
[
sum_{ein E_t}mathrm{Cost}(e)le B
]
不能枚举所有子集。初版应限制候选阶数、每节点度数和每轮新建边数量。

组合不等同于简单向量求和。对于有向关系，使用角色编码或有序槽位；对于无序集合，才允许置换不变聚合。

## 6. 并行推演与全局协调

在同一轮中选出 (K) 条候选路径：
[
P_t={p_1,ldots,p_K}
]
各路径可并行计算局部结论 (y_k)、证据集 (D_k)、不确定性 (u_k) 和成本 (c_k)。协调器计算：
[
y^*=mathrm{Aggregate}_psi({y_k,D_k,u_k,c_k}_{k=1}^K)
]
协调器必须检测互斥结论、重复证据、来源依赖和证据强弱。简单多数投票不够；建议采用证据去重、冲突图和校准后的置信度融合。

## 7. 易象状态空间（可检验假设）

将六爻状态表示为：
[
h=(h_1,ldots,h_6),quad h_iin{0,1}
]
共有 (2^6=64) 种状态。该编码只提供离散状态空间，不自动赋予每个状态固定的现实语义。

阴阳可作为二元互补变量；四象可作为两位状态组合；八卦可由三位状态构成；六十四卦由上下卦或六位状态组合得到。卦变对应状态转移：
[
P(h_{t+1}mid h_t,c_t)
]
五行关系可初步表示为带符号的可学习矩阵 (W_5)，其中正值表示促进候选关系、负值表示抑制，零附近表示无显著作用。矩阵初始化可使用传统生克结构作为先验，但训练和验证必须允许模型改变它。

重要约束：
- 传统符号映射只作为初始化/归纳偏置，不是事实标签；
- 对照随机编码、可学习编码和不含易象模块的模型；
- 允许模型输出“当前证据不足，拒绝类象”；
- 不得从符号相似直接推断现实因果。

## 8. 自组织更新

定义结构更新：
[
mathcal H_{t+1}=mathrm{Update}_omega(
mathcal H_t,Delta_t,mathcal F_t,mathcal B_t)
]
其中 (Delta_t) 为预测误差，(mathcal F_t) 为反馈，(mathcal B_t) 为计算预算。更新动作包含：
- CREATE：持续出现且有预测增益的新组合；
- MERGE：语义重叠、互补或可压缩的组合；
- SPLIT：组合内部出现稳定异质性或冲突；
- PRUNE：长期无用、低支持或高成本的组合；
- RETYPE：证据支持时修订关系类型。

更新必须通过验证集或保留集门控，避免在线反馈导致灾难性漂移。推理时临时状态调整与长期参数训练应分开记录。

## 9. 统一目标

一个初始多目标损失：
[
mathcal L =
mathcal L_{mathrm{task}}
+lambda_1mathcal L_{mathrm{consistency}}
+lambda_2mathcal L_{mathrm{evidence}}
+lambda_3mathcal L_{mathrm{sparsity}}
+lambda_4mathcal L_{mathrm{calibration}}
+lambda_5mathcal L_{mathrm{compute}}
]
各项定义：
- task：任务监督目标；
- consistency：跨路径逻辑一致性与冲突惩罚；
- evidence：结论与证据的支持关系；
- sparsity：超边数量、节点度数和冗余；
- calibration：置信度校准；
- compute：延迟、显存或 FLOPs 代理成本。

权重需在验证集上选择，不可用测试集调参。多目标 Pareto 分析应与单一加权损失并行报告。

## 10. 最小可证伪命题

- 若跨距离组合机制有效，E01 在留出组合泛化集上的准确率应高于局部邻接基线。
- 若超图有独立贡献，E02 中超图模型应在高阶关系任务上优于参数/计算匹配的普通图模型。
- 若易象先验有效，完整模型应在预先指定任务上稳定优于“可学习随机编码”和“无易象”消融。
- 若自组织有效，结构更新后分布变化任务应改善，且原分布性能下降不超过预设阈值。
- 若并行机制有效，应在相同预算下提高候选覆盖或任务质量，而不是仅增加计算量。
