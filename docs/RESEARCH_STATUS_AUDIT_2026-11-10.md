## 本轮已核实的结果

### E02-D：有限规则族的可识别性

`docs/E02D_SUPPORT_SWEEP_RESULTS_2026-11-10.md` 报告了 27 条仿射模 3 规则、100 个 seed、支持样本量 1–8 的扫描。在该预先给定的有限假设类与当前查询分布中，4 个支持样本达到 100% 识别覆盖率；3 个样本约 87.04%。这证明的是已知有限假设类中的符号枚举可识别性，不是系统自主发明规则族，也不是开放规则空间泛化。

### E02-I：暂态噪声与持续漂移

PR #12 记录的 CI 结果为：20/20 保留暂态噪声后的旧关系、20/20 在持续结构变化后剪除旧关系、20/20 恢复新概念。适用范围是预先设定的 9 窗口、两个成员不重叠的合成布尔概念和手工生命周期阈值；尚未验证渐进漂移、重叠成员或自主学习生命周期策略。

### E02-I2-C：身份事件裁决

PR #16 的开发基准包括 KEEP、MODIFY、CREATE、ABSTAIN、SUSPEND、REACTIVATE、REACTIVATE_MODIFY、RETIRE。PR 描述中的 1.0000 Macro-F1 是有限模板的 Train/Gate 开发结果，coverage 为 0.875；尚无锁定 Test、阈值校准、环境迁移或自主候选生成证据。

PR #17 的审计已指出：
- 仅删除 ID 中显式事件字符串，不足以证明 metadata-label independence。
- 若 ID 可由低熵 seed 与公开生成器反推，仍可能泄漏 episode/event 信息。
- 需要对全部可观察字段进行攻击式泄漏审计，而非只检查 ID 子串。
- 早先 workflow run 42840048462 的 unit-tests job 有 3 项失败：两项 competing support 断言返回 MODIFY 而非 ABSTAIN；一项 false CREATE 基线断言受随机 episode 分配影响。应以 PR 最新 head 的后续 CI 为准重新验证。

### E03-A：多头并行与全局协调

PR #13 的 workflow run 42824884665 已成功完成，包含 30 seeds。日志中的聚合指标：
- 全局协调：成员恢复率 1.0、完整规则恢复率 1.0、Test accuracy 0.9787109375。
- 独立 Gate 选择：成员恢复率 1.0、完整规则恢复率 1.0、Test accuracy 0.9787109375。
- 独立选择满足共享预算的比例：1.0。
- 邻接组合消融：成员恢复率 0.0、Test accuracy 约 0.719314。

因此 E03-A 支持“多头并行候选生成可以恢复固定非连续关系”，但没有证明全局协调比独立选择更好：独立方案在 30/30 seeds 已满足预算，预算约束没有成为活跃约束。该审计结论已评论到 PR #13。

## 关键研究缺口

1. **未知关系语言**：候选语言目前多由研究者预设（如 2/3 阶子集、有限真值表、有限模规则族）；系统尚未自主提出新的表示/规则语言。
2. **候选生成与选择分离**：不少实验由预定义候选池或 Oracle 式目标配置提供候选；候选生成本身还没有被端到端证实。
3. **跨环境与因果混淆**：需要处理成员重叠、混杂变量、观测缺失、环境变化、概念漂移和反事实反例。
4. **全局协调的真实收益**：E03-A 的预算约束未激活，不能证明协调必要性。
5. **易象模块的增益**：阴阳、四象、八卦、卦变等应作为可学习先验做消融；当前不能将其视为已经验证的认知机制。
6. **统一系统证据**：各实验是独立原型，不等于已有一个集成的自主认知系统。

## 建议的下一轮实验

### E02-I2-C 修复与泄漏攻击

- 对事件 ID、样本 ID、episode 顺序、窗口、环境、身份快照、candidate signature、缺失模式等可观察字段做攻击测试。
- 用独立于 truth/episode seed 的随机命名空间产生 opaque IDs；若为复现保留 ID 随机种子，应将其留在 evaluator-only 配置中，不能进入 policy 输入。
- 对训练/门控/测试拆分检查事件比例、生成机制、seed 与样本命名空间的独立性。
- 修复 competing current/changed support 的证据保留顺序；为四类 ABSTAIN 原因分别构造固定、可复现负控。
- 在阈值和策略冻结后，建立独立锁定 Test runner；Test 只作一次最终审计，不用于调参。

### E03-B 真实资源冲突协调

- 构造独立头的最优候选合并后必然超预算、但存在可行联合解的任务。
- 引入共享成员、候选互斥、不同噪声与不同样本量，避免每个头都轻易独立恢复真值。
- 比较独立贪心、全局枚举、预算约束优化、随机可行解和 Oracle。
- 统一候选池、Gate 查询预算和锁定 Test；加入无冲突控制组，检查协调器是否会无故损害性能。
- 扫描预算与 shortlist，并报告每头指标、预算违反率、协调收益和跨 seed 区间。

### E04 表示语言与易象先验

先建立不含易象先验的通用关系表示基线，再分别加入阴阳二态、四象状态、八卦组合、六爻/卦变等可学习先验。对照必须保持数据、参数、搜索预算相同；检验样本效率、OOD 组合、抗噪、校准和错误拒答。任何易象映射都允许被学习器调整或拒绝。

## 阶段判断

目前最稳妥的描述是：项目已有一组在有限合成环境中验证组合搜索、高阶关系、关系生命周期、身份匹配和多头协调的研究原型。它尚未证明开放域自主关系发现，更未证明新型 AI 已经成立。

下一阶段优先级：E02-I2-C 泄漏与裁决可信度 > E03-B 激活资源冲突 > E02-J 未知规则语言 > E04 易象先验消融 > 统一端到端原型。
