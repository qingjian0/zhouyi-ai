# 《吕氏春秋·别类》与《淮南子·说山训》：类推边界、组合效应与非单调迁移 v0.1

## 研究问题

《别类》《说山训》并非只告诉读者“相似不能乱推”，还提供了更细的边界类型：表面近似但结构不同、局部属性不能代表整体、单项效果不能线性叠加、组合后性质反转、尺度改变后类别仍可保持或失效。

本专题把这些材料转化为 Zhouyi-AI 的对抗性类象任务。所有古文仍是数字转录候选，须进一步回看影印和校勘本；工程测试标签是项目预期，不是对古人命题真伪的裁决。

## 一、《吕氏春秋·别类》：似类与可推之间存在断层

数字文本入口：https://ctext.org/lv-shi-chun-qiu/bie-lei

篇中以“物多类然而不然”提示表面相类可能导致错误判断，并以草类单独食用与合食后的不同结果、漆淖/水淖的混合变化、金柔/锡柔混合后的变化说明：单项属性不能简单线性外推到组合物。

另以“小方，大方之类也；小马，大马之类也；小智，非大智之类也”指出：某些尺度变化保持类别关系，另一些能力/性质不能按同样方式从小推大。

这组材料支持至少三种不同判断：
1. **分类保持**：尺度变化后仍属于同一类（小方/大方、小马/大马的文本例子）。
2. **尺度外推失败**：局部能力或程度不能按尺寸比例放大（小智/大智）。
3. **组合非单调**：组成部分的单独性质不能决定组合后的性质，交互作用可能改变结果。

不能把这些例子直接当成现代化学实验数据；这里分析的是文本论证结构与推类边界。

## 二、《淮南子·说山训》：相似外观并不保证相同性质

数字文本入口：https://ctext.org/huainanzi/shuo-shan-xun

“物固有似然而似不然者”“类不可必推”与小马大目、大马目眇等例，提示观察到的局部特征可能与目标分类不匹配；断指与断臂的生死例则提醒：看似相近的损伤行为，后果可能因部位、程度与条件不同而相反。

篇中另有“先倮而浴则可，以浴而倮则不可”“或吹火而然，或吹火而灭，所以吹者异也”等例，显示操作次序、作用对象或条件改变会改变结果。

这些材料适合用于检验系统是否错误地：
- 将局部特征当作类别充分条件；
- 将相同动作名称当作相同作用机制；
- 将单项成分性质线性外推到组合物；
- 忽略顺序、剂量、部位、主体和环境等交互变量。

## 三、从古典例证抽取的工程问题

### 3.1 非单调性

若单项属性 A、B 分别成立，不能推出 A+B 组合后仍保留同一性质。系统必须允许交互项、阈值和条件反转。

### 3.2 尺度与类别的分离

尺度变化可能保持类别，也可能破坏功能推断。类别层级、连续数值、能力上限应分别表示。

### 3.3 局部代理失效

观察到一个局部特征，不代表目标对象整体具有对应属性。必须检验该特征对目标结论是否具有区分效度。

### 3.4 顺序与情境依赖

相同动作集合在不同顺序下可能产生不同结果。过程表示必须保留事件顺序，不能只保存无序特征集合。

## 四、建议的模型表示

在现有类象记录上增加或明确以下字段（本节为建议，不代表现有 Schema 已实现）：

- components：组成项及其属性；
- interaction_terms：组合交互关系；
- scale_variable：尺度/量值；
- threshold_conditions：阈值；
- sequence_order：操作顺序；
- local_feature_scope：局部特征的适用对象；
- outcome_conditions：结果依赖条件；
- reversal_cases：条件变化后结论反转的反例。

## 五、M2–M8 研究接口

- M2：组合项与交互关系作为显式超边，不把组成项简单压平。
- M3：将“单项性质外推”“组合交互反转”“尺度保持”“尺度失效”作为竞争解释。
- M4：逐项移除组成项、改变顺序、尺度、部位或剂量，比较结果变化。
- M5：优先观察能区分线性叠加与交互作用的条件。
- M6：反复出现的组合残差只能成为待审提案，不能直接形成普遍规律。
- M7：在跨域迁移前先检查组合结构、交互项、顺序和适用域。
- M8：新增非单调组合、尺度外推、局部代理和顺序依赖负控。

## 六、可证伪实验

1. **交互项消融**：比较包含/不包含组合交互变量时，对组合结果的预测差异。
2. **顺序消融**：将有序过程打乱，测量顺序依赖任务的性能损失。
3. **尺度外推**：训练小尺度实例，测试大尺度实例，区分类别保持与能力外推失败。
4. **局部代理反例**：保留表面特征但改变目标属性，检查是否错误推断。
5. **组合外推**：训练 A、B 单独出现，测试 A+B 的组合；不得假设结果等于单项结果之和。
6. **条件反转**：改变剂量、部位、环境或主体，检验结论是否应当反转或暂缓。

实验数据必须是明确标注的合成数据或独立采集的真实数据。古籍格言不能直接当作现代实验标签。

## 七、来源与异文风险

- 《吕氏春秋·别类》页面标注《四部丛刊初编》本资源入口；仍需锁定具体卷次、影印页及高诱注等注释层。
- 《淮南子·说山训》平行段落检索可见“类不可必推”等句的不同录文，并出现“相伏/引服”等异文。应保存每一见证读法，不要在案例中无说明地拼接不同转录。
- 现代研究晋荣东 2013 对《淮南子》“类不可必推”及先秦推类的逻辑性质提供解释史线索，但不能替代原典校勘。

## 结论

类象系统必须能表示“局部相类但整体不类”“单项相同但组合结果不同”“小尺度可推而大尺度不可推”“操作相同但顺序不同导致结果不同”。这比增加更多静态类象条目更接近真正的推类能力：不仅寻找可迁移结构，还要识别迁移边界与条件反转。
