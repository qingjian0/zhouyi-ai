# 先秦两汉类象拒推机制专题：从同异辨析到条件迁移 v0.1

## 0. 文献边界

本札记以先秦两汉文本为研究主体，清代及以后材料只用于校勘补漏。当前引用的是公开数字见证，尚未完成馆藏影像逐字核验；因此本文是文本结构研究与工程操作化草案，不是定本校勘，也不把现代逻辑学、因果推断术语说成古人原有术语。

本批以五部典籍、七篇重点篇章为主：《墨子·小取》《荀子·非相》《淮南子·说林训》《韩非子·难势》《论衡·感类》。

## 1. 《墨子·小取》：类推不是无约束的相似扩散

《小取》开篇把辩论目标放在明是非、审治乱、明同异、察名实、处利害、决嫌疑；继而区分“效、辟、侔、援、推”等论辩操作。其价值不在于给出一个统一相似度，而在于区分不同推论动作及其适用边界。

关键论证链：

- “夫物有以同而不率遂同”：某一方面相同，不等于整体同一。
- “其然也同，其所以然不必同”：结果或现象相同，不保证所以然相同。
- “其取之也同，其所以取之不必同”：举例、选例的方式相同，也不保证选择根据相同。
- 对辟、侔、援、推的警告，强调推行过远可能转危、失当、离本；不同方术、类别、理由不能偏观。

**工程转译：**
1. 将类推操作分型，而非压缩为一个 cosine/similarity 分数。
2. 记录 shared_basis 与 non_shared_basis，并标明本次结论只迁移到哪个目标谓词。
3. 将结果相同与机制相同分开；因果类比必须另有机制及干预证据。
4. 对推论链逐步记录迁移距离、条件变化和不变量破坏。
5. “未能证明相同”与“已经证明不同”必须分开，保留 ABSTAIN。

### 文本校勘警戒

公开数字见证之间可见“其然也同”句的脱文/补字问题。相关校释材料指出旧本曾脱“其然也”三字，并补“其取之也，有所以取之”中的“所”字；同一校释还讨论“率遂”等字句的断读。项目应保留底本文字、校者补字、标点和现代解释四个层级，不能将补字无标记地回填为战国原文。

## 2. 《荀子·非相》：目标属性不能由表面代理直接判定

《非相》批评以骨状、颜色等外貌推断吉凶贵贱，并提出“相形不如论心，论心不如择术”。篇中并非简单宣称“外形无意义”，而是指出形相、心术与君子/小人的判断不应混为一层：形貌可能与目标判断脱钩，判断还须转向心志、言行和所择之术。

**工程转译：**
- 建立 observed_feature → proxy_hypothesis → target_property 的显式链路。
- 每次使用代理特征时，必须说明代理与目标属性之间的证据，不允许从可见特征直接跳到不可见性质。
- 对“外观相似→能力相同”“形态相似→道德/功能相同”设负控。
- 允许同一外形对应不同目标属性，也允许目标属性相同而外形不同。

**与《墨子·小取》的差异：**《墨子》更直接分析论辩形式及推类失当；《荀子·非相》则把“以形观人”的判断对象、代理变量与规范评价层次区分开。二者可在工程上汇合为“关系/代理有效性检查”，但不能抹平其论辩语境。

### 《荀子·正名》补充：推类必须不悖，辨异必须不过

《正名》在论名、辞、辨说的语境中提出“辨异而不过，推类而不悖”，并以“听则合文，辨则尽故”约束辨说。这里的“类”并非脱离名实关系的外观集合：命名、所指、辞意和论证理由必须相互衔接。篇中还批评以名乱名、以实乱名、以名乱实等名实错置。

**工程转译：**
- 加入 name/reference/predicate consistency 检查：标签相同不保证所指对象或谓词相同。
- 类推前检查命题的主项、谓项、关系方向和论证理由是否保持；只共享词面不构成有效同类。
- “推类不悖”操作化为迁移后不与已确认的定义、关系约束或反例冲突；“辨异不过”操作化为不把无关差异扩大为拒绝理由。
- 将语义分类错误与经验机制错误分开计分，避免把概念混淆误报成因果失败。

## 3. 《淮南子·说林训》：同一对象的用途由主体与情境共同决定

《说林训》列举多种适用关系：盲者不宜得镜、跛者不宜得履、越人不宜赏章甫；又以柳下惠与盗跖见饴的不同用途说明“见物同，而用之异”；继而用蚕、蝉、蜉蝣及不同物种对礜石、巴菽的反应，提出“类不可必推”。

这些例子不能被简化成“同物绝不能类推”。它们针对的是：对象相同或外观相类，并不足以决定其用途、效应和适配关系；主体种类、能力、目的、环境与生理条件会改变关系。

**工程转译：**
- 类象记录除对象特征外，必须表示使用主体、目标、环境、资源和约束。
- functional 相似必须带任务/目的和环境；脱离目标的“功能相似”不完整。
- 同一输入对象对不同主体可产生不同作用；同一作用也可能由不同机制产生。
- 对跨物种、跨主体、跨尺度迁移设高风险门槛。
- “类不可必推”应实现为类推不具普遍保真性，而非禁止一切类推。

## 4. 《韩非子·难势》：势与材是竞争解释，不是单变量定律

《难势》先引慎子以飞龙乘云、腾蛇游雾说明势位的重要：云雾消散，龙蛇失去所乘；又以尧、桀在不同权位下的政治效果说明势位能够改变命令效力。

但篇中随后“应慎子”反驳：有云雾之势而能乘游者，还需要龙蛇之材；云盛而蚓不能乘、雾浓而蚁不能游。文本继而以桀纣居天子位仍致乱，反驳“专任势即可治”的单因解释。此处必须保留论辩双方，而不能只摘录第一段作为韩非的最终结论。

**工程转译：**
- 以交互模型表示 主体能力 × 环境/制度势位 × 行动条件 → 结果。
- 同一主体在不同环境可能表现不同；同一环境中不同主体也可能表现不同。
- 禁止把环境资源解释成主体能力，也禁止把主体能力解释成环境条件。
- 对“单因归因”设置对照：固定主体改变环境、固定环境改变主体，分别检验。
- 将引述者（慎子）与篇中回应者的论点分开标注，避免观点归属混淆。

**重要限定：**这是一段关于政治权势、贤能和治乱的论辩性文本。龙蛇云雾是论证譬喻，不是对自然生态机制的实测报告。

## 5. 《论衡·感类》：时间相邻与仪式叙事不能独立确立因果

《感类》讨论汤旱自责而后雨的叙事。王充追问：若雨是自责所感，为何旱情持续七年、应验如此迟；若自责后雨只是时间先后，则不能据此认定雨由自责引起。其论证还涉及雩祭、忧民等行为的社会/政治解释，并提出雨旱可由自然之气解释。

**工程转译：**
- 事件先后、共现和叙事连缀只属于时间证据，不自动成为因果证据。
- 因果判断至少要求机制、替代解释、时间窗口和反事实/干预设计。
- 对“仪式之后天气变化”“预测之后事件发生”等样本设置时间共现负控。
- 对等待时长、重复发生率、基线概率与选择性记忆做记录。
- 传统文本中的自然气解释也属于历史理论主张，不能直接当作现代气象学结论。

### 《论衡·物势》补充：五行配属不能替代具体作用机制

《物势》针对以五行配属解释动物相胜的论说，列举鼠、猴、犬、蛇等关系中的反例，追问若按五行生克推演，实际动物关系为何不相应；继而把相胜解释转向齿牙、筋力、动作巧便、气势与具体情境。篇中还举小者凭借有利条件制大者的例子。

这段论证值得单独处理：它不是现代实验论文，也不能把王充的每项动物知识直接当成现代生物学事实；其方法价值在于要求抽象对应接受具体反例检验，并提出更贴近对象的竞争解释。

**工程转译：**
- 五行/象数关系先标为传统理论映射或候选先验，不得直接充当具体物理机制。
- 对每个宏观对应生成可观察预测，再用具体实例、反例和替代机制检验。
- 允许同一结果由体力、工具、位置、策略等不同因素产生；因素解释必须按场景分层。
- 将“理论内部一致”与“对外部现象有预测力”分开评估。

## 7. 对 Zhouyi-AI 认知架构的新增约束

在既有“象—类—变—关系—时—位—势—应—辨—化”结构上，增加一条不可跳过的验证链：

候选象 → 目标命题 → 关系族 → 共享依据 → 关键差异 → 主体/环境/时位条件 → 竞争机制 → 反例与负控 → 证据层级 → 裁决。

每次迁移必须回答：

1. 比较的到底是什么：对象、属性、关系、功能、过程还是结果？
2. 共享依据是否对目标命题有因果/逻辑相关性，而不只是可见相似？
3. 哪些差异可能改变结果？
4. 主体能力、环境条件、时间尺度和位置是否匹配？
5. 是否存在竞争机制或更简单的解释？
6. 证据属于象征规范、文本论证、经验相关还是干预支持？
7. 若证据不足，系统是否可以保留未决，而非生成补充故事？

**架构原则：类象不是“相似即迁移”，而是“提出映射—明确保持项—显式差异—限定条件—搜索反例—分层裁决”。**
