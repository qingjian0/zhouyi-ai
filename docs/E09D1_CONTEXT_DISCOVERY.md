# E09-D1：环境条件关系发现基准

状态：基准首版已提交；测试待执行。  
分支：`research/e09-nongradient-learning-2026-11-10`

## 研究问题

当一条关系只在某些环境条件下成立，系统能否从带环境标签的经验中恢复条件，而不是把关系错误地视为无条件规律？

## 隐藏任务

- 环境 0：目标关系为 `a == 1 AND c == 2`。
- 环境 1：目标关系为 `a == 2 AND b == 0`。
- 学习器只接收离散变量和值，不接收目标表达式。
- 按基础输入组合划分训练和测试；同一基础输入不会跨训练/测试泄漏。
- 两个环境都出现在训练数据中，测试保留未见基础组合。

## 对照臂

1. **Contextual**：输入包含环境变量，学习器可将环境作为规则条件。
2. **Context-blind**：输入不包含环境变量；同一输入若在两个环境得到不同标签，由 EvidenceLedger 隔离，不强行选择一个标签。

两个实验臂共享相同基础组合划分。比较每个环境的覆盖率、已作答准确率、总体正确率和拒答数量。

## 可证伪假设

- H1：Contextual 能学出依赖环境变量的条件规则，并在未见基础组合上泛化。
- H2：Context-blind 在环境冲突输入上应更倾向拒答，而不是产生伪确定预测。
- H3：若 Contextual 没有稳定提高环境分层的覆盖率和正确率，则显式环境条件的收益不成立。

## 关键限制

- 这是有限类别变量 DSL 中的合成基准，不是开放域关系发现。
- 环境变量已作为输入字段提供；实验验证的是条件规则识别，不是系统自主发明“环境”这一概念。
- 两种环境都出现在训练集中，不测试完全未见环境的零样本迁移。
- source_id 只是来源标签，不证明独立主体或真实身份。
- 必须报告逐种子结果；至少 5 个种子，不得只报告均值。
- 规则候选预算、训练/测试拆分和学习器结构均须记录。
