# M49：类象实验可复现运行清单与数据泄漏审计 v0.1

## 目标

把每次基准运行变成可复核的研究记录：代码提交、工作区状态、运行环境、依赖锁定、数据版本、协议、配置摘要、随机种子、数据划分、事件账本摘要、指标版本和结果工件引用均需登记。

## 数据隔离

每条数据项登记 object_family 与 source_family。相同对象家族或同一原始来源家族不得跨 train / validation / test；防止近重复对象、同源文本和衍生样本泄漏。该规则需要按具体数据集定义家族粒度，不能仅凭 item_id 切分。

## 古典依据

《墨子·小取》要求“察名实之理”，《荀子·正名》反复辨析名实与同异。M49 将其转化为数据项、来源、版本、实验配置和结果工件之间可追溯的对应关系；这不是古代文本已经提出软件复现规范。

## 现代依据

ACED-Bench 强调隐藏因果世界与程序化 oracle 的一致性；Causal-Discovery-Bench 使用固定结构方程模型、持久实验单位和资源约束。可复现比较还必须隔离发现与验证数据，避免在模型选择后重复使用同一数据造成后选择推断失效。

## 限制

本模块只审计清单完整性和家族级 split 泄漏，不检查工件 URI 是否可访问、不下载并校验工件内容、不容器化环境、不复现第三方模型运行，也不保证登记的随机种子能控制所有外部非确定性。
