# E12-A13：模型失配与环境漂移诊断

日期：2026-11-11。状态：保守型诊断原型，不作因果归因。

## 问题拆分

候选预测与新观测不一致，至少有五类解释：候选机制失效、适用 scope 改变、测量协议/设备漂移、外部环境分布变化、竞争假设不充分。仅凭目标样本本身无法可靠区分这些解释。

## 目标流 + 已知控制流

- 目标流：经 A11 签名的候选目标测量结果，和冻结候选参考分布比较。
- 控制流：同一测量协议下、具有已知稳定参考分布的校准控制对象。
- 每个 receipt 绑定 executor/key、candidate version、scope、scope digest 和 protocol。
- 控制与目标的经验分布分别计算 total variation (TV) effect size。
- 最少样本数、窗口大小和阈值必须由独立校准集确定，不能由 learner 自报。

## 诊断结果

| 结果 | 解释 | 处理 |
|---|---|---|
| INSUFFICIENT_DATA | 样本不足 | 不声称稳定或漂移 |
| STABLE | 控制和目标偏差均未越阈 | 仅说明当前阈值下未检出 |
| CONTROL_SHIFT | 控制流偏离 | 优先怀疑测量/环境共同变化 |
| TARGET_MISMATCH | 控制稳定、目标偏离 | 候选/范围不匹配，仍不可直接判机制错误 |
| JOINT_SHIFT | 两流均偏离 | 共享漂移或复合变化，需进一步实验 |

任何 shift 诊断只写入 A7 的 scope 状态 SHIFT_SUSPECTED，不修改 EpistemicStatus，不推进 workflow stage，也不全局废弃 candidate。

## 统计限制

TV 是透明的描述性 effect size，不是显著性检验，也不自动提供误报率保证。原型使用固定窗口类别频率，假设控制对象在目标测量期间确实稳定、控制与目标受同一测量链路影响。控制对象若自身漂移、代表性不足、目标/控制误差结构不同，诊断会失效。多个控制采用相同 outcome space 才允许简单聚合。

生产化前需增加：时间戳/协议版本校验、分层控制、精确或 bootstrap 区间、变化点检测、时间自相关修正、多个控制的稳健聚合、预注册阈值校准与延迟/缺失数据处理。

## 验证覆盖

测试覆盖稳定流、控制漂移、目标单独偏离、联合漂移、样本不足、scope digest 错误和控制类别越界。核心不变量：诊断不能将 epistemic status 直接改为 REFUTED_IN_SCOPE。
