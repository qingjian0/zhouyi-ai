# 类象训练框架（Classiang Training Framework）

## 定位

当前版本：v1（初始可复现训练基线；持续演进中）

类象训练框架是 ZhouyiAI 的可复现学习与训练子系统。它服务于类象认知闭环，不等同于单一文本分类器，也不把合成数据分数当作真实认知能力。

核心目标是让系统逐步具备：
1. 从可追溯观测中提取局部证据；
2. 形成可检验的特征与关系表示；
3. 通过正例、反例和边界案例学习类象边界；
4. 在未见领域中检验关系保持与组合迁移；
5. 对不确定输入弃权，并将高价值错误反馈到下一轮训练；
6. 在长文档中维护跨片段实体、关系、时间和冲突证据；
7. 学习新领域时保持既有能力，避免灾难性遗忘。

## 训练原则

- **证据优先**：每个预测必须保留原始来源、字符跨度或结构化证据引用。
- **正反对照**：不仅学习“哪些特征相似”，还要学习“哪些条件不同会改变类别”。
- **谨慎负例**：未标注跨度不自动等于负例。困难负例必须有明确标注或经过独立审阅；否则只作为待审候选。
- **来源隔离**：按来源族、文档组和领域拆分数据，防止模板、转载和近重复泄漏。
- **分阶段训练**：先学习基础正例与明确负例，再逐步引入困难边界样本；持续监测假负例和梯度偏移。
- **拒绝未知**：不把封闭标签集的高分解释成开放世界识别能力。
- **防止自证循环**：模型自生成标签不得直接充当 Gold 真值。
- **真实评测优先**：合成数据只验证管线；真实泛化必须使用许可清晰、来源独立、人工审阅的 Gold 测试集。

## 训练流水线

| 层次 | 训练对象 | 核心任务 | 验收 |
|---|---|---|---|
| L0 数据治理 | 语料、来源、许可、标注 | 清洗、去重、来源族归档 | 可追溯、无跨集泄漏 |
| L1 证据跨度 | 文本/外部感知证据 | 精确定位与拒绝 | Span P/R/F1、证据一致性 |
| L2 类象表示 | 特征、维度、属性 | 正例/反例判别 | Macro-F1、未知拒绝 |
| L3 关系结构 | 实体、关系、过程、状态 | 关系组合与反事实辨析 | 关系一致性、组合泛化 |
| L4 跨域迁移 | 未见来源与领域 | 结构保持迁移 | Leave-one-domain/source-family-out |
| L5 长上下文 | 跨片段实体与关系记忆 | 远距离证据关联、冲突更新 | 长距离链接准确率、冲突召回 |
| L6 持续学习 | 新旧领域数据 | 主动学习、回放、防遗忘 | 新域增益与旧域回归 |

## 数据协议

每条训练样本至少包含：
- `observation_id`、`subject_id`、`domain`、`source_id`、`group_id`
- 原始文本或结构化观测
- 正例跨度及其类象维度、值、用途
- 经人工确认的负例跨度（若有）
- 来源 URL/文献标识、许可证、采集时间、来源族和标注者/审阅状态

字符跨度采用 Python Unicode codepoint 的半开区间 `[start_char, end_char)`。原文不得在标注后被静默规范化；如需规范化，必须保存原文与偏移映射。

## 模型路线

1. 保留 Naive Bayes 作为低成本可复现基线，不作为最终模型。
2. 建立稀疏线性/间隔学习和困难负例基线，先证明反例学习的增益。
3. 对照轻量中文预训练编码器 + span/关系分类头；冻结编码器与小规模微调分别评估。
4. 以结构化关系学习与文档级记忆为核心能力，不把 embedding 相似度等同于类象理解。
5. 每次升级都必须与简单基线在相同数据切分、参数/计算预算和指标下比较。

## 评估协议

- 精确跨度 Precision / Recall / F1
- 类别 Macro-F1 与每类混淆矩阵
- 明确未知/弃权的 coverage-risk 曲线
- 来源族隔离与留一领域测试
- 反例辨析与反事实边界测试
- 关系结构一致性和组合 OOD
- 长上下文跨段证据链接、实体合并/拆分和冲突处理
- 校准误差（仅当分数被解释为概率且完成校准时）
- 新领域训练前后的旧领域回归

真实 Gold test 集必须冻结，不得用于训练、阈值选择或反复调参。

## 当前实现状态

- 已有 SROK 结构关系训练入口。
- 已有监督式文本跨度学习基线、审阅反馈入口和四档合成数据管线。
- 新增困难负例对比学习原型，仍需通过 CI 和独立数据评估。
- 四档合成训练只证明数据生成、切分和训练流程可运行，不证明真实语义泛化。
- 目前尚无原生图像像素感知、音频/视频感知或跨 chunk 长期记忆训练器。
- 真实许可语料、独立人工标注 Gold 集和跨来源泛化结果尚未交付。

## 训练顺序决策

优先顺序为：数据与标注可信度 → 证据跨度 → 正反例类象边界 → 关系组合 → 跨领域迁移 → 长上下文记忆 → 主动学习与防遗忘。

不以扩大合成数据量、增加模型参数或追求单一 F1 峰值替代上述能力。
