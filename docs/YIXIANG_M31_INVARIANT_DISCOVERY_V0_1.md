# M31：类象不变量发现、反证与适用边界 v0.1

## 1. 核心问题
如何从跨情境观察中提出候选不变量，并通过预设反证、边界扰动和独立复现检验其适用范围？M31 不将样本内稳定等同于普遍规律，不将未发现反例等同于不存在反例。

## 2. 古典理论线索（先秦两汉优先）
### 《墨子·小取》
篇首将辩论目标界定为明是非、明同异、察名实、决嫌疑，并区分辟、侔、援、推。关键限制是“其然也同，其所以然不必同”，且推论可能“远而失，流而离本”。这要求类象主张同时说明：观察到的共同点、推论所依赖的共同根据，以及不适用的异故。M31 将其工程化为候选主张、反证试验和反例记录；这是现代设计，不是声称先秦已有实验注册制度。原文：https://zh.wikisource.org/zh-hans/墨子/小取；校释见 https://ctext.org/mozi-jiangu/xiao-qu/ens。

### 《荀子·正名》
“物有同状而异所者，有异状而同所者”；“状变而实无别而为异者，谓之化”。它要求分开观察形态、对象身份/所处与变化连续性。候选不变量必须声明它讨论的是形态、属性、关系、机制还是系统行为，不能在观察后随意切换判准。原文：https://zh.wikisource.org/zh-hans/荀子/正名篇；四部丛刊见证：https://zh.wikisource.org/zh-hans/荀子_(四部丛刊本)/卷第十六。

### 《淮南子·说林训》
“类不可必推”及主体、物性、姿态/势态不同导致结果变化的例子，提醒研究者主动构造不利情境。它们不是现代因果实验，但适合转化为反例模板：改变主体、目标、环境、姿态、操作过程，观察候选规律是否仍成立。数字文本：https://zh.wikisource.org/zh-hans/淮南子/说林训。

## 3. 不变量层级
- FEATURE：单一可操作特征/属性。
- RELATION：对象、角色或部件之间的关系。
- MECHANISM：产生观察结果的过程/机制。
- SYSTEM：系统级输入—状态—输出规律。
层级不能自动向上蕴含：特征不变不推出关系不变；关系不变不推出机制不变；机制局部相同不推出系统行为相同。

## 4. 研究流程
1. 预注册候选不变量：操作定义、预测观察量、预期关系、适用范围、边界条件、排除条件、预注册记录。
2. 跨情境采样：记录对象、主体、任务、环境、情境版本、来源家族和方法。
3. 对抗检验：确认性、反证性、边界扰动、独立复现四种试验分开标记。
4. 反例处理：保留未审查、已审查、争议状态；不得把反例从数据集中删除后继续宣称普遍稳定。
5. 状态判定：候选、边界化、反驳、不确定、复现；任何状态均非自动语义真值认证。
6. 独立评估：按对象和情境家族分组留出；比较特征相似度、纯分类、结构关系基线及待测类象方法。

## 5. 状态规则
- CANDIDATE：定义与范围已提出，但跨情境证据尚不足。
- INCONCLUSIVE：有跨情境观察，但缺少反证覆盖、审查或必要材料。
- REFUTED：出现经审查的失败/反转观察，或经审查且未解决的反例。
- BOUNDED：在明确边界、审查材料和反证检验后，形成有限范围的主张；不等于普遍定律。
- REPLICATED：需要独立数据/团队/来源家族复现；当前 v0.1 只预留状态概念，不自动赋予。

当前原型采用保守门槛：至少两个不同情境、经过审查的观察、至少一项反证或边界测试、候选审查者，并处理反例，才可能标为 BOUNDED。尚未解决的已审查反例或已审查失败/反转直接使候选进入 REFUTED。此状态是规则化审计结果，不是自动发现科学真理。

## 6. 实验与反泄漏
必须按对象 ID 和情境家族隔离训练/测试；必要时按来源家族分组，避免同一底本、同一对象的近重复样本泄漏。报告三类基线：feature_similarity、classification、structural_relation。记录样本量、指标、置信区间方法、结果引用和限制。反证集应在候选提出后由独立人员或预先定义程序生成，防止只挑选有利例子。所有模型配置、数据划分、参数、计算预算、任务和评估脚本版本需留档。

## 7. 原型边界
prototype/yixiang_invariant_discovery_m31.py 提供候选、情境、观察、反证测试、反例、证据和评估契约。审计器检查定义完整性、证据上下文、反证覆盖、反例处理和数据泄漏。它不自动发现不变量、不自动生成可靠反例、不判断文本真伪、不证明因果或语义真值。M27/M29/M30 的依赖图、证据谱系、不确定性和跨情境模块尚未端到端接线。

## 8. 36 项专项测试范围
覆盖候选定义与边界、情境/证据端点、观察证据匹配、反证试验完整性、审查人、反例状态、候选状态转换、对象/情境家族泄漏、对照基线、指标与结果引用、复现与反证区分，以及语义真值边界。

## 9. 后续
