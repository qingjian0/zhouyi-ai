# E12-A7-B：易象与《太玄》结构先验的受控消融协议

日期：2026-11-11

## 1. 研究问题

研究周易易象与《太玄》数理结构能否帮助 CPG-EI 更有效地提出、排序或测量候选机制，而不是把传统象数直接当作世界真值或监督标签。

本实验比较两套不同的结构先验：
- **易象二值先验**：阴/阳二态及由此构成的三爻/六爻关系编码；
- **太玄三值先验**：以三分结构为启发的多值编码与层级组合。

两者先独立评估，不预设哪一套更优，也不强制把二值与三值压成同一编码。

## 2. 《太玄》结构的工程抽象

《太玄经》传统结构包括三方、九州、二十七部、八十一首，以及每首九赞、合计七百二十九赞。其结构可以形式化为连续的三分层级：
- 3 方；
- 3×3 = 9 州；
- 3×3×3 = 27 部；
- 3×3×3×3 = 81 首；
- 每首 9 赞，得到 729 赞。

这提供了一个可研究的**三值分层组合结构**。工程上只提取组合、层级、状态转换与索引结构，不把古代术数解释直接当成因果规律。方州部家等层级映射是候选编码设计，不是已证明的认知机制。

## 3. 先验接口约束

先验只能影响：
1. 候选生成的优先级；
2. 候选搜索顺序；
3. 主动测量/查询的排序；
4. 稀疏组合搜索的初始偏好。

先验不得：
- 读取 Gate-Final 或 Locked-Test 标签；
- 改写观测、真值或世界生成器；
- 降低候选接受门槛；
- 把表面相似直接当成机制同构；
- 阻止反例挑战或强制迁移；
- 在证据不足时覆盖 abstain。

## 4. 对照组

所有组必须使用相同的候选预算 K、测量预算 Q、每次评估计算成本上限、数据划分和随机种子。

| 组别 | 定义 | 目的 |
|---|---|---|
| No-prior | 无结构先验，基础搜索 | 主基线 |
| Random-prior | 随机初始化排序 | 控制“有偏好”本身的收益 |
| Yi-binary | 易象二值结构先验 | 检验二值关系结构 |
| Taixuan-ternary | 太玄三值层级先验 | 检验三值层级结构 |
| Shuffled-prior | 打乱符号—结构对应关系 | 检验语义/结构对应是否重要 |
| Anti-aligned | 将先验偏好反向映射 | 检验先验是否可能造成系统性负迁移 |
| Data-learned | 只用训练世界学习候选排序 | 检验数据驱动先验 |
| Combined | 易象与太玄独立提议后再竞争 | 检验互补性，不做强行融合 |

## 5. 世界划分与防泄漏

- Train：可学习候选排序和先验参数；
- Gate-Dev：可调搜索超参数；
- Gate-Final：只做一次冻结验证；
- Locked-Test：候选决策冻结后揭示；
- World-family OOD：整个机制家族留出；
- Motif OOD：留出关系组合，而不只是随机留出样本。

同一个潜在机制的近重复实例不能跨 Train 与 Locked-Test 泄漏。所有 prior variant 使用相同 episode、种子和测量预算，按配对比较。

## 6. 指标

主指标：
- 机制识别覆盖率；
- 在给定覆盖率下的风险；
- 错误类象迁移率 / false-transfer rate；
- OOD 组合泛化准确率；
- 达到正确识别所需的测量次数；
- 候选多样性、重复率与 top-k 召回；
- 置信度校准（Brier score / ECE）；
- abstention precision 与 coverage-risk curve；
- 计算成本与单位正确发现成本。

不能只报告平均准确率。若某先验通过更频繁地弃答而降低错误迁移，也必须同时报告覆盖率，避免把过度保守误判为能力提升。

## 7. 预注册假设

- H1：若易象/太玄先验包含可迁移的结构信息，应在匹配预算下优于 Random-prior 与 Shuffled-prior。
- H2：若先验只是表面标签偏见，Shuffled 或 Anti-aligned 可能出现同等甚至更高的训练内表现，但会在世界族 OOD 上增加错误迁移。
- H3：三值先验可能更适合多状态/条件关系，但不预设其一定优于二值先验。
- H4：Combined 只有在两类先验提供互补候选时才应优于单独先验；否则应由竞争机制淘汰冗余 proposer。

所有假设必须通过多随机种子、配对置信区间和多重比较控制评估。若差异不稳定或置信区间跨越零，结论应为“证据不足”。

## 8. 当前状态

本文件是 E12-A7-B 实验协议，不代表先验编码、学习器或消融实验已经实现。E12-A7 第一切片只验证了有限合成世界中的结构识别、观察等价弃答和负迁移拒绝。
