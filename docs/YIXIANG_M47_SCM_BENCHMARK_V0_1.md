# M47：可控因果机制合成基准 v0.1

M47 提供确定性 SCM 数据生成器，显式输出 ground-truth edges 与 observational/interventional 样本，支持潜在共同原因、机制变化、测量噪声偏移和结果依赖的选择偏差开关。

设计约束：
- seed 固定后数据可复现；
- 真值图与数据生成配置一起返回；
- 观察样本和干预样本分开；
- 选择偏差导致观察样本量变化；
- 机制变化发生在样本后半段，便于跨域拆分。

古典参照：《墨子·小取》“其然也同，其所以然不必同”以及“殊类异故，则不可偏观也”，可转化为基准必须显式改变生成机制并记录真值，不能把观察相关性当作稳定机制。

限制：这是小型线性高斯合成基准，不代表真实世界；测量偏移只加在 X 观测通道；选择偏差规则简单；尚未支持非线性、时序、干扰、异质处理效应、潜变量多层结构或真实数据校准。
