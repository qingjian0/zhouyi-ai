# ZNCA 实验协议：原生认知架构的可证伪验证

日期：2026-11-11  
状态：预注册草案；在冻结数据生成器、评估器和预算后才能执行正式实验。  
关联：`docs/ZNCA_NATIVE_COGNITIVE_ARCHITECTURE_2026-11-11.md`

## 1. 实验目的

验证关系状态动力学网络（RSDN）是否能在资源受限条件下，较序列模型更好地完成结构记忆、长程关系推理、类象迁移和持续任务；并检验优势是否来自易象/类象先验，而非数据泄漏、模型容量或额外计算。

不以单一 needle-in-a-haystack 分数代表认知能力。

## 2. 基线矩阵

| 编号 | 系统 | 目的 |
|---|---|---|
| B0 | 规则/精确 oracle | 验证任务可解与上界 |
| B1 | 小型 Transformer | 序列建模基线 |
| B2 | Mamba-2 或 RWKV-7 | 递归/状态空间基线 |
| B3 | xLSTM 或 RetNet | 门控递归基线 |
| B4 | RAG + PCS | 外部结构记忆基线 |
| B5 | 图/超图网络 | 显式关系基线 |
| Z0 | RSDN，无易象先验 | 新计算架构核心 |
| Z1 | RSDN + 类象映射 | 类象增益 |
| Z2 | RSDN + 易象编码 | 象数结构先验增益 |
| Z3 | RSDN + 神经记忆 | 神经/结构双轨增益 |

尽可能匹配参数量、训练 FLOPs、输入信息、检索候选数、活动工作集、硬件和优化预算。不能匹配时必须同时报告差异，不得只按参数量宣称公平。

## 3. 核心任务集

### T1：长程精确事实与来源
随机位置注入实体、数值、否定和条件，经过大量干扰事件后查询。测 exact match、source span accuracy 和 evidence coverage。

### T2：关系绑定与角色反转
同一对象参与多种相似关系，改变方向、角色和条件。测试模型是否真正保存关系，而非记住词共现。

### T3：非连续组合
使用 A+C+E 等稀疏组合，成员可跨时间、跨事件出现。对比枚举、规则、MLP、Transformer、图模型和 RSDN。

### T4：多跳结构推理
至少跨多个会话、多个关系类型和时间版本。报告正确路径、路径长度、证据覆盖与无效跳转。

### T5：类象跨域迁移
源域与目标域对象不相交、词汇不相似，但关系骨架存在部分对应。加入结构扰动、关系反转、缺失节点、错误类比负例。

### T6：动态状态与冲突
事实更新、撤回、失效、条件变化、多个来源冲突。检查系统是否保留时间版本并在证据不足时拒答。

### T7：目标连续性
任务跨会话、中断、进程杀死和恢复。测试目标、约束、进度、阻塞、工具执行状态的恢复。

### T8：资源压力
在 4GB、6GB、8GB RAM Android 设备测试冷启动、持续交互、后台切换、低内存、磁盘 IO、温度和电量。

### T9：多模态结构
图像/文本/音频中的实体、属性、空间关系、事件变化。分开评估感知错误与推理错误。

### T10：安全与污染
检索内容包含 prompt injection、伪造事实、过期规则和相互矛盾的指令。记忆数据不得升级为系统策略。

## 4. 类象专项消融

必须包含：
- 无类象；
- 人工定义关系映射；
- 可学习关系映射；
- 随机映射；
- 反向映射；
- 表面相似度映射；
- 精确结构 oracle；
- 传统易象候选先验（仅作为一个可消融因素）。

评估结构保持、目标域预测、负迁移率、错误自信率、映射撤回时间和跨生成器稳定性。

## 5. 资源指标

每个测试同时记录：
- 峰值 RSS/PSS 与内存分配峰值；
- 模型权重、工作状态、索引、缓存分别占用；
- 首次响应延迟、P50/P95 延迟；
- CPU 时间、GPU/NPU 利用率；
- 磁盘读写字节与随机 IO；
- 能耗、温升和持续吞吐；
- 活动 token、结构节点数、边/超边数、候选数；
- 新事件增量更新成本。

不能只报告平均延迟。必须报告历史规模 N 从 10K、100K、1M、5M 到 10M source tokens 的扩展曲线。

## 6. 统计与独立性

- 先注册假设、主要指标、样本量、随机种子和排除规则。
- 按 episode/source group 做独立划分，禁止同一生成器模板或对象身份跨训练/测试泄漏。
- 使用多个独立 seed，报告 micro/macro 指标、效应量和置信区间。
- 多重比较预先定义校正族。
- Locked test 只用于最终评价。
- 实现者不得单独签发最终结果；独立 evaluator 运行。
- 失败、abstain、预算耗尽必须计入分母并分别报告。

## 7. 主要成功门槛（待首轮 pilot 校准后冻结）

1. 在相同资源预算下，Z0 在至少两类结构任务上稳定优于 B1-B5 中最强基线。
2. Z1 的跨域迁移收益在对象不相交和领域不相交测试中复现，且随机/反向映射不能获得相同收益。
3. 关系与事实均可追溯到原始证据；错误记忆和错误自信率不高于基线。
4. 任务恢复不需要把全部历史重新送入模型。
5. 4GB 设备上峰值内存受硬预算控制，历史规模增长主要影响磁盘与索引，而不是活动工作集线性增长。
6. 语言表达器替换后，核心结构推理结论保持稳定。

若只满足第 4、5 条，结论只能是“有效的移动端认知记忆系统”，不能称为新通用模型架构成功。若只在人工合成数据有效，不得宣称通用智能提升。

## 8. 研究产物

每个实验必须保存：
- Hypothesis / ExperimentSpec；
- 数据生成器版本与数据 digest；
- 代码 commit、模型权重 digest、训练配置；
- 设备型号、OS、运行时、温度和电量；
- 原始预测、证据、失败与 abstention；
- 指标脚本、运行日志和独立复核报告。

## 9. 关键风险

- 显式结构表示带来过高抽取成本；
- 关系图膨胀导致 IO/内存反而超过 KV；
- 类象映射过拟合人工设计的结构；
- 多路径搜索计算量失控；
- 状态压缩导致精确细节丢失；
- 小语言表达器限制开放式语言能力；
- 端到端训练无法稳定优化离散结构操作；
- 新架构仅在窄域任务有效，无法迁移到开放文本。

每个风险都必须有独立测试，不能以理论叙述代替性能测量。
