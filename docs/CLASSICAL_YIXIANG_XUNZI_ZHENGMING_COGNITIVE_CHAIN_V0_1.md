# 《荀子·正名》“天官—征知—同异—名实—化”认知链研究 v0.1

## 1. 研究定位与文本边界

本专题以《正名》篇中“然则何缘而以同异”以下论述为核心，重点不在把荀子改写成现代认知科学，而在提取文本自身呈现的辨物、分类、命名与对象连续性问题。当前引用来自数字转录入口；尚未完成影印底本逐字校勘，故所有引文仍是检索候选，不升级为已校勘原文。

核心文本片段包括：

- “凡同类同情者，其天官之意物也同。”
- “形体、色理以目异；声音清浊……以耳异；甘苦咸淡……以口异……”
- “心有征知……征知必将待天官之当簿其类，然后可也。”
- “然后随而命之，同则同之，异则异之。”
- “物也者，大共名也……鸟兽也者，大别名也。”
- “名无固宜，约之以命，约定俗成谓之宜。”
- “物有同状而异所者，有异状而同所者……状变而实无别……谓之化。”

这些句子属于同一篇章的论述链，但不意味着它们是一个严格形式化的单一演绎证明。项目将其拆成可独立审查的认知阶段。

## 2. 五阶段认知链

### S1：天官——按感官通道取得差异

文本分别举目、耳、口、鼻、形体、心等方面的辨别对象。其重要性在于：辨异并非脱离观察条件的抽象标签。不同性质有其相应的感知通道，不能要求单一通道承担全部识别。

项目操作化：
- 每条观察记录注明感知/测量通道、对象属性、条件、时间和来源。
- 未被当前通道观察到，不等于对象不存在该属性。
- 不同通道的证据不能无条件互换；视觉相似不能代替声音、功能或因果证据。

### S2：征知——综合判断仍须受观察约束

“心有征知”并非授权心任意裁定；文本紧接着强调，征知必须等待天官“当簿其类”。可谨慎理解为：判断活动要以相应感官已正确接触、登记其类为条件。

项目操作化：
- 将观察证据与解释/分类结论分开存储。
- 结论必须追溯到支持它的观察通道和原始记录。
- 观测缺失、通道冲突或对象属性不可辨时，保留 UNKNOWN / ABSTAIN，不用模型补齐。

注意：这里的“征知”“天官”是先秦文本概念；将其映射为感知输入与高层判别只是工程类比，不代表荀子提出了现代神经科学或机器学习模型。

### S3：同异——明确“在哪一方面相同”

“同则同之，异则异之”不是让系统为两个对象贴一个全局的 SAME/DIFFERENT 标签。前文已列出形色、声音、味、气味、形体感受等不同辨别维度。

项目操作化：
- 同异判断必须绑定谓词/维度：same-in-color、same-in-shape、same-in-function 等。
- 对象可在属性 P 上相同，同时在位置、个体、来源或机制上不同。
- “同类同情”不应未经训诂和上下文审查就被翻译为现代统计学的同分布或心理学的同情绪。

### S4：名与共别——分类层级和共同约定

“物”为大共名，“鸟兽”为大别名，文本又说可继续推共、推别，直至无共/无别。此处呈现的是分类粒度可以随表达目的调整；名称的适宜性还与共同约定、通行习俗有关。

项目操作化：
- 将对象、类、名称和指称分成不同节点。
- 一个对象可同时属于多个不同粒度的类；上位类与下位类不可混同。
- 同名不保证同物，异名也不必然异物；需要记录共同指称证据。
- 命名约定具有共同体、时代和语境范围，不应把一个时代的名制无条件迁移到另一时代。

### S5：状、所、实、化——外观差异不等于实体变化

“同状而异所”可合而仍为“二实”；“状变而实无别”则被称为“化”。这至少要求把外观、所在/个体化条件和对象连续性分开处理。

项目操作化：
- 外观相似不能单独证明是同一对象。
- 外观变化不能单独证明对象已经变成另一对象。
- 位置相同也不能单独证明实体同一；需要时间、因果连续性、边界和上下文证据。
- 对象连续性判断必须显式列出允许的变化与身份保持条件；条件不足时输出 UNRESOLVED。

## 3. 与《墨经》“同—异—类—故”的交叉关系

二者不能被合并成一套同义术语：

| 维度 | 《荀子·正名》本专题 | 《墨经》研究接口 |
|---|---|---|
| 观察基础 | 天官辨别不同性质 | 不直接等同；需逐条对读经说例证 |
| 判断约束 | 征知待天官当簿其类 | “故”讨论判断/推论所依的根据 |
| 同异 | 按不同感官属性辨同异 | “同”存在多种关系根据，“异”也非单一反义 |
| 分类 | 大共名、大别名，推共推别 | 类同/不类、同类相推等需结合各篇条目 |
| 名实 | 约定命名、辨别异实 | 名、辞、故、类之间的关联 |
| 对象连续性 | 状同异所、状变实不别 | 不可直接把《墨经》术语套入“化”的解释 |

《墨经》“同，异而俱于之一也”及“小故/大故”等条目存在具体训释、传本文字和校改争论。项目必须同时保存底本读法、校家读法、现代解释和本项目操作化，不得把一种现代解释标成唯一古义。

## 4. 类象迁移的新增硬门禁

每次跨对象迁移，依次检查：

1. **观察可比性**：源对象与目标对象的证据是否来自可比较的观察通道？
2. **维度明确性**：声称相同的是哪一个属性或关系？
3. **分类依据**：共同类是否由相关属性建立，而不是由名称相似或外观联想建立？
4. **名实对齐**：两边术语是否同指？是否存在同名异实、异名同实？
5. **个体连续性**：若讨论同一对象，是否有时序/因果连续性证据？
6. **关键差异**：是否有差异会破坏当前推论？
7. **反例搜索**：能否构造“同外观异对象”“异外观同对象”“同名异物”“同结果异机制”的反例？
8. **结论范围**：只能输出被证据支持的维度和条件，不得从局部相同升级为整体相同。

若第 1、2、3、4 或 5 项对当前任务属于必要条件而证据缺失，应暂缓或拒绝迁移，不以相似度分数补偿。

## 5. 反向审查：从错误结论回溯失效阶段

当系统给出错误类象结论时，不只记录“预测错”，还要定位最早失效阶段：

- S1 观察错误：通道不匹配、测量条件变化、观测缺失。
- S2 征知错误：解释越过观察证据、把未知当成已知。
- S3 同异错误：把某维度相同误写成全局相同。
- S4 名实错误：同名异物、异名同物、分类粒度错置。
- S5 连续性错误：把形变当作换物，或把同形当作同一实体。
- T 迁移错误：源/目标之间的关系结构或范围条件未保持。

工程上应记录 failure_stage、evidence_refs、violated_condition、counterexample 和 recovery_action，使错误可定位、可回滚。

## 6. 对 Zhouyi-AI 的实现映射

- M2：显式表达 observation → discrimination → classification → naming → identity-tracking 的分层图。
- M3：将属性同、功能同、同名、同指、同处、同一实体等候选解释并列，竞争裁决。
- M4：干预观察通道、属性、位置、时间和命名约定，观察分类是否改变。
- M5：优先选择能区分竞争假设的观测，而非重复确认已有相似特征。
- M6：新类象候选必须保留其观察依据和未迁移属性，不以新签名替代证据。
- M8：增加通道错配、同名异物、异名同物、形变连续性、局部同异混淆等测试集。

## 7. 可证伪验收

- 系统不得仅凭外观相似判定实体同一。
- 系统不得仅凭名称相同判定指称相同。
- 系统不得仅凭某一维度相同判定整体同类。
- 系统不得将未观测属性当作不存在或已知。
- 系统必须在证据不足时输出 ABSTAIN/UNRESOLVED。
- 系统必须能指出结论依赖的感知通道、分类维度和范围条件。
- 对同一对象的连续性判断必须引用时序或因果证据；只有形态变化/相似时应拒绝确定结论。
