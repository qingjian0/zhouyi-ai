# 类象、象数、象理与拟象推演：传统易学认知方法专题研究

日期：2026-11-11  
研究状态：第一轮文献与公开视频索引研究；不是穷尽性文献综述  
用途：修订 CPG-EI 核心认知理论，不直接等同于已验证的计算算法

## 1. 研究结论摘要

本研究的首要结论是：不能把“象、数、理、类、变”简单拆成五个互不相关的模块。传统易学中的象、类、数、理、变具有历史层次、流派差异和相互生成关系。现代 AI 架构应当把它们实现为相互作用的认知过程和表示层，同时保留概念来源与适用边界。

暂定核心认知循环：

**观物 / 观事 → 取象 → 立象 / 拟象 → 触类 / 比类 → 倚数 / 极数 / 错综 → 穷理 / 明义 → 观变 / 推演 → 回到观察与证据修正。**

这个流程是跨文献归纳出的研究模型，不应冒称所有时代、流派均采用同一套固定步骤。

## 2. “象”的多层含义

依据《系辞》及相关研究，“象”不能缩减为图像或外观。至少需要区分：

1. 现象 / 物象 / 事象：外部可观察的自然、社会、个体、事件和过程。
2. 意象：主体从观察中形成的心象、整体把握、意义组织和联想结果。
3. 类象：通过取象比类建立的模型性表达，把不同对象放在某个可比较的结构或属性之下。
4. 卦爻象 / 符号象：用爻、卦、图式等符号形式组织和表达关系、位置、变化与意义。
5. 法象 / 拟象：观察、效法、模拟对象的某些形态、关系或变化方式，形成可供思考的表征。

这些分类在不同研究者处的边界不完全相同，应当在术语元数据中记录采用的定义、作者和文献语境。

工程含义：
- 象应是多模态、多尺度、可带视角的结构表示；
- 一个对象可以有多个象，一个象也可对应多个候选对象；
- 象必须记录观察主体/来源、时间、条件、尺度、抽象过程和不确定性；
- 象是对对象某些方面的表达，不是对象本身，也不是完整真相。

## 3. “类”与“类象”：不是普通相似度

取象比类的关键在于：从具体事物中选取某些特征、功能、关系、位置或变化过程，形成可以比较的象；再通过类的组织，将已知领域的结构用于理解未知领域。

类象并非只问“两个东西像不像”，而要问：

- 取象依据是什么：形态、功能、属性、位置、角色、关系拓扑、过程还是变化？
- 相似发生在哪个层次和尺度？
- 哪些结构保持不变（invariants）？
- 哪些特征不匹配？
- 这种映射在什么边界条件下成立？
- 由此可以迁移什么推断？哪些推断禁止迁移？
- 有哪些反例？怎样验证？

### 3.1 类象的双向性

正向：
具体观察 → 抽象取象 → 形成类别/模式 → 发现共同结构 → 形成解释。

反向：
已有象/模式 → 预测目标对象可能呈现的结构 → 设计观察 → 获取证据 → 保留、修订或拒绝映射。

因此，类象既参与归纳，也参与基于模型的演绎/推演。它是往返过程，不是一次性标签分配。

### 3.2 类象的工程判定

每个 AnalogyMapping 至少应包含：
- source / target domain；
- selected aspect；
- abstraction level；
- role correspondence；
- relational/topological correspondence；
- preserved invariants；
- unmatched features；
- boundary conditions；
- transferable hypotheses；
- non-transferable properties；
- supporting evidence / counterexamples；
- confidence calibration；
- validation protocol；
- status（candidate / tested / supported / rejected / expired）。

向量相似度可以用于候选召回，但不能直接作为类象成立的判据，更不能把类象升级为因果关系。

## 4. “数”的多义性和工程隔离

象数研究中的“数”有多种语义。文献讨论中可见：
- 数目：数量、计数；
- 序数：位置、次序、层级；
- 算术：计量、演算方法；
- 结构数：奇偶、阴阳、爻数、组合；
- 规律意义的数：对秩序、节度和变化规律的表达；
- 气数、术数：具有特定传统哲学、占筮或方术语境的概念。

工程上必须将以下内容分开：
1. 传统易学的数象解释；
2. 形式系统的编码约定；
3. 可测量的物理/业务数值；
4. 统计估计和模型参数；
5. 算法复杂度、计算预算与概率。

它们可以通过显式映射关联，但不得把传统数象的意义自动当作数学定理或经验事实。

## 5. “理”：关系、秩序、规则与义理，不是任意解释

在不同易学语境中，“理”可以关联义理、数理、事物运行规则和规范意义。不能将所有“理”都等同于现代科学因果律。

在 CPG-EI 中应区分：
- 描述性规律：观察到的稳定共现或趋势；
- 结构关系：部分—整体、互补、对立、依赖、制约；
- 规则：给定条件下可执行的转换约束；
- 因果假设：需要干预、时序证据或其他方法检验；
- 规范性义理：价值、应然和行动原则；
- 解释框架：组织事实和意义的理论。

规则对象必须有来源、适用条件、反例、版本、验证状态和失效条件。不能由象的相似性直接推出因果关系。

## 6. 象数关系：不应设定唯一固定方向

研究中存在“象生数”“数生象”等不同立场；从共时关系看，象与数也可以通过奇偶、常变、动静、体用、阴阳等范畴相互刻画。

因此工程实现不应预设：
- 一切象都由数产生；
- 一切数都只是象的标签；
- 象数之间存在唯一固定映射。

更合理的是支持双向、多对多、版本化映射：
- 从观察象中抽取数量与结构；
- 从数值/结构约束形成候选象；
- 通过新证据校正映射；
- 保留不同理论体系对同一对象的不同解释。

## 7. 观象、法象、立象与倚数、极数、错综

可作为 CPG-EI 的候选认知算子研究：

### 象侧
- OBSERVE：收集多模态观察；
- ABSTRACT：抽取特征和关系；
- MODEL：形成候选象；
- SIMULATE：构造拟象或模型；
- INTERPRET：将象与语境、文本和目标关联。

### 类侧
- CLASSIFY：按所取特征归类；
- ANALOGIZE：跨领域建立候选映射；
- TRANSFER：在边界约束下迁移推断；
- CONTRAST：寻找差异和反例；
- REFINE：根据验证结果修订类别。

### 数侧
- COUNT / MEASURE：计数与测量；
- ORDER：位置和序列；
- COMBINE：组合与排列；
- CONSTRAIN：数值/结构约束；
- TRANSFORM：按形式规则变化；
- ENUMERATE：生成候选空间。

### 理侧
- RELATE：构建关系；
- INFER：推导候选规则；
- EXPLAIN：组织解释；
- TEST：对照证据和反例；
- REVISE：修订规则与适用范围。

### 变侧
- DETECT_CHANGE：发现状态差异；
- MODEL_TRANSITION：建立状态转换候选；
- BRANCH：生成多条可能路径；
- FORECAST：形成预测；
- OBSERVE_OUTCOME：比较实际结果；
- UPDATE：回写模型。

这些是工程候选算子，不宣称传统经典原文中已经存在同名算法。

## 8. “变”与多路径推演

变化不应只编码成一个标签翻转。至少要记录：
- 当前状态；
- 触发条件；
- 变化主体、位置与关系；
- 不变量和变化项；
- 时间顺序；
- 可行的下一状态；
- 多个并行路径；
- 路径成本和约束；
- 预测及其实际结果。

卦变、爻变可以作为一种离散结构变换研究，但不能把所有真实变化都强行压成六爻状态。连续变量、多值状态、概率状态、混合状态必须保留。

## 9. 与现代认知科学、机器学习的接口

潜在对应关系（只作为研究类比，不等同）：
- 取象：多模态表征学习、特征抽象、概念形成；
- 类象：analogical reasoning、结构映射、关系迁移；
- 象数：符号表征与数值/组合约束协同；
- 理：规则学习、关系推理、模型解释；
- 变：动态系统、状态空间模型、规划和预测；
- 观变：主动感知、实验设计、反馈学习。

需要防止用现代术语反向覆盖古代概念，也要防止把传统概念包装成现代算法已经证明有效。

## 12. 对 CPG-EI 的架构修订建议

不再把象、数、理、类、变实现成五个孤立“知识库”。建议采用：

- 一个统一的 Cognitive Representation Layer；
- 多种可互操作的象/数/关系/变化表示；
- 一组可组合的认知算子；
- 一个类象与结构迁移引擎；
- 一个证据与反例约束系统；
- 一个可增量更新的动态关系/超图；
- 一个支持多路径生成、评估、合并和淘汰的组合推演引擎。

每个理论体系（周易、太玄、阴符经及学习得到的模式）应有独立 schema、算子、参数和来源标签。它们可在任务级编排中协同，但必须能独立启停、比较和消融。

### 核心实验

- 表面相似检索 vs 关系结构类象；
- 单向归纳 vs 归纳—演绎往返；
- 有边界约束 vs 无边界约束；
- 有反例检索 vs 无反例检索；
- 象数分离表示 vs 过早混合表示；
- 单路径推演 vs 多路径组合；
- 传统模式先验 vs 学习模式先验；
- 周易、太玄、阴符经独立与组合消融。

关键指标：跨域迁移准确率、负迁移率、反例敏感度、校准、拒绝率、预测质量、证据可追溯性、计算/内存/能耗。

## 13. 需要继续查证的问题

1. 先秦《易传》、汉易、魏晋易学、宋代图书易学中的“象”和“类”是否具有连续或不同的定义？
2. “取象比类”在《周易》、中医、名物制度、兵法、工艺设计等领域具体怎样操作？其成功与失败案例有哪些？
3. 象、数、理究竟是同一认知过程的不同侧面，还是存在更明确的层级关系？不同流派的答案不能强行统一。
4. 卦象、爻位、互体、错综、卦变、卦气、纳甲等方法中，哪些可形式化为通用结构算子，哪些依赖特定历史解释体系？
5. 怎样区分有生产力的结构类比与任意附会？需要负例库、边界条件和可重复验证。
6. 怎样将这些方法与现代 analogical reasoning、structure mapping、active learning、causal inference、dynamic systems 进行严格对照？

结论：CPG-EI 应研究的不是“把八卦套到所有知识上”，而是从易学的观象、拟象、取象比类、象数互动和观变推演中，提炼一种可形式化、可实验、可拒绝、可持续修订的结构认知方法。
