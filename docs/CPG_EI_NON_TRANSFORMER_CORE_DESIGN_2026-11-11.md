# CPG-EI 非 Transformer 核心架构研究设计（2026-11-11）

状态：研究设计 / 待实现；不是已验证模型，也不构成优于 Transformer 的结论。

## 0. 本轮审计纠正

当前 `main` 的 README/ROADMAP 明显滞后于研究分支。跨线审计分支 `research/cpg-ei-cross-track-synthesis-2026-11-11` 已记录 E02-E12 的多项进展，以及 E12-A3 固定预算分配的负结果。不能再仅依据 main 上的 M1/M2 描述判断项目整体进度。

本设计吸收现有跨线审计的六层职责划分，并进一步回答：怎样把分散的符号实验收敛成一个不以 Transformer 为核心的可训练计算系统。

## 1. 目标与非目标

### 目标

建立一个以**可执行语义原语、证据账本、稀疏关系结构、组合程序和可修订世界模型**为核心的学习系统。系统内部的基本状态不是 Token 序列，而是带类型、角色、来源和不确定性的观测、概念、关系、机制与计划。

核心闭环：

`Observe -> Propose -> Discriminate -> Verify -> Compose -> Predict/Act -> Reveal -> Revise`

### 非目标

- 不承诺一次性替代所有 Transformer 功能。
- 不把并行 Token 解码、超图、三进制或易象标签本身视为创新。
- 不把有限 DSL 搜索称为开放世界概念发现。
- 不把被动观测相关性称为因果。
- 不在没有参数量、训练数据、计算量匹配基线前宣称优越。

## 2. 核心架构：五个学习 substrate + 一个证据内核

### L0 观测与表征（Observation Substrate）

输入可以是结构化字段、数值序列、事件流、文本或图像。输出统一为 Observation：

- `observation_id`、通道、时间、原始值/片段引用；
- 可直接测量的属性与缺失掩码；
- 编码器提出的候选特征（必须标记为推断，不冒充真值）；
- 来源、质量、噪声模型和权限。

初期使用结构化观测和手工/固定特征，先验证下游机制。后续再分别加入 MLP、卷积、状态空间或其他编码器。Transformer 只能作为可选对照编码器，不是系统必需组件。

### L1 原语提议器（Primitive Proposer Substrate）

多个可替换提议器并行工作：

1. 统计提议器：阈值、变化点、共现、残差结构；
2. 类型谓词提议器：生成带类型的可执行谓词；
3. 关系提议器：搜索有序角色、对称/反对称和高阶关系；
4. motif 提议器：提出重复结构候选；
5. 神经提议器：从连续表示提出特征或关系候选；
6. 反例扩展器：仅在声明的算子语法边界内提出扩展。

每个候选必须提供 executable definition、输入类型、作用域、证据 ID、复杂度、成本、置信度、反例和版本。提议器不得读取 Gate-Final 或 Locked-Test。

### L2 主动辨识器（Active Identification Substrate）

当多个候选对当前证据同样成立时，系统不能任意选一个。它维护版本空间/后验假设集合，并选择最有区分力且成本可接受的观测：

`probe* = argmax_p [ExpectedInformationGain(p) - λ Cost(p)]`

EIG 是有限候选基线，不是因果干预。若只能被动测量，输出必须标注为 observational identification；只有允许且实际执行干预，才进入因果结论。

### L3 稀疏组合器（Sparse Composition Substrate）

把已验证或暂定原语组合成 typed DAG / hypergraph / executable program。支持不连续成员，如 A+C+E，且保留：

- 参与成员和角色槽位；
- 有序/无序语义；
- 关系类型、作用域和组合深度；
- 原语版本及证据谱系；
- proposed / tested / accepted / suspended / rejected 状态；
- 描述长度和执行成本。

组合器与原语提议器必须分开计量，避免把“候选多”误算成“组合能力强”。

### L4 竞争与预算控制器（Competition Substrate）

候选价值不是置信度或投票数，而是独立 Gate 上的增量效用，扣除复杂度、重复、评估成本和迁移风险。比较 equal、round-robin、UCB1、racing/successive-halving、novelty-aware 和小规模 exact oracle。

UCB1 只作为启发式基线：E12-A3-M1 的现有实现是策略单测，使用预生成奖励流，不能当成真实提议器集成的性能证据。奖励非平稳且候选之间相关，不宣称经典 UCB1 regret 保证。

### L5 预测、动作与生成（Prediction/Generation Substrate）

核心输出先是结构化的预测、关系图、程序、计划或动作，不强制先生成 Token 序列。结构输出可由约束求解器/程序执行器产生；自然语言表面化可以使用独立 renderer。

如果 renderer 使用自回归 LLM，整个产品应称为“非 Transformer 核心 + 自回归语言接口”的混合系统，而不是端到端非自回归语言模型。只有在结构化任务上，才可先声称内部推理与结构生成不依赖自回归解码。

### E 证据与版本内核（Evidence Kernel）

所有层共享 append-only 证据账本和不可变结构版本：

`Predict -> Commit -> Reveal -> Append -> Revise`

证据揭示前必须先持久化预测；结构修订生成新版本并指向父版本和支持证据。区分工作记忆、结构版本、神经参数 checkpoint 和批量重训。出现冲突时可 suspend / split / refine / abstain，不得静默覆盖。

## 3. 非 Transformer 学习机制：不要押注单一算法

CPG-EI 应采用多种学习机制的组合，并以任务选择，不应先把所有学习压到一个大网络里。

| 学习对象 | 首选机制 | 可学习参数 | 主要验证 |
|---|---|---|---|
| 原语候选 | 程序/谓词归纳 + 统计提议 | 候选分布、特征权重 | 候选召回、误发现率 |
| 关系结构 | 稀疏超图结构学习 | 角色、边权、关系参数 | 规则族 OOD、角色置换 |
| 组合策略 | 排序学习 / contextual bandit | 组合评分和预算策略 | 增量效用、成本 |
| 不确定性 | Bayesian/version-space 或 conformal 校准 | 假设权重/校准器 | 覆盖率、选择性风险 |
| 连续感知 | MLP / CNN / SSM 等可替换编码器 | 表征参数 | 样本效率、迁移 |
| 结构修订 | 反例驱动的局部更新 + 门控 | 原语/边版本 | 抗遗忘、恢复成本 |

关键原则：结构学习、连续表示学习和策略学习分开记录梯度/更新来源。不要用一个端到端损失掩盖是哪一层真正带来收益。

## 4. 统一目标函数（待实验校准）

候选总目标可写为：

`J = L_task + λ_e L_evidence + λ_c L_contradiction + λ_m L_MDL + λ_r L_redundancy + λ_u L_uncertainty + λ_k Cost`

其中：

- `L_task`：预测/决策任务损失；
- `L_evidence`：结论缺少支持证据的惩罚；
- `L_contradiction`：与已确认事实或结构约束冲突的惩罚；
- `L_MDL`：模型/程序描述长度，抑制无必要复杂度；
- `L_redundancy`：重复原语、重复超边与等价程序惩罚；
- `L_uncertainty`：校准与过度自信惩罚；
- `Cost`：提议、探测、评估、推理的实际计算成本。

不要只优化一个加权标量。报告各项 Pareto 前沿，并对权重做敏感性分析。结构更新必须在独立 Gate 上通过，不能由 Locked-Test 驱动。

## 5. 易象与三进制：作为可学习的结构假设，不是硬编码真理

易象模块应拆成可单独开关的因素：

- 阴阳：二元互补/对偶分区；
- 四象：两位状态的层次化分解；
- 八卦：三位二元局部状态；
- 六十四卦：六位状态空间；
- 卦变：状态转移算子；
- 五行：带符号的多类型关系矩阵；
- 《太玄经》三玄/三分结构：三值状态、三元关系或三进制编码候选。

必须明确：八卦/六十四卦的二进制编码与三进制系统不是同一表示。不要把太玄的三分结构强行塞进六爻二进制编码。应分别比较：

A. 无符号先验；B. 可学习随机分区；C. 传统二元易象初始化；D. 三值/三进制结构；E. 传统关系初始化且可学习；F. 打乱/反向错配先验。

主要指标是样本效率、规则族 OOD、校准、拒绝能力和成本。若传统先验不优于通用可学习分区，或在错配环境造成过度自信，应删除或降级该先验。

## 6. 最小可训练系统 MTS-0

第一版不训练大型语言模型。先在 CPU 可复现的结构化世界中建立完整闭环：

1. 世界生成器产生隐藏机制和原始观测；
2. Learner 只拿到 schema、Support 和允许的 probe 描述；
3. 提议器提出谓词/关系候选；
4. 辨识器在允许预算内请求 probe；
5. 组合器构造非连续稀疏程序；
6. 竞争器选择候选或 abstain；
7. Locked evaluator 独立评分；
8. 新证据进入账本，触发受控修订；
9. 新 episode 检验旧知识复用和遗忘。

必须覆盖 unary、pairwise、A+C+E、嵌套组合、角色置换、相关干扰、噪声/缺失、规则族 OOD、观测等价、反例和分布漂移。

MTS-0 的“训练”至少包括从 Support 学习谓词/关系参数、从 Gate-Dev 学习预算策略、从反例更新候选结构。有限语法和已知假设类必须明确披露；不能称为开放世界自主学习。

## 7. 从 MTS-0 到神经认知模型的阶段

### MTS-0：符号闭环

验收：端到端 episode 可复现；训练/Gate/Locked-Test 权限隔离；比简单查表、固定特征、随机提议和专业单一提议器更有收益。

### MTS-1：连续表征接入

在相同 episode 中把人工属性逐步替换为可学习 MLP/卷积/状态空间编码器。分别评估冻结编码器、联合训练和分层训练。神经提议器输出候选，必须走同一证据协议。

### MTS-2：神经-结构联合学习

加入可微稀疏路由/超边评分，但保留显式候选、证据和结构版本。比较离散结构更新、软门控、直通估计等方式。检查训练稳定性和结构坍缩。

### MTS-3：多模态与语言接口

先验证视觉/时间序列中的对象与事件 grounding，再接入文本。Token 可作为输入载体，不是唯一内部单元。自然语言输出先采用结构计划 + renderer；若 renderer 自回归，必须如实报告。

### MTS-4：规模与效率

只有在 MTS-0 至 MTS-3 证明机制有增益后，才扩大模型和数据。对照 Transformer、MLP、Graph/Hypergraph、NAR/Discrete Diffusion，并匹配数据、参数、FLOPs、训练/推理预算。

## 8. 下一轮优先实验：E12-Loop

优先把 E12 原语发现、E12-A2 主动测量、E02 稀疏关系、E09 证据修订连接成一个小型闭环，而不是继续平行增加孤立 toy task。

最小接口对象：

- Observation
- OperatorCandidate
- Probe
- Evidence
- RelationCandidate
- Composition
- Prediction
- LifecycleEvent
- EpisodeResult

关键验收：

1. 生成器隐藏真值不能进入 learner 可见对象；
2. Truth mutation 不得改变 learner 的 proposal；
3. Gate-Final mutation 不得改变已冻结的 allocator trace；
4. 重复 proposer/candidate 不得获得额外预算或信用；
5. 观测等价候选必须保留为等价类或 abstain；
6. 非连续组合必须胜过随机/局部邻接组合，且在预算匹配下成立；
7. 反例必须触发可追溯的 suspend/refine/split；
8. 所有成本分别记录 proposal、predicate eval、probe、gate query、inference 和 wall-clock。

## 9. 证伪条件

- 专业单一提议器在相同预算下持续支配组合系统：停止复杂 portfolio，保留专业路由。
- 稀疏组合在规则族 OOD 上不优于简单规则/MLP：缩小组合机制主张。
- 主动探测不优于固定或随机测量：移除复杂 EIG 策略。
- 证据内核不能阻止测试泄漏或无法一致重放：暂停能力实验，先修协议。
- 易象/三进制先验不优于容量匹配的通用结构：不把传统符号纳入默认模型。
- 结构更新导致旧任务明显遗忘且门控无效：改为离线更新或不可变知识版本。
- 在匹配预算下整体质量/成本 Pareto 被简单基线支配：不继续宣称新架构优势。

## 10. 当前结论

CPG-EI 可以成为**非 Transformer 中心的认知与结构学习系统**，但目前更准确的定位是“符号/程序学习 + 稀疏关系组合 + 主动辨识 + 证据治理”的研究框架。要成为完整 AI，还必须增加可学习的感知表征、跨任务可复用的连续/离散记忆、可验证的结构生成和语言/动作接口。

近期最正确的工程顺序是：先完成 E12-Loop 的小型闭环，再逐步接入神经表征；不是立即训练一个大模型，也不是把所有功能改写成 Transformer。
