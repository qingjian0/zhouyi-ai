# 古典类象四层解释防混淆门禁 v0.1

## 研究结论

古典类象解释至少包含四个先后相依、但不可相互替代的层次：

1. **词项（lexeme）**：此处字词的义项是否确定？是否有通假、异体、多义或断句争议？
2. **名物/指称（referent）**：该词在此处指向什么对象、制度、事件或抽象实体？
3. **类别（category）**：对象凭何归类？分类依据是形、质、用、位、时、结构还是约定？
4. **谓词与推论（predicate/inference）**：文本究竟断言了什么属性、功能、结构、因果、象征、规范或修辞关系？

这四层不能压缩为一个 embedding 相似度或一个“类象”标签。词义相近不等于所指相同；所指相同不等于分类依据相同；同属一类不等于任意谓词可继承；共享属性更不等于因果机制相同。

## 原典研究入口与可证伪问题

### 《公孙龙子·白马论》

“白马”问题应拆成颜色词、形类词、复合名词及指称条件。它不是现代生物学意义上“白马是否属于马科”的简单分类题，而是名、实、属性限定和指称范围的论辩。传世文本又带有宋注及后世校本层，引用时须把正文、注释、校语分开。传世篇章和宋注信息可用于定位，不替代影印核验。数字入口：https://zh.wikisource.org/zh-hans/公孫龍子/1

### 《吕氏春秋·别类》《淮南子·说山训》

这两类材料提示“相类”与“可推”之间存在断层：局部特征相似，不能直接保证整体类别、功能、组合结果或行动效果也相同。尤其需要记录主体、目的、材料、尺度、顺序、环境和延迟结果。李秋红对《吕氏春秋》“邻类”“类固不必”的解释应作为现代竞争解释，而不是回填为原典唯一含义。

### 《论衡·感类》

王充对感应叙事的批评可作为“文本提出因果解释”与“经验上识别因果”之间的边界案例。数字文本可定位“感类”篇及其不同版本入口；文本本身仍需逐段结合上下文和版本复核。不得把王充的解释自动升级为现代自然科学结论。

## 工程数据契约

新增原型 yixiang_interpretation_firewall.py，将解释记录拆为词项、指称、类别、谓词四层，并显式记录原典定位、解释记录、证据层级、上下文条件、竞争读法、独立见证、谓词类型和因果主张状态。

门禁采取三态：

- **SCOPE_RECORDED**：四层均已明确，原典引用和上下文齐备；仅代表记录达到最低完整性。
- **ABSTAIN**：词义/指称/类别未决、上下文缺失、竞争读法待裁决、解释层级混淆或模型输出冒充证据。
- **REFUSE**：已知词项歧义却强行固定指称，属于层级冲突，拒绝自动迁移。

任何状态均不代表古籍解释已被最终证实。因果谓词不能由文本声称单独升级为经验因果结论。

## 与既有模块的关系

- yixiang_taxonomic_scope 负责类别层级与谓词继承。
- yixiang_lei_claims 负责古典“类”的论证用途和行动—结果账本。
- yixiang_mozi_inference 负责论辩操作，不把辩学术语当作真值担保。
- 新门禁负责更上游的词项—指称—类别—谓词解释完整性。
- M3 保留竞争解释；M8 应将词义混淆、指称错误、类别越级和因果越级分开计分。

## 验证限制

测试覆盖完整记录、词项歧义、指称未知、上下文缺失、竞争读法、模型自证、注疏层混淆、文本因果越级和重复见证。测试只验证门禁逻辑，不验证任何古籍释义的真伪。所有案例仍须遵守古籍数字来源规程，未逐字核验的转录继续标记为 candidate/unreviewed。
