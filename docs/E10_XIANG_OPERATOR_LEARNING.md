# E10：象—势—变关系算子学习架构（研究提案）

状态：设计提案；未实现、未运行实验、没有性能结论。  
基线：E09 当前研究头 `7bb22fe30fdd5414f324a859d1e077f390c439c5`。  
目标：提出一种不依赖反向传播的结构学习主路线，并把易象思想转化为可消融、可证伪的计算假设。

## 0. 核心判断

E09 目前的主要学习器在预先给定的有限变量域与合取式 DSL 中搜索规则。它能研究“给定语言内如何选规则”，但尚未解决更关键的问题：

1. 系统如何从原始经验中形成可复用的“象”（概念/角色/属性束）？
2. 系统如何发现不同对象之间真正保持的关系结构，而不是表面相似？
3. 系统如何发明、组合、拆分和迁移关系算子？
4. 系统如何发现规律的适用条件（时、位、势），并在条件改变时变通？
5. 如何证明新结构来自数据，而不是研究者把答案写进 DSL？

因此建议 E10 不再只扩大 E09 的布尔规则 DSL，而是研究一个分层的关系算子发现系统。

## 1. 新架构：象—势—变关系算子系统（Xiang-Potential-Change Operator System, XPC）

### 1.1 象层：可组合的结构化对象

一个“象”不是单个标签，也不是一个不可解释的向量，而是一个可修订的结构束：

- 核心属性：可观测属性及其类型；
- 角色槽位：对象在关系中的作用；
- 行为/变化签名：在干预或时间推进下可观察的变化；
- 关系邻域：已验证的关系及其证据；
- 来源与边界：来源域、适用条件、反例和不确定性。

对象的概念身份与其当前状态分离。系统允许两个对象共享部分结构，但不因此把它们合并为同一概念。

### 1.2 关系层：高阶关系结构

关系不是相似度分数，而是带类型、角色和约束的多元结构：

`R(x_1^{role_1},...,x_k^{role_k}\mid c)`

其中 `c` 是环境/上下文条件。关系可有方向、互斥、促进、抑制、组成、转换、时序等类型。高阶关系必须保留角色位置，不能被无序集合池化破坏。

### 1.3 势层：关系的条件有效性

“势”操作化为关系在当前环境下的可实现性与倾向，不解释为神秘力量。记录：

- 条件变量及其可观测来源；
- 关系的支持/反例分布；
- 预测收益与代价；
- 当前适用域和失效边界；
- 证据变化趋势。

同一关系可以在环境 A 成立、环境 B 失效；不允许把条件规律提升为无条件规律。

### 1.4 变层：结构变换算子

系统学习可执行的变换，而不是只记忆状态标签：

- `COMPOSE`：组合多个象/关系；
- `DECOMPOSE`：把失效的复合结构拆成子结构；
- `DUALIZE`：寻找角色/属性的互补变换；
- `INVERT`：反转关系方向或作用；
- `PERMUTE_ROLE`：角色置换并检验不变性；
- `CONDITION`：增加/删除适用条件；
- `TRANSFER`：把关系映射到新域并执行验证；
- `REVISE`：由反例局部修改算子。

这些算子是待学习候选，不是把传统术语直接当作正确答案。

## 2. 周易思想到计算机制的映射

| 易学思想 | 计算假设 | 不允许的偷换 |
|---|---|---|
| 象 / 类象 | 由属性、角色、行为签名构成的结构化概念；以关系保持映射做类比 | 向量接近就认定同类 |
| 阴阳 | 对偶、互补、约束或可逆的二元状态维度 | 所有事物都强制二分 |
| 四象 / 八卦 | 多层状态组合与局部模式编码 | 把卦名当现实标签 |
| 六爻 / 六十四卦 | 六维离散状态与组合状态空间；用于候选组织/控制 | 把 64 状态当作天然完备的知识分类 |
| 卦变 | 状态转移算子及转移条件 | 只按固定卦序查表 |
| 互体、错综、综卦 | 子结构抽取、关系重排、视角变换与角色置换 | 不经验证就认为变换后语义等价 |
| 时位 | 条件化关系与角色位置约束 | 忽略环境与角色 |
| 变通 | 反例驱动的局部结构修订 | 为迎合单个反例任意改规则 |
| 五行生克 | 带符号的促进/抑制关系网络 | 把传统生克直接当作普适因果 |

## 3. 非梯度学习机制：反例驱动的关系算子归纳

主算法建议采用以下闭环：

1. **观察归纳**：从样本形成候选对象束、角色槽位和关系片段。
2. **结构对齐**：寻找跨样本重复的关系骨架；保留变量角色与条件。
3. **算子提案**：通过反统一（anti-unification）、子结构拼接、角色置换、条件增删产生候选算子。
4. **证据分区**：每个候选独立维护支持、反例、未知和冲突证据。
5. **主动区分**：选择最能区分竞争假设的输入/干预，而不是只选择最容易答对的样本。
6. **复杂度选择**：用 MDL/描述长度、预测覆盖、反例数量、计算成本和校准拒答共同评分。
7. **局部修订**：只修改被反例定位的结构区域；修订前后保留版本与谱系。
8. **迁移验证**：在新组合、新角色、新环境和新领域上测试；不通过则隔离或撤销。

候选评分不能只优化训练准确率。初始多目标排序可采用词典序门控：
(1) 不违反硬约束；(2) 不覆盖已确认反例；(3) 达到最低支持量；(4) 最大化留出预测收益；(5) 最小化描述长度与计算成本。具体阈值必须预注册。

## 4. 核心算法模块

### A. 结构化类象映射（Relational Analogy）

给定源域结构 `G_s` 与目标域结构 `G_t`，寻找部分映射 `f`，使关键关系尽可能保持：

`R_s(x_1,...,x_k) => R_t(f(x_1),...,f(x_k))`

映射必须显式报告：
- 保持的关系；
- 未保持/冲突的关系；
- 角色映射；
- 条件差异；
- 支持证据与反例；
- 可迁移范围。

允许部分映射和拒绝映射。评价重点不是类比数量，而是有效迁移率与错误类比接受率。

### B. 关系算子合成（Operator Synthesis）

算子采用小型可执行 AST。初始原语只包含可解释的结构操作（选择、组合、角色重排、条件化、比较、状态转移）。系统通过子树替换、算子组合和反例定位产生新程序。必须区分：
- 已有原语的新组合；
- 新宏/新算子发明；
- 新变量/新概念发明。

三者是不同难度等级，不能把第一类结果宣称为开放式概念发现。

### C. 反例定位与最小修订

反例不仅让候选整体淘汰，还应尝试定位失效因素：角色、属性、上下文、时序或算子步骤。候选修订优先选择最小结构编辑，并在独立证据上复核。若无法定位，降低置信度或拒答，不进行无约束修补。

### D. 主动实验选择

从竞争假设中选择能最大化区分度的查询。可使用版本空间分裂度、预期信息增益或最小反例搜索；所有查询成本计入预算。若没有真实环境可干预，则用生成器构造反事实输入，并明确标记为合成实验。

## 5. 易象先验的独立实验臂

在完全相同的数据、算子语言、搜索预算和随机种子下比较：

- X0：无易象先验；
- X1：随机对偶/状态先验；
- X2：仅二元互补先验；
- X3：六位状态结构与转移先验；
- X4：类象关系保持先验；
- X5：错综/互体/角色变换候选；
- X6：完整可学习、可拒绝的易象先验。

传统映射只允许影响候选排序或初始化，不得进入隐藏标签、数据生成目标或评测答案。另设先验失配任务，检查系统是否能放弃无效先验。

## 6. E10 分阶段实验

### E10-A：对象束与关系骨架归纳
从带噪的属性/事件记录中恢复对象角色和重复关系。训练/测试按对象组合与模板双重隔离。基线：查表、固定特征、普通图、超图、有限 DSL。

### E10-B：类象迁移
训练域学习若干关系结构，测试域使用未见对象与表面特征重命名；只有结构保持映射可迁移。加入结构相似但关系不保持的硬负例。

### E10-C：算子发明与组合
训练只暴露基础原语及部分复合行为；测试包含未见算子组合。另设新宏发现任务，检查是否能压缩重复程序并提升预测。

### E10-D：条件变化与变通
改变环境、时序、角色或约束，使旧关系局部失效。比较冻结、全量重学、局部反例修订、条件化修订和生命周期控制。

### E10-E：易象消融
执行 X0-X6，报告跨种子差异、错误类比、拒答、计算成本与先验失配表现。

### E10-F：开放词汇桥接（后续）
允许外部解析器提出候选概念，但解析器只能提供候选，不得替关系学习器决定真值。单独测量外部模型贡献。

## 7. 必须设置的强基线

- 精确查表与最近样本；
- 固定关系/固定算子；
- E09 NG-A 至 NG-E；
- 受限 DSL 的 CEGIS/程序合成；
- 普通图与动态超图；
- 随机结构先验；
- 参数/计算预算匹配的梯度学习器；
- 混合学习器（只作为单独实验臂）。

所有方法同时报告样本预算、候选评估预算、墙钟时间、内存、结构复杂度、覆盖率、已答准确率、总体正确率和拒答质量。

## 8. 关键防泄漏与停止规则

- 数据生成器不得把目标结构编码进 ID、顺序、字段数量、模板或元数据。
- 训练/验证/测试按对象、模板、关系族和环境分层隔离。
- 预先登记候选 DSL、预算、停止条件和主要指标。
- 保留逐种子原始结果与学习前后结构快照。
- 若只在已知 DSL 内恢复规则，结论限定为 DSL 内归纳。
- 若类象先验未稳定优于随机先验/无先验，移除其性能主张。
- 若主动查询收益来自更多样本，必须与相同样本预算基线比较。
- 若新算子无法在未见组合上执行，不称为算子发现。

## 9. 与现有 E09 的关系

E10 是独立研究支线，不替换 E09，也不修改 E09 文件。E09 继续回答有限规则语言中的非梯度学习是否可行；E10 研究更上游的对象束、关系骨架、类象映射和算子归纳。后续只有在接口与证据标准一致时，才考虑合并算法组件。

建议优先顺序：
1. 先实现 E10-A 的最小结构数据模型与数据生成器；
2. 建立双重隔离与泄漏攻击；
3. 实现关系对齐和硬负例；
4. 再做算子合成；
5. 最后引入易象先验消融。

## 10. 当前结论

这是一个研究提案，不是已验证的新型智能架构。它的价值在于把“取象比类、时位、变通、互体错综”拆成可执行的结构操作与独立实验问题。是否有用必须由未见对象、未见关系组合、先验失配和公平预算实验决定。
