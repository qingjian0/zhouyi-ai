# 类象关系保持基准 v0.1

## 目的

为类象验证器建立一个可重复、可控的最小基准，覆盖关系保持与反事实拒绝，并通过模板族级拆分降低同构样本泄漏风险。

## 数据设计

`prototype/analogy_benchmark.py` 提供六类有向、带类型的符号图模板：链式、分叉、循环、层级、竞争和反馈。每个模板生成有效映射与一个关系类型被反事实篡改的无效映射。默认每个模板生成三个变体，共 36 条样本。

拆分按模板族固定：
- train：chain、fork
- validation：cycle、hierarchy
- test：competition、feedback

同一模板族的全部变体只能出现在一个拆分中。此设计测试关系保持规则的结构泛化，不等价于真实领域迁移；模板族数量有限，不能据此估计现实场景准确率。

## 指标

报告 accuracy、precision、recall、false_accept_rate 及混淆矩阵计数，并分别输出 train/validation/test。基准构造器只产生受控合成样本；没有经典文献或现实观测证据，因此不用于宣称易学理论有效。

## 基线与限制

当前唯一被评估的是现有确定性关系保持评估器。它应当识别完全保持的映射，并拒绝单关系类型被篡改的候选。后续必须加入随机映射、实体特征基线、语义相似度基线和可学习模型，并在相同数据、参数与计算预算下比较。

该基准是测试夹具与协议起点，不是训练数据规模扩张，不是学习型发现器，也不是类象认知能力已经成立的证据。
