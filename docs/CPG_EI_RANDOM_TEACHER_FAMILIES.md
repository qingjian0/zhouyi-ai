# CPG-EI random teacher-family generalization

Status: research-only; follows the state-disjoint evaluation in PR #407.

## Motivation

PR #407 validates state-disjoint generalization on a finite six-bit parity
truth table, but all five seeds use the same three planted triples. Those seeds
are different state partitions, not independent teacher structures.

This benchmark samples ten distinct teacher families. Each teacher chooses
three distinct triple relations from the 20 possible three-line combinations.
The six output heads are paired, with each pair generated by one selected
parity triple.

## Protocol

- Generate three distinct teacher triples from a deterministic family seed.
- Enumerate all 64 six-bit states and partition them into 32 train, 16 dev,
  and 16 locked-test states.
- Assert zero overlap and complete state-space coverage.
- Rank conditional motifs using training states only.
- Carry forward the fixed SGD configuration from PR #407 (learning rate 4.2,
  600 epochs); development metrics are diagnostic and do not retune it.
- Refit on train + development states and evaluate locked states.
- Report support precision/recall, exact support recovery, bit accuracy,
  exact-state accuracy, and finite-loss status for every family.

## Claim boundary

This is a broader but still finite six-line GF(2) family. It tests whether
conditional motif proposals recover varied planted triples, not open-world
relation discovery, arbitrary arity, natural-language reasoning, or superiority
to Transformer models.
