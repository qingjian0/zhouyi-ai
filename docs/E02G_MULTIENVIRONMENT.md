# E02-G：多环境关系稳定性、条件性与漂移

## 研究问题

系统发现候选关系后，能否在不读取真实关系标签的情况下，区分：
- stable：同一关系在多个环境中保持相同方向；
- conditional：关系只在部分环境中成立；
- drift：关系在多个环境中都成立，但方向发生反转；
- unresolved：证据不足，不强行分类。

## 协议

- 两个环境，8 个二值特征，隐藏三阶乘积关系。
- 训练集每个环境独立生成，候选搜索仅看训练数据。
- 候选空间为 2–4 阶交互；按跨环境最大绝对相关度选择候选，以免把条件关系或方向反转因简单池化而抵消。
- 每个环境使用 5 份独立 gate split；每份 256 个样本。
- 每个环境的方向只由该环境训练数据估计；gate 不参与拟合。
- 对重复 gate 的预测正确数计算 95% Wilson 区间。
- 区间下界高于 0.75 判为 active；区间上界低于 0.75 判为 inactive。
- 两环境 active 且方向相同为 stable；仅一环境 active 为 conditional；两环境 active 但方向相反为 drift；其余为 unresolved。
- 真实目标成员和 regime 仅用于最终审计，不能进入候选发现或分类。

## 必须报告

每种 regime 的逐 seed 分类、目标成员恢复率、分类准确率、分类混淆计数、每个环境的重复 gate 准确率和 Wilson 区间。

## 证伪标准

- stable / conditional / drift 任一类别频繁互相误判，说明系统无法可靠区分关系的存在性与方向。
- candidate recovery 高但分类低，说明“找对成员”不等于“理解关系状态”。
- unresolved 比例高，说明当前样本量或门槛不足，不能用强行分类掩盖不确定性。

## 局限

这是两个环境、三种预定义状态、二值乘法交互的合成实验，不是一般环境迁移或因果发现。Wilson 区间只描述二项准确率的不确定性，不解决搜索过程的全局多重比较和后选择推断。未来需要更多环境、连续漂移、关系成员变化和预注册的独立确认集。
