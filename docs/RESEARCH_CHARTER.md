# CPG-EI 研究总纲

## 1. 研究目标

CPG-EI（Combinatorial Parallel Generation & Epistemic Intelligence，组合并行生成与易象启发式认知架构）研究一种以动态语义结构为核心的计算范式。系统从输入中抽取概念、属性、事件和证据单元，在动态高阶关系结构上生成有限候选组合，再通过并行推演、全局协调和证据校验形成输出。

目标不是简单替换 Transformer 的序列生成，而是研究：**内部认知计算能否由动态结构化组合驱动，语言生成仅作为表达接口之一。**

## 2. 核心假设

- H1（跨距离组合）：基于内容和任务价值选择节点的组合机制，在跨距离关系任务上可能优于仅依赖局部邻接的基线。
- H2（高阶结构）：动态超图能够表达普通边图难以直接表达的多元关系，并改善高阶关系推理。
- H3（并行候选推演）：多个候选组合并行评估，加上全局证据协调，可能改善多解问题的覆盖率与鲁棒性。
- H4（易象先验）：将阴阳互补、状态转化、关系制约等抽象成可学习的结构先验，在部分结构迁移任务上可能提供增益；也可能没有增益，必须通过消融判断。
- H5（自组织结构）：基于预测误差、证据质量和任务反馈的结构创建/合并/拆分/淘汰机制，可能提高分布变化下的适应性。
- H6（预算有效性）：稀疏候选生成和计算预算控制可以限制组合爆炸，使收益不完全被搜索成本抵消。

## 3. 研究范围

### 纳入
- 动态语义单元与事件表示
- 超图/超边的创建、打分、更新与剪枝
- 跨位置组合与组合泛化
- 多路径并行推演与全局冲突检测
- 易象启发式状态编码及其可证伪性
- 自组织结构学习、记忆与证据追踪
- 与 AR Transformer、扩散/NAR、图网络和超图网络的对照

### 暂不纳入
- 一开始训练大规模基础模型
- 将传统卦辞直接当作神经网络标签而不做语义验证
- 将类比关系直接当作因果规律
- 未经测试宣称具备通用智能或超越现有大模型

## 4. 研究方法

1. 先建立小型合成任务，隔离组合机制本身。
2. 实现透明、可解释的非神经基线，验证数学与数据管线。
3. 引入可学习的组合打分器与消息传递模块。
4. 逐项引入易象模块和自组织机制，做消融。
5. 在公开基准与真实任务上扩展，报告质量、延迟、内存、FLOPs 和失败案例。
6. 所有结果绑定代码 commit、数据版本、随机种子、硬件与配置。

## 5. 成功标准

不能只以流畅度或单一准确率判断。至少同时考察：
- 组合泛化与跨距离关系识别；
- 高阶关系推理；
- 类比迁移及错误类比拒绝；
- 证据一致性和冲突识别；
- 计算成本、延迟、峰值内存；
- 分布变化后的稳定性；
- 可复现性与消融结果。

## 6. 研究纪律

所有内容标记为事实、假设、设计或实验结果。未执行的实验不得标成结果；没有数据的性能主张不得写成结论。若某模块在预注册指标上没有稳定增益，应允许移除该模块。
