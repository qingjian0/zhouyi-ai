# Zhouyi-AI 类象认知研究总纲

## 1. 研究目标

Zhouyi-AI 的第一研究目标是构建领域无关、证据约束、可学习、可拒绝、可修正的类象认知引擎：从对象、事件和环境观测中抽取任务相关之象，形成类别假设，辨析边界，建立关系保持的跨域映射，执行有范围的推类迁移，并根据新证据持续修正。

CPG-EI（Combinatorial Parallel Generation & Epistemic Intelligence）、SROK、动态超图和并行候选生成属于可替换的计算支撑路线；易象/周易属于可插拔领域知识源与结构先验。它们的价值必须由类象发现、立类、映射、迁移和修正任务上的独立实验决定。

研究目标不是简单替换 Transformer，也不以语言流畅度作为类象能力。语言模型可以作为输入解析或表达接口，但其能力贡献必须与类象机制分开测量。

## 2. 计算支撑假设（服务于类象主线）

- H1（跨距离组合）：基于内容和任务价值选择节点的组合机制，在跨距离关系任务上可能优于仅依赖局部邻接的基线。
- H2（高阶结构）：动态超图能够表达普通边图难以直接表达的多元关系，并改善高阶关系推理。
- H3（并行候选推演）：多个候选组合并行评估，加上全局证据协调，可能改善多解问题的覆盖率与鲁棒性。
- H4（易象先验）：将阴阳互补、状态转化、关系制约等抽象成可学习的结构先验，在部分结构迁移任务上可能提供增益；也可能没有增益，必须通过消融判断。
- H5（自组织结构）：基于预测误差、证据质量和任务反馈的结构创建/合并/拆分/淘汰机制，可能提高分布变化下的适应性。
- H6（预算有效性）：稀疏候选生成和计算预算控制可以限制组合爆炸，使收益不完全被搜索成本抵消。

## 3. 研究范围

### 纳入
- 观象、任务条件取象、类别形成、类别边界与开放集拒绝
- 跨对象/跨领域比类、关系保持映射、推类迁移、证据验证与反例修订
- 动态语义单元与事件表示
- 超图/超边的创建、打分、更新与剪枝
- 跨位置组合与组合泛化
- 多路径并行推演与全局冲突检测
- 易象启发式状态编码及其可证伪性
- 自组织结构学习、记忆与证据追踪
- 与 AR Transformer、扩散/NAR、图网络和超图网络的对照

### 暂不纳入
- 一开始训练大规模基础模型
- 将传统卦辞直接当作神经网络标签而不做语义验证
- 将类比关系直接当作因果规律
- 未经测试宣称具备通用智能或超越现有大模型

## 4. 研究方法

1. 先定义类象任务、正负例边界、开放集状态和关系迁移验收协议。
2. 建立透明、可解释、证据可追溯的符号基线。
3. 引入可学习的特征选择、类别形成和映射提议器。
4. 将动态超图、CPG-EI/SROK、并行推演和易象先验作为独立后端逐项接入并消融。
5. 在公开基准与真实多域任务上验证，报告类象质量、迁移收益、拒绝质量、延迟、内存、FLOPs 和失败案例。
6. 所有结果绑定代码 commit、数据版本、随机种子、硬件与配置。

## 5. 成功标准

不能只以流畅度或单一准确率判断。至少同时考察：
- 类别形成、成员/非成员边界与开放集识别；
- 结构保持映射、跨域类象迁移及错误类象拒绝；
- 组合泛化与高阶关系推理；
- 证据一致性和冲突识别；
- 计算成本、延迟、峰值内存；
- 分布变化后的稳定性；
- 可复现性与消融结果。

## 6. 研究纪律

所有内容标记为事实、假设、设计或实验结果。未执行的实验不得标成结果；没有数据的性能主张不得写成结论。若某模块在预注册指标上没有稳定增益，应允许移除该模块。
